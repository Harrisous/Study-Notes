# 第 0 课 §9 · 怎么读这门课 · 分镜

第 0 课十集里的第九集。内容全部来自第 0 课 §9：推荐顺序与分钟数、两条跳读路线、数学补课对照表、图色语义、八个类比、"这门课是怎么做出来的"、批注的写法。这些都已在 `reference-docs/lesson-00-doc.md` 里核对过。

两处是从课文的表或配色里直接读出来的：
- 03 段的矩阵：由对照表逐格读出（每格的数字是正文链接到的小节数）。
- 04 段的色块：取课程配图主题变量（--fig-*）在深色主题下的取值，与课文网页一致。

## 开场

镜头路线与前几集相同。第 1 句让第 1–19 课一起亮起。进入树以后不推近，因为这一页讲的是整门课的读法，不属于哪一条主线。i4 时主线 A 和主线 D 两条色带亮起，就是本集要讲的两条跳读路线。
