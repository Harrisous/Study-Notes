# 第 0 课 §11 · 练习与答案 · 分镜

第 0 课的第十一页，也是这一课的最后一集。题目和答案全部来自第 0 课的练习页。每个数字都按练习页的算式复算过，与研究笔记 `reference-docs/lesson-00-doc.md` 一致。

## 形式

每道题一段，节奏固定：
1. 题目卡出现，第一句口播读题；
2. 口播停 2.5 秒，画面中央转一圈"想一想"；
3. 答案卡按口播的标记一张张亮起，每张一句话，配一道算式。

练习 7 在右侧加一张小图：三个点画在对数纵轴上，斜率越陡，缩得越快。

## 开场

镜头路线与前几集相同。第 1 句点亮第 0 课。三组题各钉在它们练习的地方：
- 概念题钉在时间轴上（认日期）；
- 计算题钉在主线 A 上（复算 KV）；
- 推导题钉在主线 C 上（UE8M0）。
