GPT 做的事情，说白了就是这个候选栏：读进前 \(t\) 个 token，给出第 \(t+1\) 个 token 在整个词表上的概率分布。只不过它的候选栏有 50,257 格，每一格都要标上一个概率。这 50,257 个数是怎么算出来的？难就难在中间那一步。今天这一课，我们就把这一次计算从头到尾拆开。

讲完这一课，下面这些问题大家都能自己回答，而且能把答案写成公式、算出数字：

接下半句话：GPT 要算什么

好，我们正式上课。我先念半句英文，大家在心里把它接下去：“The cat sat on the ……”

接的是什么？mat？floor？sofa？我猜大家脑子里冒出来的不止一个词，而且每个词的把握不一样：mat 大概最有把握，floor、sofa 也说得过去，“quantum”几乎不可能。

那么问题来了：能不能把这种“心里的把握”写成一组数？GPT 做的正是这件事。这一页先把任务说清楚，再给出整张地图：一张画出每条边上张量形状的结构图，和一组把整次前向传播写完的方程。后面每一页都只是把地图上的一个方框放大。读到后面任何地方迷路了，都可以回到这一页的图 1.1 和方程组。

问题：从一段前缀到下一个词的分布

我们先在黑板上把世界缩小。

黑板上 · 一个只有 5 个词的世界

假设词表里只有 5 个词：the、cat、sat、on、mat。模型读完一段前缀，要交出 5 个数，每个词一个，表示“下一个词是它”的把握。比如：

候选词 概率
the 0.090
cat 0.106
sat 0.557
on 0.129
mat 0.117

这 5 个数守两条规矩：没有负数；加起来等于 1（表里是四舍五入到三位小数的值，相加得 0.999；精确值相加正好是 1）。它们也不是我随手编的：§7 会用一个玩具输出层把它们一个一个算出来。

好，现在把 5 换成 \(V\)。含义。 语言模型（language model）是一个函数：输入一段 token 序列的前 \(t\) 个，\(x_1,\dots,x_t\)，输出一个长度为 \(V\) 的概率向量，第 \(v\) 个分量是“下一个 token 恰好是 \(v\)”的概率。写成

\[p_\theta(x_{t+1}=v\mid x_1,\dots,x_t),\qquad v=0,1,\dots,V-1,\]

其中 \(\theta\) 代表模型的全部参数。GPT-2 small 的 \(V=50{,}257\)，所以每一步的输出是 50,257 个非负数，加起来等于 1。黑板上那张表，就是 \(V=5\) 的版本。

理解。 就是开头那个接半句话的游戏：每读完一个词就猜下一个词，不只猜一个，而是给每个候选词都报一个把握。“The cat sat on the” 之后，“mat”“floor”“sofa”都该有不小的把握，“quantum”则几乎为零。GPT 做的就是这件事，只是它要为 50,257 个候选词同时报数。

这个函数要满足四个要求。大家记住这四条，后面每一条都会逼出一个具体的设计：

  1. 任意长度。 前缀可以是 1 个 token，也可以是 1024 个。同一组参数必须能处理任何长度。
  2. 按内容取用前文。 预测“The cat that the dog chased sat”里的 sat 时，要用到隔了四个词的 cat。该回头看哪个词，取决于词的内容，不取决于固定的距离。
  3. 不许偷看未来。 预测 \(x_{t+1}\) 时只能用 \(x_1,\dots,x_t\)。
  4. 训练能并行。 一段 1024 个 token 的训练文本，最好一次前向传播就同时给出全部 1024 个位置的预测，而不是一个一个算。

循环神经网络（RNN）满足前三条，第 4 条却不行：它必须读完第 \(t\) 个 token 才能处理第 \(t+1\) 个。《Attention Is All You Need》的表 1 把这个差别量化了：一层自注意力需要的“顺序步骤数”是 \(O(1)\)，一层循环层是 \(O(n)\)（\(n\) 是序列长度）；代价是自注意力每层的计算量是 \(O(n^2\cdot d)\)，而循环层是 \(O(n\cdot d^2)\) 3。GPT 选择了前者。这笔 \(n^2\) 的账，会在第 4 课和第 14 课回来找我们。

一句话答案

GPT 的回答，压缩成一句话就是：先查表把每个 token 变成一个向量，然后让这些向量流过 \(L\) 个结构相同的块，每块里先让 token 之间交换信息（注意力，只许看过去），再让每个 token 自己加工（前馈网络），每次都把结果“加回”一条贯穿全程的向量流（残差流）；最后把每个位置的向量变回词表上的概率。

后面的每一页都是这句话里的一个短语：查表与位置在 §2，注意力在 §3、§4，前馈网络在 §5，残差流与 LayerNorm 在 §6，变回概率在 §7，最后在 §8 把参数和运算次数一笔一笔算清。

从 Transformer 到 GPT

这张图不是凭空来的。2017 年的 Transformer 是为机器翻译设计的编码器–解码器（encoder–decoder）结构：编码器读源语言句子，解码器一边读已经译出的目标语言前缀，一边通过交叉注意力（cross-attention）查看编码器的输出，逐词生成译文 3。解码器的自注意力带着因果掩码，本身就是一个“只看过去、预测下一个”的语言模型。

GPT-1（2018）做了减法：删掉编码器，也就删掉了交叉注意力，只留下带掩码自注意力的解码器，堆 12 层，报告的原话是“12-layer decoder-only transformer with masked self-attention heads” 5。它同时把正弦位置编码换成了可学习的位置表、把 ReLU 换成了 GELU；输出层则沿用原 Transformer 的权重共享，直接乘以输入嵌入矩阵的转置 5,3。GPT-2（2019）在此基础上把 LayerNorm 移到每个子层的输入处，并在最后一块之后再加一个 LayerNorm 1,4。图 1.2 把这三步画在一起。

GPT 前向传播方程组（GPT-2 式，Pre-LN）

输入：token 编号 \(x_1,\dots,x_T\in\{0,\dots,V-1\}\)。输出：每个位置的下一词分布。

\[\begin{aligned} &\text{(1.1)}&\mathbf h^{(0)}_t&=E^\top\mathbf e_{x_t}+P^\top\mathbf e_{t}\\[4pt] &&&\text{对每一块 } l=1,\dots,L\text{（每块一套独立参数）：}\\[4pt] &\text{(1.2)}&\bar{\mathbf h}_t&=\LayerNorm_1^{(l)}\big(\mathbf h^{(l-1)}_t\big)\\ &\text{(1.3)}&\mathbf q_{t,i}&=W^Q_i\bar{\mathbf h}_t+\mathbf b^Q_i\quad(\mathbf k_{t,i},\ \mathbf v_{t,i}\text{ 同理，换成 }K,V)\\ &\text{(1.4)}&\alpha_{t,j,i}&=\frac{\exp\!\big(\mathbf q_{t,i}^\top\mathbf k_{j,i}/\sqrt{d_h}\big)}{\sum_{s=1}^{t}\exp\!\big(\mathbf q_{t,i}^\top\mathbf k_{s,i}/\sqrt{d_h}\big)}\ \ (j\le t),\qquad\alpha_{t,j,i}=0\ \ (j>t)\\ &\text{(1.5)}&\mathbf o_{t,i}&=\sum_{j=1}^{t}\alpha_{t,j,i}\,\mathbf v_{j,i}\\ &\text{(1.6)}&\mathbf u_t&=W^O\big[\mathbf o_{t,1};\mathbf o_{t,2};\dots;\mathbf o_{t,n_h}\big]+\mathbf b^O\\ &\text{(1.7)}&\mathbf h'_t&=\mathbf h^{(l-1)}_t+\mathbf u_t\\ &\text{(1.8)}&\mathbf m_t&=W_2\,\mathrm{GELU}\big(W_1\LayerNorm_2^{(l)}(\mathbf h'_t)+\mathbf b_1\big)+\mathbf b_2\\ &\text{(1.9)}&\mathbf h^{(l)}_t&=\mathbf h'_t+\mathbf m_t\\[4pt] &&&\text{最后：}\\[4pt] &\text{(1.10)}&\mathbf z_t&=E\,\LayerNorm_f\big(\mathbf h^{(L)}_t\big)\\ &\text{(1.11)}&p_\theta(x_{t+1}=v\mid x_{\le t})&=\softmax(\mathbf z_t)_v=\frac{e^{z_{t,v}}}{\sum_{w=0}^{V-1}e^{z_{t,w}}} \end{aligned}\]

其中用到的两个逐位置函数（对一个 \(d\) 维向量或逐个元素作用）：

\[\begin{aligned} &\text{(1.12)}&\LayerNorm(\mathbf x)&=\boldsymbol\gamma\odot\frac{\mathbf x-\mu\mathbf 1}{\sqrt{\sigma^2+\epsilon}}+\boldsymbol\beta,\qquad \epsilon=10^{-5},\\ &&\mu&=\frac1d\sum_{k=1}^{d}x_k,\qquad \sigma^2=\frac1d\sum_{k=1}^{d}(x_k-\mu)^2\\[4pt] &\text{(1.13)}&\mathrm{GELU}(x)&=x\,\Phi(x)=\frac x2\Big[1+\mathrm{erf}\big(x/\sqrt2\big)\Big]\\ &&&\approx\frac x2\Big[1+\tanh\Big(\sqrt{2/\pi}\,\big(x+0.044715\,x^3\big)\Big)\Big] \end{aligned}\]

三类运算

把方程组按“谁和谁发生关系”分一下类。别小看这个分类，本课后面几乎所有结论都从它里面来：

  1. 查表：(1.1)。不做乘加，只按编号取行。
  2. 逐位置运算：(1.2)(1.3)(1.6)(1.7)(1.8)(1.9)(1.10)(1.11)。对 \(T\) 个位置各做一遍同样的计算，位置之间互不相干。这类运算的参数占了模型的绝大部分，运算量与 \(T\) 成正比。
  3. 跨位置运算：只有 (1.4) 和 (1.5)。位置 \(t\) 在这里读取位置 \(j\le t\) 的键和值。它没有任何参数，运算量却与 \(T^2\) 成正比。

这个分类马上给出三个推论。第一，因为跨位置的只有注意力，“不偷看未来”只需要在 (1.4) 一处设防（§4）。第二，因为逐位置运算对每个 token 都一样，参数量与 \(T\) 无关，而每个 token 的运算量约等于“每个参数做一次乘加”，这就是 \(2N\)（§8）。第三，生成新 token 时，旧 token 的逐位置结果不会变，只有注意力需要回头读旧 token 的键和值，这就是第 4 课 KV cache 的出发点。

这一页讲了三件事
  • 第一，GPT 要算的是一个分布。 它是一个函数 \(x_{\le t}\mapsto p_\theta(x_{t+1}\mid x_{\le t})\)：黑板上 5 个词的世界里是 5 个加起来为 1 的数，GPT-2 small 里是 50,257 个。一次前向传播对序列里每个位置同时给出这样一个分布（“The unbelievable tokenization”是 4 个）。
  • 第二，结构是一张图、一组方程。 嵌入 → \(L\) 个相同的块（注意力 + FFN，各自读一份残差流、再把结果加回去）→ 最终 LayerNorm → 乘 \(E^\top\) → softmax；GPT-2 small：\(L=12\)、\(d=768\)、\(n_h=12\)、\(d_{ff}=3072\)、\(V=50{,}257\)。方程组 (1.1)–(1.13) 是全课的参考卡。
  • 第三，只有注意力跨位置。 只有 (1.4)(1.5) 让位置之间发生关系，其余都是逐位置运算或查表。这一条管着“不偷看未来”（§4）、“每个 token 约 \(2N\) 次运算”（§8）和 KV cache（第 4 课）。

从文字到向量：分词、嵌入与位置

用过大模型的人，大概都见过这样的说法：“上下文最长多少多少个 token”“按 token 计费”。token 到底是什么？一个字？一个词？

大家先别急着回答。网络只会对数做乘法和加法，而我们交给它的是文字；这一页要走完方程 (1.1) 之前和之中的三步：把文字切成 token 并编号（分词），把编号变成向量（词嵌入），再告诉模型每个 token 排在第几（位置）。三步里只有后两步属于网络本身；分词在网络之外完成，训练时也不会改变。我们先上黑板，真的切一次。

黑板上 · 把两段话交给 GPT-2 的分词器

第一段是英文 The cat sat，11 个字符（算上两个空格）。第二段是中文“大模型”，3 个字。大家猜一猜：GPT-2 的分词器各切出几个 token？

英文那段是 3 个：The、Ġcat、Ġsat，编号 464、3797、3332。一个 token 差不多就是一个词。

中文那段呢？3 个？还是更少？答案是 7 个。“大”是 1 个 token，“模”和“型”却各被切成了 3 个。

一个字怎么会被切成三块？因为 GPT-2 的分词器看到的不是字，而是字节。一个常用汉字在 UTF-8 编码里占 3 个字节：

字 UTF-8 字节 切成几个 token 编号
大 E5 A4 A7 1 个（三个字节已经合成一块） 32014
模 E6 A8 A1 3 个（每个字节单独一块） 162、101、94
型 E5 9E 8B 3 个 161、252、233

这两组结果是把 GPT-2 官方分词代码的逻辑，跑在 Hugging Face 上的 GPT-2 词表与合并表文件上得到的 4,2。

所以 token 既不是“字”也不是“词”。它是分词器从一张合并表里拼出来的一个片段。这张表是怎么来的？“大”为什么有资格合成一块，“模”却没有？下面就讲。

分词：BPE 把文字切成常见的片段

问题。 词表该用什么单位？用单个字符，词表很小，但一句话会变成很长的序列，而 §1 说过注意力的代价随长度的平方增长；用整词，序列短了，可词表会大到装不下，而且训练时没见过的词（比如一个新造的专有名词）根本无法表示。需要一个中间方案：常见的词整个保留，罕见的词拆成常见的片段。

含义。 字节对编码（byte pair encoding，BPE）是一种自动找出这些“常见片段”的算法：从单个字符出发，反复把语料里出现次数最多的相邻一对粘成一个新符号，粘多少次由人事先定好 7。

理解。 它很像一个人记笔记时逐渐发明缩写：先注意到“e”后面最常跟“s”，于是把“es”当成一个符号；接着发现“es”后面常跟“t”，于是有了“est”……常见的词最后会被粘成一个整体，罕见的词则停留在几个片段的组合上。

数学。 Sennrich 等人把它写成一个很短的算法：符号表初始化为全部字符，每个词末尾加一个词尾符号 </w>；每一轮统计所有相邻符号对 \((A,B)\) 的出现次数（每个词里出现的次数乘以这个词的频数，再对所有词求和），把次数最多的那一对在所有词里替换成新符号 \(AB\)。最终的符号表大小 = 初始字符数 + 合并次数，合并次数是这个算法唯一的超参数 7。

小故事 · “编码”两个字从哪来

BPE 名字里的“编码”，来自它的老本行：它本来是一种数据压缩的办法。Sennrich 等人为了让神经机器翻译能处理罕见词，把它改造成了切分子词的算法，论文 2016 年发表在 ACL 上 7。

好，我们在黑板上亲手合并三次。

黑板上 · 手算前三次合并

Sennrich 论文算法 1 的玩具语料是四个词及其频数：low 出现 5 次、lower 2 次、newest 6 次、widest 3 次 7。先把它们拆成字符：l o w </w>、l o w e r </w>、n e w e s t </w>、w i d e s t </w>。

第 1 轮，数几对候选：\((e,s)\) 出现在 newest 和 widest 里，\(6+3=9\) 次；\((s,t)\)、\((t,\texttt{</w>})\) 同样是 9 次；\((w,e)\) 出现在 lower 和 newest 里，\(2+6=8\) 次；\((l,o)\) 是 \(5+2=7\) 次。最多的是 9 次，有三对打平，算法取最先遇到的 \((e,s)\)，于是 newest 变成 n e w es t </w>。

第 2 轮：\((es,t)\) 9 次，合并成 est。第 3 轮：\((est,\texttt{</w>})\) 9 次，合并成 est</w>。三次之后，newest 已经是 n e w est</w>，widest 是 w i d est</w>：两个词共享了一个表示“最高级词尾”的片段。继续做下去，第 4、5 轮会合出 lo、low，一直到第 10 轮的全部轨迹画在图 1.3 (a)。

现在回答黑板上那个“大模型”。GPT-2 用的是 BPE 的字节级（byte-level）变体：初始符号不是字符，而是 256 个可能的字节值，所以任何文字（任何语言、表情符号、乱码）都能表示成字节序列，永远不会遇到“词表外”的输入 1。它的词表有 50,257 项，来历是

\[50{,}257=\underbrace{256}_{\text{单字节}}+\underbrace{50{,}000}_{\text{合并次数}}+\underbrace{1}_{\texttt{<|endoftext|>}},\]

最后那一个是标记文档结尾的特殊 token，编号 50256 2。合并表里有两条规则恰好把“大”的三个字节 E5、A4、A7 先粘成两块、再粘成一块，所以“大”是一个 token；“模”“型”的字节之间没有能用的合并规则，只好一个字节一个 token。哪些字节对能被粘起来，取决于它们在构造合并表的语料里出现得多不多：这就是“按频率合并”的意思。

为了让字节能打印出来，GPT-2 把每个字节映射成一个可见字符，空格字节 0x20 被映射成 Ġ，所以词表里的 Ġworld 表示“空格 + world” 4。下表是几个真实的切分结果（用官方分词代码与 Hugging Face 上的词表文件复现）：

很多人以为：一个 token 就是一个字，或者一个词

很多人以为：token 就是“字”（中文）或“词”（英文）的另一个叫法。

其实：token 是合并表拼出来的片段，和字、词都不必对齐。Ġunbelievable 是“空格 + 一整个词”，“tokenization”是两个 token，“大模型”是 7 个。更极端的是“你好”：GPT-2 把它切成 4 个 token，按字节分组是 E4 BD | A0 | E5 A5 | BD，编号 19526、254、25001、121。“你”的三个字节 E4 BD A0 被切在了两个 token 里，token 的边界落在了一个汉字的中间。

分词器不是网络的一部分

分词规则在训练前就定死了，梯度下降不会改变它。网络只看到一串整数，它对 24479 的全部“理解”都存在嵌入表的第 24479 行里；切分方式的缺陷（词被切碎、数字被切成奇怪的片段）只能靠后面的层去弥补。

嵌入：一次查表

问题。 编号 24479 只是一个标签。它不比 11241 “大”，也不和 24478 “相近”。如果把编号本身当成一个数喂给网络，网络会被迫学习一个毫无意义的大小关系。我们需要的是：每个 token 对应一个向量，意思相近的 token，向量也可以相近。

含义。 词嵌入（token embedding）就是一张表 \(E\in\R^{V\times d}\)：每个 token 占一行，每行 \(d\) 个可学习的数。用的时候按编号取出那一行。

理解。 可以把它想成一本有 50,257 页的档案册，每页记着一个 token 的 768 项“特征”。这些特征没有人为指定的名字，它们是训练出来的：训练结束时，经常出现在相似上下文里的 token，它们的档案往往也相似。

“按编号取一行”听上去不像数学。能不能把它写成矩阵乘法，好放进方程里？我们先在黑板上试一个 5 行的小表。

黑板上 · 从 5 行的表里取出 cat 那一行

还是 5 个词的世界，\(d=3\)。嵌入表 \(E\) 是 \(5\times3\)，每行一个词：the \((0.2,-0.1,0.4)\)，cat \((0.9,0.3,-0.2)\)，sat \((-0.3,0.8,0.1)\)，on \((0.1,0,0.6)\)，mat \((0.7,0.4,-0.5)\)。

cat 是第 2 个词，写成一个独热向量 \((0,1,0,0,0)\)：只有 cat 那一格是 1。拿它去乘 \(E\)，一列一列地算：

  • 第 1 列：\(0.2\times0+0.9\times1+(-0.3)\times0+0.1\times0+0.7\times0=0.9\)；
  • 第 2 列：同样只剩 cat 那一项，\(0.3\)；
  • 第 3 列：\(-0.2\)。

结果是 \((0.9,\ 0.3,\ -0.2)\)，正好是 cat 那一行。15 次乘法里，有 12 次乘的是 0，白算。

好，把 5 换成 \(V\)。数学。 为了把“查表”写进方程，引入独热向量（one-hot vector）\(\mathbf e_v\in\R^{V}\)：第 \(v\) 个分量是 1，其余都是 0。于是

独热向量乘矩阵 = 取出一行
(1)\(\displaystyle (E^\top\mathbf e_v)_k=\sum_{w=0}^{V-1}(E^\top)_{kw}\,(\mathbf e_v)_w\)矩阵乘向量的定义（M01 §2）
(2)\(\displaystyle =\sum_{w=0}^{V-1}E_{wk}\,(\mathbf e_v)_w\)转置：\((E^\top)_{kw}=E_{wk}\)
(3)\(\displaystyle =E_{vk}\)\(\mathbf e_v\) 只有第 \(v\) 个分量是 1，求和里只剩 \(w=v\) 这一项
嵌入 = 独热向量乘嵌入表\[E^\top\mathbf e_v=\big(E_{v1},E_{v2},\dots,E_{vd}\big)^\top=E\text{ 的第 }v\text{ 行（竖起来）}\]数学上它是一个没有偏置的线性层，输入恰好是独热向量；实现上它是按下标取行，不做任何乘法。(1.14)

代回黑板：\(v=\text{cat}\)，(1.14) 说结果是 \(E\) 的 cat 那一行，\((0.9,0.3,-0.2)\)；我们一列一列乘出来的也是它。对，一模一样。图 1.4 (a) 把这次乘法画了出来。

黑板上白算了 12 次乘法。换成真模型，白算多少？

查表省下了多少运算

如果老老实实做独热向量乘矩阵，\([1,V]\times[V,d]\) 要 \(2Vd\) 次运算（M01 §5 的 \(2mnk\) 规则）。GPT-2 small：\(2\times50{,}257\times768=77{,}194{,}752\)，每个 token 约 \(7.7\times10^7\) 次，其中 \(50{,}256\) 行乘的都是 0。查表把这些全部省掉，只剩一次内存读取：768 个数。

这一数字并没有消失：§7 的输出层要把最终向量与所有 50,257 行做点积，那里的 \(2Vd\) 次运算一次也省不了。

嵌入表的梯度是稀疏的。 由 (1.14)，\(\mathbf h=E^\top\mathbf e_v\) 的第 \(k\) 个分量就是 \(E_{vk}\)，所以经输入端流到 \(E\) 的梯度只落在第 \(v\) 行：从输入这一侧看，一次训练只更新本批数据里出现过的那些行，极少出现的 token 几乎得不到训练（训练过程是第 2 课的内容）。GPT-2 的输出层还会再用一次同一个 \(E\)，那一侧的梯度是稠密的，§7 会回到这一点。

GPT-2 的代码把 wte 初始化为标准差 0.02 的正态分布、wpe 为 0.01，并直接把两者相加 4。《Attention Is All You Need》在嵌入之后还要乘一个 \(\sqrt{d_{model}}\) 3，GPT-2 没有这一步。

组件卡 · 词嵌入

含义：给词表里每个 token 一行可学习的向量，按编号取出。

数学意义：一个输入为独热向量的线性映射 \(\mathbf e_v\mapsto E^\top\mathbf e_v\)，即 \(E\) 的第 \(v\) 行；实现为查表。

逻辑意义：把没有大小关系的离散编号，变成可以做点积、做加法、可以被梯度塑造几何关系的 \(d\) 维向量；后面所有层都只处理这种向量。没有它，网络只能处理编号本身，而编号之间的大小与远近毫无意义。

位置：没有它，注意力分不清先后

中文里有句老话：“狗咬人不是新闻，人咬狗才是新闻。”同样三个字，换个顺序，意思就反了。

那么问题来了：到现在为止，模型知不知道谁在前、谁在后？

问题。 先偷看一眼下两页要讲的注意力输出 (1.5)：\(\mathbf o_t=\sum_{j\le t}\alpha_{t,j}\mathbf v_j\)。这是一个求和，求和不管各项的次序。假如只有词嵌入、没有位置信息，把前缀里 \(x_1,\dots,x_{t-1}\) 的顺序任意打乱，第一层里位置 \(t\) 看到的是同一组键和值，只是编号换了，于是权重 \(\alpha_{t,j}\) 跟着各自的键一起换位，加权和一分不差。

“Alice thanked Bob .”与“Bob thanked Alice .”

两句话的最后一个 token 都是句号，前面三个 token 是同一组词、顺序不同。没有位置信息时，第一层注意力里句号的查询 \(\mathbf q_4\) 相同，面对的键值对集合 \(\{(\mathbf k_j,\mathbf v_j)\}_{j=1}^{4}\) 也相同，所以 \(\mathbf o_4\) 完全相同。可这两句话谁感谢谁正好相反。模型必须知道 Alice 在 thanked 的前面还是后面。

严格地说，多层的因果模型能从掩码本身间接推出一点位置信息（位置 1 只看得见自己，第二层以后各位置不再对称）。这是笔者从方程组推出的，不是所引论文的结论；这种信息很间接，GPT 系列都显式地加入了位置。第一层对前缀排列不敏感这件事，§9 的练习 12 会逐步证明一遍。

含义。 位置编码（positional encoding）是给每个位置 \(t\) 一个 \(d\) 维向量，把它加到该位置的词嵌入上，于是同一个词出现在不同位置时，进入网络的向量不同。

做法一：可学习的位置表（GPT-1、GPT-2）。再建一张表 \(P\in\R^{T_{max}\times d}\)，第 \(t\) 行给第 \(t\) 个位置，和词嵌入一样靠训练学出来 5,4。这就是方程 (1.1) 的第二项 \(P^\top\mathbf e_t\)。它简单，代价是一个硬上限：GPT-2 small 的表只有 1024 行，第 1025 个位置没有向量可查。

做法二：正弦位置编码（Transformer 原论文）。不学，而是用固定公式给出。我们先在黑板上造一个只有 4 维的。

黑板上 · 一个 4 维的位置编码

4 维只有两对坐标，就当成两根指针。第一根转得快：位置 \(t\) 时转过 \(t\) 弧度，约 6.28 个位置转一圈；第二根慢一百倍：转过 \(0.01t\) 弧度，约 628 个位置转一圈。位置 \(t\) 的编码就是两根指针的读数 \((\sin t,\ \cos t,\ \sin0.01t,\ \cos0.01t)\)：

位置 \(t\) 快针 \((\sin t,\ \cos t)\) 慢针 \((\sin0.01t,\ \cos0.01t)\)
1 \((0.8415,\ 0.5403)\) \((0.0100,\ 1.0000)\)
2 \((0.9093,\ -0.4161)\) \((0.0200,\ 0.9998)\)
3 \((0.1411,\ -0.9900)\) \((0.0300,\ 0.9996)\)
9 \((0.4121,\ -0.9111)\) \((0.0899,\ 0.9960)\)

大家看位置 3 和位置 9。快针的读数有点像：两者差 6 个位置，快针差不多转回了原处。可慢针的读数 0.0300 和 0.0899 差了三倍，一下就分开了。快针分辨近处，慢针分辨远处，合起来谁也不会认错。

好，把 4 维换成 \(d\) 维，两根针换成 \(d/2\) 根转速各不相同的针，就是原论文的公式 3：

正弦位置编码\[PE_{(t,2m)}=\sin(\omega_m t),\qquad PE_{(t,2m+1)}=\cos(\omega_m t),\qquad \omega_m=10000^{-2m/d}\]\(m=0,1,\dots,\tfrac d2-1\)。维度两两成对，第 \(m\) 对是一个以角速度 \(\omega_m\) 转动的“时钟”，波长 \(2\pi/\omega_m\) 从 \(2\pi\) 按等比数列增长到接近 \(10000\cdot2\pi\)。(1.15)

代回黑板：\(d=4\) 时 \(m=0,1\)，\(\omega_0=10000^{0}=1\)，\(\omega_1=10000^{-2/4}=0.01\)。两根针的转速正是我们在黑板上用的 1 和 0.01。

理解。 把一个位置写成一组时钟的读数：秒针转得最快（\(m=0\)，每 6.28 个位置转一圈），分针慢一些，时针更慢……只看秒针分不清第 3 个和第 9 个位置（差不多转了一圈），但加上慢针就分得清了。\(d=512\) 时一共有 256 根指针，最慢的一根要约 60,611 个位置才转一圈（图 1.5）。但是这个比方有个地方不对：真时钟的读数单独显示在表盘上，而这里的读数是加进词向量的，和词的特征挤在同一组坐标里（下文“为什么是相加而不是拼接”）；模型也不会像人一样“读表”，只能通过后面的矩阵乘法和点积间接用上这些数。

位置 1 的前四维（\(d=512\)）

\(d=512\)，\(t=1\)。第 0 对：\(\omega_0=1\)，\((\sin1,\cos1)=(0.8415,\ 0.5403)\)，和黑板上的快针一样。第 1 对：\(\omega_1=10000^{-2/512}=e^{-(2/512)\ln10000}\approx0.9647\)，\((\sin0.9647,\cos0.9647)=(0.8219,\ 0.5697)\)。两对的读数很接近，因为相邻两根快针的转速只差约 3.5%；要到 \(m\) 大很多的维度，读数才明显不同。

为什么偏偏用正弦和余弦？ 原论文给出的理由是一个假设：对任意固定的位移 \(k\)，位置 \(t+k\) 的编码是位置 \(t\) 编码的一个线性函数，这可能让模型容易学会按相对位置取用信息 3。这个线性关系可以直接推出来：

位移 k 等于把每一对维度旋转一个固定角度
(1)\(\displaystyle \sin(\omega(t+k))=\sin(\omega t)\cos(\omega k)+\cos(\omega t)\sin(\omega k)\)正弦的和角公式
(2)\(\displaystyle \cos(\omega(t+k))=\cos(\omega t)\cos(\omega k)-\sin(\omega t)\sin(\omega k)\)余弦的和角公式
(3)\(\displaystyle \begin{pmatrix}\sin\omega(t+k)\\\cos\omega(t+k)\end{pmatrix}=\begin{pmatrix}\cos\omega k&\sin\omega k\\-\sin\omega k&\cos\omega k\end{pmatrix}\begin{pmatrix}\sin\omega t\\\cos\omega t\end{pmatrix}\)把两行写成矩阵乘向量；矩阵只依赖 \(k\)，不依赖 \(t\)

我们代回黑板验一下：从位置 1 挪到位置 2，快针 \(\omega=1\)、\(k=1\)。第一行给出 \(\sin2=\sin1\cos1+\cos1\sin1=2\times0.8415\times0.5403=0.9093\)；第二行给出 \(\cos2=\cos^21-\sin^21=0.2919-0.7081=-0.4161\)。正是表里第 2 行的快针读数。

中间那个矩阵是一个二维旋转。也就是说，“往后挪 \(k\) 个位置”等于把每一对维度各自旋转角度 \(\omega_mk\)。这个观察是第 5 课 RoPE（旋转位置编码）的种子：RoPE 不再把位置加到嵌入上，而是直接把查询和键按位置旋转，让点积只依赖相对位移。

原论文也试过可学习的位置表，结果“几乎相同”：表 3 的 (E) 行，可学习版本困惑度 4.92、BLEU 25.7，正弦版本 4.92、25.8 3。选正弦的理由是它“或许”能外推到比训练时更长的序列，论文没有用实验验证这一点。GPT 选择了可学习的表 5。

为什么是相加而不是拼接？ 这是一个选择。拼接 \([\mathbf a;\mathbf b]\) 再乘 \(W=[W_a\ W_b]\) 等于 \(W_a\mathbf a+W_b\mathbf b\)（分块乘法，M01 §4），相加再乘 \(W\) 等于 \(W\mathbf a+W\mathbf b\)：相加是拼接在 \(W_a=W_b\) 时的特例。好处是维度不变、后面各层不必变宽；代价是词和位置共用同一组坐标，要由模型自己在 768 维里分配方向。本课引用的论文没有单独检验这个代价。

组件卡 · 位置编码

含义：给每个位置一个向量，加到该位置的词向量上。

数学意义：可学习版是第二张查找表 \(P^\top\mathbf e_t\)；正弦版是固定函数 (1.15)，位移 \(k\) 在每一对维度上是一个旋转。

逻辑意义：注意力的加权求和对前缀的排列不敏感，没有位置信息就分不清“谁在谁前面”。可学习表的代价是长度上限 \(T_{max}\)；正弦编码没有上限，但能否外推只是一个假设。

这一页讲了三件事
  • 第一，分词在网络之外。 GPT-2 用字节级 BPE：反复合并出现最多的相邻一对，\(50{,}257=256+50{,}000+1\)。token 不必和字、词对齐：“The cat sat”是 3 个 token，“大模型”是 7 个。
  • 第二，嵌入就是查表。 \(E^\top\mathbf e_v\) 就是取 \(E\) 的第 \(v\) 行（黑板上取出了 cat 的 \((0.9,0.3,-0.2)\)）：数学上是线性层，实现上是查表，经输入端的梯度只落在出现过的行上。
  • 第三，求和不管次序，所以要加位置。 GPT 用可学习的表（上限 1024），原 Transformer 用一组转速不同的正弦时钟；位移是逐对旋转，这是 RoPE 的起点。于是 (1.1)：\(\mathbf h^{(0)}_t=E^\top\mathbf e_{x_t}+P^\top\mathbf e_t\)，形状 \([T,768]\)。

往回翻：注意力是内容寻址的加权平均

大家读小说的时候一定有过这种体验：读到“他终于坐了下来”，脑子里会自动往回翻：这个“他”是谁？往回翻几行？不一定。翻到那个跟“他”对得上的人为止，可能是上一句，也可能是三段以前。

机器怎么“往回翻”？这是全课最核心的问题：位置 \(t\) 怎样从它前面的位置取信息。答案是方程 (1.3)–(1.5)，也就是缩放点积注意力。为了先看清骨架，这一页只讲一个头，并暂时把 \(\sqrt{d_k}\) 当成一个给定的常数；为什么除以它、为什么要掩码、为什么要多个头，是下一页的事。

问题：固定权重的平均为什么不够

回到 §1 的第 2 个要求：预测“The cat that the dog chased sat”中 sat 之后的词时，模型需要知道“坐下的是 cat”。位置 \(t\)（sat）必须从前面的某个位置（cat）把信息拿过来。

最省事的办法是把前面所有位置的向量平均一下：\(\mathbf o_t=\frac1t\sum_{j\le t}\mathbf v_j\)。它的毛病是一视同仁：sat 是第 \(t=7\) 个 token，每个位置都分到 \(1/7\approx0.1429\) 的权重，cat 只占其中一份，其余 \(6/7\) 是 The、that、the、dog、chased 和 sat 自己的混合。再进一步，给每个相对距离配一个固定权重（比如“总是多看前一个词”，卷积网络就是这样做的），也不行：cat 与 sat 之间隔了几个词，取决于具体句子，“隔 4 个位置”这条规则换一句话就错了。

所以权重不能是常数，也不能只依赖距离，而要依赖内容：位置 \(t\) 需要什么，位置 \(j\) 有什么，两者对得上，权重就大。这正是读小说时往回翻的方式。我们要的是一个函数 \(\alpha_{t,j}=f(\text{位置 }t\text{ 的内容},\ \text{位置 }j\text{ 的内容})\)，而且它要便宜、可导、能对所有 \((t,j)\) 一次算完。

图景：图书馆检索

类比：注意力 = 图书馆检索

映射。 位置 \(t\) 带着一个检索问题走进图书馆，这个问题就是查询（query）\(\mathbf q_t\)；书架上每本书（每个位置 \(j\)）的书脊上贴着一张标签，这是键（key）\(\mathbf k_j\)；书的内容是值（value）\(\mathbf v_j\)。问题与标签的匹配度是点积 \(\mathbf q_t^\top\mathbf k_j\)；softmax 按匹配度分配阅读时间；输出 \(\mathbf o_t\) 是按阅读时间加权的读书笔记。

收益。 它解释了为什么要把“标签”和“内容”分开：决定读不读一本书的依据（键），和从书里读到的东西（值），可以是两回事。它也解释了“按内容寻址”：你按主题找书，不是按书架编号找书。

但是这个比方有几个地方不对。 真实的检索是挑出一本书来读；注意力却把所有书按权重混在一起读，权重永远不会恰好是 0 或 1。标签和内容都是学出来的，而且同一本书在不同的头里可以贴完全不同的标签（每个头有自己的 \(W^K\)）。还有一点真实图书馆里没有：检索者自己也是书架上的一本书，位置 \(t\) 的查询也会和它自己的键做匹配。

黑板上：只算 sat 这一行

好，我们不急着写公式，先在黑板上真的“翻”一次。句子是 “The cat sat”，3 个 token。每个 token 手里有三个 2 维的向量（\(d_k=2\)）：查询 \(\mathbf q\)（我想找什么）、键 \(\mathbf k\)（我的标签）、值 \(\mathbf v\)（被找到后交出什么）。真实模型里它们由 (1.3) 从隐藏状态算出，下一节写成公式；这里直接把数写在黑板上：

位置 \(t\) token 查询 \(\mathbf q_t\) 键 \(\mathbf k_t\) 值 \(\mathbf v_t\)
1 The \((1,\ 1)\) \((0,\ 1)\) \((1,\ 0)\)
2 cat \((0,\ 2)\) \((2,\ 0)\) \((0,\ 1)\)
3 sat \((2,\ 1)\) \((1,\ 1)\) \((1,\ 1)\)
黑板上 · sat 往回翻：比一比、调一调、分一分、拿回来

sat 在第 3 个位置，它看得见 The、cat 和它自己。

  • 比一比（打分）。 拿 sat 的查询 \(\mathbf q_3=(2,1)\) 和三个键各做一次点积：\(\mathbf q_3\cdot\mathbf k_1=2\times0+1\times1=1\)，\(\mathbf q_3\cdot\mathbf k_2=2\times2+1\times0=4\)，\(\mathbf q_3\cdot\mathbf k_3=2\times1+1\times1=3\)。
  • 调一调（缩放）。 每个分数除以 \(\sqrt{d_k}=\sqrt2\approx1.4142\)，得 \((0.7071,\ 2.8284,\ 2.1213)\)。
  • 分一分（softmax）。 取指数：\(e^{0.7071}=2.0281\)，\(e^{2.8284}=16.9188\)，\(e^{2.1213}=8.3421\)，总和 \(27.2891\)；各除以总和，得权重 \((0.0743,\ 0.6200,\ 0.3057)\)，加起来是 1。
  • 拿回来（加权和）。 按这三个权重把三个值加起来：\(\mathbf o_3=0.0743\,(1,0)+0.6200\,(0,1)+0.3057\,(1,1)\)，也就是 \((0.3800,\ 0.9257)\)。

sat 把 62% 的注意力给了 cat，因为它的查询和 cat 的键点积最大。它往回翻，翻到了 cat；拿回来的 \(\mathbf o_3\) 主要由 cat 的值 \(\mathbf v_2\) 构成。

四步：比一比，调一调，分一分，拿回来。没有哪一步超出乘法、加法和指数。下面把它们写成字母。

形式化：查询、键、值

三个新术语，按“含义 → 理解 → 数学”各走一遍。它们都由同一个输入 \(\bar{\mathbf h}_j\)（LayerNorm 之后的隐藏状态，§6 讲）经过三个不同的矩阵得到：

术语 含义 理解（图书馆里） 数学（一个头，GPT-2 small）
查询 query 位置 \(t\) 想找什么 检索问题 \(\mathbf q_t=W^Q\bar{\mathbf h}_t+\mathbf b^Q\in\R^{64}\)
键 key 位置 \(j\) 能被什么找到 书脊标签 \(\mathbf k_j=W^K\bar{\mathbf h}_j+\mathbf b^K\in\R^{64}\)
值 value 位置 \(j\) 被找到后交出什么 书的内容 \(\mathbf v_j=W^V\bar{\mathbf h}_j+\mathbf b^V\in\R^{64}\)

其中 \(W^Q,W^K,W^V\in\R^{d_k\times d}\)，这里 \(d_k=d_h=64\)，\(d=768\)。注意三个矩阵作用在同一个 \(\bar{\mathbf h}_j\) 上：每个位置同时扮演三个角色，作为提问者（\(\mathbf q\)）、作为被检索的标签（\(\mathbf k\)）、作为被取走的内容（\(\mathbf v\)）。黑板上的 sat 也是这样：它拿 \(\mathbf q_3\) 去问，同时它的 \(\mathbf k_3\)、\(\mathbf v_3\) 也被自己问到。这就是“自注意力”（self-attention）的“自”：查询和键值来自同一个序列。

有了这三样东西，黑板上的四步就是下面三个式子（“调一调”并进了第一步）：

第一步：打分\[s_{t,j}=\frac{\mathbf q_t^\top\mathbf k_j}{\sqrt{d_k}},\qquad j=1,\dots,t\]\(s_{t,j}\) 是一个实数，表示“位置 \(t\) 的问题”与“位置 \(j\) 的标签”有多对得上。除以 \(\sqrt{d_k}\) 的理由在 §4。(1.16)

代回黑板：\(t=3,\ j=2\)，\(s_{3,2}=4/\sqrt2=2.8284\)。对，就是 sat 对 cat 的那个分数。

softmax 与它的三条性质熟悉 softmax 的可以跳过

softmax 把任意一组实数 \(z_1,\dots,z_n\) 变成一组概率：\(\softmax(\mathbf z)_i=e^{z_i}/\sum_{k=1}^{n}e^{z_k}\)。本课反复用到它的三条性质：

  1. 输出非负、和为 1：\(e^{z_i}>0\)，分子加起来正好等于分母。
  2. 单调：\(z_i\) 越大，\(\softmax(\mathbf z)_i\) 越大，排名不变。
  3. 平移不变：所有 \(z_i\) 同时加上同一个常数 \(c\)，结果不变，因为 \(e^{z_i+c}/\sum_ke^{z_k+c}=e^ce^{z_i}/(e^c\sum_ke^{z_k})\)，\(e^c\) 上下约掉。实现里常先减去最大值再取指数，防止 \(e^{z}\) 溢出，靠的就是这一条。

还有一个会在 §4 用到的量：温度（temperature）。把 \(\mathbf z\) 先除以 \(\tau>0\) 再做 softmax，\(\tau\) 越小分布越尖，\(\tau\to0\) 时趋向只在最大值处为 1 的“独热”分布（前提是最大值只有一个；若有 \(r\) 个并列最大，极限是在这 \(r\) 处各为 \(1/r\)）；\(\tau\) 越大分布越平，\(\tau\to\infty\) 时趋向均匀分布。softmax 与温度在 M04 §4 有专门一节。

第二步：softmax 得到权重\[\alpha_{t,j}=\softmax_j(s_{t,1},\dots,s_{t,t})=\frac{e^{s_{t,j}}}{\sum_{k=1}^{t}e^{s_{t,k}}},\qquad \alpha_{t,j}\ge0,\quad\sum_{j=1}^{t}\alpha_{t,j}=1\]只对 \(j\le t\) 求和：位置 \(t\) 只能看自己和前面的位置。这件事在矩阵形式里由“因果掩码”实现（§4）。(1.17)

代回黑板：\(\alpha_{3,2}=16.9188/27.2891=0.6200\)。

第三步：加权平均\[\mathbf o_t=\sum_{j=1}^{t}\alpha_{t,j}\,\mathbf v_j\in\R^{d_k}\]输出是值向量的加权平均，权重由查询与键的匹配度决定。(1.18)

代回黑板：\(\mathbf o_3=(0.3800,\ 0.9257)\)。三个式子一个不差地复现了我们手算的四步。(1.16)–(1.18) 连起来就是方程组里的 (1.4)(1.5)。

数学意义：内容寻址的加权平均

(1.17) 说权重非负、和为 1，所以 (1.18) 的 \(\mathbf o_t\) 是 \(\mathbf v_1,\dots,\mathbf v_t\) 的一个凸组合（convex combination）：几何上，它一定落在这 \(t\) 个点围成的凸多边形（凸包）里面。黑板上的 \(\mathbf o_3=(0.3800,0.9257)\) 就落在 \((1,0)\)、\((0,1)\)、\((1,1)\) 三点围成的三角形里（下面的图 1.8 右）。这句话有两个极端值得记住：

  • 若某个 \(\alpha_{t,j}\approx1\)，其余 \(\approx0\)：\(\mathbf o_t\approx\mathbf v_j\)，注意力退化成“查表取一个”。
  • 若所有 \(\alpha_{t,j}=1/t\)：\(\mathbf o_t\) 是简单平均，退化成本页开头那个一视同仁的方案。

真实的注意力介于两者之间，而且在哪里取值由内容决定。“内容寻址”（content-based addressing）是相对于计算机内存的“按地址寻址”说的：内存按编号取数据，而注意力按“键与查询像不像”取数据，并且是软性的、按相似度混合的。

很多人以为：注意力就是“挑出最相关的那个词”

很多人以为：注意力像检索一样，从前文里挑出一个最相关的词，把它的信息拿过来。

其实：它是加权平均，而且是“软”的。softmax 的输出永远严格大于 0，注意力永远做不到“只取一个”；要近似做到，分数之间必须拉开很大的差距。黑板上 sat 最看重 cat，也只给了 62%，The 和它自己还分走了 38%。反过来，当前缀很长、很多位置的分数差不多时，有用的信息会被大量无关位置稀释。这一点在 §4 讲缩放时还会出现。

为什么用点积打分？ 点积 \(\mathbf q^\top\mathbf k=\norm{\mathbf q}\norm{\mathbf k}\cos\varphi\)（\(\varphi\) 是两个向量的夹角）同时量了方向是否一致和向量有多长（M01 §1），它只含乘法和加法，处处可导，而所有 \((t,j)\) 的点积恰好是一次矩阵乘法 \(QK^\top\)。原论文比较过另一种打分方式“加性注意力”（用一个带隐藏层的小网络打分）：两者理论复杂度相近，但点积注意力可以用高度优化的矩阵乘法代码实现，实践中快得多、也更省内存 3。

为什么要三个不同的矩阵？ 把 (1.16) 展开（忽略偏置）：\(\mathbf q_t^\top\mathbf k_j=\bar{\mathbf h}_t^\top(W^Q)^\top W^K\bar{\mathbf h}_j\)。中间的 \((W^Q)^\top W^K\) 是一个学出来的 \(d\times d\) 矩阵，所以“相关”的标准不是固定的几何相似，而是模型自己学的一种双线性打分。它一般不对称：\(t\) 找 \(j\) 的分数不等于 \(j\) 找 \(t\) 的分数（“我需要你”不等于“你需要我”）。黑板上就是这样：sat 找 cat 得 4 分，cat 找 sat 却是 \(\mathbf q_2\cdot\mathbf k_3=0\times1+2\times1=2\) 分。而值用第三个矩阵 \(W^V\)，让“被找到的理由”和“交出去的内容”可以不同。

矩阵形式：一次算完整段

代码不会一个位置一个位置地算。把 \(T\) 个位置的查询按行堆成 \(Q\in\R^{T\times d_k}\)（第 \(t\) 行是 \(\mathbf q_t^\top\)），\(K\)、\(V\) 同理，三步就变成三次矩阵运算：

缩放点积注意力（矩阵形式）\[\Attn(Q,K,V)=\softmax\!\Big(\frac{QK^\top}{\sqrt{d_k}}+M\Big)V,\qquad M_{tj}=\begin{cases}0,&j\le t\\-\infty,&j>t\end{cases}\]形状：\([T,d_k]\times[d_k,T]\to[T,T]\)；softmax 逐行；\([T,T]\times[T,d_k]\to[T,d_k]\)。这是《Attention Is All You Need》的式 (1) 加上解码器的掩码 \(M\) 3。本课的 \(M\) 只表示这个 \(T\times T\) 的掩码矩阵；第 6 课沿用 DeepSeek LLM 的记号，那里的 \(M\) 是每个 token 的非嵌入运算量，两者无关。(1.19)

\(QK^\top\) 的第 \((t,j)\) 格正是 \(\mathbf q_t^\top\mathbf k_j\)（矩阵乘法的“批量点积”读法，M01 §2）；加上 \(M\) 之后，上三角变成 \(-\infty\)，\(e^{-\infty}=0\)，所以逐行 softmax 恰好只在 \(j\le t\) 上归一化，与 (1.17) 一致；最后 \(A V\) 的第 \(t\) 行是 \(\sum_j\alpha_{t,j}\mathbf v_j^\top\)，正是 (1.18)。

黑板上：三行一起算

刚才只算了 sat 这一行。现在用 (1.19) 把 The、cat、sat 三行一起算，顺便看看掩码怎么管住前两行。

黑板上 · 五步手算：打分、缩放、掩码、softmax、加权和

第 1 步：原始点积 \(QK^\top\)。 第 \(t\) 行第 \(j\) 列是 \(\mathbf q_t\cdot\mathbf k_j\)。例如 \(\mathbf q_3\cdot\mathbf k_2=2\times2+1\times0=4\)。

\[QK^\top=\begin{pmatrix}1&2&2\\2&0&2\\1&4&3\end{pmatrix}\]

第 2 步：除以 \(\sqrt{d_k}=\sqrt2\approx1.4142\)。

\[S=\frac{QK^\top}{\sqrt2}=\begin{pmatrix}0.7071&1.4142&1.4142\\1.4142&0&1.4142\\0.7071&2.8284&2.1213\end{pmatrix}\]

第 3 步：加掩码。 上三角（\(j>t\)）换成 \(-\infty\)：第 1 行只留第 1 格，第 2 行留前 2 格，第 3 行全留。

\[S+M=\begin{pmatrix}0.7071&-\infty&-\infty\\1.4142&0&-\infty\\0.7071&2.8284&2.1213\end{pmatrix}\]

第 4 步：逐行 softmax。 先取指数（\(e^{-\infty}=0\)），再除以行和：

  • \(\mathbf o_1=1\cdot(1,0)=(1,\ 0)\)，原样取回自己的值。
  • \(\mathbf o_2=0.8044\,(1,0)+0.1956\,(0,1)=(0.8044,\ 0.1956)\)。

组件卡 · 缩放点积注意力（单头）

含义：每个位置用一个查询去和前面所有位置的键比对，按匹配度把它们的值加权平均，作为自己从上下文里取到的信息。

数学意义：\(\mathbf o_t=\sum_{j\le t}\softmax_j(\mathbf q_t^\top\mathbf k_j/\sqrt{d_k})\,\mathbf v_j\)，是值向量的凸组合，权重由一个学出来的双线性打分 \(\bar{\mathbf h}_t^\top(W^Q)^\top W^K\bar{\mathbf h}_j\) 决定；矩阵形式 (1.19) 是三次矩阵运算。

逻辑意义：它是整个网络里唯一让不同位置交换信息的地方。没有它，每个 token 只能看见自己，模型退化成“只凭当前这一个词猜下一个词”；有了它，取哪些信息由内容决定，而不是由固定距离决定。

失败模式：平方的账单

账单随 \(T^2\) 增长。 每个头每层都要算一张 \(T\times T\) 的表。黑板上 \(T=3\)，一张表 9 格。GPT-2 small 在 \(T=1024\) 时，一张表 \(1{,}048{,}576\) 格，12 个头 × 12 层就是 \(150{,}994{,}944\) 个分数，其中每张表严格上三角的 \(1024\times1023/2=523{,}776\) 格（49.95%）会被掩码丢掉。上下文每长一倍，这个数乘 4。第 4 课、第 14 课都在和这笔账打交道。

这一页讲了三件事
  • 第一，注意力 = 按内容往回翻。 比一比（点积）、调一调（除以 \(\sqrt{d_k}\)）、分一分（softmax）、拿回来（加权和）：\(s_{t,j}=\mathbf q_t^\top\mathbf k_j/\sqrt{d_k}\)，\(\alpha_{t,j}=\softmax_j(s_{t,j})\)，\(\mathbf o_t=\sum_{j\le t}\alpha_{t,j}\mathbf v_j\)。黑板上 sat 把 62% 的权重给了 cat，\(\mathbf o_3=(0.3800,0.9257)\)。
  • 第二，查询、键、值由三个矩阵从同一个隐藏状态算出。 打分是学出来的双线性形式，一般不对称（sat 找 cat 4 分，cat 找 sat 2 分）。输出是值向量的凸组合，介于“取一个”与“取平均”之间，永远是软的。
  • 第三，矩阵形式一次算完整段。 \(\softmax(QK^\top/\sqrt{d_k}+M)V\)；唯一的 \([T,T]\) 部分就是它的 \(T^2\) 账单。

注意力（二）：缩放、因果掩码与多头

先请大家做一个思想实验。抛一枚硬币，正面记 +1，反面记 −1。抛 64 次，把结果加起来。大家猜一猜，这个和通常落在什么范围？±64？±32？

都不是。它通常在 ±8 上下：大约有四分之三的机会落在 −8 到 8 之间；绝对值达到 32 的机会，连万分之一都不到。为什么偏偏是 8？因为 \(8=\sqrt{64}\)。

这跟注意力有什么关系？注意力的打分 \(\mathbf q^\top\mathbf k\)，恰好就是这样一个“64 项相加”。上一页还留着三个“为什么”：为什么分数要除以 \(\sqrt{d_k}\)；为什么要把上三角换成 \(-\infty\)；为什么 GPT-2 用 12 个 64 维的头，而不是一个 768 维的头。三个问题的答案分别是：控制 softmax 的温度，让并行训练不作弊，让一个位置能同时按几种标准取信息。

为什么除以 \(\sqrt{d_k}\)

问题。 点积 \(\mathbf q^\top\mathbf k=\sum_{i=1}^{d_k}q_ik_i\) 是 \(d_k\) 项之和。项数越多，和的波动越大。GPT-2 small 每个头 \(d_k=64\)；如果分数的典型大小随 \(d_k\) 增长，softmax 就会越来越尖，最后几乎把全部权重压在一个位置上。我们希望打分的尺度不依赖于头的维度这种架构上的任意选择。

先量一量点积会有多大。还是从黑板开始，把 64 缩成 4。

黑板上 · 4 维的点积，就是抛 4 次硬币

取 \(d_k=4\)，让 \(\mathbf q\)、\(\mathbf k\) 的每个分量都随机取 +1 或 −1，各占一半机会，互相独立。于是每个乘积 \(q_ik_i\) 也是 ±1、各占一半，点积就是 4 个 ±1 相加，和抛 4 次硬币一样。4 次硬币一共 \(2^4=16\) 种等可能的结果，按点积的值分一分：

点积的值 有几种结果 值的平方
−4 1 16
−2 4 4
0 6 0
2 4 4
4 1 16

均值是 0（左右对称）。方差是“平方的平均”：\((16\times1+4\times4+0\times6+4\times4+16\times1)/16=64/16=4\)，标准差 2。

方差恰好等于 \(d_k=4\)，标准差恰好是 \(\sqrt4=2\)。如果每个分数都除以 2，取值就变成 −2、−1、0、1、2，方差回到 1。

好，现在把 4 换成 \(d_k\)，把硬币换成一般的随机数。这需要两条关于方差的事实。

独立随机变量的方差熟悉“独立变量之和的方差等于方差之和”的可以跳过

期望（mean）\(\E[X]\) 是随机变量 \(X\) 的平均值；方差（variance）\(\Var(X)=\E[X^2]-(\E[X])^2\) 量的是它偏离平均值的程度，标准差是方差的平方根。本节只用两条事实：

  1. 若 \(X,Y\) 独立，则 \(\E[XY]=\E[X]\E[Y]\)。
  2. 若 \(X_1,\dots,X_n\) 相互独立，则 \(\Var(X_1+\cdots+X_n)=\Var(X_1)+\cdots+\Var(X_n)\)：独立的波动不会互相抵消，也不会互相放大，只是方差相加。

所以 \(n\) 个独立、方差为 1 的数相加，和的标准差是 \(\sqrt n\)，不是 \(n\)。开头那 64 枚硬币，标准差就是 \(\sqrt{64}=8\)。推导与更多例子见 M04 §3（期望与方差的定义在 M04 §2）。

推导。 《Attention Is All You Need》的脚注给出了下面这个估算，前提是一个明确的假设：\(\mathbf q\) 与 \(\mathbf k\) 的各分量是相互独立、均值为 0、方差为 1 的随机变量 3。黑板上的 ±1 硬币正好满足这个假设。

点积的均值与方差
(1)\(\displaystyle \E[\mathbf q^\top\mathbf k]=\sum_{i=1}^{d_k}\E[q_ik_i]=\sum_{i=1}^{d_k}\E[q_i]\,\E[k_i]=0\)期望的线性；\(q_i\) 与 \(k_i\) 独立；均值都是 0
(2)\(\displaystyle \Var(\mathbf q^\top\mathbf k)=\sum_{i=1}^{d_k}\Var(q_ik_i)\)全部 \(2d_k\) 个分量相互独立，所以 \(d_k\) 个乘积 \(q_ik_i\) 也相互独立（各用一组互不重叠的分量），方差相加
(3)\(\displaystyle \Var(q_ik_i)=\E[q_i^2k_i^2]-\big(\E[q_ik_i]\big)^2=\E[q_i^2]\,\E[k_i^2]-0=1\cdot1\)方差的定义；\(q_i^2,k_i^2\) 独立；\(\E[q_i^2]=\Var(q_i)=1\)
(4)\(\displaystyle \Var(\mathbf q^\top\mathbf k)=d_k\)把第 3 行代回第 2 行，\(d_k\) 个 1 相加
(5)\(\displaystyle \Var\!\big(\mathbf q^\top\mathbf k/\sqrt{d_k}\big)=\frac{1}{d_k}\Var(\mathbf q^\top\mathbf k)=1\)常数 \(c\) 乘随机变量，方差乘 \(c^2\)
缩放之后，分数的方差回到 1\[\Var\big(\mathbf q^\top\mathbf k\big)=d_k,\qquad\Var\Big(\frac{\mathbf q^\top\mathbf k}{\sqrt{d_k}}\Big)=1\]前提：\(\mathbf q,\mathbf k\) 的分量相互独立、均值 0、方差 1。\(d_k=64\) 时，不缩放的分数标准差是 8；\(d_k=128\) 时是 \(\sqrt{128}\approx11.31\)。(1.20)

代回黑板：\(d_k=4\)，方差 4，除以 \(\sqrt4=2\) 之后方差 1，和我们一种一种数出来的一样。\(d_k=64\) 时标准差 8，正是开头那 64 枚硬币。

用随机数验证

在 Python 里生成 200,000 对 64 维向量，每个分量独立地取自标准正态分布，算出它们的点积：样本方差是 63.77（理论 64），标准差 7.985（理论 8）；除以 8 之后方差是 0.996。图 1.9 (a) 画的就是这两组数的分布。

这为什么要紧：softmax 的温度。 把分数除以 \(\sqrt{d_k}\)，等于把 softmax 的温度固定在“分数标准差约为 1”的地方。反过来，不缩放就等于用温度 \(\tau=1/\sqrt{d_k}\) 做 softmax，头越宽，分布越尖。下表用一组固定的分数 \(\mathbf z=(2,\ 1,\ 0.1)\) 看温度的效果，最后一行相当于 \(d_k=64\) 不缩放时把分数放大 8 倍：

分布尖一点，有什么坏处？坏在训练。要看清这一点，得先会求 softmax 的导数。

导数、雅可比矩阵与链式法则熟悉多元微积分的可以跳过

导数量的是“输入动一点，输出跟着动多少”：\(f'(x)\approx\big(f(x+h)-f(x)\big)/h\)，\(h\) 很小。输入和输出都是向量时，要回答的是“第 \(j\) 个输入动一点，第 \(i\) 个输出动多少”，这些数排成一个矩阵，叫雅可比矩阵（Jacobian）：若 \(\mathbf y=f(\mathbf x)\)，\(\mathbf x\in\R^{n}\)，\(\mathbf y\in\R^{m}\)，则 \(J\in\R^{m\times n}\)，\(J_{ij}=\partial y_i/\partial x_j\)。两个马上要用的例子：线性映射 \(\mathbf y=W\mathbf x\) 的雅可比就是 \(W\) 本身；逐元素函数 \(y_i=g(x_i)\) 的雅可比是对角矩阵 \(\diag\big(g'(x_1),\dots,g'(x_n)\big)\)。

链式法则：几步串起来的函数 \(\mathbf z=g(f(\mathbf x))\)，它的雅可比是各步雅可比的乘积 \(J_{g\circ f}=J_g\,J_f\)（后一步写在左边）。反向传播就是从损失出发，把这些矩阵从后往前一路乘回来：只要途中有一个因子是零矩阵，梯度就传不到更前面的参数。详见 M06 §3；softmax 的雅可比在 M06 §5 有更完整的推导。

饱和为什么伤害训练。 softmax 对输入的导数（雅可比矩阵）是

softmax 的导数
(1)\(\displaystyle \dfrac{\partial p_i}{\partial z_j}=\dfrac{\partial}{\partial z_j}\dfrac{e^{z_i}}{\sum_ke^{z_k}}=\dfrac{\delta_{ij}e^{z_i}\sum_ke^{z_k}-e^{z_i}e^{z_j}}{\big(\sum_ke^{z_k}\big)^2}\)商的求导法则；\(\delta_{ij}\) 在 \(i=j\) 时为 1、否则为 0
(2)\(\displaystyle =p_i\,\delta_{ij}-p_ip_j=p_i(\delta_{ij}-p_j)\)用 \(p_i=e^{z_i}/\sum_ke^{z_k}\) 化简
(3)\(\displaystyle p=(1,0,\dots,0)\ \Rightarrow\ \dfrac{\partial p_i}{\partial z_j}=0\ \text{对所有 }i,j\)\(i=1\) 时 \(\delta_{1j}-p_j=0\)；\(i\ne1\) 时 \(p_i=0\)。有限的 \(\mathbf z\) 给出的 \(p_i\) 都严格大于 0，所以这是 \(z_1-\max_{j\ne1}z_j\to\infty\) 时的极限

我们拿温度表里的两行代进去，看对角线上的 \(p_i(1-p_i)\)。\(\tau=1\) 时 \(p=(0.6590,\ 0.2424,\ 0.0986)\)，对角线是 \((0.2247,\ 0.1837,\ 0.0889)\)，输入动一点，输出就跟着动。放大 8 倍以后 \(p\approx(0.99966,\ 0.00034,\ 2.5\times10^{-7})\)，对角线只剩约 \((0.00034,\ 0.00034,\ 2.5\times10^{-7})\)：输入再怎么动，输出几乎纹丝不动。

也就是说，当 softmax 的输出变成独热分布时，它对所有分数的导数都是 0，梯度传不回 \(\mathbf q\) 和 \(\mathbf k\)，这个头的打分方式就学不动了。原论文 v2 的正文说，点积变大会把 softmax 推进“梯度极小”的区域，并用上面那个方差估算作为脚注解释 3。

两处需要诚实的地方

这是一个估算，不是证明缩放最优。 脚注只算了一个方差，而且依赖“分量独立、单位方差”的假设；训练开始之后，\(\mathbf q,\mathbf k\) 的分量既不独立、方差也不是 1。论文自己用的词是“我们猜测”（We suspect）。它解释了“为什么点积会大”，没有证明“除以 \(\sqrt{d_k}\) 是最好的做法”。

“梯度变小”要分清说的是什么。 严格为 0 只发生在完全独热的极限（上面放大 8 倍的三个数已经很接近这个极限）。沿用图 1.9 (b) 的设定（512 个独立的 \(\mathcal N(0,s^2)\) 分数，\(s\) 是分数的标准差），在 \(s=8\) 的中等饱和情形下，雅可比矩阵的整体大小（Frobenius 范数，即全部元素的平方和再开方）反而比 \(s=1\) 时大（笔者用 20,000 组随机分数估计：平均约 0.24 对 0.071）；接近 0 的是流向非最大位置的梯度。更准确的说法是：不缩放时，softmax 的温度被头的维度这个无关的选择绑架，维度越大越容易饱和。

实验上的动机。 原论文还提到，另有研究发现 \(d_k\) 较小时点积注意力与加性注意力表现相近，\(d_k\) 较大时加性注意力胜过不缩放的点积注意力，这是他们引入缩放的实验依据 3。

这是一个选择，还有别的选法。 除以 \(\sqrt{d_k}\) 与把 \(W^Q\)（连同偏置 \(\mathbf b^Q\)）的初始值缩小 \(\sqrt{d_k}\) 倍在初始化时的前向计算上是等价的（\(\mathbf q/\sqrt{d_k}=(W^Q/\sqrt{d_k})\bar{\mathbf h}+\mathbf b^Q/\sqrt{d_k}\)）。区别在训练中：固定的 \(1/\sqrt{d_k}\) 一直都在，缩小的初始值却会被梯度更新改掉；而且固定因子也把流到 \(W^Q\) 的梯度缩小了 \(\sqrt{d_k}\) 倍（对一个位置，\(\partial\mathcal L/\partial W^Q=\mathbf g\,\bar{\mathbf h}^\top/\sqrt{d_k}\)，其中 \(\mathbf g\in\R^{d_k}\) 是损失对缩放后查询 \(\mathbf q/\sqrt{d_k}\) 的梯度，形状 \([d_k,1]\times[1,d]=[d_k,d]\)，与 \(W^Q\) 同形），所以同样的学习率下，两种写法每一步对分数的改动并不一样。GPT-2 的代码采用固定的缩放：w = w * tf.rsqrt(v.shape[-1])，也就是乘以 \(1/\sqrt{64}=1/8\) 4。

因果掩码：让并行训练诚实

小时候背单词，大家多半用过这一招：拿一张纸盖住下面还没背到的行，背一行，往下挪一行，对一次答案。那张纸就是这一节的主角。

问题。 §1 的例子说，一次前向传播对 4 个 token 给出了 4 个预测。训练时，我们正是要让每个位置的预测去对准下一个真实的 token：位置 1 的预测对准 Ġunbelievable，位置 2 对准 Ġtoken，依此类推（第 2 课会把这写成交叉熵损失）。可是，这 4 个 token 是同时喂进去的。如果位置 1 的注意力能看到位置 2，它只要把位置 2 的输入“抄”过来，就能完美地“预测”位置 2：损失降得飞快，模型却什么都没学会。到了真正生成的时候，位置 2 还不存在，这种“能力”一点用也没有。

含义。 因果掩码（causal mask）是一个加在打分表上的 \(T\times T\) 矩阵：允许看的格子（\(j\le t\)）加 0，不允许看的格子（\(j>t\)）加 \(-\infty\)。原论文的说法是在 softmax 的输入里把“非法连接”置为 \(-\infty\) 3。但是背单词那个比方有个地方不对：背单词时纸是一行一行往下挪的，先后发生；注意力里 \(T\) 行是同时算的，相当于给每一行各发一张纸，第 \(t\) 行那张正好盖住第 \(t\) 列以后的所有格子。

数学。 就是 (1.19) 里的 \(M\)。它起作用的关键在于：\(-\infty\) 是加在 softmax 之前的。先在黑板上看一行。

黑板上 · 给 cat 那一行盖上纸

上一页的第 2 行（cat）缩放后的分数是 \((1.4142,\ 0,\ 1.4142)\)，第 3 格是“未来”的 sat。加掩码：\((1.4142,\ 0,\ -\infty)\)。取指数：\((4.1133,\ 1,\ 0)\)，和 \(5.1133\)。除以和：\((0.8044,\ 0.1956,\ 0)\)。

被盖住的那一格权重正好是 0，剩下两格加起来仍然是 1，不用再做任何修补。

一般地：

掩码之后的 softmax 恰好只在前缀上归一化
(1)\(\displaystyle \softmax(S_{t,:}+M_{t,:})_j=\dfrac{e^{S_{tj}+M_{tj}}}{\sum_{k=1}^{T}e^{S_{tk}+M_{tk}}}\)softmax 的定义；\(S=QK^\top/\sqrt{d_k}\)，\(S_{t,:}\)、\(M_{t,:}\) 是 \(S\)、\(M\) 的第 \(t\) 行
(2)\(\displaystyle e^{S_{tk}+M_{tk}}=e^{S_{tk}}\ (k\le t),\qquad e^{S_{tk}+M_{tk}}=e^{-\infty}=0\ (k>t)\)\(M_{tk}=0\) 或 \(-\infty\)
(3)\(\displaystyle \softmax(S_{t,:}+M_{t,:})_j=\dfrac{e^{S_{tj}}}{\sum_{k=1}^{t}e^{S_{tk}}}\ (j\le t),\qquad =0\ (j>t)\)分子、分母里 \(k>t\) 的项都消失；\(S_{tj}=s_{t,j}\)，正是 (1.17)

代回黑板：\(t=2\)，分母只剩 \(e^{1.4142}+e^{0}=5.1133\)，权重 \((0.8044,\ 0.1956,\ 0)\)。

如果反过来先做 softmax、再把上三角的权重清零，每行的权重就加不到 1 了，还得再归一化一次（练习 2 会拿黑板上这一行算给大家看）。先加 \(-\infty\) 一步到位。GPT-2 的代码没有用真正的 \(-\infty\)，而是减去 \(10^{10}\)：w = w*b - 1e10*(1-b) 4；\(e^{-10^{10}}\) 在浮点数里就是 0，效果相同。

因果掩码保证了什么？ 下面证明一个比“注意力不看未来”更强的结论：整个网络在位置 \(t\) 的每一个中间结果，都只依赖 \(x_1,\dots,x_t\)。记号 \(f(x_1,\dots,x_t)\) 表示“某个只以 \(x_1,\dots,x_t\) 为自变量的函数”，不同的行里 \(f\) 可以不同。

位置 \(t\) 的状态只依赖前缀 \(x_1,\dots,x_t\)（对层数归纳）
(1)\(\displaystyle \mathbf h^{(0)}_t=E^\top\mathbf e_{x_t}+P^\top\mathbf e_t=f(x_t)\)起点：(1.1) 逐位置查表
(2)\(\displaystyle \mathbf h^{(l-1)}_j=f(x_1,\dots,x_j)\quad\text{对所有 }j\)归纳假设
(3)\(\displaystyle \bar{\mathbf h}_j,\ \mathbf q_{j,i},\ \mathbf k_{j,i},\ \mathbf v_{j,i}=f(x_1,\dots,x_j)\)(1.2)(1.3) 逐位置
(4)\(\displaystyle \mathbf o_{t,i}=\sum_{j\le t}\alpha_{t,j,i}\,\mathbf v_{j,i}=f(x_1,\dots,x_t)\)掩码：只剩 \(j\le t\)
(5)\(\displaystyle \mathbf h^{(l)}_t=\mathbf h^{(l-1)}_t+\mathbf u_t+\mathbf m_t=f(x_1,\dots,x_t)\)(1.6)–(1.9) 逐位置
(6)\(\displaystyle p_\theta(x_{t+1}\mid x_{\le t})=\softmax\big(E\,\LayerNorm_f(\mathbf h^{(L)}_t)\big)=f(x_1,\dots,x_t)\)归纳到 \(l=L\)

整个链条里只有第 4 行用到了别的位置，而掩码恰好在这里把 \(j>t\) 的权重变成 0；剩下的 \(j\le t\) 满足 \(x_{\le j}\subseteq x_{\le t}\)，所以不会引入 \(x_{t+1}\) 及以后的任何信息。其余各行都是逐位置运算，本来就不会把别的位置混进来。

这个结论有两个后果，分别属于第 2 课和第 4 课。

  1. 训练是诚实的，而且是并行的。 一次前向传播给出 \(T\) 个预测，第 \(t\) 个预测在数学上就是只读了前 \(t\) 个 token 时模型会给出的预测。于是一段 1024 个 token 的训练文本一次提供 1024 个合法的训练信号，不必像循环网络那样一步一步地展开。这就是 §1 第 4 个要求的答案。
  2. 旧位置的结果永远不变。 在序列末尾追加新 token，不会改变任何旧位置的 \(\mathbf k_{j,i}\)、\(\mathbf v_{j,i}\)。所以生成时可以把它们存起来反复使用，这就是第 4 课的 KV cache，而且它是精确的优化，不是近似。GPT-2 的官方代码里已经有这个缓存，形状为 [batch, n_layer, 2, n_head, sequence, n_embd // n_head] 4。
很多人以为：生成是一个字一个字来的，训练也得一个字一个字喂

很多人以为：模型写东西是一个 token 一个 token 往外蹦的，所以训练时也只能先喂 1 个 token 算一次，再喂 2 个 token 算一次……

其实：训练时整段一起喂，一次前向传播就给出全部 \(T\) 个位置的预测（“The unbelievable tokenization”一次给出 4 个）。上面的归纳证明保证，第 \(t\) 个预测和“只喂前 \(t\) 个 token”时算出的预测是同一个函数。串行只发生在生成时，因为那时第 \(t+1\) 个 token 还没被写出来，第 4 课专门讲它。

组件卡 · 因果掩码

含义：打分表上三角加 \(-\infty\)，让每个位置只能看见自己和前面的位置。

数学意义：\(\softmax(S+M)\) 的第 \(t\) 行恰好是只在 \(j\le t\) 上归一化的 softmax；配合逐位置运算，整张网络在位置 \(t\) 的输出只依赖 \(x_1,\dots,x_t\)（归纳证明）。

逻辑意义：它让“一次前向算出 \(T\) 个预测”的并行训练不作弊，也让生成时缓存旧位置的键和值成为精确的做法。没有它，训练损失会被“抄答案”压低，而模型在真正生成时一无所能。

多头注意力：同时按几种标准取信息

大家看过作文比赛打分吧：如果只请一位评委，他只能打一个总分，把内容、结构、文笔全揉在一起；请三位评委，一位盯内容，一位盯结构，一位盯文笔，信息就多得多。但是这个比方有个地方不对：评委的分工是事先定好的，头的分工是训练出来的；而且每个头交出来的不是一个分数，是一整套权重。

问题。 一个头只有一套 softmax 权重，也就是说，位置 \(t\) 在一个头里只能按一种标准给前文分配注意力。可一个词往往同时需要几种信息：预测 sat 之后的词，既要知道主语是谁（cat），也要知道紧挨着的前一个词、时态、句子结构……一套权重只能在这些需求之间妥协，结果是把几种信息平均成一团。原论文的说法是：只用一个头时，“平均”会妨碍模型同时关注不同表示子空间里、不同位置上的信息 3。

含义。 多头注意力（multi-head attention）把一个宽的注意力拆成 \(n_h\) 个窄的头，每个头有自己的 \(W^Q_i,W^K_i,W^V_i\)，各自独立地打分、softmax、加权平均，最后把 \(n_h\) 个结果拼起来，再乘一个输出矩阵 \(W^O\)。

还是先上黑板，把上一页那个 2 维的头拆成两个 1 维的头。

黑板上 · 同一个 sat，两位评委

回到 §3 的 “The cat sat”（\(d=2\)）。把它拆成 \(n_h=2\) 个头、每头 \(d_h=1\)：头 1 只用查询、键、值的第 1 个坐标，头 2 只用第 2 个坐标。这相当于取 \(W^Q_1=W^K_1=W^V_1=(1\ \ 0)\)、\(W^Q_2=W^K_2=W^V_2=(0\ \ 1)\)，都是 \(1\times2\) 的矩阵，正是“按行切块”。只看第 3 行（sat），缩放因子 \(\sqrt{d_h}=1\)。

  • 头 1：查询 \(2\)，三个键 \((0,\ 2,\ 1)\)，分数 \((0,\ 4,\ 2)\)；指数 \((1,\ 54.598,\ 7.389)\)，和 62.987；权重 \((0.0159,\ 0.8668,\ 0.1173)\)。三个值 \((1,\ 0,\ 1)\)，输出 \(o_{3,1}=0.0159+0.1173=0.1332\)。
  • 头 2：查询 \(1\)，三个键 \((1,\ 0,\ 1)\)，分数 \((1,\ 0,\ 1)\)；指数 \((2.7183,\ 1,\ 2.7183)\)，和 6.4366；权重 \((0.4223,\ 0.1554,\ 0.4223)\)。三个值 \((0,\ 1,\ 1)\)，输出 \(o_{3,2}=0.1554+0.4223=0.5777\)。

同一个位置，头 1 把 87% 的权重给了 cat，头 2 只给 cat 16%，把其余权重平分给 The 和 sat 自己。单头时（§3）只有一套折中的权重 \((0.0743,\ 0.6200,\ 0.3057)\)。两位评委，两套看法。

数学。 这就是方程组的 (1.3)–(1.6)。GPT-2 small 取 \(n_h=12\)、\(d_h=d/n_h=64\)：

多头注意力\[\mathbf o_{t,i}=\sum_{j\le t}\softmax_j\!\Big(\frac{\mathbf q_{t,i}^\top\mathbf k_{j,i}}{\sqrt{d_h}}\Big)\mathbf v_{j,i},\qquad \mathbf u_t=W^O\begin{pmatrix}\mathbf o_{t,1}\\\vdots\\\mathbf o_{t,n_h}\end{pmatrix}+\mathbf b^O\]\(\mathbf q_{t,i},\mathbf k_{t,i},\mathbf v_{t,i},\mathbf o_{t,i}\in\R^{d_h}\)；\(W^O\in\R^{d\times n_hd_h}\)；\(i=1,\dots,n_h\) 是头的编号。(1.21)

拆头不花任何计算。 黑板上的两个头，只是把 2 维向量的两个坐标分开读。GPT-2 也一样：把 12 个头的 \(W^Q_i\) 按行叠起来，就是一个 \(768\times768\) 的大矩阵 \(W^Q\)；大矩阵乘 \(\bar{\mathbf h}_t\) 得到的 768 维向量，按顺序每 64 个数切一段，第 \(i\) 段就是 \(\mathbf q_{t,i}\)（分块乘法，M01 §4）。所以代码先用一次大乘法算出全部查询，再 reshape 成 \([12,T,64]\)。GPT-2 更进一步，把 \(W^Q,W^K,W^V\) 拼成一个 c_attn，一次乘完再切成三份 4；按本课的列写法它是 \(2304\times768\)，代码按行写法转置存放，形状是 \([768,2304]\)（§1 的“代码里的两处约定”）。

合头：\(W^O\) 在做什么。 把 \(W^O\) 按列切成 12 块 \(W^O_i\in\R^{d\times d_h}\)，分块乘法给出：

拼接再乘 \(W^O\) = 每个头各写一份、再相加
(1)\(\displaystyle W^O\big[\mathbf o_{t,1};\dots;\mathbf o_{t,n_h}\big]=\big[W^O_1\ \cdots\ W^O_{n_h}\big]\begin{pmatrix}\mathbf o_{t,1}\\\vdots\\\mathbf o_{t,n_h}\end{pmatrix}\)把 \(W^O\) 按列分成 \(n_h\) 块，每块 \(d_h\) 列
(2)\(\displaystyle =\sum_{i=1}^{n_h}W^O_i\,\mathbf o_{t,i}\)分块乘法：内侧维度被切开时，结果是各块乘积之和
\(W^O\) 的另一种读法\[\mathbf u_t=\sum_{i=1}^{n_h}W^O_i\,\mathbf o_{t,i}+\mathbf b^O,\qquad W^O_i\in\R^{d\times d_h}\]每个头用自己的“写入矩阵” \(W^O_i\) 把 64 维的结果映射回 768 维，12 份相加。Elhage 等人指出，“拼接再乘”与“各头独立相加”在数学上等价 8。(1.22)
黑板上 · 两位评委的意见怎么合成一份

接着上面的两个头。拼接得 \((0.1332,\ 0.5777)\)。取 \(W^O=\begin{pmatrix}1&0.5\\-1&1\end{pmatrix}\)，按 (1.22) 读：头 1 经第 1 列 \(W^O_1=(1,-1)^\top\) 写入 \(0.1332\,(1,-1)\)，头 2 经第 2 列 \(W^O_2=(0.5,\ 1)^\top\) 写入 \(0.5777\,(0.5,\ 1)\)，相加得 \(\mathbf u_3=(0.4220,\ 0.4445)\)（忽略偏置）。直接计算 \(W^O(0.1332,\ 0.5777)^\top\)，结果一样。

如果 \(W^O=I\)，头 1 只能写第 1 个坐标、头 2 只能写第 2 个；换成一般的 \(W^O\)，两个头都能写到两个坐标上。

(1.22) 回答了“\(W^O\) 做什么”。第一，它把每个头的 64 维结果放回 768 维的残差流：没有它，12 个头的输出只能拼成 768 维，第 \(i\) 个头永远只能写第 \(64(i-1)+1\) 到 \(64i\) 这 64 个坐标，而下一层想从哪些方向读取信息，是由下一层自己的 \(W^Q,W^K,W^V\) 决定的，不一定是这 64 个坐标。第二，它让头与头的结果混合：残差流上的同一个方向可以同时接收好几个头的贡献。黑板上 \(\mathbf u_3\) 的两个坐标里都有两个头的份儿，就是这个意思。

“多个子空间”是什么意思。 第 \(i\) 个头的打分（忽略偏置）是 \(\bar{\mathbf h}_t^\top(W^Q_i)^\top W^K_i\bar{\mathbf h}_j\)，中间的 \(768\times768\) 矩阵是一个 \([768,64]\) 与一个 \([64,768]\) 相乘，秩至多是 64。几何上，这个头只通过一个 64 维的“窗口”比较两个 768 维的状态，窗口之外的方向它看不见（M01 §6）。黑板上的窗口更窄：头 1 只看得见第 1 个坐标，所以它眼里 cat 的键是 2、sat 的是 1。12 个头有 12 个不同的窗口，所以位置 \(t\) 能同时按 12 种标准挑选前文。

多个小头不比一个大头贵。 一个 768 维的大头，打分要 \(2T^2d\) 次运算；12 个 64 维的小头各 \(2T^2d_h\)，合计 \(12\times2T^2\times64=2T^2\times768\)，一样多（M01 §4）。原论文也说，由于每个头的维度变小了，多头的总计算量与全维度的单头相近 3。多出来的只是 \(n_h\) 次 softmax，而 softmax 相对于矩阵乘法可以忽略。

那么头是不是越多越好？

头数的实测效果与 GPT-2 的参数账

原论文的消融实验（机器翻译，表 3 的 (A) 行，保持总计算量不变）3：基线是 8 个头、每头 64 维，BLEU 25.8、困惑度 4.92。改成 1 个 512 维的头，BLEU 降到 24.9（低 0.9），困惑度升到 5.29；16 个头与 8 个头持平；32 个头、每头只有 16 维时，BLEU 又降到 25.4。头太少，一个位置只能按一种标准取信息；头太多，每个头的窗口太窄。

GPT-2 small 一层注意力的参数。 融合的 c_attn：\(768\times2304+2304=1{,}771{,}776\)；输出投影 \(W^O\) 加偏置：\(768\times768+768=590{,}592\)；合计 \(2{,}362{,}368\)，其中偏置只占 3,072 个。忽略偏置就是 \(4d^2=4\times768^2=2{,}359{,}296\)，§8 会用到这个 \(4d^2\)。

组件卡 · 多头与 \(W^O\)

含义：把注意力拆成 12 个 64 维的头，各自独立地选择看哪里，再由 \(W^O\) 把 12 份结果合起来写回残差流。

数学意义：拆头是对 \(W^Q,W^K,W^V\) 按行分块（不花运算）；每个头的打分是一个秩至多为 \(d_h\) 的双线性形式；合头 \(W^O[\mathbf o_{t,1};\dots;\mathbf o_{t,n_h}]=\sum_iW^O_i\mathbf o_{t,i}\)。

逻辑意义：一个 softmax 只能给出一种权重分配，多头让一个位置同时按多种标准取信息，而总运算量不变。\(W^O\) 让每个头的结果能写到残差流的任意方向上，并与其他头的结果叠加。

这一页讲了三件事
  • 第一，除以 \(\sqrt{d_k}\) 是为了让分数不随头宽变尖。 就像抛硬币：\(d_k\) 个独立、方差为 1 的数相加，标准差是 \(\sqrt{d_k}\)（黑板上 4 次硬币标准差 2，64 次是 8）。除以它，分数方差回到 1，等于把 softmax 的温度固定下来；这是一个估算和一个选择，不是最优性证明。
  • 第二，因果掩码是 softmax 之前加的 \(-\infty\)。 黑板上 cat 那一行盖掉 sat 之后是 \((0.8044,0.1956,0)\)，不用再归一化。配合逐位置运算，位置 \(t\) 的一切结果只依赖 \(x_1,\dots,x_t\)：并行训练诚实，旧位置的 K、V 可以精确缓存（第 4 课）。
  • 第三，多头 = 几套独立的 softmax，总运算量不变。 黑板上两个头对 cat 的权重是 87% 与 16%；\(\mathbf u_t=\sum_iW^O_i\mathbf o_{t,i}\)，每个头经自己的 \(W^O_i\) 写回残差流。GPT-2 small 一层注意力 2,362,368 个参数 \(\approx4d^2\)。

前馈网络：每个位置自己的键值记忆

大家都背过乘法口诀。看到“七八”，“五十六”直接就冒出来了，用不着现场去数七个八相加。“五十六”不在题目里，它是你脑子里早就存好的一条记忆：“七八”是钥匙，“五十六”是钥匙打开以后取出来的东西。

注意力负责在位置之间搬运信息。这一页讲块里的另一个子层：前馈网络（feed-forward network，FFN），方程 (1.8)。它不跨位置，却占了每个块三分之二的参数。我们会看到，它可以读成一张“钥匙 → 内容”的记忆表，只不过钥匙和内容都是向量。

问题：注意力只会“搬运”，不会“加工”

先看注意力在做什么样的运算。把权重 \(\alpha_{t,j}\) 看作已经算好，输出 \(\mathbf o_t=\sum_j\alpha_{t,j}\mathbf v_j=\sum_j\alpha_{t,j}(W^V\bar{\mathbf h}_j+\mathbf b^V)\) 对各位置的隐藏状态是线性的，再乘 \(W^O\) 也还是线性的。注意力唯一的非线性藏在权重的 softmax 里，它决定“从哪里搬”，而搬过来的内容只经过了线性变换。

线性变换再怎么叠也还是线性变换：两个矩阵相乘仍是一个矩阵（M01 §2）。用一个数来看最清楚：先乘 2 再乘 3，等于直接乘 6，两步合成了一步，什么新东西也没多出来。可要是在中间夹一个非线性，比如把负数变成 0 的 ReLU，\(3\cdot\mathrm{ReLU}(2x)\) 在 \(x=1\) 时是 6、在 \(x=-1\) 时是 0，就不再是任何“乘一个数”能写出来的函数了。如果网络里只有注意力，每个位置能表达的“加工”方式非常有限。我们需要在每个位置上再放一个有足够容量的非线性函数，把搬来的信息和自己原有的信息组合、变换成新的特征。

形式化：两层、4 倍宽、逐位置

含义。 FFN 是一个两层的全连接网络：先把 768 维升到 3072 维，过一个非线性函数，再降回 768 维。

理解。 它对每个位置单独、用同一套参数计算，位置之间互不相干，所以叫“逐位置”（position-wise）的前馈网络 3。可以把它想成传送带旁的一个加工工位：每个 token 路过时被同一台机器加工一次。

数学。

前馈网络\[\FFN(\mathbf x)=W_2\,\mathrm{GELU}(W_1\mathbf x+\mathbf b_1)+\mathbf b_2,\qquad W_1\in\R^{d_{ff}\times d},\ \ W_2\in\R^{d\times d_{ff}},\ \ d_{ff}=4d\]GPT-2 small：\(768\to3072\to768\)。原 Transformer 用 ReLU \(\max(0,x)\)，GPT 系列换成 GELU 3,5。(1.23)

参数量：\(W_1\) 与 \(\mathbf b_1\) 共 \(768\times3072+3072=2{,}362{,}368\)，\(W_2\) 与 \(\mathbf b_2\) 共 \(3072\times768+768=2{,}360{,}064\)，合计 \(4{,}722{,}432=8d^2+5d\)。注意力一层是 \(4d^2+4d\)（§4），所以 FFN 占了两个子层权重的 \(8/12=2/3\)。Geva 等人的论文开篇第一句说的就是这件事：前馈层占了 Transformer 参数的三分之二 9。

为什么偏偏是 4 倍？ 这是惯例，不是推论。原论文只给了数值 \(d_{ff}=2048=4\times512\)，没有解释 3；它的表 3 (C) 行改过这个数：\(d_{ff}=1024\) 时困惑度 5.12、BLEU 25.4，\(4096\) 时 4.75、26.2（基线 2048 是 4.92、25.8），越宽越好，但参数也越多。GPT-3 的论文说它“总是”让前馈层是瓶颈层的四倍宽 10。第 5 课会看到，换成 SwiGLU 之后常用的 \(\tfrac83d\) 也是在“保持参数量不变”这个约束下从 4 倍推出来的。

黑板上：一个只有 3 条记忆的 FFN

768 升到 3072 太大，我们在黑板上把它缩成 2 升到 3。

黑板上 · 按 (1.23) 老老实实算一遍

取 \(d=2\)、\(d_{ff}=3\)，偏置都为 0。\(W_1\) 是 \(3\times2\)，三行分别是 \((1,0)\)、\((0,1)\)、\((-1,-1)\)；\(W_2\) 是 \(2\times3\)，三列分别是 \((1,1)\)、\((-1,2)\)、\((3,0)\)。输入 \(\mathbf x=(1.5,\ 0.5)\)。

  • 升维。 \(W_1\mathbf x\)：每一行和 \(\mathbf x\) 做点积，\((1.5,\ 0.5,\ -2)\)。
  • 过 GELU。 GELU 的定义是 (1.13) 的 \(x\,\Phi(x)\)，本页最后一节细讲，这里先照公式算：\(\mathrm{GELU}(1.5)=1.5\,\Phi(1.5)=1.5\times0.93319=1.39979\)；\(\mathrm{GELU}(0.5)=0.5\times0.69146=0.34573\)；\(\mathrm{GELU}(-2)=-2\times0.02275=-0.04550\)。
  • 降维。 \(W_2\) 乘 \((1.39979,\ 0.34573,\ -0.04550)\)，就是把 \(W_2\) 的三列按这三个数加权相加：\(1.39979\,(1,1)+0.34573\,(-1,2)-0.04550\,(3,0)=(0.91756,\ 2.09125)\)。

大家看最后一步：输出是 \(W_2\) 三列的加权和，权重由 \(\mathbf x\) 和 \(W_1\) 三行的点积决定。这像什么？像不像上两页的注意力：比一比，再按比的结果把一些向量加起来？

键值记忆：换一种读法

对，就是一回事。把 (1.23) 的两个矩阵按行、按列拆开，FFN 就能读成一张“键–值”表，和注意力摆在一起比较。记 \(W_1\) 的第 \(m\) 行为 \(\mathbf k_m^\top\)（\(\mathbf k_m\in\R^{d}\)），\(W_2\) 的第 \(m\) 列为 \(\mathbf v_m\in\R^{d}\)，\(m=1,\dots,d_{ff}\)：

把 FFN 写成 3072 条“键–值”的加权和
(1)\(\displaystyle W_1\mathbf x+\mathbf b_1=\big(\mathbf k_1^\top\mathbf x+b_{1,1},\ \dots,\ \mathbf k_{d_{ff}}^\top\mathbf x+b_{1,d_{ff}}\big)^\top\)矩阵乘向量的“批量点积”读法：每一行与 \(\mathbf x\) 做点积
(2)\(\displaystyle c_m:=\mathrm{GELU}\big(\mathbf k_m^\top\mathbf x+b_{1,m}\big),\qquad m=1,\dots,d_{ff}\)GELU 逐元素作用，得到 \(d_{ff}\) 个系数
(3)\(\displaystyle W_2\,\mathbf c=\sum_{m=1}^{d_{ff}}c_m\,\mathbf v_m\)矩阵乘向量的“列的加权和”读法（M01 §2）
(4)\(\displaystyle \FFN(\mathbf x)=\sum_{m=1}^{d_{ff}}\mathrm{GELU}\big(\mathbf k_m^\top\mathbf x+b_{1,m}\big)\,\mathbf v_m+\mathbf b_2\)合起来
FFN 的键值记忆读法\[\FFN(\mathbf x)=\sum_{m=1}^{d_{ff}}\underbrace{\mathrm{GELU}\big(\mathbf k_m^\top\mathbf x+b_{1,m}\big)}_{\text{第 }m\text{ 条记忆被“唤起”的程度}}\ \mathbf v_m+\mathbf b_2\]Geva 等人的式 (1) 写作 \(\mathrm{FF}(\mathbf x)=f(\mathbf x\cdot K^\top)\cdot V\)（行向量写法，忽略偏置），并把它与记忆网络 \(\mathrm{softmax}(\mathbf x\cdot K^\top)\cdot V\) 对照：两者只差非线性是否归一化 9。(1.24)

代回黑板：三把钥匙是 \(\mathbf k_1=(1,0)\)、\(\mathbf k_2=(0,1)\)、\(\mathbf k_3=(-1,-1)\)，三份内容是 \(\mathbf v_1=(1,1)\)、\(\mathbf v_2=(-1,2)\)、\(\mathbf v_3=(3,0)\)。第 1 条记忆被强烈唤起（1.39979），第 2 条中等（0.34573），第 3 条的钥匙和输入方向相反，几乎没被唤起，只“漏”出一点负值（−0.04550）。换成 ReLU，第 3 条的系数会恰好是 0。输出 \((0.91756,\ 2.09125)\) 主要是 \(\mathbf v_1\) 的样子。

读成文字就是：FFN 里存着 \(d_{ff}=3072\) 条“记忆”，每条由一个键 \(\mathbf k_m\) 和一个值 \(\mathbf v_m\) 组成；输入 \(\mathbf x\) 与每个键比一比（点积），GELU 把比对结果变成“这条记忆被唤起多少”，最后把被唤起的值按程度加起来。开头那句“七八五十六”就是一条记忆。但是乘法口诀这个比方有个地方不对：口诀是一问一答，只取一条；FFN 是 3072 条记忆同时被不同程度地唤起，再加在一起；而且钥匙和内容都是学出来的向量，不是人能直接读的字。

它和注意力是同一个骨架（比对键 → 算权重 → 加权求和值），区别只在键值从哪里来、权重怎么算：

注意力 FFN
键、值从哪来 由上下文里的其他 token 现算：\(\mathbf k_j=W^K\bar{\mathbf h}_j\) 训练好的参数本身：\(W_1\) 的行、\(W_2\) 的列
有多少条 \(t\) 条（随上下文变长） 固定 3072 条

黑板上三个系数 \(1.39979+0.34573-0.04550=1.70002\)，并不等于 1：这就是表里第三行“不必和为 1”。

这个读法有实证支持，但它是一种解释框架。 Geva 等人在一个 16 层、\(d=1024\)、\(d_{ff}=4096\) 的语言模型（共 65,536 个键）上做了分析：许多键与训练文本中可以辨认的模式相关，值则在输出词表上诱导出一个分布；低层（第 1–9 层）的键更多对应浅层的模式（如重复出现的 n-gram、以同一个词结尾的前缀），高层（第 10–16 层）的键更多对应语义层面的模式（如同一个话题）9。这些是实测结论，针对的是他们分析的那个模型。第 17 课的 Engram 会把“用查表存知识”这个想法推得更远。

很多人以为：FFN 里每个神经元都对应一个能读懂的概念

很多人以为：既然 FFN 是“记忆表”，那 3072 条记忆里每一条都该对应一个人能叫出名字的东西，比如“首都”或者“过去时”。

其实：Geva 等人发现的是许多键与可辨认的文本模式相关，而且这是针对他们分析的那一个模型 9。它说明 (1.24) 这个读法有用，并不意味着每个神经元都有一个人类能读懂的含义。黑板上的钥匙 \((1,0)\) 是我们为了手算挑的；训练出来的钥匙是 768 维向量，没有人给它们起名字。

GELU：按大小加权，而不是按正负一刀切

含义。 GELU（Gaussian error linear unit，高斯误差线性单元）定义为 \(\mathrm{GELU}(x)=x\,\Phi(x)\)，其中 \(\Phi\) 是标准正态分布的累积分布函数（\(\Phi(x)\) = 一个标准正态随机变量小于 \(x\) 的概率）11。

理解。 ReLU 按符号决定去留：\(x>0\) 就原样通过，否则变成 0，像一扇只有开和关的门。GELU 按大小给权重：把 \(x\) 乘上一个介于 0 和 1 之间的“通过概率” \(\Phi(x)\)。\(x\) 很大时 \(\Phi(x)\approx1\)，几乎原样通过；\(x\) 很负时 \(\Phi(x)\approx0\)，几乎被关掉；在 0 附近则是平滑过渡。黑板上 \(\Phi(1.5)=0.93319\)，1.5 几乎原样通过；\(\Phi(-2)=0.02275\)，−2 几乎被关掉。原论文的说法是：它按输入的值加权，而不是按输入的符号门控 11。

数学。 见方程组 (1.13)。几个可以用计算器核对的值：\(\mathrm{GELU}(1)=0.84134\)，\(\mathrm{GELU}(-1)=-0.15866\)，\(\mathrm{GELU}(2)=1.95450\)，\(\mathrm{GELU}(-3)=-0.00405\)；最小值约为 \(-0.170\)，出现在 \(x\approx-0.752\) 处。它处处光滑，而且在负半轴有一个小小的“下凹”：与 ReLU 不同，它不是单调的。

\(\Phi\) 本身要用误差函数 \(\mathrm{erf}\) 计算，原论文给了两个近似：tanh 形式（方程组 (1.13) 第二行）和 \(x\,\sigma(1.702x)\)，作者说他们的所有实验都用前者 11。GPT-2 的官方代码用的正是 tanh 近似：0.5*x*(1+tanh(sqrt(2/pi)*(x+0.044715*x^3))) 4；Hugging Face 把它叫作 gelu_new 2。在 \([-6,6]\) 上，tanh 近似与精确值的最大误差是 \(4.73\times10^{-4}\)（在 \(x\approx-2.70\) 处），sigmoid 近似是 \(2.03\times10^{-2}\)（在 \(x\approx2.27\) 处）；\(\abs{x}\) 更大时两种误差都趋于 0，所以这也是整条实轴上的最大误差。

GPT 为什么用 GELU 而不是 ReLU？ GPT-1 的报告只写了“用了 GELU”，没有给理由 5，本课也没有找到说明动机的一手资料。GELU 处处可导、在 0 附近平滑，这是它与 ReLU 的数学区别；在 GPT 的规模上这带来多大好处，所引论文里没有对照实验。第 5 课会讲后来普遍换成的 SwiGLU。

组件卡 · 前馈网络（FFN）

含义：每个位置独立地过一个 \(768\to3072\to768\) 的两层网络，把注意力搬来的信息与自身信息加工成新特征。

数学意义：\(\FFN(\mathbf x)=W_2\,\mathrm{GELU}(W_1\mathbf x+\mathbf b_1)+\mathbf b_2\)；等价地，\(\sum_m\mathrm{GELU}(\mathbf k_m^\top\mathbf x+b_{1,m})\,\mathbf v_m+\mathbf b_2\)，是 3072 条“键–值记忆”的加权和（再加一个固定偏置），权重互相独立、不归一化。

逻辑意义：注意力对值是线性的，只负责搬运；FFN 提供每个位置上的非线性与大容量（每层 \(8d^2\) 个参数，占权重的 2/3），模型的大部分“知识”被认为存储在这里。去掉它，网络在每个位置上几乎只剩线性变换。

这一页讲了三件事
  • 第一，FFN 负责加工。 注意力对值是线性的，只会搬运；FFN 逐位置作用：\(768\to3072\to768\)，GELU 夹在中间，每层 \(8d^2+5d=4{,}722{,}432\) 个参数，是注意力的两倍。4 倍宽是惯例，没有理论推导；原论文的消融显示更宽更好，但更贵。
  • 第二，FFN 可以读成一张记忆表。 \(\FFN(\mathbf x)=\sum_m\mathrm{GELU}(\mathbf k_m^\top\mathbf x+b_{1,m})\mathbf v_m+\mathbf b_2\)：黑板上三条记忆被唤起 1.39979、0.34573、−0.04550，输出 \((0.91756,2.09125)\)。与注意力相比，键值是固定参数，权重不归一化；这是有实证支持的解释框架，不是每个神经元都有名字。
  • 第三，GELU 是按大小加权的软门控。 \(\mathrm{GELU}(x)=x\Phi(x)\)；GPT-2 用 tanh 近似，与精确值的最大误差约 \(4.73\times10^{-4}\)。

残差流与 LayerNorm

大家玩过传话游戏吧：第一个人悄悄说一句话，一个传一个，传过十几个人，到最后一个人嘴里，常常面目全非。

GPT-2 small 有 24 个子层。信号从嵌入走到输出，要传 24 手；训练时，梯度还要从输出倒着传回来，又是 24 手。怎么才能不走样？前面几页的每个子层都有一个共同的动作：从残差流上“读一份”，算完之后“加回去”。这一页讲这两个动作本身：加回去是残差连接，它让深层网络训练得动；读一份之前先归一化是 LayerNorm，它控制每个子层看到的数值尺度。最后讲 GPT-2 把 LayerNorm 挪了位置这件事，以及它背后的一个定理。

残差连接：每层只学“改多少”

问题。 把几十个非线性层直接串起来，会出两类麻烦。第一，如果某一层最好“什么都不做”，它得费力学出一个恒等映射，而一个随机初始化的非线性层离恒等映射很远。第二，反向传播时梯度要依次乘上每一层的导数（雅可比矩阵）；如果每层都让梯度缩小一点，比如乘 0.9，那么 24 层之后只剩 \(0.9^{24}\approx0.080\)，最底下的层几乎学不到东西，这就是梯度消失（vanishing gradient）。这就是传话游戏：每传一手丢一点，传 24 手就所剩无几。

传话游戏有个简单的补救：让写着原话的纸条跟着一起往下传，每个人只许在纸条上添批注，不许重写。

含义。 残差连接（residual connection）就是这张纸条：一层的输出等于“输入 + 这一层算出的修正量”，而不是完全由这一层重新算出。He 等人的原始写法是：想让一组层拟合映射 \(\mathcal H(\mathbf x)\)，不如让它们拟合残差 \(\mathcal F(\mathbf x)=\mathcal H(\mathbf x)-\mathbf x\)，输出写成 12

残差连接\[\mathbf y=\mathcal F(\mathbf x,\{W_i\})+\mathbf x\]恒等捷径不增加任何参数，也几乎不增加计算 12。GPT 的 (1.7) \(\mathbf h'_t=\mathbf h^{(l-1)}_t+\mathbf u_t\) 与 (1.9) \(\mathbf h^{(l)}_t=\mathbf h'_t+\mathbf m_t\) 都是这个形式。(1.25)

理解。 “什么都不做”现在变得很容易：让 \(\mathcal F\) 输出 0 就行，而一个权重很小的层输出本来就接近 0。每一层只需要学“在现有基础上改多少”。

小故事 · 残差连接来自图像识别

残差连接不是为语言模型发明的。它出自 He 等人 2016 年的论文《Deep Residual Learning for Image Recognition》：他们要训练的是很深的图像识别网络，恒等捷径不增加参数和计算，却让很深的网络也训练得动 12。

残差流：所有子层共用的一条总线

把 (1.7)(1.9) 从第 1 块一直展开到第 \(L\) 块，整条残差流就写成了一个求和：

把 L 个块的残差连接一路展开
(1)\(\displaystyle \mathbf h^{(l)}_t=\mathbf h^{(l-1)}_t+\mathbf u^{(l)}_t+\mathbf m^{(l)}_t\)把 (1.7) 代入 (1.9)；上标 \((l)\) 标出这是第 \(l\) 块的增量
(2)\(\displaystyle \mathbf h^{(L)}_t=\mathbf h^{(L-1)}_t+\mathbf u^{(L)}_t+\mathbf m^{(L)}_t=\mathbf h^{(L-2)}_t+\sum_{l=L-1}^{L}\big(\mathbf u^{(l)}_t+\mathbf m^{(l)}_t\big)\)对 \(\mathbf h^{(L-1)}_t\) 再用一次同一个式子
(3)\(\displaystyle \mathbf h^{(L)}_t=\mathbf h^{(0)}_t+\sum_{l=1}^{L}\big(\mathbf u^{(l)}_t+\mathbf m^{(l)}_t\big)\)一直展开到第 0 层（望远镜求和）
残差流 = 嵌入 + 所有子层增量之和\[\mathbf h^{(L)}_t=\underbrace{E^\top\mathbf e_{x_t}+P^\top\mathbf e_t}_{\text{嵌入}}+\sum_{l=1}^{L}\big(\underbrace{\mathbf u^{(l)}_t}_{\text{注意力写入}}+\underbrace{\mathbf m^{(l)}_t}_{\text{FFN 写入}}\big)\]GPT-2 small：1 份嵌入 + 24 份增量，每一份都是 768 维向量。(1.26)

最后一行就是那张纸条：原话（嵌入）一直都在，24 个人的批注（增量）一条条加上去。这就是残差流（residual stream）的观点：Elhage 等人把残差流描述为此前所有层的输出与原始嵌入之和，它本身不做任何处理，所有层都通过它来通信 8。每个子层先从流上读一份（经过 LayerNorm），算出一个增量，再把增量写回流上。因为一切都是加法，流上的 768 个坐标没有哪一个是“特殊的”，Elhage 等人称之为残差流没有“特权基”（privileged basis）：信息可以存在任何方向上，一个子层写下的方向要靠后面的子层用自己的矩阵去读 8。

类比：残差流 = 传送带

映射。 残差流是一条传送带，每个位置的 768 维向量是带上的一件货；24 个子层是带子旁边的 24 个工位。每个工位先看一眼（LayerNorm 之后读一份），加工出一个增量，再把增量放回带上（⊕）。没人动的货原样往下走，这就是恒等映射。

收益。 它让 (1.26) 一眼可见：终点的货 = 起点的货 + 每个工位放上去的东西；放回的增量必须与货同形，所以宽度处处是 768。它也预告了第 16 课：Hyper-Connections 把一条带子扩成几条，mHC 要求带子之间的调度“守恒”。

但是这个比方有两个地方不对。 真实的“件”是连续向量空间里的一个点，“放回”是向量加法：两个工位放上去的增量可以互相抵消，也可以叠加成一个新方向，这是实物传送带没有的。工位也不是只拿走一件货来加工：注意力工位会同时看带上其他位置的货。

梯度高速公路

纸条保住了前向的信号。反向的梯度呢？我们在黑板上把网络缩成 3 层来看。

黑板上 · 3 层网络里，梯度有几条路

把每一层都想成一个“很会缩小梯度”的层：梯度穿过它，只剩十分之一。为了能手算，把每层的导数（雅可比矩阵）当成一个数，\(J=0.1\)。

没有残差：梯度要依次穿过 3 层，\(0.1\times0.1\times0.1=0.001\)。千分之一，基本没了。

有残差：每一层是 \(h\leftarrow h+f(h)\)，导数是 \(1+0.1=1.1\)，三层乘起来 \(1.1^3=1.331\)。把乘积展开：

\[(1+0.1)(1+0.1)(1+0.1)=1+3\times0.1+3\times0.01+0.001=1+0.3+0.03+0.001\]

每一项都是梯度走的一条路：在每一层，它要么走捷径（乘 1），要么穿过这一层（乘 0.1）。3 层一共 \(2^3=8\) 条路：1 条全走捷径，贡献 1；3 条只穿过一层，各 0.1；3 条穿过两层，各 0.01；1 条三层都穿过，0.001。没有残差的网络，只剩最后那一条路。

好，现在把 3 换成 \(L-l\)，把数换成矩阵。记第 \(l\) 块两个分支合起来的雅可比矩阵为 \(J_l=\partial(\mathbf u^{(l)}_t+\mathbf m^{(l)}_t)/\partial\mathbf h^{(l-1)}_t\)。

这里要交代一个细节（第一次读可以跳过这一段）。\(J_l\) 是只让同一位置的 \(\mathbf h^{(l-1)}_t\) 变动、其他位置固定时的雅可比矩阵。注意力让 \(\mathbf h^{(l)}_t\) 还依赖 \(j<t\) 的旧状态，但下面的乘积对 \(\partial\mathbf h^{(L)}_t/\partial\mathbf h^{(l)}_t\) 仍然是精确的：由 §4 的因果性，\(\mathbf h^{(l)}_t\) 的变动只会传到位置 \(\ge t\)，而位置 \(t\) 在每一层只读位置 \(\le t\)，所以从 \(\mathbf h^{(l)}_t\) 到 \(\mathbf h^{(L)}_t\) 的每一条路都始终走在位置 \(t\) 上。损失对 \(\mathbf h^{(l)}_t\) 的梯度还要加上经过后面位置 \(s>t\) 的那些项；把 \(T\) 个位置的状态拼成一个 \(Td\) 维向量、\(J_l\) 取整段序列的雅可比矩阵，下面每一行也原样成立，只是 \(I\) 变成 \(Td\times Td\) 的单位矩阵。雅可比矩阵与链式法则见 §4 的前置框，M06 §7 从 \(\mathbf x+f(\mathbf x)\) 的导数讲起，专讲这条路。

反向传播穿过 L−l 个残差块
(1)\(\displaystyle \dfrac{\partial\mathbf h^{(l)}_t}{\partial\mathbf h^{(l-1)}_t}=I+J_l\)对 \(\mathbf h^{(l)}_t=\mathbf h^{(l-1)}_t+(\mathbf u^{(l)}_t+\mathbf m^{(l)}_t)\) 求导，恒等项求导得单位矩阵
(2)\(\displaystyle \dfrac{\partial\mathbf h^{(L)}_t}{\partial\mathbf h^{(l)}_t}=(I+J_L)(I+J_{L-1})\cdots(I+J_{l+1})\)链式法则：逐层相乘
(3)\(\displaystyle =I+\sum_{k=l+1}^{L}J_k+\sum_{k>k'}J_kJ_{k'}+\cdots\)把乘积展开：第一项永远是 \(I\)
梯度高速公路\[\frac{\partial\mathbf h^{(L)}_t}{\partial\mathbf h^{(l)}_t}=I+\sum_{k=l+1}^{L}J_k+(\text{两个及以上 }J\text{ 的乘积})\]无论中间的层把梯度缩小多少，恒等项 \(I\) 这一条路径都把顶层的梯度原样送到第 \(l\) 层。没有残差连接时，这里只有 \(J_LJ_{L-1}\cdots J_{l+1}\) 这一项。总梯度是所有项之和，其余项可以加强它，也可以部分抵消它；恒等项保证的是“有一条不经过任何 \(J\) 的路”，不是总和的大小。(1.27)

代回黑板：\(L-l=3\)，每个 \(J_k=0.1\)。\(I\) 对应 1，\(\sum J_k\) 对应 \(0.3\)，两两的乘积对应 \(0.03\)，三个的乘积对应 \(0.001\)，正是图 1.14 的四组路。

对照开头的例子：若每个子层让梯度乘 0.9，没有残差时 24 层之后剩 \(0.9^{24}\approx0.080\)；有残差时，至少还有一条“乘 1”的直达路径。这是残差结构给出的结构性保证，不依赖训练得好不好。

初始化要跟着层数缩小。 (1.26) 说残差流是 \(2L\) 份增量之和。GPT-2 的报告说，它在初始化时把残差层的权重乘以 \(1/\sqrt N\)，\(N\) 是残差层的数目 1。Hugging Face 和 nanoGPT 把 \(N\) 解读为 \(2L\)（每块两个残差分支），对每个输出投影（\(W^O\) 与 \(W_2\)）用标准差 \(0.02/\sqrt{2L}\) 初始化；GPT-2 small 是 \(0.02/\sqrt{24}\approx0.00408\) 2,6。值得注意的是，OpenAI 公开的 GPT-2 代码是推理代码，里面每个线性层的权重都按标准差 0.02 初始化（只有位置表 wpe 是 0.01），并没有这一步 4。这个缩放的用意可以这样理解（笔者的推导）：若 \(2L\) 份增量在初始化时近似独立、各自方差为 \(\sigma^2\)，它们之和的方差是 \(2L\sigma^2\)，标准差是 \(\sqrt{2L}\,\sigma\)（GPT-2 small 是 \(\sqrt{24}\approx4.90\) 倍）；把每份的标准差乘以 \(1/\sqrt{2L}\)，总和的方差就回到 \(\sigma^2\)，与层数无关。这和 §4 里抛硬币、除以 \(\sqrt{d_k}\) 是同一个“独立变量之和”的道理。

组件卡 · 残差连接与残差流

含义：每个子层的输出不替换输入，而是加到输入上；整条残差流是嵌入与所有子层增量之和。

数学意义：\(\mathbf h^{(l)}=\mathbf h^{(l-1)}+\mathbf u^{(l)}+\mathbf m^{(l)}\)，展开为 (1.26)；反向时 \(\partial\mathbf h^{(L)}/\partial\mathbf h^{(l)}\) 总含单位矩阵 \(I\) (1.27)。

逻辑意义：让每层只学“改多少”，“什么都不做”变得容易；给梯度一条不衰减的直达路径，使几十层的网络可训练；并给所有子层一条共享的、线性可加的通信总线。代价是：流上的东西只加不删，尺度会随深度累积，这正是下面 LayerNorm 要处理的问题。

LayerNorm：控制每个子层看到的尺度

问题。 残差流是几十份增量之和，它的大小会随深度变化；到了某一层，流上向量的长度可能是嵌入层的好几倍。而子层对输入的尺度很敏感：§4 说过，查询和键的长度直接决定 softmax 的温度；GELU 在输入的不同尺度上表现也完全不同（接近线性，或接近 ReLU）。我们希望每个子层读到的输入都有一个稳定的尺度，不管它处在第几层。

含义。 层归一化（layer normalization，LayerNorm）把每个 token 自己的 \(d\) 个分量减去它们的均值、除以它们的标准差，再乘一个可学习的缩放 \(\boldsymbol\gamma\)、加一个可学习的平移 \(\boldsymbol\beta\)。

理解。 就像把每份答卷先换算成“标准分”，再按需要统一调整：不管原始分数整体偏高还是偏低、分散还是集中，换算后都在同一个尺度上。关键是统计量只在同一个 token 的 768 个分量上计算，不跨 token、不跨样本，所以训练和推理时的计算完全一样（这是它与 batch normalization 的区别）13。但是这个比方有个地方不对：学校的标准分是拿一个人的分数和全体考生比，LayerNorm 却是拿一个分量和同一个 token 的其他分量比，更像把一份答卷里 768 道小题的得分互相比较；换算之后还要乘 \(\boldsymbol\gamma\)、加 \(\boldsymbol\beta\)，模型可以学着把某些分量重新放大。

我们在黑板上换算三份“答卷”。

黑板上 · 三份答卷，一个结果

取 \(d=4\)，\(\boldsymbol\gamma=\mathbf 1\)，\(\boldsymbol\beta=\mathbf 0\)。第一份答卷 \(\mathbf x=(2,4,6,8)\)：

  • 减均值。 均值 \(\mu=(2+4+6+8)/4=5\)，减掉之后是 \((-3,\ -1,\ 1,\ 3)\)。
  • 除标准差。 方差 \(\sigma^2=\big((-3)^2+(-1)^2+1^2+3^2\big)/4=20/4=5\)，标准差 \(\sqrt5\approx2.2361\)。于是
\[\begin{aligned} \LayerNorm(\mathbf x)&=\Big(\frac{-3}{2.2361},\ \frac{-1}{2.2361},\ \frac{1}{2.2361},\ \frac{3}{2.2361}\Big)\\ &=(-1.3416,\ -0.4472,\ 0.4472,\ 1.3416). \end{aligned}\]

第二份答卷整体放大 10 倍，\((20,40,60,80)\)：均值 50，方差 500，标准差 22.361，结果还是 \((-1.3416,\ -0.4472,\ 0.4472,\ 1.3416)\)。第三份整体加 100 分，\((102,104,106,108)\)：均值 105，方差 5，结果还是这四个数。

三份答卷，一个结果：LayerNorm 对整体放大和整体平移都不敏感（忽略 \(\epsilon\)）。再量一下结果的长度：\(\sqrt{1.3416^2\times2+0.4472^2\times2}=2=\sqrt d\)。

数学。 就是方程组的 (1.12)：先减 \(\mu\)，再除以 \(\sqrt{\sigma^2+\epsilon}\)，最后逐分量乘 \(\boldsymbol\gamma\)、加 \(\boldsymbol\beta\)。Ba 等人的原式没有 \(\epsilon\) 13；实现里在方差上加一个很小的 \(\epsilon=10^{-5}\) 防止除以 0 4,2。代回黑板：\(\sigma^2=5\) 加上 \(10^{-5}\)，前四位小数不变。

几何意义。 黑板上那个长度 \(\sqrt d\) 不是巧合。减去均值，等于把 \(\mathbf x\) 投影到与全 1 向量 \(\mathbf 1\) 垂直的超平面上（M01 §6 的投影）；再除以标准差，由 \(\sum_k(x_k-\mu)^2=d\,\sigma^2\) 得 \(\norm{\mathbf x-\mu\mathbf 1}/\sigma=\sqrt d\)。所以在乘 \(\boldsymbol\gamma\)、加 \(\boldsymbol\beta\) 之前，LayerNorm 的输出总是落在一个半径为 \(\sqrt d\) 的球面上（\(d=768\) 时半径约 27.7）。这里有两个前提：忽略 \(\epsilon\)（带上它，半径是 \(\sqrt d\,\sigma/\sqrt{\sigma^2+\epsilon}\)，略小于 \(\sqrt d\)）；\(\mathbf x\) 的分量不全相等（否则 \(\sigma=0\)，输出是零向量）。它丢掉了“长度”这一个自由度和“均值”这一个自由度，只保留方向。这就是“尺度控制”的准确含义。

参数账。 每个 LayerNorm 有 \(\boldsymbol\gamma,\boldsymbol\beta\) 两个 \(d\) 维向量，共 \(2d=1536\) 个参数。GPT-2 small 每块 2 个、最后 1 个，共 25 个，合计 \(25\times1536=38{,}400\) 个参数，只占总数的 0.031%。它们便宜，但位置很重要。

Post-LN 与 Pre-LN：GPT-2 挪了什么

LayerNorm 放在哪里，有两种做法。原 Transformer 把它放在每个子层之后、残差相加之后：\(\mathbf x_{l+1}=\LayerNorm(\mathbf x_l+\mathrm{Sublayer}(\mathbf x_l))\) 3，后来称为 Post-LN。GPT-2 把它挪到每个子层的输入处，并在整个堆栈之后加一个最终 LayerNorm 1,4，即方程组里的 (1.2)(1.8)(1.10)，称为 Pre-LN：

两种放法（每个子层）\[\begin{aligned} \text{Post-LN：}&\quad \mathbf x_{l+1}=\LayerNorm\big(\mathbf x_l+\mathrm{Sublayer}(\mathbf x_l)\big)\\ \text{Pre-LN：}&\quad \mathbf x_{l+1}=\mathbf x_l+\mathrm{Sublayer}\big(\LayerNorm(\mathbf x_l)\big) \end{aligned}\]\(\mathbf x_l\in\R^{d}\) 是第 \(l\) 个子层之前残差流上的向量，\(\mathrm{Sublayer}\) 是注意力或 FFN。Post-LN 的主干上每一步都要经过 LayerNorm；Pre-LN 的主干上只有加法，LayerNorm 只在分支里。(1.28)

用传话游戏的话说：Pre-LN 是每个人先把纸条誊一份、整理好了再看，批注加在原纸条上；Post-LN 是每个人加完批注，把整张纸条重新誊写一遍再往下传。后一种做法，原话每一手都被“重写”了一次。

Xiong 等人的定理。 为什么这个挪动重要？Xiong 等人在一个简化的设定下分析了初始化时的梯度 14。他们的假设必须一起说清：单头注意力；\(W^Q,W^K\) 初始化为 0（注意力退化为均匀平均）；所有权重都是 \(d\times d\)；输入向量也从同一个高斯分布采样；FFN 用 ReLU；并对若干向量的范数做了“以高概率有界”的假设。在这个设定下，他们的定理 1 说：

初始化时最后一层 FFN 权重的梯度（Xiong 等 2020，定理 1）

以至少 \(0.99-\delta-\frac{\epsilon}{0.9+\epsilon}\) 的概率，

\[\text{Post-LN：}\ \Big\|\frac{\partial\tilde{\mathcal L}}{\partial W^{2,L}}\Big\|_F\le\mathcal O\big(d\sqrt{\ln d}\big),\qquad \text{Pre-LN：}\ \Big\|\frac{\partial\tilde{\mathcal L}}{\partial W^{2,L}}\Big\|_F\le\mathcal O\Big(d\sqrt{\tfrac{\ln d}{L}}\Big)\]

\(\tilde{\mathcal L}\) 是该定理所分析的训练损失（一个标量，记号沿用原文），\(W^{2,L}\in\R^{d\times d}\) 是第 \(L\) 层（最后一层）FFN 的第二个权重矩阵，\(\norm{\cdot}_F\) 是 Frobenius 范数（所有元素平方和再开方），\(\epsilon,\delta\) 来自上述有界性假设（这里的 \(\epsilon\) 沿用原文记号，与 LayerNorm 里的 \(\epsilon=10^{-5}\) 无关）。Post-LN 的上界与层数 \(L\) 无关，Pre-LN 的上界随 \(L\) 增大而按 \(1/\sqrt L\) 变小。

直观的来源是他们的两个引理。引理 2 就是图 1.16 (c)：Pre-LN 的残差流范数平方随层数线性增长。引理 3 说 LayerNorm 的雅可比矩阵的范数与输入的范数成反比，约为 \(\sqrt d/\norm{\mathbf x}\)。两者合起来：Pre-LN 最后那个 LayerNorm 的输入越深越大，于是把传回来的梯度按 \(1/\sqrt L\) 缩小了；Post-LN 没有这个效果，顶层的梯度在训练一开始就很大。

实测后果：warm-up。 顶层梯度一开始就很大，意味着一开始就用较大的学习率会把训练搞坏。所以 Post-LN 必须先用很小的学习率“热身”（warm-up），再逐渐增大；Pre-LN 可以去掉这一步 14。他们在 IWSLT14 德英翻译上的实验：Post-LN 不用 warm-up、直接用 Adam，BLEU 只有 8.45；用了 warm-up，约 34 14。学习率调度本身是第 2 课的内容。

三个常见的说法：很多人以为……其实……

很多人以为 Pre-LN 是 GPT-2 发明的。 其实不是。GPT-2 的报告自己说这一改动类似于“pre-activation”的残差网络 1；Xiong 等人说 Pre-LN 此前已经在若干系统里实现过 14。本课没有确定最早的出处。

很多人以为 Transformer 原论文用的是 Pre-LN。 其实论文的 §3.1 写的是 Post-LN 3；但 Google 的官方代码库 tensor2tensor 后来把默认配置改成了 Pre-LN：2017 年 6 月的早期版本与论文一致，是 Post-LN；2017 年 10 月的 v1.2.5 加入 transformer_base_v2（Pre-LN），并让默认的 transformer_base 改用它，transformer_base_v1 则保留论文的 Post-LN 15。论文与代码不一致，说哪个版本要讲清楚。

很多人以为 GPT-2 的最终 LayerNorm 在最后一个自注意力之后。 报告的字面说法确实如此，但代码里的 ln_f 位于全部 12 个块（包括最后一个 FFN）之后、输出层之前 1,4。本课以代码为准。

Pre-LN 也有代价（笔者推论）。 由引理 2，Pre-LN 的残差流越来越长，而每个子层的输入先经过 LayerNorm、增量的尺度大致固定，所以越往深处，单个子层的增量占整条流的比例越小。这是笔者的直观推论，不是所引论文的结论。Post-LN 与 Pre-LN 各有代价，这个两难是第 16 课 mHC 的出发点之一；第 5 课则把 LayerNorm 换成更便宜的 RMSNorm。

组件卡 · LayerNorm

含义：把每个 token 的 768 个分量减均值、除标准差，再做一次可学习的逐分量缩放和平移。

数学意义：\(\boldsymbol\gamma\odot(\mathbf x-\mu\mathbf 1)/\sqrt{\sigma^2+\epsilon}+\boldsymbol\beta\)；在 \(\boldsymbol\gamma,\boldsymbol\beta\) 之前，输出是投影到 \(\mathbf 1^\perp\) 超平面、再缩放到半径 \(\sqrt d\) 球面上的向量，对输入的整体放大与平移不变。

逻辑意义：让每个子层读到尺度稳定的输入，不受残差流随深度累积的影响。放在分支里（Pre-LN）时，主干保持一条只有加法的直路，训练更稳，可以去掉 warm-up；放在主干上（Post-LN）时，顶层梯度在初始化时偏大。

这一页讲了三件事
  • 第一，残差连接让每层只学增量，并给梯度留一条直路。 \(\mathbf y=\mathbf x+\mathcal F(\mathbf x)\)；残差流 \(\mathbf h^{(L)}=\mathbf h^{(0)}+\sum_l(\mathbf u^{(l)}+\mathbf m^{(l)})\) 是所有子层共享的线性总线，没有特权基。反向时 \(\partial\mathbf h^{(L)}/\partial\mathbf h^{(l)}=I+\cdots\)（黑板上 3 层：\(1.331=1+0.3+0.03+0.001\)，没有残差只剩 0.001）；残差分支的初始化按 \(1/\sqrt{2L}\) 缩小（Hugging Face / nanoGPT 的解读）。
  • 第二，LayerNorm 在每个 token 的 \(d\) 个分量上归一化。 去均值、缩放到半径 \(\sqrt d\) 的球面，再乘 \(\boldsymbol\gamma\) 加 \(\boldsymbol\beta\)；黑板上三份答卷得到同一个 \((-1.3416,-0.4472,0.4472,1.3416)\)。GPT-2 small 全部 LN 只有 38,400 个参数。
  • 第三，LN 放哪里有讲究。 Post-LN 的主干穿过 LN，Pre-LN 的主干只有加法。Xiong 等人的定理：初始化时 Post-LN 顶层梯度 \(\mathcal O(d\sqrt{\ln d})\)，Pre-LN 为 \(\mathcal O(d\sqrt{\ln d/L})\)；所以 Post-LN 需要 warm-up。

输出：从向量回到词表

大家玩过“你比划我猜”吧：一个人比划，另一个人盯着看，脑子里把能想到的词过一遍，挑一个最像的喊出来。

GPT 的最后一步也是这样猜词。12 个块之后，每个位置 \(t\) 手里是一条 768 维的向量 \(\mathbf h^{(12)}_t\)，这就是它的“比划”。它要拿这条向量和 50,257 个候选词逐个比一比，给每个词打一个分，再把分数变成概率，也就是方程组的 (1.10)(1.11)。§1 黑板上那 5 个概率，就要在这一页算出来。这一页讲这最后三步，然后把整次前向传播的形状从头到尾追一遍。

最终 LayerNorm

Pre-LN 的残差流越往深处越长（§6 图 1.16），如果直接拿 \(\mathbf h^{(12)}_t\) 去算 logits，logits 的整体大小、也就是 softmax 的“温度”，会随层数漂移。所以 GPT-2 在所有块之后、输出层之前加了一个 LayerNorm（代码名 ln_f），记它的输出为 \(\tilde{\mathbf h}_t=\LayerNorm_f(\mathbf h^{(12)}_t)\) 1,4。它只有 1,536 个参数。

反嵌入：与每个 token 做一次点积

含义。 反嵌入（unembedding）是嵌入的反方向：嵌入把 token 编号变成 \(d\) 维向量，反嵌入把 \(d\) 维向量变回“每个 token 一个分数”。这些分数叫 logits。

理解。 可以把 \(\tilde{\mathbf h}_t\) 看成一个查询，拿它去和词表里 50,257 个 token 的“标签”逐一比对；比对的分数越高，这个 token 越可能是下一个。这和注意力的打分是同一种运算，只是“键”换成了固定的 token 向量，而且不做加权平均，只要分数。但是“你比划我猜”这个比方有个地方不对：人猜词只会想到几个候选，模型却老老实实地和词表里每一个 token 都比一次，一个不落。

还是回到 5 个词的世界，在黑板上比一次。

黑板上 · 一个 5 个词的输出层

用图 1.4 (b) 的玩具例子：词表 {the, cat, sat, on, mat}，\(d=3\)，嵌入表 \(E\) 就是 §2 黑板上那张 \(5\times3\) 的表，最终向量 \(\tilde{\mathbf h}=(-0.4,\ 2.0,\ 0.6)\)。

  • 比一比。 拿 \(\tilde{\mathbf h}\) 和 \(E\) 的每一行做点积。例如 sat 那一行是 \((-0.3,0.8,0.1)\)：\(z_{\text{sat}}=(-0.3)(-0.4)+0.8\times2.0+0.1\times0.6\)，也就是 \(0.12+1.60+0.06=1.78\)。五个词都算完，logits 是 \(\mathbf z=E\tilde{\mathbf h}=(-0.04,\ 0.12,\ 1.78,\ 0.32,\ 0.22)\)。
  • 变概率。 \(\log\sum_we^{z_w}=\log(0.9608+1.1275+5.9299+1.3771+1.2461)\)，也就是 \(\log10.6414=2.3647\)。\(\log p(\text{sat})=1.78-2.3647=-0.5847\)，\(p(\text{sat})=e^{-0.5847}=0.557\)。五个概率是 \((0.090,\ 0.106,\ 0.557,\ 0.129,\ 0.117)\)，精确值加起来等于 1（这五个三位小数是四舍五入后的值，相加得 0.999）。

大家翻回 §1 对一对：就是那张表里的 5 个数。

再做一个实验：把 \(\tilde{\mathbf h}\) 放大一倍，logits 也放大一倍，\(p(\text{sat})\) 变成 0.862。最终向量的长度起着温度的作用，这正是为什么需要 ln_f 来稳住它。

数学。 用输入嵌入表 \(E\in\R^{V\times d}\) 本身来打分（为什么可以这样，见下一节）：

反嵌入与 logits\[\mathbf z_t=E\,\tilde{\mathbf h}_t\in\R^{V},\qquad z_{t,v}=E_{v,:}\cdot\tilde{\mathbf h}_t=\sum_{k=1}^{d}E_{vk}\,\tilde h_{t,k}\]第 \(v\) 个 logit 是最终向量与第 \(v\) 个 token 的嵌入向量的点积。形状 \([V,d]\times[d]\to[V]\)；整段序列是 \(\tilde H E^\top\)，\([T,768]\times[768,50257]\to[T,50257]\)。(1.29)

代回黑板：\(V=5\)、\(d=3\)，\(z_{\text{sat}}=\sum_kE_{\text{sat},k}\tilde h_k=1.78\)，一模一样。

logits 这个词。 含义：未经归一化的分数，可正可负。理解：它们本身不是概率，只有相对大小有意义，所有 logits 同时加一个常数，概率不变（softmax 的平移不变性，§3）。数学：取对数之后，概率与 logits 只差一个与 \(v\) 无关的常数：

对数概率 = logit − log-sum-exp
(1)\(\displaystyle p_\theta(x_{t+1}=v\mid x_{\le t})=\dfrac{e^{z_{t,v}}}{\sum_{w}e^{z_{t,w}}}\)(1.11)
(2)\(\displaystyle \log p_\theta(x_{t+1}=v\mid x_{\le t})=z_{t,v}-\log\sum_{w}e^{z_{t,w}}\)两边取自然对数；分母对所有 \(v\) 相同

黑板上用的就是这一行：\(\log p(\text{sat})=1.78-2.3647\)。所以 logits 就是“差一个公共常数的对数概率”。第 2 课会看到，训练的损失正是 \(-\log p_\theta(\text{真实的下一个 token})\)，也就是 \(-z_{t,v^\star}+\log\sum_we^{z_{t,w}}\)。

很多人以为：logits 就是概率，或者就是“分数越高越好”的绝对分

很多人以为：logit 是 0.12，意思就是 12% 的概率；或者 logit 本身有一个绝对的大小含义。

其实：logits 可正可负，加起来也不等于 1，只有差值有意义。黑板上 5 个 logits 同时加 10，概率一个都不变；而 \(\tilde{\mathbf h}\) 放大一倍，logits 的差值跟着放大，\(p(\text{sat})\) 就从 0.557 变成 0.862。要读成概率，必须过一次 softmax。

这一步很贵。 黑板上只比了 5 次。GPT-2 small 每个位置要做 50,257 个 768 维的点积，约 \(2dV=77{,}194{,}752\) 次运算（§8 会看到它占了 GPT-2 small 前向运算的约 29%）。训练时 \(T=1024\) 个位置一起算，logits 张量是 \(1024\times50257=51{,}463{,}168\) 个数，按 32 位浮点约 205.9 MB，比一整层的参数还大得多。

权重共享：同一个 E 用两次

含义。 权重共享（weight tying）是让输出层的打分矩阵就是输入嵌入矩阵 \(E\)，而不是另学一个 \(V\times d\) 的矩阵。黑板上 §2 取 cat 那一行、这一页拿 \(\tilde{\mathbf h}\) 去比的，是同一张表。

理解。 输入端，\(E\) 的第 \(v\) 行回答“token \(v\) 该用哪个向量表示”；输出端，\(E\) 的第 \(v\) 行回答“最终向量指向哪个方向时，下一个词该是 \(v\)”。两者都是“token 与 \(d\) 维方向之间的一本对照词典”，共用一本，既省参数，也让两端的几何一致。

数学。 GPT-1 报告的输出公式直接写成 \(P(u)=\mathrm{softmax}(h_nW_e^\top)\)（行写法：\(h_n\) 每行一个位置），\(W_e\) 就是输入的词嵌入矩阵 5；GPT-2 的代码是 logits = tf.matmul(h_flat, wte, transpose_b=True) 4；《Attention Is All You Need》也让两个嵌入层与 softmax 前的线性层共享同一个矩阵 3。原论文为这个做法引用的是 Press 与 Wolf：他们发现把输入嵌入与输出嵌入绑成同一个矩阵，能降低多种语言模型的困惑度，在神经机器翻译里还能把模型缩小到原来的一半以下而不损失性能 16。

小故事 · 权重共享并非首创

Press 与 Wolf 自己交代过：这个做法不是他们第一个用的。更早的 log-bilinear 模型（Mnih 与 Hinton，2009）已经这样用过，只是没有解释为什么、也没有检验效果；Inan 等人同期独立地给出了另一种解释 16。

共享省了多少

GPT-2 small 的 \(E\) 有 \(50{,}257\times768=38{,}597{,}376\) 个参数。不共享的话，输出层要再多这么多，总参数从 124,439,808 变成 163,037,184，多出 31%。对 GPT-2 xl（\(d=1600\)），这一项是 80,411,200，只占其总数 1,557,611,200 的约 5%：共享对小模型省得最多。

共享还改变了 \(E\) 的学习方式。§2 说过，输入端只有出现过的 token 那几行会拿到梯度；输出端却不同：softmax 对所有 50,257 个 logits 都有梯度（第 2 课会推出它等于“预测概率减去独热目标”），所以每一步训练，\(E\) 的每一行都会从输出端得到更新。

类比的边界：两种角色并不完全相同

输入端要的是“这个 token 本身是什么”，输出端要的是“什么样的上下文之后该出现它”。两者相关但不相同，共享是一个选择，不是推论；所引文献报告的是困惑度的改善和参数的节省 16。

组件卡 · 反嵌入、权重共享与 softmax

含义：用最终向量与每个 token 的嵌入向量做点积得到 logits，再用 softmax 变成下一词的概率；打分矩阵与输入嵌入共用。

数学意义：\(\mathbf z_t=E\,\LayerNorm_f(\mathbf h^{(L)}_t)\)，\(\log p(v)=z_{t,v}-\log\sum_we^{z_{t,w}}\)；每个 logit 是一个点积，概率对 logits 的整体平移不变。

逻辑意义：把 \(d\) 维的内部表示翻译回离散的词表，产生可以计算损失、可以采样的分布。共享 \(E\) 让输入与输出的“词典”一致，GPT-2 small 省下 3,860 万个参数（占 31%）；代价是一个矩阵要同时服务两种角色。

生成：把这一切放进一个循环（预告第 4 课）

训练时，一次前向传播给出 \(T\) 个位置的分布。生成时，我们只关心最后一个位置的分布：从中选出一个 token（怎么选、温度和 top-p 采样，是第 4 课的内容），把它接到序列末尾，再做一次前向传播，如此循环。这正是开头那个输入法候选栏：挑一个词，再给下一个词排候选。

§4 的归纳证明说，追加新 token 不会改变任何旧位置的结果，所以每一步真正需要新算的，只有新 token 自己那一列，外加它的查询要和所有旧位置的键、值做注意力。于是可以把旧位置的 \(\mathbf k,\mathbf v\) 存起来，这就是 KV cache。GPT-2 small 每个 token 要存 12 层 × 2（K 和 V）× 768 个数，按 16 位浮点是 \(2\times12\times768\times2=36{,}864\) 字节 = 36 KiB，1024 个 token 就是 36 MiB；同样算法下 GPT-3 175B（96 层、\(d=12288\)）每个 token 要 4.5 MiB。这笔“字节账”是第 4 课、第 9 课的主角。

这一页讲了三件事
  • 第一，输出层是“和每个词比一比”。 最终 LayerNorm ln_f 稳住尺度；反嵌入 \(\mathbf z_t=E\tilde{\mathbf h}_t\)，每个 logit 是最终向量与一个 token 嵌入的点积。黑板上 \(z_{\text{sat}}=1.78\)，\(p(\text{sat})=0.557\)，正是 §1 那张表。
  • 第二，logits 是差一个公共常数的对数概率。 \(\log p(v)=z_v-\log\sum_we^{z_w}\)，第 2 课的损失由此而来。权重共享让输出层复用 \(E\)，GPT-2 small 省下 38,597,376 个参数（总数的 31%），输出端让 \(E\) 的每一行每步都得到梯度。
  • 第三，全程形状：\([T]\to[T,768]\to\cdots\to[T,50257]\)。 只有注意力内部出现 \([T,T]\)；参数逐步相加恰为 124,439,808。生成时旧位置的 K、V 可以缓存：GPT-2 small 每 token 36 KiB（fp16）。

小故事 · 117M 和 124M

124,439,808 正是 OpenAI 仓库现在给 GPT-2 small 起的名字 “124M” 的来历。GPT-2 报告的表 2 印的是 117M；官方仓库后来在说明里承认，最初的参数计数有误 1,4。至于当初是怎么算错的，仓库没有说；练习 8 带大家做一回侦探。

\(12Ld^2\) 从哪里来。 当 \(d\) 很大时，每块的 \(13d\) 远小于 \(12d^2\)（在 GPT-2 small 里，\(13d/12d^2\) 只有 0.14%），略去它，再略去块外的嵌入和 LayerNorm，就得到 Kaplan 等人的近似 17：

非嵌入参数的近似\[N\approx2\,d\,L\,(2d_{attn}+d_{ff})=12\,L\,d^2\qquad(d_{attn}=d,\ d_{ff}=4d)\]12 = 注意力的 4（\(Q,K,V,O\) 四个 \(d\times d\) 矩阵）+ FFN 的 8（两个 \(d\times4d\) 矩阵）。Kaplan 等人把 \(N\) 定义为不含嵌入的参数量，式 (2.1) 17。(1.31)

代回黑板，这个近似就不灵了：玩具 GPT 的非嵌入参数是 \(244+8=252\)，\(12Ld^2\) 只有 192，差了近四分之一。原因是 \(d=4\) 时 \(13d=52\) 相对 \(12d^2=192\) 一点也不小（27%）。所以 \(12Ld^2\) 是一个“\(d\) 大才准”的近似。

运算量：每个 token 约 2N

参数数完了，再数运算。还是先上黑板，看一个 \(2\times3\) 的小矩阵。

黑板上 · 一个权重，两次运算

\(W\) 是 \(2\times3\)，带偏置 \(\mathbf b\)，乘一个 3 维向量 \(\mathbf x\)。第一个输出是 \(y_1=b_1+w_{11}x_1+w_{12}x_2+w_{13}x_3\)：3 次乘法，3 次加法（从偏置开始往上加）。第二个输出一样。合计 6 次乘法、6 次加法，12 次运算。

这个矩阵有 6 个权重。12 除以 6 等于 2：每个权重，对每个 token，一次乘法加一次加法。

推导。 M01 §5 数过：一个 token 经过一个 \(m\times k\) 的权重矩阵，要做 \(mk\) 次乘法和 \(mk\) 次加法，共 \(2mk\) 次运算，而 \(mk\) 正是这个矩阵的参数个数。所以每个权重、每个 token，两次运算。把一个块里所有的矩阵乘加起来：

每个 token 的前向运算量
(1)\(\displaystyle 2\times(3d^2+d^2+4d^2+4d^2)=24d^2\)每块的四组权重矩阵：\(W_{qkv}\)、\(W^O\)、\(W_1\)、\(W_2\)，每个参数 2 次运算
(2)\(\displaystyle L\times24d^2=2\times12Ld^2\approx2N\)\(L\) 个块；偏置、LayerNorm、GELU、softmax 的运算相对很少，略去
(3)\(\displaystyle +\ 4\,t\,d\ \text{（每层，位置 }t\text{）}\)注意力的打分 \(QK^\top\) 与加权求和 \(AV\)：位置 \(t\) 与 \(t\) 个位置各做一次 \(d\) 维点积，两步各 \(2td\)
(4)\(\displaystyle +\ 2dV\)反嵌入：与 \(V\) 个 token 各做一次 \(d\) 维点积；共享的 \(E\) 不计入 \(N\)，但运算照做

注意力那一项不含参数，却随上下文长度增长，而且不同文献的算法差一倍。Kaplan 等人的表 1 把它记为每 token \(2\,n_{layer}\,n_{ctx}\,d_{attn}\) 17；PaLM 的附录和 Chinchilla 论文的附录按整张 \(T\times T\) 表计算，相当于每 token \(4LTd\) 18,19。一个自洽的解释是（笔者推导，Kaplan 的论文没有这样说明）：因果模型里位置 \(t\) 只和 \(t\) 个位置做注意力，每层 \(4td\)，对 \(t=1,\dots,T\) 取平均约为 \(2Td\)；而稠密实现往往先算满整张表再掩码，就是 \(4Td\)。

用黑板上的小数验一下这个解释。\(T=4\)：4 个位置分别和 1、2、3、4 个位置做注意力，每层合计 \(4d\times(1+2+3+4)=40d\)，平均每个 token \(10d\)，也就是 \(2(T+1)d\)；\(T\) 大时 \(T+1\approx T\)，就是 Kaplan 的 \(2Td\)。先算满整张表再掩码，每个 token 都是 \(4Td=16d\)，这是 PaLM 的口径。

每个 token 的前向运算量\[C_{fwd}\approx\underbrace{2N}_{\text{权重矩阵乘}}+\underbrace{2LTd}_{\text{注意力（Kaplan 口径）}}\quad\Big[+\underbrace{2dV}_{\text{反嵌入}}\Big],\qquad N\approx12Ld^2\]Kaplan 等人的式 (2.2) 只有前两项，而且 \(N\) 不含嵌入 17；按 PaLM 口径，注意力项是 \(4LTd\) 18。(1.32)
GPT-2 small，T = 1024
  • 权重矩阵乘：\(2\times12\times12\times768^2=169{,}869{,}312\)。
  • 注意力（Kaplan 口径）：\(2\times12\times1024\times768=18{,}874{,}368\)，是前一项的 11%；按 PaLM 口径翻倍为 \(37{,}748{,}736\)。
  • 反嵌入：\(2\times768\times50{,}257=77{,}194{,}752\)。
  • 合计（Kaplan 口径，含反嵌入）：\(265{,}938{,}432\)，约 \(2.66\times10^8\) 次运算。反嵌入占其中 29%。

一个有用的巧合：共享嵌入的小模型里，“\(2\times\)（总参数 − 位置表）”\(=2\times123{,}653{,}376=247{,}306{,}752\)，与真实的矩阵乘运算量 \(169{,}869{,}312+77{,}194{,}752=247{,}064{,}064\) 只差 0.1%。因为共享的 \(E\) 在输出端被用了一次“乘法”，它的每个参数也贡献了 2 次运算。

注意力项什么时候追上权重项？ 令 \(2LTd=2\cdot12Ld^2\)，得 \(T=12d\)；按 PaLM 口径是 \(T=6d\)。GPT-2 small：\(12d=9{,}216\)、\(6d=4{,}608\)，都远大于它的上下文 1024，所以在 GPT-2 上注意力只占小头（Kaplan 口径 10.0%）。GPT-3 175B 的 \(12d=147{,}456\)，在 2048 的上下文下注意力项只有 \(4.83\times10^9\)，占“权重 + 注意力”的 \(2048/(147{,}456+2048)=1.37\%\)（若权重项改用表 D.1 的 \(2N=349.2\times10^9\)，是 1.36%，见练习 6）。这就是 Kaplan 等人说“当 \(d_{model}>n_{ctx}/12\) 时，与上下文有关的计算只占小部分”的来历 17。可是当上下文长到十几万、上百万 token（第 14、18、19 课）时，比例就反过来了。

很多人以为：Transformer 的运算主要花在注意力上

很多人以为：注意力是 \(T^2\) 的，所以 Transformer 的运算大头一定是注意力。

其实：要看 \(T\) 和 \(d\) 谁大。每个 token 的注意力运算约 \(2LTd\)，权重运算约 \(24Ld^2\)，前者要到 \(T=12d\) 才追上后者。GPT-2 small 在 \(T=1024\) 时注意力只占“权重 + 注意力”的 10.0%，GPT-3 175B 在 \(T=2048\) 时只占 1.37%。\(T^2\) 的账单是真的，但在这些模型的上下文长度下，它还排不上第一；上下文长到十几万 token 以后才轮到它。

两个预告：训练的 6N，解码的带宽

训练约 \(6N\)。 反向传播要为每个权重矩阵算两次矩阵乘（对输入的梯度、对权重的梯度），运算量约为前向的两倍，所以训练一个 token 约 \(2N+4N=6N\) 次运算；训练 \(D\) 个 token 就是 \(6ND\)。第 2 课会推导它，并用它来谈 scaling law。

解码受带宽限制。 生成一个新 token 时，运算量仍是约 \(2N\)，可是这 \(2N\) 次运算要把 \(N\) 个权重（外加整份 KV cache）从显存里读一遍，每读一个数只做两次运算。第 4 课会说明，这使得解码的速度由显存带宽而不是算力决定，这也是 DeepSeek 一再想办法少存、少读 KV cache 的根本原因：第 9、18、19 课压缩缓存本身，第 14 课的稀疏注意力则不减少缓存、只让每一步少读一些。

最后给大家留个问题

这一课我们把 GPT-2 small 拆到了最后一个参数：124,439,808 个，每一个在哪、是什么形状、每个 token 要为它做几次运算，都清清楚楚。可是有一件事，这一课一个字都没提：这些参数的值是多少？

刚造好的 GPT-2，权重矩阵里全是随机数：GPT-2 的代码按标准差 0.02 的正态分布初始化它们，位置表 wpe 按 0.01 4。拿这样一台机器去接“The cat sat on the”，它没有任何理由把 mat 排在 quantum 前面。

大家先想一想：怎样把一堆随机数，变成一个会接话的模型？提示一下。第一，§7 说 \(\log p=z_v-\log\sum_we^{z_w}\)，而训练的损失正是 \(-\log p_\theta(\text{真实的下一个 token})\)。这个数该往哪个方向推？一次前向给出 1024 个诚实的预测（§4），一段训练文本就是 1024 道题。第二，训练一个 token 约 \(6N\) 次运算。一个 1.24 亿参数的模型，要读多少个 token 才算“读够了”？给定一笔算力，模型该做多大、数据该喂多少？

怎样把随机数训练成语言模型，又该花多少算力？ 这就是 第 2 课 要揭晓的问题。

这一页讲了三件事
  • 第一，参数量可以一个不差地数出来。 \(N_{total}=(V+T_{max})d+L(12d^2+13d)+2d\)：黑板上的玩具 GPT 是 308，GPT-2 small 是 124,439,808（报告误印 117M）。非嵌入参数 \(\approx12Ld^2\)：注意力 \(4d^2\) + FFN \(8d^2\)；\(d\) 小时这个近似不准（玩具差 24%），小模型里嵌入占比也不能忽略（GPT-2 small 31.6%）。
  • 第二，每个权重、每个 token 两次运算。 前向 \(\approx2N\)；再加注意力 \(2LTd\)（Kaplan，因果平均）或 \(4LTd\)（PaLM，算满整张表），以及反嵌入 \(2dV\)（小模型里不可忽略，GPT-2 small 占 29%）。注意力项在 \(T=12d\)（或 \(6d\)）时才追上权重项。
  • 第三，两个预告。 训练 \(\approx6N\) 每 token（第 2 课）；解码受带宽限制（第 4 课）。而这些参数的值从哪来，是第 2 课的问题。

概念题

练习 1 · 让查询和键共用一个矩阵

假设某个头令 \(W^Q=W^K=W\)，且没有偏置。（a）这个头的打分表 \(S\)（掩码之前）有什么性质？（b）模型因此失去了什么表达能力？

看答案

（a）\(S_{tj}=(W\bar{\mathbf h}_t)^\top(W\bar{\mathbf h}_j)=\bar{\mathbf h}_t^\top W^\top W\bar{\mathbf h}_j\)，中间的 \(W^\top W\) 是对称矩阵，所以 \(S_{tj}=S_{jt}\)：打分表对称。对角线 \(S_{tt}=\norm{W\bar{\mathbf h}_t}^2\ge0\)。

（b）“\(t\) 需要 \(j\) 的程度”被迫等于“\(j\) 需要 \(t\) 的程度”。可语言里的关系常常是不对称的：动词要找它的主语，主语却不一定需要找这个动词。用两个不同的矩阵，打分矩阵 \((W^Q)^\top W^K\) 一般不对称（§3；黑板上 sat 找 cat 是 4 分，cat 找 sat 是 2 分），模型才能表达这种方向性。

练习 2 · 掩码为什么加在 softmax 之前

用 §3 手算例子的第 2 行（缩放后的分数 \((1.4142,\ 0,\ 1.4142)\)）说明：如果先对整行做 softmax、再把第 3 格清零，会得到什么？怎样修补才能与“先加 \(-\infty\)”一致？

看答案

整行 softmax：\(e^{1.4142}=4.1133\)，\(e^0=1\)，\(e^{1.4142}=4.1133\)，和为 9.2266，权重 \((0.4458,\ 0.1084,\ 0.4458)\)。把第 3 格清零后得 \((0.4458,\ 0.1084,\ 0)\)，和只有 0.5542，不再是一个分布，输出也会被整体缩小。

修补办法是清零后再除以剩下的和：\((0.4458,0.1084)/0.5542=(0.8044,\ 0.1956)\)，正是 §3 里加掩码得到的结果，也就是 §4 黑板上给 cat 那一行“盖上纸”的结果。先加 \(-\infty\) 一步就做到了“清零 + 重新归一化”（§4 的推导）。

练习 3 · 主干上有几个 LayerNorm

对 12 层的模型，数一数从嵌入到输出层之间，残差主干上要穿过几个 LayerNorm：（a）Post-LN；（b）Pre-LN（GPT-2）。这和 §6 的“梯度高速公路”有什么关系？

看答案

（a）Post-LN 每个子层之后都在主干上做一次 LayerNorm，12 层共 24 个。（b）Pre-LN 的 24 个 LayerNorm 都在分支里，主干上只有最后的 ln_f 一个。

梯度高速公路 (1.27) 说 \(\partial\mathbf h^{(L)}/\partial\mathbf h^{(l)}\) 含一个单位矩阵 \(I\)，前提是主干上只有加法。Post-LN 的主干每一步都乘上一个 LayerNorm 的雅可比矩阵，直达路径不再是 \(I\)，而是 24 个雅可比矩阵的乘积（用 §6 黑板上的话说，那条贡献恒为 1 的绿线不见了）。Xiong 等人正是从 LayerNorm 雅可比矩阵的大小（引理 3）入手分析梯度尺度的；他们对其他层的初步分析（细节在附录）还认为，Post-LN 的梯度在靠近输出的层最大、并可能随层号降低而衰减，Pre-LN 则各层大致相同，6 层模型上的实测梯度范数也是这样 14。

（b）\(2\times96\times12288\times2=4{,}718{,}592\) 字节 = 4.5 MiB 每 token；2048 个 token 是 \(9{,}663{,}676{,}416\) 字节 = 9 GiB。光一条序列的缓存就要 9 GiB，这就是第 4 课和第 9 课要解决的问题。

练习 8 · “117M”从哪里来（侦探题）

GPT-2 报告表 2 印的四个规模是 117M、345M、762M、1542M，官方仓库只说“计数有误”。大家试着用 (1.30) 但把词表换成 GPT-1 的 40,478 来计算四个规模，看看会得到什么。再算 GPT-1 本身（\(V=40{,}478\)，\(T_{max}=512\)，Post-LN、没有最终 LayerNorm）的参数量。

看答案

把 \(V=40{,}478\)、\(T_{max}=1024\) 代入 \((V+T_{max})d+L(12d^2+13d)+2d\)：small \(116.93\)M，medium \(344.81\)M，large \(761.51\)M，xl \(1541.96\)M，四舍五入恰好是 117、345、762、1542。GPT-1：\((40{,}478+512)\times768+12\times(12\times768^2+13\times768)=116{,}534{,}784\approx117\)M。

四个数全部吻合，提示报告里的数字可能是用 GPT-1 的词表算出来的。但这只是推测：OpenAI 从未说明错在哪里。它是一个好例子，说明为什么论文里的数字值得自己算一遍。

练习 9 · 方差估算的推广

设 \(\mathbf q,\mathbf k\in\R^{d_k}\) 的分量相互独立、均值为 0，\(\Var(q_i)=\sigma_q^2\)，\(\Var(k_i)=\sigma_k^2\)。（a）求 \(\Var(\mathbf q^\top\mathbf k)\)。（b）要让分数方差为 1，应除以多少？（c）若只知道 \(d_k=128\) 且 \(\sigma_q=\sigma_k=1\)，不缩放时分数的标准差是多少？

看答案

（a）沿用 §4 的推导：\(\Var(q_ik_i)=\E[q_i^2]\E[k_i^2]-(\E[q_i]\E[k_i])^2=\sigma_q^2\sigma_k^2\)；\(d_k\) 项独立，方差相加：\(\Var(\mathbf q^\top\mathbf k)=d_k\sigma_q^2\sigma_k^2\)。

（b）除以 \(\sigma_q\sigma_k\sqrt{d_k}\)。标准做法只除以 \(\sqrt{d_k}\)，隐含了 \(\sigma_q=\sigma_k=1\) 的假设；实际的 \(\sigma_q,\sigma_k\) 由 LayerNorm 与投影矩阵的尺度决定，训练中会变。

（c）\(\sqrt{128}\approx11.31\)。

练习 10 · LayerNorm 的两条性质

忽略 \(\epsilon\)，取 \(\boldsymbol\gamma=\mathbf 1\)、\(\boldsymbol\beta=\mathbf 0\)，并设 \(\mathbf x\) 的分量不全相等（\(\sigma>0\)），记 \(\mathbf y=\LayerNorm(\mathbf x)\)。证明：（a）\(\mathbf y\) 的分量均值为 0，且 \(\norm{\mathbf y}=\sqrt d\)；（b）对任意 \(a>0\) 与实数 \(b\)，\(\LayerNorm(a\mathbf x+b\mathbf 1)=\LayerNorm(\mathbf x)\)。用 \(\mathbf x=(1,2,3,4)\) 核对。

看答案

（a）\(y_k=(x_k-\mu)/\sigma\)。\(\sum_ky_k=(\sum_kx_k-d\mu)/\sigma=0\)。\(\norm{\mathbf y}^2=\sum_k(x_k-\mu)^2/\sigma^2=d\sigma^2/\sigma^2=d\)，因为 \(\sigma^2\) 的定义就是 \(\frac1d\sum_k(x_k-\mu)^2\)。

（b）\(\mathbf x'=a\mathbf x+b\mathbf 1\) 的均值 \(\mu'=a\mu+b\)，方差 \(\sigma'^2=a^2\sigma^2\)，\(\sigma'=a\sigma\)（\(a>0\)）。于是 \(y'_k=(ax_k+b-a\mu-b)/(a\sigma)=(x_k-\mu)/\sigma=y_k\)。

核对：\(\mathbf x=(1,2,3,4)\)，\(\mu=2.5\)，\(\sigma^2=(2.25+0.25+0.25+2.25)/4=1.25\)，\(\mathbf y=(-1.3416,\ -0.4472,\ 0.4472,\ 1.3416)\)，与 §6 黑板上 \((2,4,6,8)\) 的结果完全相同，因为 \((2,4,6,8)=2\cdot(1,2,3,4)\)。长度 \(\sqrt{2\times1.8+2\times0.2}=\sqrt4=2=\sqrt d\)。

练习 11 · 用参数量抓笔误

GPT-3 论文的表 2.1 把 13B 模型写成 \(L=40\)、\(d_{model}=5140\)、40 个头 × 每头 128 维；附录表 D.1 给出它的参数量是 12,850M 10。用 \(12Ld^2+(V+T_{max})d\)（\(V=50{,}257\)，\(T_{max}=2048\)）分别按 \(d=5140\) 与 \(d=5120\) 计算，判断哪个是笔误。

看答案

\(d=5140\)：\(12\times40\times5140^2+52{,}305\times5140=12{,}681{,}408{,}000+268{,}847{,}700=12{,}950{,}255{,}700\approx12{,}950\)M。

\(d=5120\)：\(12\times40\times5120^2+52{,}305\times5120=12{,}582{,}912{,}000+267{,}801{,}600=12{,}850{,}713{,}600\)，即 12,850.7M，与表 D.1 的 12,850M 只差 0.7M（0.006%）；按 (1.30) 再算上偏置与 LayerNorm 是 12,853.4M，也只差 0.03%。\(d=5140\) 却多出约 100M（0.78%），差距大了两个数量级。而且 \(40\times128=5120\) 正好等于头数乘每头维度。所以表 2.1 的 5140 是笔误，应为 5120。这里的 50,257 沿用 GPT-2 的词表，GPT-3 论文本身没有写词表大小。

练习 12 · 没有位置编码，注意力分不清先后

设第一层没有位置编码：\(\mathbf h^{(0)}_j=E^\top\mathbf e_{x_j}\)。看单头注意力在位置 \(t\) 的输出 \(\mathbf o_t=\sum_{j\le t}\alpha_{t,j}\mathbf v_j\)。（a）设 \(\pi\) 是 \(\{1,\dots,t-1\}\) 的任意一个排列，把前缀换成 \(x'_j=x_{\pi(j)}\)（\(j<t\)），保留 \(x'_t=x_t\)。证明第一层的新输出 \(\mathbf o'_t=\mathbf o_t\)。（b）加上可学习的位置表 \(P\) 之后，证明在哪一步失效？（c）用 §2 的 “Alice thanked Bob .” 说明这个结论的含义，并说明为什么它只对第一层成立。

看答案

（a）第一层的查询、键、值都是逐位置算出来的（方程 (1.2)(1.3)），只取决于该位置的 token。所以对 \(j<t\)，\(\mathbf k'_j=\mathbf k_{\pi(j)}\)、\(\mathbf v'_j=\mathbf v_{\pi(j)}\)；而 \(x'_t=x_t\) 给出 \(\mathbf q'_t=\mathbf q_t\)、\(\mathbf k'_t=\mathbf k_t\)、\(\mathbf v'_t=\mathbf v_t\)。记 \(c=\sqrt{d_k}\)，逐项比较：

  • 分母：\(Z'=\exp(\mathbf q_t^\top\mathbf k_t/c)+\sum_{s<t}\exp(\mathbf q_t^\top\mathbf k_{\pi(s)}/c)\)。\(\pi\) 只是把 \(1,\dots,t-1\) 换了个次序，求和里还是原来那 \(t-1\) 项，所以 \(Z'=Z\)。
  • 权重：\(\alpha'_{t,j}=\exp(\mathbf q_t^\top\mathbf k_{\pi(j)}/c)/Z=\alpha_{t,\pi(j)}\)（\(j<t\)），\(\alpha'_{t,t}=\alpha_{t,t}\)。
  • 输出：\(\mathbf o'_t=\alpha_{t,t}\mathbf v_t+\sum_{j<t}\alpha_{t,\pi(j)}\mathbf v_{\pi(j)}=\alpha_{t,t}\mathbf v_t+\sum_{i<t}\alpha_{t,i}\mathbf v_i=\mathbf o_t\)。中间一步令 \(i=\pi(j)\)：\(j\) 走遍 \(1,\dots,t-1\) 时，\(i\) 也恰好把它们各走一遍。

（b）有了位置表，\(\mathbf h^{(0)}_j=E^\top\mathbf e_{x_j}+P^\top\mathbf e_j\) 由 token 和位置号 \(j\) 共同决定。排列之后，位置 \(j\) 上的 token 换成了 \(x_{\pi(j)}\)，位置号却还是 \(j\)，所以 \(\mathbf k'_j\) 一般不等于任何一个原来的 \(\mathbf k_i\)。第一步“\(\mathbf k'_j=\mathbf k_{\pi(j)}\)”不再成立，后面的换元也就无从谈起。

（c）两句话的最后一个 token 都是句号，前三个 token 互为排列（\(\pi\) 对调位置 1 和 3）。由（a），没有位置编码时，句号在第一层的输出一模一样，模型分不出谁感谢谁，就像分不出“狗咬人”和“人咬狗”。这个结论只对第一层成立：到了第二层，句号读取的是其他位置的第一层输出，而位置 2（thanked）在第一层看到的前缀从 “Alice thanked” 变成了 “Bob thanked”，它的输出变了，新的键值集合就不再是原来的一个排列。这正是 §2 所说“因果掩码能间接带来一点位置信息”的来源，只是这种信息很间接。
