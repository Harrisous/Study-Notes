# 费曼学习层（每一课都加）

> 用户要的是“学完之后真的理解、真的吸收”。费曼学习法的核心只有一句：**能用大白话讲给一个外行听，
> 才算真的懂；讲不出来的地方，就是还没懂的地方。** 所以这一层不改课文的知识点，而是在课文里嵌入
> 一连串“逼你自己讲出来”的环节：先写下已有理解 → 每页读完立刻讲一遍、对照、查漏 → 课末用三种
> 深浅复述整课、找错、按间隔复习。读者从“看懂了”变成“讲得出、写得对、过几天还记得”。
>
> 本文件叠加在 `style-guide.md`、`style-blackboard.md` 与 `writer-brief.md` 之上。事实、公式、符号、
> 引用规则不变；称呼读者用“大家/你”，讲的人自称“我”。

## 0. 四步循环，对应到课里

| 费曼法的一步 | 在课里是什么 | 组件 |
|---|---|---|
| 1. 选一个概念，先写下你现在怎么理解 | 封面：开课前的 2–3 个问题 | `::: predict … {#before-1}` |
| 2. 讲给一个外行听 | 每页末：费曼时刻（指定听众、限句数、必须用到的词、**不许用**的术语） | `:::: feynman` |
| 3. 找出卡壳的地方，回到原文 | 自查清单 + “卡住了？回到这里” + 参考讲法（写完再看） | `::: check`、`::: gaps`、`::: answer` |
| 4. 简化、用类比，再讲一遍 | 课末“费曼复盘”：一句话版 / 讲给中学生 / 讲给工程师，对照开课前的自己，找错，间隔复习 | 新的最后一页 |

在 Artifact 版本里，每个费曼时刻还有一个“请 Claude 找漏洞”按钮：它把你写的讲解、本页的自查要点和
参考讲法交给 Claude，返回讲清了什么、漏了什么、哪些术语没解释、一个追问，以及一句更简单的说法。
本地版没有这个按钮，但所有文字都存在浏览器里，复盘页有“复制我的全部讲解”，可以整段贴给 Claude。

## 1. 封面：开课前，先写下你的理解

- 2–3 个 `predict`，id 固定为 `{#before-1}`、`{#before-2}`、`{#before-3}`，放在“读完你能……”之后、
  `[[legend]]` 之前。问题要让一个**没学过这课的人也能试着回答**（“你觉得 GPT 拿到一句话，第一步做什么？”），
  不要考定义。这里**不给答案**：答案就是整课。
- 框里提示一句：“写错没关系，写下来才有对照。课末会把你现在写的话拿出来，和学完后的你比一比。”

## 2. 页首：先猜一猜（可选，每页至多 1 个）

- 只用在**真能猜**的地方：一个数（“一个 token 要占多少显存？”）、一个结果（“不除以 √d_k 会怎样？”）。
- `::: predict 先猜一猜 · ……`，里面一个问题，再嵌一个 `::: answer 揭晓` 写答案与一句解释。
- 黑板课正文里已有的“先猜后揭晓”，挑最好的一处改成这个可写的框；其余保留在正文里。

## 3. 页末：费曼时刻（每个讲内容的页都要有，练习页与复盘页除外）

写法（一个页只抓**一个最核心的问题**，不是把整页复述一遍）：

````
:::: feynman 费曼时刻 · 为什么要除以 $\sqrt{d_k}$
- **讲给谁听**：一个学过高中概率、没学过机器学习的朋友。**4 句话以内**。
- **必须用到**：点积、方差、softmax
- **不许用**：“缩放因子”“梯度消失”——用你自己的话说出它们的意思。

::: check 讲完对照：你讲到了吗？
- 维度越高，点积这个“和”的波动越大（方差等于维度）
- 数一大，softmax 几乎只挑一个，其余权重接近 0
- 除以 √d_k 让方差回到 1，权重分布不再一边倒
:::

::: gaps 卡住了？回到这里
- 说不清“为什么维度越高越大” → [§4「抛 64 次硬币」](#p4)
- 说不清“softmax 一边倒有什么坏处” → [§4 图 1.9](#p4)
:::

::: answer 写完再看：参考讲法
（一段 200–400 字的大白话讲解：一个类比或一个数字例子，读起来像讲给朋友听。）

**这一页讲了三件事**（专业版要点）……
:::
::::
````

规则：

- 题目的三行（讲给谁听 / 必须用到 / 不许用）写成列表，否则会被并成一段。标题里的公式写成 `$…$`。
- **讲给谁听**：具体的人和他会什么（“学过高中数学的表弟”“刚学完线性代数的同学”“做后端的工程师朋友”）。
- **限句数**：2–5 句。限制逼你抓重点。
- **必须用到**：2–4 个本页关键词，保证讲的是对的东西。
- **不许用**：1–3 个本页的术语或“黑话”。这是费曼法最关键的一招：不准拿术语糊弄过去，必须说出它背后的意思。
  被禁用的词，要在参考讲法里示范怎么绕开它。
- **自查清单**：3–5 条，每一条都能客观判断“讲到了没有”（写成一句结论，而不是“理解了 X”）。
- **卡住了？回到这里**：2–4 条“症状 → 回看位置”，症状写成读者真实会有的卡点（“说不清……”“分不清……”），
  位置写到页和小节（`[§4「……」](#p4)`）。
- **参考讲法**：写完再看。先是一段真正的费曼式讲解（大白话 + 类比或算例，200–400 字，不许用的词在这里也不用），
  再把原来页末的 `::: key 这一页讲了三件事`（或“要点”）的内容移进来，标成“专业版要点”。**页末不再单独放
  key 框**：先产出，再对照，这是检索练习起作用的前提。复习时可以点顶栏的“展开答案”一次看全。

## 4. 课末新页：费曼复盘

放在“练习与答案”**之后**、参考文献之前（这样已有页码 `#pN` 都不变），标题 `# 费曼复盘 | 把这一课讲给别人听 | 30`。
依次包含：

1. **对照开课前的你**：用 `::: mirror before-1 | 开课前你写的` 把封面写的话原样显示出来（每个问题一个），
   再接一个 `feynman`：“现在重新回答这几个问题，并写下：你的理解哪里变了？还有哪里说不清？”
2. **三种讲法**（三个 `feynman`，各有自查清单与参考讲法）：
   - **一句话版**：≤ 40 字，讲出这一课最核心的那件事；
   - **讲给中学生**：≤ 300 字，必须有一个类比、一个能手算的数字例子，不许用本课的 3 个核心术语；
   - **讲给工程师**：公式、张量形状、真实数字（来自课文），说清每个设计“解决了什么、代价是什么”。
3. **概念链填空**：用一个 `quiz` 给出本课的逻辑链，挖掉 6–10 个关键环节（“token id →（___）→ 向量 → …”），
   答案里给完整链条。
4. **我以为我懂了**：4–6 道“这句话哪里不对？”的找错题（`quiz`），取材于本课的 `err` 框和研究笔记里的勘误，
   每道答案说明错在哪、正确说法是什么、回看哪一页。
5. **间隔复习**：一张表：1 天后 / 3 天后 / 7 天后 / 30 天后，每格 2–3 个不看书就要能答出的小问题；再加
   1–2 道**跨课**问题，把本课和前面的课（或数学补课）连起来。答案放在一个 `quiz` 的 `answer` 里。
6. **把讲解交给 Claude**：`::: fmexport` 放一个“复制我的全部讲解”按钮，附一句用法说明：贴给 Claude，
   请它按费曼法找漏洞。

## 5. 篇幅与质量

- 每课新增约 8,000–12,000 字（每个费曼时刻约 500–900 字，复盘页约 4,000–6,000 字）。
- 参考讲法与找错题里的每个数字、每个说法都要来自课文或研究笔记；新算的数字用 Python 复算，记到研究笔记的
  “补充核实（费曼层）”下。
- 不许用的词、类比、例子尽量复用 `style-guide.md` 第 5 节的全课类比，保持全课一致。
- 禁用词照旧：显然、易证、不难看出、容易看出、众所周知。

## 6. 组件速查（构建器支持）

| 写法 | 效果 |
|---|---|
| `:::: feynman 标题 {#id}` | 费曼时刻：题目 + 自动生成的书写框（存在本浏览器）+ Artifact 版的“请 Claude 找漏洞” |
| `::: check 标题`（在 feynman 里） | 可勾选的自查清单，每行 `- 一条要点`，勾选状态也会保存 |
| `::: gaps 标题`（在 feynman 里） | “卡住了？回到这里”的回看指引 |
| `::: answer 标题`（在 feynman / predict 里） | 写完再看的参考讲法（折叠） |
| `:::: predict 标题 {#id}` | 先猜一猜：题目 + 书写框 + 可选的 `answer` 揭晓 |
| `::: mirror id \| 标题` | 原样显示读者在 `{#id}` 那个框里写过的话 |
| `::: fmexport 标题` | “复制我的全部讲解”按钮（整理成 Markdown，附请 Claude 找漏洞的提示语） |

`{#id}` 可省略：省略时用标题生成一个稳定的键。同一课里的标题不要重复。
