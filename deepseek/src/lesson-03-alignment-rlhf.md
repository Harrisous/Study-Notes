## 这一课回答什么问题

上课之前，先请大家回想一件小事。在搜索框里敲下半句话，比如“怎么用三句话解释”，它马上帮你补全：“光合作用”“相对论”“通货膨胀”……补得又快又顺。可是它只管补全，从来不回答你。

第 2 课训练出来的模型，说白了就是一个极其强大的“补全”：给定前文，预测下一个 token。把“用三句话解释光合作用”交给它，它会按网上文本的统计规律往下写：可能写出一段解释，也可能再写出几道类似的题目，因为在网上，一道题后面常常跟着更多的题。（这是说明问题的假想例子，不是某个模型的实测输出。）它没有做错什么，它的训练目标本来就不是“回答你”。

所以这一课要回答的问题是：**怎样把一个会续写的模型，变成一个按人的意图办事的助手？** 讲完这一课，下面这些问题大家都能自己回答，而且能拿计算器验算：

- 为什么只用示范数据做监督微调（SFT）还不够，还要人去**比较**两个回答的好坏？
- 人只说了一句“A 比 B 好”，怎样从成千上万句这样的话里，学出一个能给**任意**回答打分的函数？
- 有了打分函数，为什么不直接把分数推到最大，而要加一个“别离原来的模型太远”的 KL 惩罚？不加会怎样？
- PPO 的“裁剪”到底裁掉了什么？价值网络和 GAE 在给谁记功、记多少？
- 训练时显存里要同时放下几个模型？一个 7B 的策略，模型状态要多少 GB？
- DPO 怎样把“训练奖励模型 + 强化学习”两步合成一个损失？它的梯度在做什么，又会在哪里出问题？

## 这一课在科技树上的位置

这是主线 D（训练目标与后训练）的第二站。[第 2 课](lesson-02-gpt-training.html)的终点是一个困惑度很低的预训练模型；可困惑度量的是“像不像训练语料”，不是“有没有帮到用户”。本课讲的三步法，也就是监督微调、奖励模型、带 KL 惩罚的强化学习，来自 OpenAI 2022 年的 InstructGPT [@ouyang2022]，本课以它为主线。

DeepSeek 后来的做法，都可以看成在这套原版上的改动：[第 6 课](lesson-06-deepseek-llm.html)的 DeepSeek LLM 在 SFT 之后用的是本课最后讲的 DPO [@deepseek2024llm]；[第 8 课](lesson-08-deepseekmath-grpo.html)的 DeepSeekMath 保留了本课的 KL 惩罚和裁剪目标，却把 PPO 里的价值网络整个去掉，换成“同一道题多答几次、组内比较”的 GRPO [@shao2024deepseekmath]；[第 13 课](lesson-13-r1-reasoning.html)的 R1 又用规则判分代替了一部分奖励模型。要看懂这些改动各自省下了什么、付出了什么，先得把本课的原版彻底弄明白。

## 读完你能……

1. 画出 InstructGPT 的三步流程，说出每一步用什么数据、训练哪个模型、数据量是多少。
2. 从“分数差 = 对数几率”出发推出 Bradley–Terry 偏好概率和奖励模型损失，手算一对回答的损失与梯度，并解释为什么奖励只能确定到一个常数平移。
3. 写出带 KL 惩罚的强化学习目标，推出它的闭式最优策略 $\pi^*\propto\pi_{ref}\,e^{r/\beta}$，说清 KL 项防的是什么。
4. 对任意一组 $(\rho,\hat A)$ 算出 PPO 裁剪目标的值和梯度是否为零；用 GAE 手算一段回答上每个 token 的优势。
5. 估算 PPO 四个模型的显存；从闭式最优策略逐行推出 DPO 损失与梯度，用隐式奖励解释 DPO 在学什么、会在哪里失败。

::: note 本课的记号
本课沿用整门课的约定（见课程符号表），并补充几个只在这里用到的记号。

- $q$：提示（prompt），一段 token 序列。$o=(o_1,\dots,o_{\abs{o}})$：回答，$o_t$ 是它的第 $t$ 个 token，$o_{<t}$ 是排在它前面的回答 token，$\abs{o}$ 是回答长度。
- $\pi_\theta(o\mid q)$：参数为 $\theta$ 的语言模型在提示 $q$ 下生成整段回答 $o$ 的概率，按自回归分解等于 $\prod_{t}\pi_\theta(o_t\mid q,o_{<t})$。在强化学习的语境里，这个模型叫**策略**（policy）。
- $\pi_{ref}$：参考策略，训练中冻结不动；$\pi_{\theta_{old}}$：采样那一刻的策略快照。
- $r_\phi(q,o)\in\R$：参数为 $\phi$ 的奖励模型给整段回答打的分数，一个实数。$V_\psi$：参数为 $\psi$ 的价值网络。
- $o_w,o_l$：一次比较里被偏好（win）和不被偏好（lose）的两个回答。$\sigma(z)=1/(1+e^{-z})$：logistic 函数（sigmoid）。
- $\beta$：KL 系数；$\varepsilon$：PPO 裁剪系数；$\rho_t$：新旧策略的概率比；$\hat A_t$：优势估计；$\gamma$、$\lambda$：折扣因子与 GAE 参数；$\gamma_{ptx}$：预训练混合系数。
- 黑板上的小例子（“黑板上”开头的例题框）用的是为了手算而随手取的小数字，不是任何真实模型的输出；真实系统的数字都注明了来源。

读原论文时注意三处撞车：InstructGPT 用 $\theta$ 表示**奖励模型**的参数、$\phi$ 表示策略参数，DPO 论文恰好反过来；PPO 论文用 $r_t(\theta)$ 表示概率比（本课写 $\rho_t$），又在别处用 $r_t$ 表示奖励；InstructGPT 式 (2) 里的 $\gamma$ 是预训练系数（本课写 $\gamma_{ptx}$），不是折扣。本课一律用上面的写法。
:::

# 从续写到助手 | 书读得多，不等于会答题：目标的缺口、三步法与监督微调 | 25

好，我们正式上课。大家身边多半有过这样的同学：书读得很多，天文地理什么都知道一点。可你问他一个具体的问题，比如“明天考试要带什么”，他不直接回答，而是从考试制度的历史讲起，讲着讲着又想起一道有意思的题，干脆出给你做。他懂的东西不少，只是没学会“你问什么，我答什么”。

预训练模型就是这位同学。那么问题来了：一个“懂得多”的模型，到底缺了什么？我们先把这个缺口说准确，再看 InstructGPT 怎样分三步把它补上。这一页讲第一步，监督微调；后面几页把第二、三步逐一拆开。

## 缺口在哪里：三道缝

第 2 课的预训练目标是在网上文本上最大化对数似然 $\E_{x\sim\mathcal D_{web}}[\log p_\theta(x)]$：模型越会模仿语料，损失越低。我们真正想要的却是另一个量：对用户发来的提示 $q$，模型的回答 $o$ 让人满意的程度，平均越高越好。这两个量之间有三道缝。

- **第一，分布不同。** 网上的文本不是“提示—好回答”的配对。
- **第二，目标不同。** 模仿语料会把语料里的错误、偏见和废话一并学会。
- **第三，也是最难的一道：“让人满意”没有公式。** 它写不成一个可以求导的损失，只能去问人。

回到那位同学身上，三道缝他全占了：他读的书不是问答，他练的是“把书记下来”，而答得好不好，只有问他的人说了算。

## 三步法

**含义。** InstructGPT 的方法分三步 [@ouyang2022]：① 收集示范数据，训练一个监督策略；② 收集比较数据，训练一个奖励模型；③ 用 PPO 针对奖励模型优化策略。第 2、3 步可以反复迭代：用新策略的回答再去收集比较数据（论文说大部分比较数据来自 SFT 策略，少部分来自 PPO 策略）。

**理解。** 三步各自回答一个问题。第一步问“好回答大概长什么样”：让人写示范，模型照着学。第二步问“两个回答哪个更好”：人不再动笔写，只做判断；把大量判断压缩进一个能给任意回答打分的模型。第三步问“怎样写出评委打高分的回答”：模型自己写、评委打分、按分数调整，这一步不再需要人。

::: fig figures/l03-pipeline.svg | 图 3.1 InstructGPT 的三步：监督微调、训练奖励模型、用 PPO 做强化学习
**看每一列最下面那个彩色框：三步各产出一个模型。** 第一列产出 SFT 模型，它初始化第三步的策略，并冻结一份作参考；第二列产出奖励模型 $r_\phi$，它在第三步里给策略的回答打分。虚线框是需要人工的两步：写示范、给回答排序；第三步只用提示，不需要任何人工标签。据 InstructGPT 论文图 2 重绘 [@ouyang2022]，数据量取自其表 6。
:::

三份数据的规模都按**提示**（prompt）计，来自论文表 6 [@ouyang2022]：

| 数据集 | 训练集提示数 | 来源构成 | 人做什么 |
|---|---|---|---|
| SFT | 12,725 | 标注员自写 11,295 + API 用户 1,430 | 为每个提示写一段示范回答 |
| RM | 33,207 | 标注员自写 6,623 + API 用户 26,584 | 给同一提示下的 4 到 9 个回答排序 |
| PPO | 31,144 | 全部来自 API 用户 | 不做任何事（没有人工标签） |

这张表有三个地方值得停一下。第一，标注员约 40 人，是通过 Upwork 和 ScaleAI 雇的合同工 [@ouyang2022]。第二，三份数据加起来不过几万个提示，比第 2 课的预训练语料小好几个数量级：后训练是在一个已经很有能力的模型上做**小剂量**的调整。第三，最后一份数据没有标签。这是强化学习阶段最大的好处：只要有提示，模型就能自己写、自己挨打分，无限地“练习”。

## 效果：一个小模型胜过大 100 多倍的原版

好，先看看这套办法管不管用。InstructGPT 训练了 1.3B、6B、175B 三种尺寸的策略，都是 GPT-3 架构 [@ouyang2022]。大家先猜一猜：要让标注员觉得它的回答比 175B 的原版 GPT-3 更好，InstructGPT 至少得多大？也得 175B 吧？退一步，几十 B？

答案是 1.3B。这是论文的标题级结论：**1.3B 的 InstructGPT 的回答比 175B 的 GPT-3 更受偏好**，参数少了约 135 倍（175/1.3；论文写作“100 倍”或“超过 100 倍”）。如果是 175B 对 175B，InstructGPT 的回答对 GPT-3 的胜率是 $85\pm3\%$，对精心写了 few-shot 提示的 GPT-3 是 $71\pm4\%$ [@ouyang2022]。

读这个结论要看清它量的是什么。胜率是**标注员**在**留出的 API 用户提示**上做的两两偏好判断，不是公开 NLP 基准的分数。论文还专门说明：这个流程把模型对齐到的是“一群特定的人”（主要是标注员和研究者）表达出来的偏好，而不是某种普遍的“人类价值” [@ouyang2022]。

::: err 很多人以为：做过 RLHF，模型就在各方面都变强了
很多人以为：既然 1.3B 都能胜过 175B，RLHF 一定让模型全面变聪明了。

其实：胜过的是“标注员更喜欢谁的回答”这一项。在 SQuAD、DROP、HellaSwag 和 WMT15 法译英这些公开数据集上，做过 RLHF 的模型反而退步了，论文把这种现象称为“对齐税”（alignment tax）[@ouyang2022]。这笔税怎么补，[§3](#p3) 会讲。
:::

::: note 小故事 · RLHF 从哪里来
RLHF 不是 InstructGPT 发明的。用“两段轨迹哪段更好”的比较来学奖励、再用强化学习优化，Christiano 等人 2017 年把它做到了深度强化学习的规模（Atari 游戏和模拟机器人控制）；他们自述算法的基本做法沿用了 Akrour 等人 2012、2014 年的工作。他们用的是 A2C 和 TRPO，还不是 PPO：PPO 的论文比它晚 38 天才出现在 arXiv 上 [@christiano2017; @schulman2017ppo]。把“比较数据训练的奖励模型 + PPO + 对初始模型的 KL 惩罚”用到预训练语言模型（GPT-2 774M）上的是 Ziegler 等人 2019 年的工作 [@ziegler2019]，用到摘要任务上的是 Stiennon 等人 2020 年的工作 [@stiennon2020]。InstructGPT 自述其方法沿用了这两篇 [@ouyang2022]；它的贡献是把这套方法用到开放式的指令跟随上，并在 175B 的规模上做通。
:::

## 第一步：照着范文学

第一步最朴素：让人写示范，模型照着学。怎么“照着学”？还是第 2 课那个老办法：把示范回答里的每个 token 当作标准答案，模型给它的概率越高越好。我们先在黑板上写一段只有三个 token 的示范。

::: ex 黑板上 · 一段三个 token 的示范回答
设某条示范回答有 3 个 token，模型在{{教师强制::训练时每一步都喂给模型真实的前文，而不是它自己生成的前文}}（teacher forcing，第 2 课）下给这三个正确 token 的概率分别是 0.5、0.2、0.9。每个 token 的损失是 $-\ln p$：

- 第 1 个：$-\ln0.5=0.6931$；
- 第 2 个：$-\ln0.2=1.6094$；
- 第 3 个：$-\ln0.9=0.1054$。

加起来，这一条的损失是

$$-(\ln0.5+\ln0.2+\ln0.9)=0.6931+1.6094+0.1054=2.4079,$$

平均每个 token 0.8026。

哪个 token 最该改？第二个：它一个就占了约三分之二的损失（$1.6094/2.4079\approx66.8\%$）。梯度也是这么看的：$-\ln p$ 对 $p$ 的导数是 $-1/p$，$p=0.2$ 时是 $-5$，$p=0.9$ 时只有 $-1.11$，所以梯度会把第二个 token 的概率往上推得最用力。（模型实际改的是 softmax 之前的 logit；对正确 token 的 logit 求导是 $p-1$，即 $-0.8$ 对 $-0.1$，结论相同。）
:::

好，现在把 3 个 token 换成任意长的回答，把一条示范换成一整个数据集。这就是**监督微调**（supervised fine-tuning，SFT）：在“提示 + 人写的示范回答”上，用和预训练同样的下一词预测损失继续训练。设示范数据集 $\mathcal D_{demo}$ 由若干对 $(q,o)$ 组成，SFT 最小化示范回答在提示条件下的负对数似然：

::: eq SFT 损失 | (3.1)
$$\mathcal L_{SFT}(\theta)=-\E_{(q,o)\sim\mathcal D_{demo}}\Big[\sum_{t=1}^{\abs{o}}\log\pi_\theta(o_t\mid q,o_{<t})\Big]$$
和第 2 课的交叉熵是同一个式子，只是提示 $q$ 只当条件、不计损失。“只对回答部分计损失”是常见写法；InstructGPT 原文没有写到这一层细节。归一化的写法各课不同：第 2 课 (2.3) 除以 token 总数，这里按条求和，两者对一批固定的数据只差一个常数；第 8 课 DeepSeekMath 的写法先在每条回答内除以 $\abs{o}$，那会改变长短回答的相对权重（第 8 课 §4 的“长度偏差”）。
:::

代回黑板：$\abs{o}=3$ 时，方括号里是 $\ln0.5+\ln0.2+\ln0.9=-2.4079$，前面再乘一个负号，正是 2.4079。对，一模一样。

**理解。** 预训练教会模型“语言是什么样的”，SFT 教它“在这里，一段回答应该长什么样”：先直接回应问题，格式清楚，该拒绝时拒绝。它仍然是模仿，只是模仿的对象从整个互联网换成了几十位标注员精心写的一万多段示范。

InstructGPT 的 SFT 训了 16 个 epoch，用余弦学习率衰减和 0.2 的残差 dropout。论文观察到一个反直觉的现象：训练 1 个 epoch 之后，验证集损失就开始上升（过拟合），可多训几个 epoch 反而让奖励模型打分和人的偏好都更好；所以最终的 SFT 模型是按**奖励模型的分数**、而不是按验证损失挑出来的 [@ouyang2022]。这件小事预告了本课的主题：我们在意的量（人的偏好）和我们能直接优化的量（似然）不是一回事。

## 为什么光照着学还不够

那么，SFT 做完是不是就够了？大家想一想，一个只会临摹范文的学生，会卡在哪里？至少有三处。

**问题一：示范贵，而且示范的上限就是写示范的人。** 让人写出一段好回答，要比让人判断两段回答哪段更好费事得多（这是笔者的判断，InstructGPT 没有给出两种标注的耗时对比）。更要紧的是，SFT 学到的最多是“像标注员那样写”；标注员写不出的更好回答，模仿学不到。

**问题二：似然只会说“像”，不会说“更好”。** 最大似然把示范里的每个 token 都当作唯一正确答案。两个都说得通的回答，一个略好一个略差，SFT 没法表达这种**比较**；比较数据恰好能。

**问题三：模型从没见过自己犯的错。** SFT 的输入永远是人写的前文（教师强制），模型自己生成时却要接着自己写的前文往下写。自己写偏了之后该怎么办，示范数据里没有（这是笔者的分析）。第 2、3 步用的都是**模型自己的回答**：先让人比较模型自己的回答，再让模型在自己的回答上接受打分。

::: ana 类比：学生练写作文（本课反复使用）
**映射。** 策略 = 写作文的学生；SFT = 临摹范文；奖励模型 = 一位看过大量“两篇里哪篇更好”判决的**模拟评委**，学会了给任意一篇打分；强化学习 = 学生自己写、模拟评委打分、按分数改进；KL 惩罚 = 规定学生的文风不许离原来的自己太远；PPO 裁剪 = 每次改稿只许改一小步；价值网络 = 一位**预测分数的老师**，在评委打分之前先估计“这篇写到这里大概能得几分”。

**收益。** 它解释了三步的顺序：先临摹才有基本功，先有评委才能自己练，自己练时要有约束，否则会去讨好评委。

**但是这个比方有几个地方不对。** 真的学生能读懂评语，模型只收到一个数；真的评委有稳定的品味，模拟评委只是对几万条判决的统计拟合，在它没见过的文章上会乱打分；而且这里的“学生”每写一个字都可以重新掷骰子（按概率采样），同一个题目能写出成百上千篇不同的作文。
:::

::: key 这一页讲了三件事
- **第一，缺口有三道缝。** 预训练目标（模仿语料）和我们想要的目标（让人满意）之间，分布不同、目标不同，而且“让人满意”写不成可求导的公式。
- **第二，InstructGPT 分三步补缝。** SFT（12,725 个提示的示范）→ 奖励模型（33,207 个提示的排序）→ PPO（31,144 个无标签提示）。1.3B 的结果被偏好于 175B GPT-3，但公开基准上交了对齐税。
- **第三，SFT 就是在示范上做下一词预测 (3.1)。** 黑板上三个 token 的损失是 2.4079，概率最低的那个 token 挨的梯度最大。它学得到“像”，学不到“更好”，也学不到从自己的错误里恢复；后两步用比较和自我练习补上这两点。
:::

# 奖励模型：两篇作文哪篇好 | 从成对比较到 Bradley–Terry 损失 | 35

大家上学时都写过作文。让一位语文老师给一篇作文打一个绝对分，他往往要犹豫：42 分还是 45 分？换一位老师，可能给 48；同一位老师上午看和下午看，也未必一样。可要是把两篇作文并排放在他面前，问“哪篇更好”，他通常很快就能说出来。

人很难给出稳定的**绝对**分数，更擅长回答“这两篇哪篇更好”。而且即便是比较，人和人之间也常常不一致：InstructGPT 的训练标注员彼此一致的比例只有 $72.6\pm1.5\%$，留出的另一批标注员之间是 $77.3\pm1.3\%$ [@ouyang2022]。

可我们要的是一个函数 $r_\phi(q,o)\in\R$：给定提示和回答，输出一个实数，越大表示越好。所以这一页真正的问题是：**手里只有一大堆带噪声的“A 比 B 好”，怎样学出一个能给任意回答打分的函数？** 这需要一座桥，把“分数”和“比较结果的概率”连起来。我们先在黑板上把这座桥搭出来。

## 黑板上：分数差怎么变成胜率

::: ex 黑板上 · 两篇作文、两个分数
假设评委心里给作文甲打 2.1 分，给作文乙打 0.6 分。我们想从这两个数算出“标注员选甲”的概率。这个规则至少该满足三条：

- 两篇一样好（分数差为 0）时，胜率是 0.5；
- 分数差越大，甲的胜率越接近 1；
- 只看分数差：两篇都加 5 分，胜率不变。

一个满足这三条的最简单办法是：让分数差等于胜率的**对数几率**。几率（odds）就是“赢的概率 ÷ 输的概率”。这里分数差 $\Delta=2.1-0.6=1.5$，于是

- 几率 $=e^{1.5}=4.4817$：甲赢的可能是输的约 4.5 倍；
- 胜率 $=4.4817/(1+4.4817)=4.4817/5.4817=0.8176$。

三条逐一核对：分数差为 0 时几率 $e^{0}=1$，胜率 $1/2$；分数差越大，几率越大，胜率越接近 1；两篇都加 5 分，变成 7.1 与 5.6，差还是 1.5，胜率还是 0.8176。三条全满足。
:::

黑板上这条规则有名字，叫 Bradley–Terry 模型。下面把它写成一般的形式。

## Bradley–Terry：分数差就是对数几率

**含义。** Bradley–Terry 模型（简称 BT）是一个成对比较的概率模型：每个被比较的对象有一个分数，两者比较时谁胜出的概率只取决于**两个分数之差**。它由 Bradley 与 Terry 在 1952 年提出 [@bradley1952]（原文的参数化写法本课未能读到原文，下面用 DPO 论文里的现代写法 [@rafailov2023dpo]）。

**理解。** 国际象棋的 Elo 等级分就是这个思想：两位棋手的等级分差 400 分时，强者的期望得分约为 91%（$1/(1+10^{-1})=0.909$），差多少分决定胜率，和两人各自是多少分无关。Christiano 等人用它从人类比较中学奖励时，也拿 Elo 做类比 [@christiano2017]。**但是这个比方有个地方不对**：Elo 给**有限几位棋手**各记一个分数，一张表就存得下；奖励模型面对的“棋手”是无穷多种可能的回答，大多数从未参加过比较，所以它学的是一个**函数** $r_\phi(q,o)$，要能给没见过的回答打分，这正是本页末尾“奖励模型的盲区”的来源。

**数学。** 几率是事件发生与不发生的概率之比 $P/(1-P)$。BT 模型的假设是：“$o_w$ 胜过 $o_l$”的对数几率等于两个分数之差。把黑板上那两步写成一般形式：

::: deriv 从“分数差 = 对数几率”到 sigmoid
$\log\dfrac{P(o_w\succ o_l)}{1-P(o_w\succ o_l)}=r_w-r_l=:\Delta$ || BT 的建模假设；$r_w=r(q,o_w)$，$r_l=r(q,o_l)$，$\Delta$ 是分数差
$\dfrac{P}{1-P}=e^{\Delta}\ \Rightarrow\ P=e^{\Delta}(1-P)\ \Rightarrow\ P(1+e^{\Delta})=e^{\Delta}$ || 两边取指数，再把含 $P$ 的项移到一边
$P=\dfrac{e^{\Delta}}{1+e^{\Delta}}=\dfrac{1}{1+e^{-\Delta}}=\sigma(\Delta)$ || 分子分母同除以 $e^{\Delta}$
$P=\dfrac{e^{r_w}}{e^{r_w}+e^{r_l}}$ || 把 $\Delta=r_w-r_l$ 代回，分子分母同乘 $e^{r_l}$：两个选项上的 softmax
:::

::: eq Bradley–Terry 偏好模型 | (3.2)
$$P(o_w\succ o_l\mid q)=\sigma\big(r(q,o_w)-r(q,o_l)\big)=\frac{e^{r(q,o_w)}}{e^{r(q,o_w)}+e^{r(q,o_l)}}$$
$\succ$ 读作“胜过”。概率只依赖分数差：两边同时加上任何常数，概率不变。
:::

代回黑板：$\sigma(1.5)=1/(1+e^{-1.5})=1/1.2231=0.8176$。用 softmax 那种写法也一样：$e^{2.1}/(e^{2.1}+e^{0.6})$，分子分母同除以 $e^{0.6}$，还是 $e^{1.5}/(e^{1.5}+1)$。对，0.8176。

::: pre sigmoid 的三条性质 | 熟悉 logistic 函数的可以跳过
$\sigma(z)=1/(1+e^{-z})$ 把任意实数压到 $(0,1)$ 里：$\sigma(0)=0.5$，$z\to+\infty$ 时趋于 1，$z\to-\infty$ 时趋于 0。下面三条本课反复用到。

1. **对称**：$1-\sigma(z)=\sigma(-z)$。因为 $1-\frac{1}{1+e^{-z}}=\frac{e^{-z}}{1+e^{-z}}=\frac{1}{e^{z}+1}$。
2. **导数**：$\sigma'(z)=\sigma(z)\,(1-\sigma(z))$。因为 $\sigma'(z)=\frac{e^{-z}}{(1+e^{-z})^2}=\frac{1}{1+e^{-z}}\cdot\frac{e^{-z}}{1+e^{-z}}$，后一个因子由第 1 条等于 $1-\sigma(z)$。
3. **对数的导数**：$\frac{d}{dz}\log\sigma(z)=\frac{\sigma'(z)}{\sigma(z)}=1-\sigma(z)=\sigma(-z)$。

更完整的推导见 [M06 §1](../math/m06-calculus-backprop.html#p1)（sigmoid 的导数与数值核对）；“两个数的 softmax 就是 sigmoid”见 [M04 §4](../math/m04-probability.html#p4)。
:::

## 为什么偏偏是 sigmoid

大家可能会问：满足黑板上那三条的函数多得是，为什么偏偏选 sigmoid？说实话，(3.2) 是一个**建模选择**，不是推论。不过它有一个很自然的来历：假设标注员心里对每个回答的感受是“真实分数 + 一点随机噪声”，谁的感受值大就选谁。如果噪声服从一种叫 Gumbel 的分布，胜出的概率恰好就是 (3.2)。

我们把这一点算出来。设标注员对两个回答的感受值是 $U_w=r_w+\epsilon_w$、$U_l=r_l+\epsilon_l$，噪声 $\epsilon_w,\epsilon_l$ 相互独立，都服从标准 Gumbel 分布：累积分布函数 $F(x)=P(\epsilon\le x)=\exp(-e^{-x})$，密度 $f(x)=F'(x)=e^{-x}\exp(-e^{-x})$。

::: deriv 带噪声的评分：Gumbel 噪声 ⇒ Bradley–Terry
$P(o_w\succ o_l)=P(U_w>U_l)=P(\epsilon_l<\Delta+\epsilon_w)$ || 谁的感受值大就选谁；把 $r$ 移到一边，$\Delta=r_w-r_l$
$=\int_{-\infty}^{\infty}f(a)\,F(\Delta+a)\,da$ || 先固定 $\epsilon_w=a$，此时 $\epsilon_l<\Delta+a$ 的概率是 $F(\Delta+a)$；再按 $a$ 的密度平均
$=\int_{-\infty}^{\infty}e^{-a}\exp\!\big(-e^{-a}\big)\exp\!\big(-e^{-\Delta}e^{-a}\big)\,da$ || 代入 $f$ 与 $F$，并把 $e^{-(\Delta+a)}$ 拆成 $e^{-\Delta}e^{-a}$
$=\int_{0}^{\infty}\exp\!\big(-(1+e^{-\Delta})\,u\big)\,du$ || 换元 $u=e^{-a}$，$du=-e^{-a}\,da$；$a$ 从 $-\infty$ 走到 $\infty$ 时 $u$ 从 $\infty$ 走到 0，负号正好把积分上下限换回来
$=\dfrac{1}{1+e^{-\Delta}}=\sigma(\Delta)$ || $\int_0^\infty e^{-cu}du=1/c$，这里 $c=1+e^{-\Delta}>0$
:::

这个推导是笔者为说明 sigmoid 的来历而给的，不是 InstructGPT 的论证。它也告诉我们换一种噪声会得到别的模型：如果噪声是正态分布，胜率就变成正态分布的累积函数，那是另一个经典模型。用 sigmoid 的实际好处是计算方便：损失就是 logistic 回归的交叉熵，导数形式简单（上面的前置框）。后面 DPO 的推导真正要用的是“胜率只依赖分数差”这条性质；正态噪声的模型也有这条性质（胜率是分数差的函数），换成它，DPO 的推导同样成立，只是损失里的 $\log\sigma$ 要换成 $\log\Phi$（$\Phi$ 是标准正态分布的累积分布函数，自变量还要除以一个尺度常数）。

## 评委长什么样

桥搭好了，现在要一位会打分的“评委”。

**含义。** 奖励模型（reward model，RM）是一个读入“提示 + 回答”、输出一个实数的神经网络。

**理解。** 它通常就是一个语言模型，把最后的反嵌入层（第 1 课里把隐藏状态映射成 $\abs{\mathcal V}$ 个 {{logits::每个词表条目一个未归一化的分数，softmax 之后变成概率}} 的那一层）换成一个只输出一个数的线性头。InstructGPT 的奖励模型是 6B 的 GPT-3 系模型；论文正文说它从去掉反嵌入层的 SFT 模型出发，附录又说最终用的是在公开 NLP 数据上微调过的 6B GPT-3，并说这“主要是历史原因”、两种初始化效果相近 [@ouyang2022]。分数一般从最后一个 token 位置的隐藏状态读出（常见实现；InstructGPT 原文没有写明读哪个位置）。

**数学。** 记最后一层在回答末尾的隐藏状态为 $\mathbf h_{end}\in\R^{d}$，标量头为 $\mathbf w\in\R^{d}$，则 $r_\phi(q,o)=\mathbf w^\top\mathbf h_{end}$。$\phi$ 包括 Transformer 的全部参数和 $\mathbf w$。

InstructGPT 所有尺寸的策略共用**同一个 6B 奖励模型**。论文给了两个理由：省算力；175B 的奖励模型训练不稳定，也就不适合拿来初始化价值网络（§5 会讲价值网络从奖励模型初始化）[@ouyang2022]。

## 奖励模型的损失：最大似然

有了 (3.2)，每一条比较数据 $(q,o_w,o_l)$ 在模型下的概率就是 $\sigma(r_\phi(q,o_w)-r_\phi(q,o_l))$。记比较数据集为 $\mathcal D_{pref}$（pref 是 preference 的缩写，和示范数据集 $\mathcal D_{demo}$、§3 的提示分布 $\mathcal D$ 区分开）。按最大似然的老办法（第 2 课）：让整个数据集出现的概率最大，等价于最小化平均负对数似然。

::: eq 奖励模型损失（成对 Bradley–Terry） | (3.3)
$$\mathcal L_{RM}(\phi)=-\E_{(q,o_w,o_l)\sim\mathcal D_{pref}}\Big[\log\sigma\big(r_\phi(q,o_w)-r_\phi(q,o_l)\big)\Big]$$
这是一个二分类交叉熵：“$o_w$ 胜”是正类，logit 是分数差。Stiennon 等人和 DPO 论文都写成这个形式 [@stiennon2020; @rafailov2023dpo]。
:::

它的梯度告诉我们训练在做什么。记 $\Delta=r_\phi(q,o_w)-r_\phi(q,o_l)$：

::: deriv 奖励模型损失的梯度
$\dfrac{\partial}{\partial\Delta}\big[-\log\sigma(\Delta)\big]=-\sigma(-\Delta)$ || 上面前置框第 3 条
$\nabla_\phi\big[-\log\sigma(\Delta)\big]=-\sigma(-\Delta)\,\nabla_\phi\Delta$ || 链式法则：$\Delta$ 通过 $\phi$ 变化
$=-\sigma(-\Delta)\big(\nabla_\phi r_\phi(q,o_w)-\nabla_\phi r_\phi(q,o_l)\big)$ || $\Delta=r_w-r_l$，梯度对减法可分配
:::

::: eq 奖励模型的梯度 | (3.4)
$$\nabla_\phi\mathcal L_{RM}=-\E\Big[\underbrace{\sigma(r_l-r_w)}_{\text{排得越错，权重越大}}\big(\nabla_\phi r_\phi(q,o_w)-\nabla_\phi r_\phi(q,o_l)\big)\Big]$$
梯度下降沿 $-\nabla$ 走：把 $o_w$ 的分数往上推，把 $o_l$ 的分数往下压，推压的力度是 $\sigma(r_l-r_w)$。
:::

权重 $\sigma(r_l-r_w)$ 就是“模型认为这一对**排反了**的概率”。模型已经很有把握排对的一对（$\Delta\gg0$），权重接近 0，几乎不再学；模型排反了的一对（$\Delta<0$），权重大于 0.5，学得最用力。§7 的 DPO 梯度会有完全相同的结构。

::: fig figures/l03-bt-sigmoid.svg | 图 3.2 Bradley–Terry 概率（左）与奖励模型损失、梯度大小（右）
**看左图的 S 形曲线：奖励差 $\Delta$ 每增加 1，偏好概率沿 sigmoid 上升，要到 $\Delta=\ln9\approx2.20$ 才达到 90%。** 虚线是 Christiano 等人加入 10% 随机作答后的版本 $0.05+0.9\sigma(\Delta)$，它永远到不了 0 或 1。右图实线是单对损失 $-\log\sigma(\Delta)$：排反时近似线性增长，排对后迅速趋于 0；蓝色虚线是梯度大小 $\sigma(-\Delta)$，标出的点对应正文例题。曲线由脚本按公式计算。
:::

好，把黑板上那对作文代进 (3.3) 和 (3.4)。

::: ex 代回黑板 · 一对回答的概率、损失与梯度
奖励模型给偏好回答打 2.1 分，给另一个回答打 0.6 分。

- 分数差 $\Delta=2.1-0.6=1.5$。模型认为标注员偏好前者的概率 $\sigma(1.5)=1/(1+e^{-1.5})=1/1.2231=0.8176$。
- 这一对的损失 $-\ln0.8176=0.2014$。
- 对 $\Delta$ 的梯度 $-\sigma(-1.5)=-0.1824$：梯度下降会让 $\Delta$ 再大一点，但已经不太用力了。对照一对排反的（$\Delta=-1$）：损失 1.3133，梯度 $-0.7311$，力度是前者的 4 倍。

现在把两个分数都加 5 分：7.1 与 5.6。$\Delta$ 仍是 1.5，概率、损失、梯度**一个都不变**。
:::

最后这一句，是 BT 模型的一条根本性质：**奖励只确定到一个常数平移**。对同一个提示下的所有回答同时加一个常数，所有比较概率都不变，损失也就看不出任何区别。

::: err 很多人以为：奖励模型打的分数有绝对的意义
很多人以为：奖励模型给某个回答打 3 分，就像考试 60 分一样，表示“及格”或者“好”。

其实：由 (3.2)，损失只看同一提示下的分数差，所以每个提示上的分数都可以整体平移而损失不变，单看一个分数没有意义。InstructGPT 因此说它的奖励模型损失“对奖励的平移不变”，在进入强化学习前加一个偏置，把**标注员示范回答**的平均分调成 0 [@ouyang2022]；Stiennon 等人把参考摘要的平均分调成 0 [@stiennon2020]，Ziegler 等人把奖励归一化到均值 0、方差 1 [@ziegler2019]。
:::

平移看起来无害，但 §3 会看到，奖励的**尺度**会直接影响 KL 系数该取多大。§7 还会看到，这个“只确定到一个常数”的自由度，正是 DPO 能消掉一个难算的归一化常数的原因。

## 从 K 个回答的排序到 $\binom K2$ 对比较

InstructGPT 让标注员一次看同一个提示下的 $K=4$ 到 $9$ 个回答并排出名次 [@ouyang2022]。一次排序蕴含的两两比较数是从 $K$ 个里任取 2 个的组合数 $\binom K2=K(K-1)/2$：$K=4$ 时 6 对，$K=9$ 时 36 对。

::: fig figures/l03-rank-pairs.svg | 图 3.3 一次排序拆成 C(K,2) 对两两比较
**看左图的 6 条箭头：4 个回答排一次名次，就同时给出了 6 个“谁胜过谁”。** 每个回答出现在 $K-1=3$ 对里。右图是每个提示产生的比较对数随 $K$ 的增长；InstructGPT 的 $K$ 在 4 到 9 之间，一个 batch 有 64 个提示，所以一个 batch 含 384 到 2,304 对比较。标注员给出的平局在训练中被丢弃 [@ouyang2022]。
:::

那么问题来了：这 $\binom K2$ 对彼此并不独立，同一个回答出现在 $K-1$ 对里。InstructGPT 发现，如果把所有比较对打散、当作独立样本混进数据集，每个回答会在一个 epoch 里参与 $K-1$ 次梯度更新，模型一个 epoch 就过拟合。它的做法是把同一个提示的全部 $\binom K2$ 对当成**一个 batch 元素**，损失对这些对取平均：

::: eq InstructGPT 的奖励模型损失 | (3.5)
$$\mathcal L_{RM}(\phi)=-\frac{1}{\binom K2}\,\E_{(q,o_w,o_l)\sim\mathcal D_{pref}}\Big[\log\sigma\big(r_\phi(q,o_w)-r_\phi(q,o_l)\big)\Big]$$
据论文式 (1)，记号换成本课的写法 [@ouyang2022]。除以 $\binom K2$ 的作用是把一个提示的所有比较对平均成一个样本（笔者的读法：否则 $K=9$ 的提示贡献 36 对、$K=4$ 的提示只贡献 6 对，前者的权重是后者的 6 倍）。按这个读法写得更精确些：先在提示 $q$ 的全部 $\binom{K_q}2$ 对上对 $-\log\sigma(\cdot)$ 求平均（$K_q$ 是这个提示的回答数），再对提示取期望；论文把 $1/\binom K2$ 写在期望外面，字面上只在所有提示的 $K$ 都相同时成立。
:::

放在一个 batch 元素里还有一个计算上的好处：每个回答只需要过一次前向，就能参与它所在的全部 $K-1$ 对比较。奖励模型只训 1 个 epoch，多训会很快过拟合 [@ouyang2022]。我们在黑板上排一次最小的名次：三个回答。

::: ex 黑板上 · 三个回答排一次名次
某提示下有三个回答，标注员排成 A > B > C，奖励模型当前给的分是 $r_A=1.2$、$r_B=0.4$、$r_C=-0.3$。$\binom32=3$，一次排序拆成三对比较：

| 对 | $\Delta$ | $\sigma(\Delta)$ | $-\log\sigma(\Delta)$ |
|---|---|---|---|
| A 胜 B | 0.8 | 0.6900 | 0.3711 |
| A 胜 C | 1.5 | 0.8176 | 0.2014 |
| B 胜 C | 0.7 | 0.6682 | 0.4032 |

按 (3.5) 取平均：$(0.3711+0.2014+0.4032)/3=0.3252$。三对的方向都排对了，但 B 与 C 的差距最小，它的损失最大，梯度也会最用力地拉开这一对。
:::

::: note 另外两种写法
**K 选 1。** Ziegler 等人让标注员从 4 个回答里只挑最好的一个，损失是 4 个选项上的 softmax 交叉熵：$-\E\big[\log\frac{e^{r(q,o_b)}}{\sum_ie^{r(q,o_i)}}\big]$，$o_b$ 是被挑中的那个 [@ziegler2019]。（原文印刷的式子漏了前面的负号，按字面最小化会把正确答案的概率压低。）$K=2$ 时它就是 BT。

**完整排序。** 把整个名次当作依次“从剩下的里选出最好的”，得到 Plackett–Luce 模型；DPO 论文附录给出了它的形式，并指出 $K=2$ 时退化为 BT [@rafailov2023dpo]。InstructGPT 没有用它，而是拆成两两比较。
:::

## 噪声、准确率与 Elo

人的判断有噪声，BT 损失对排反了的对惩罚是无界的（$\Delta\to-\infty$ 时 $-\log\sigma(\Delta)\approx-\Delta$）。大家想一想：一条标错的数据，会不会把模型拽歪？Christiano 等人的做法是假设人有 10% 的概率随手乱选 [@christiano2017]，于是预测概率变成

::: eq 带随机作答的偏好模型 | (3.6)
$$\hat P(o_w\succ o_l)=0.05+0.9\,\sigma(\Delta)$$
10% 的乱选里有一半恰好选中 $o_w$，贡献 0.05；其余 90% 按 BT 选。概率被夹在 $[0.05,0.95]$ 之间。
:::

这样一来，排反一对的损失最多只有 $-\ln0.05\approx3.0$（$\Delta=-10$ 时已经是 2.995），一条错标的数据最多贡献有限的损失，拽不歪整个模型。

那么这样训出来的评委，到底有多准？大家先猜一猜：预测标注员会选哪一篇，准确率 95%？至少 90% 吧？

::: ex 奖励模型能达到多准
InstructGPT 用 5 折交叉验证测奖励模型能否推广到没参与标注的人：在训练标注员组上准确率 $72.4\pm0.4\%$，在留出标注员组上 $69.6\pm0.9\%$ [@ouyang2022]。只有七成左右。

可是对照本页开头：训练标注员彼此一致的比例也只有 $72.6\pm1.5\%$。笔者的比较：奖励模型预测一位标注员偏好的准确率，已经和“另一位标注员能预测他”的准确率差不多。70% 左右看上去不高，但它的上限本来就被人与人之间的分歧卡住了。

Stiennon 等人在摘要任务上测了奖励模型的规模化：训练数据翻倍，验证准确率约提高 1.1%；模型尺寸翻倍，约提高 1.8% [@stiennon2020]。
:::

回到开头的 Elo。Anthropic 的 HH-RLHF 论文把偏好模型的分数换算成 Elo：$\Delta(\text{Elo})\approx174\,\Delta(\text{PM})$ [@bai2022hh]。这个 174 从哪来？Elo 的胜率公式是 $1/(1+10^{-\Delta_{Elo}/400})$（这里 $\Delta_{Elo}$ 取“自己减对手”），BT 的胜率是 $1/(1+e^{-\Delta_{PM}})$。令两者相等：$e^{-\Delta_{PM}}=10^{-\Delta_{Elo}/400}$，两边取自然对数得 $\Delta_{Elo}=\frac{400}{\ln10}\Delta_{PM}=173.7\,\Delta_{PM}$。所以奖励模型分数差 1，相当于 Elo 差约 174 分，胜率 $\sigma(1)=73.1\%$。

::: warn 奖励模型的盲区
奖励模型只在它见过的回答分布上学过：InstructGPT 的比较数据大部分来自 SFT 模型的回答 [@ouyang2022]。当第三步的策略开始写出 SFT 模型从来不写的东西（比如特别长、特别谄媚、重复某些评委爱看的词），奖励模型的打分就是外推，没有任何保证。这是下一页 KL 惩罚要解决的问题。
:::

:::: quiz 小练习：平移与缩放
奖励模型给某提示下的三个回答打分 $(3.0,\ 1.0,\ 0.0)$。（1）若所有分数都减去 1，三对比较的 BT 概率变不变？（2）若所有分数都乘 2 呢？（3）由此说明 BT 模型下奖励“确定到什么程度”。
::: answer 看答案
（1）不变。BT 概率只依赖差值，平移不改变差值。

（2）变。差值 $(2,3,1)$ 变成 $(4,6,2)$，例如第一对的概率从 $\sigma(2)=0.881$ 变成 $\sigma(4)=0.982$。缩放改变的是“模型有多确定”，会被数据的似然检验出来，所以缩放是可以从数据学出来的。

（3）在 BT 模型下，同一提示下的奖励只确定到一个平移（每个提示可以有不同的平移量）；尺度由数据中偏好的“确定程度”决定。
:::
::::

::: key 这一页讲了三件事
- **第一，分数差就是对数几率。** Bradley–Terry：$P(o_w\succ o_l)=\sigma(r_w-r_l)$ (3.2)，黑板上分数差 1.5 对应胜率 0.8176。它可以看成“真实分数 + Gumbel 噪声”的评分模型；奖励模型 = 语言模型 + 标量头，InstructGPT 所有尺寸的策略共用一个 6B 奖励模型。
- **第二，损失是最大似然 (3.3)，梯度 (3.4) 按“排反的概率”加权。** $\sigma(r_l-r_w)$ 大的对学得最用力（排反的 $\Delta=-1$ 比排对的 $\Delta=1.5$ 力度大 4 倍）。InstructGPT 把 $K$ 个回答的 $\binom K2$ 对放进一个 batch 元素，只训 1 个 epoch；准确率约七成，和标注员彼此的一致率相当。
- **第三，奖励只确定到每个提示上的一个平移。** 所以要额外归一化；这个看不见的平移，§7 会派上大用场。
:::

# 带 KL 惩罚的目标：别去讨好评委 | 为什么要把策略拴在参考模型上，以及它的闭式最优解 | 40

大家有没有见过这样的同学：他摸清了某位阅卷老师的口味，比如这位老师看到排比句就给高分、看到字数多就不忍心扣分。于是他每篇作文都塞满排比，越写越长。分数确实上去了，文章却越来越没法看。

上一页我们训练出了一位“模拟评委” $r_\phi$。有了它，最直接的想法是：让策略写的回答平均得分最高，即最大化 $\E_{o\sim\pi_\theta}[r_\phi(q,o)]$。大家先想一想，这样做会出什么事？

至少会出三种事。

1. **讨好评委。** 奖励模型只在 SFT 模型会写的那类回答上学过（上一页末尾）。策略一旦发现某种奇怪的写法能骗到高分，就会一路往那里跑，而那里奖励模型的分数和人的真实偏好已经没有关系。这叫**奖励黑客**（reward hacking），也叫奖励的**过度优化**（over-optimization）。开头那位塞满排比的同学，就是在做这件事。
2. **离开人类语言。** Ziegler 等人报告：去掉 KL 惩罚后，模型的输出变成乱码，即使另加熵奖励也一样 [@ziegler2019]。（那个实验的奖励是一个在亚马逊商品评论上训练的情感分类器给出的“正面”对数几率，论文称之为 mock sentiment 任务，用它模拟人的判断；它不是从人类偏好学出来的奖励模型。但道理相通：只要奖励函数在某些非语言的输出上给高分，策略就会去那里。）
3. **只剩一种回答。** 只最大化期望奖励，最优解是把全部概率放在得分最高的那一个回答上：一个确定性的、没有任何多样性的策略。

这一页讲 RLHF 的标准补救：在目标里减去一项“离参考模型有多远”的 KL 散度。我们会先在黑板上看清这一项在做什么，再写出目标、推出它的闭式最优解，最后讲它管不住的东西（对齐税）。

## 语言模型上的强化学习

**含义。** 强化学习（reinforcement learning，RL）研究的是：一个**策略**在环境里做出**动作**，环境给出**奖励**，怎样调整策略让累积奖励的期望最大。

**理解。** 放到语言模型上：环境给出一个提示 $q$，策略写出一段回答 $o$，奖励模型给这段回答打一个分，这一轮就结束了。InstructGPT 把这个环境称为**赌博机**（bandit）环境 [@ouyang2022]：像拉一次老虎机的拉杆，做一个动作（写一整段回答）、拿一次奖励，没有后续状态。但一段回答是一个 token 一个 token 写出来的，所以也可以换个粒度看：**状态**是 $s_t=(q,o_{<t})$（提示加上已经写出的部分），**动作**是下一个 token $a_t=o_t$，写到结束符为止是一个**回合**（episode）。这种逐 token 的看法叫马尔可夫决策过程（MDP），§4、§5 的 PPO 与 GAE 都在这个粒度上工作。两种看法说的是同一件事，下面会把它们对上。

::: pre 期望与采样 | 熟悉“用样本平均估计期望”的可以跳过
$\E_{o\sim\pi_\theta(\cdot\mid q)}[f(o)]=\sum_o\pi_\theta(o\mid q)f(o)$：按策略的概率给每个可能的回答加权，求 $f$ 的平均。回答的可能数目是 $\abs{\mathcal V}^{\abs{o}}$ 这个量级（$\abs{\mathcal V}$ 是词表大小），根本加不完。实际做法是**采样**：让策略独立地生成 $n$ 个回答 $o^{(1)},\dots,o^{(n)}$，用 $\frac1n\sum_if(o^{(i)})$ 估计期望。这个估计是**无偏**的（它的期望正好等于要估的量）；只要 $f(o)$ 的方差 $\Var[f(o)]$ 有限，估计的标准差就是 $\sqrt{\Var[f(o)]/n}$，按 $1/\sqrt n$ 缩小。这叫蒙特卡洛估计，见 [M04 §6](../math/m04-probability.html#p6)。
:::

## 黑板上：三个回答，只追分会怎样

我们把世界缩到最小：一个提示，只有三个可能的回答。这个例子本页会一直用，后面 §7 还要回来。

::: ex 黑板上 · 三个回答，三种分配
参考模型给三个回答的概率是 $\pi_{ref}=[0.6,\ 0.3,\ 0.1]$，评委给的分是 $r=[0,\ 1,\ 2]$：参考模型最爱写的回答 1 得分最低，它很少写的回答 3 得分最高。

**不动。** 照参考分布写，期望得分 $0\times0.6+1\times0.3+2\times0.1=0.5$。

**只追分。** 全押回答 3，分配 $[0,0,1]$，期望得分 2，翻了 4 倍。可它离原来的自己有多远？我们用一个量来度量“一个分配 $\pi$ 离参考分布多远”：$\sum_o\pi(o)\ln\frac{\pi(o)}{\pi_{ref}(o)}$（它叫 KL 散度，下面的前置框会讲它为什么总是大于等于 0）。全押回答 3 时只有一项：$1\times\ln\frac{1}{0.1}=\ln10=2.3026$。

**折中。** 分配 $[0.4,\ 0.4,\ 0.2]$：期望得分 $0.4+2\times0.2=0.8$；距离 $0.4\ln\frac{0.4}{0.6}+0.4\ln\frac{0.4}{0.3}+0.2\ln\frac{0.2}{0.1}$，即 $-0.1622+0.1151+0.1386=0.0915$。

现在给“走远”定个价：每走 1 个单位的距离，扣 1 分。三种分配的净得分：

| 分配 | 期望得分 | 距离 | 净得分（扣价 1 分/单位） |
|---|---|---|---|
| 不动 $[0.6,0.3,0.1]$ | 0.5 | 0 | 0.5 |
| 折中 $[0.4,0.4,0.2]$ | 0.8 | 0.0915 | 0.7085 |
| 全押 $[0,0,1]$ | 2 | 2.3026 | −0.3026 |

一加上价钱，“全押”就从第一名掉到了最后一名。
:::

黑板上这张表，就是 RLHF 目标的全部意思：得分减去“扣价 × 距离”。下面把它写成一般形式。

## 目标函数

**数学。** RLHF 的目标是：在提示分布 $\mathcal D$ 上，让策略自己生成的回答得分高，同时离参考策略不远 [@ziegler2019; @stiennon2020; @ouyang2022]：

::: eq 带 KL 惩罚的 RLHF 目标 | (3.7)
$$\mathcal J(\theta)=\E_{q\sim\mathcal D,\;o\sim\pi_\theta(\cdot\mid q)}\Big[r_\phi(q,o)-\beta\log\frac{\pi_\theta(o\mid q)}{\pi_{ref}(o\mid q)}\Big]$$
$\beta>0$ 是 KL 系数；$\pi_{ref}$ 通常是 SFT 阶段得到的模型，训练中冻结。方括号里的量叫 **KL 修正后的奖励**。
:::

代回黑板：只有一个提示时，方括号对 $o\sim\pi$ 取期望，就是“期望得分 $-\ \beta\times$ 距离”；黑板上的扣价 1 分/单位，就是 $\beta=1$。

方括号里第二项是**一个样本**上的对数概率比。它的期望就是 KL 散度：

::: pre KL 散度与它为什么非负 | 熟悉 KL 与 Gibbs 不等式的可以跳过
两个分布 $p$、$q$ 的 **KL 散度**（Kullback–Leibler divergence）定义为 $\KL(p\,\|\,q)=\sum_xp(x)\log\frac{p(x)}{q(x)}=\E_{x\sim p}\big[\log\frac{p(x)}{q(x)}\big]$。它量的是“用 $q$ 去近似 $p$ 损失了多少”，单位是 nat（用自然对数时）。

**非负，且只在 $p=q$ 时为 0**（Gibbs 不等式）。只用一个事实 $\ln x\le x-1$（等号仅在 $x=1$）；约定 $0\log0=0$，所以求和只取 $p(x)>0$ 的项（若某个 $p(x)>0$ 处 $q(x)=0$，KL 为 $+\infty$，结论照样成立）：

$$-\KL(p\,\|\,q)=\sum_{x:\,p(x)>0}p(x)\ln\frac{q(x)}{p(x)}\le\sum_{x:\,p(x)>0}p(x)\Big(\frac{q(x)}{p(x)}-1\Big)=\sum_{x:\,p(x)>0}q(x)-1\le0.$$

等号要求每个 $p(x)>0$ 的位置都有 $q(x)/p(x)=1$，也就是 $p=q$。**不对称**：$\KL(p\|q)\ne\KL(q\|p)$ 一般成立。RLHF 用的是 $\KL(\pi_\theta\|\pi_{ref})$，期望按**策略自己**的分布取，所以可以用策略自己的样本来估计。非负性的另一种证明（Jensen 不等式）见 [M05 §4](../math/m05-information-theory.html#p4)，前向与反向 KL 的区别见 [M05 §5](../math/m05-information-theory.html#p5)。
:::

::: deriv 序列级的对数比 = 逐 token 对数比之和，其期望 = KL
$\log\dfrac{\pi_\theta(o\mid q)}{\pi_{ref}(o\mid q)}=\log\dfrac{\prod_t\pi_\theta(o_t\mid q,o_{<t})}{\prod_t\pi_{ref}(o_t\mid q,o_{<t})}$ || 两个模型都按自回归分解（第 2 课）
$=\sum_{t=1}^{\abs{o}}\log\dfrac{\pi_\theta(o_t\mid q,o_{<t})}{\pi_{ref}(o_t\mid q,o_{<t})}$ || 乘积的对数 = 对数之和
$\E_{o\sim\pi_\theta}\Big[\log\dfrac{\pi_\theta(o\mid q)}{\pi_{ref}(o\mid q)}\Big]=\KL\big(\pi_\theta(\cdot\mid q)\,\|\,\pi_{ref}(\cdot\mid q)\big)$ || KL 的定义，期望按 $\pi_\theta$ 取，正好是采样的分布
:::

第一行说明整段回答的 KL 惩罚可以**摊到每个 token 上**。这就解释了 InstructGPT 的两句话为什么不矛盾：环境是“赌博机”（整段回答一个奖励），却又“在每个 token 上加 KL 惩罚” [@ouyang2022]。把逐 token 奖励定义成

::: eq 逐 token 的奖励 | (3.8)
$$r_t=-\beta\log\frac{\pi_\theta(o_t\mid q,o_{<t})}{\pi_{ref}(o_t\mid q,o_{<t})}+\mathbb 1[t=\abs{o}]\;r_\phi(q,o)$$
$\mathbb 1[t=\abs{o}]$ 在最后一个 token 处为 1、其余为 0：奖励模型的分数只在回答结束时发一次，KL 惩罚每个 token 都有。不打折扣地求和，$\sum_tr_t$ 恰好等于 (3.7) 方括号里的量。
:::

所以 InstructGPT 说估计优势时“不打折扣”（§5 的 $\gamma=1$）不是随手的选择：只有不打折扣，逐 token 奖励之和才等于序列级的目标 [@ouyang2022]。DeepSeekMath 在介绍 PPO 时写的也是这个逐 token 形式 [@shao2024deepseekmath]。

::: ex 一段四个 token 的回答（§5 还会用到）
$\beta=0.05$，奖励模型给这段回答 1.0 分。采样时逐 token 的对数比 $\log\frac{\pi_\theta}{\pi_{ref}}$ 依次是 $0.10,\ -0.05,\ 0.20,\ 0.00$（这组数是笔者自拟的）。

- 逐 token 奖励：$r_1=-0.05\times0.10=-0.005$，$r_2=-0.05\times(-0.05)=+0.0025$，$r_3=-0.05\times0.20=-0.010$，$r_4=-0.05\times0+1.0=1.0$。
- 总和 $0.9875$。按序列算：对数比之和 $0.25$，$1.0-0.05\times0.25=0.9875$，一致。

注意第 2 个 token 的 KL 奖励是**正**的：这个 token 上策略的概率比参考模型低，单个样本的对数比可以为负。只有取期望之后 KL 才一定非负。用单个样本的对数比估计 KL 是无偏的，但方差不小；第 8 课会讲 GRPO 换用的另一种估计器。
:::

## KL 项在做什么

KL 项不只是“别跑太远”。把它拆开看，里面有两股力。下面把 $\E_{o\sim\pi_\theta}$ 简写成 $\E$，并省略“$(o\mid q)$”：

::: deriv KL 惩罚 = 熵奖励 + 参考似然奖励
$-\beta\,\E\Big[\log\dfrac{\pi_\theta}{\pi_{ref}}\Big]=-\beta\,\E[\log\pi_\theta]+\beta\,\E[\log\pi_{ref}]$ || 商的对数 = 对数之差，期望可以拆开
$=\beta\,H(\pi_\theta)+\beta\,\E[\log\pi_{ref}]$ || 熵的定义：$H(p)=-\E_{x\sim p}[\log p(x)]$
:::

::: eq KL 惩罚的两个分量 | (3.9)
$$-\beta\,\KL(\pi_\theta\|\pi_{ref})=\underbrace{\beta\,H(\pi_\theta)}_{\text{别把概率押在一处}}+\underbrace{\beta\,\E_{o\sim\pi_\theta}[\log\pi_{ref}(o\mid q)]}_{\text{写参考模型认为“像话”的东西}}$$
第一项是**熵奖励**：分布越分散越好，防止上面说的“只剩一种回答”。第二项奖励参考模型给出高概率的回答，把策略留在奖励模型见过的区域、留在自然语言里。
:::

回到黑板上的“全押”：它的熵是 0，而且把全部概率放在参考模型只给 0.1 的回答上，$\E[\log\pi_{ref}]=\ln0.1$。两股力一起罚它，罚了 2.3026。Ziegler 等人和 Stiennon 等人都把 KL 项解释为一个熵奖励，外加“防止策略跑到奖励模型没见过的输出上去” [@ziegler2019; @stiennon2020]；(3.9) 把这两种解释写成了等式。

## 闭式最优策略

黑板上扣价 1 分/单位时，我们试了三种分配，最好的是折中的 0.7085。那么问题来了：还有没有更好的？最好的分配长什么样？

大家先别急着推导，我把答案写在黑板上，我们先验算它是不是真的更好。

::: ex 黑板上 · 最优分配：乘一乘，再归一化
规则只有两步：每个回答的参考概率乘上 $e^{r/\beta}$，再除以总和。$\beta=1$ 时：

- 乘：$0.6\times e^0=0.6$，$0.3\times e^1=0.8155$，$0.1\times e^2=0.7389$。它们的和 $Z=2.1544$。
- 除：$\pi^*=[0.6,\ 0.8155,\ 0.7389]/2.1544=[0.2785,\ 0.3785,\ 0.3430]$。
- 期望得分：$0\times0.2785+1\times0.3785+2\times0.3430=1.0645$（参考分布只有 0.5）。
- 距离：$\KL(\pi^*\|\pi_{ref})=0.2785\ln\frac{0.2785}{0.6}+0.3785\ln\frac{0.3785}{0.3}+0.3430\ln\frac{0.3430}{0.1}$，算出来是 $0.2970$。
- 净得分：$1.0645-1\times0.2970=0.7675$。

0.7675，比折中的 0.7085 高，比全押的 $-0.3026$ 高出一大截。它既把概率往高分回答挪了（回答 3 从 0.1 涨到 0.343），又没有挪得太远。
:::

为什么是这个规则？下面逐行推出来。对每个提示 $q$，策略 $\pi(\cdot\mid q)$ 可以单独选，所以只需对固定的 $q$ 求最优。为了简洁，下面省略“$\mid q$”，并记 $r(o)=r(q,o)$。如果策略可以是**任意**分布（不受神经网络能表示什么的限制），这个问题有精确的答案，它也是 §7 DPO 的起点。

::: deriv KL 约束下奖励最大化的最优解
$\max_\pi\ \E_{o\sim\pi}\Big[r(o)-\beta\log\dfrac{\pi(o)}{\pi_{ref}(o)}\Big]$ || (3.7) 对固定 $q$ 的部分；$\pi$ 可以是任意分布
$=-\beta\,\min_\pi\ \E_{o\sim\pi}\Big[\log\dfrac{\pi(o)}{\pi_{ref}(o)}-\dfrac{r(o)}{\beta}\Big]$ || 提出 $-\beta$（$\beta>0$），最大化变成最小化
$Z:=\sum_o\pi_{ref}(o)\,e^{r(o)/\beta}$ || 定义一个只依赖提示的正数
$\pi^*(o):=\pi_{ref}(o)\,e^{r(o)/\beta}/Z$ || 每项非负，除以总和后和为 1，所以 $\pi^*$ 是合法的概率分布
$\log\dfrac{\pi(o)}{\pi_{ref}(o)}-\dfrac{r(o)}{\beta}=\log\dfrac{\pi(o)}{\pi_{ref}(o)\,e^{r(o)/\beta}}$ || 把 $r/\beta$ 收进对数：$r/\beta=\log e^{r/\beta}$
$=\log\dfrac{\pi(o)}{Z\,\pi^*(o)}=\log\dfrac{\pi(o)}{\pi^*(o)}-\log Z$ || 由第 (4) 行，$\pi_{ref}\,e^{r/\beta}=Z\,\pi^*$
$\E_{o\sim\pi}\Big[\log\dfrac{\pi(o)}{\pi^*(o)}-\log Z\Big]=\KL(\pi\|\pi^*)-\log Z$ || $\log Z$ 不依赖 $o$；前一项按定义是 KL
$\min_\pi\big[\KL(\pi\|\pi^*)-\log Z\big]=-\log Z$ || $Z$ 不依赖 $\pi$；KL $\ge0$，且仅在 $\pi=\pi^*$ 时为 0（Gibbs 不等式），所以最小值在 $\pi=\pi^*$ 处取到
$\max_\pi(\cdots)=-\beta\cdot(-\log Z)=\beta\log Z$ || 代回第 (2) 行
:::

这个推导照 DPO 论文附录 A.1 的步骤走，理由是笔者补的 [@rafailov2023dpo]。结论写成两个式子：

::: eq KL 约束下的最优策略 | (3.10)
$$\pi^*(o\mid q)=\frac{1}{Z(q)}\,\pi_{ref}(o\mid q)\,\exp\!\Big(\frac{r(q,o)}{\beta}\Big),\qquad Z(q)=\sum_o\pi_{ref}(o\mid q)\exp\!\Big(\frac{r(q,o)}{\beta}\Big)$$
$Z(q)$ 叫**配分函数**（partition function），只依赖提示，不依赖回答。
:::

::: eq 最优目标值 | (3.11)
$$\max_\pi\ \Big(\E_{o\sim\pi}[r]-\beta\,\KL(\pi\|\pi_{ref})\Big)=\beta\log Z(q)$$
:::

代回黑板：$\beta\log Z=1\times\ln2.1544=0.7675$，正是黑板上算出的净得分。对，0.7675。倒数第二行还告诉我们，任何别的分配都要比它少 $\beta\,\KL(\pi\|\pi^*)$：折中的 $[0.4,0.4,0.2]$ 比它少 $0.7675-0.7085=0.0590$，这就是折中分配到 $\pi^*$ 的 KL。

用 (3.9) 也能核对：$\pi^*$ 的熵 $H=1.09076$，$\E_{\pi^*}[\log\pi_{ref}]=-1.38773$，两者之和 $-0.29697$，正是 $-\KL$（四位小数 $-0.2970$；如果先把两项各取四位小数再相加，得到 $1.0908-1.3877=-0.2969$，差的 1 在舍入）。

**读法。** 最优策略就是把参考分布按 $e^{r/\beta}$ **倾斜**：奖励高的回答概率被放大，奖励低的被缩小，放大倍数由 $\beta$ 控制。$\beta$ 像一个温度：$\beta\to\infty$ 时 $e^{r/\beta}\to1$，$\pi^*\to\pi_{ref}$，完全不动；$\beta\to0$ 时 $e^{r/\beta}$ 被最大的那个 $r$ 压倒，$\pi^*$ 把全部概率押在（参考模型给了正概率的回答里）最高分的回答上。还要注意：参考模型给 0 概率的回答，无论奖励多高，$\pi^*$ 也给 0；参考模型给极小概率的回答，要有很大的奖励才能被放大到可观的概率（放大倍数是 $e^{r/\beta}/Z$）。所以最优策略**主要是在参考模型已经会写的回答之间重新分配概率**。（严格为 0 的情形在神经网络里几乎不出现，softmax 给任何 token 的概率都是正的；这句话说的是量级，不是定理。）

::: fig figures/l03-kl-tilt.svg | 图 3.4 KL 约束下的最优策略：参考分布按 exp(r/β) 倾斜
**看每一行深绿色那一段（奖励最高的回答 3）怎样随 $\beta$ 变小而变长。** 第一行是参考分布 $[0.6,0.3,0.1]$，三个回答的奖励是 $0,1,2$。$\beta=2$ 时只是轻轻倾斜；$\beta=0.25$ 时回答 3 已拿走 94.6% 的概率。右边三列是期望奖励、到参考分布的 KL、以及最优目标值 $\E[r]-\beta\,\KL$；最后一列在每个 $\beta$ 行都等于 $\beta\log Z$，与 (3.11) 一致（参考分布那一行没有 $\beta$，所以不填）。数字由脚本计算。
:::

::: fig figures/l03-frontier.svg | 图 3.5 奖励–KL 前沿：最优策略族，以及一个在前沿之下的策略
**看绿色曲线：它是所有 $\beta$ 下最优策略的轨迹，任何策略都到不了它的左上方。** 横轴是离参考分布的 KL，纵轴是期望奖励。在给定 $\beta$ 下，最优点是斜率为 $\beta$ 的直线（目标值相等的线）与曲线相切的地方；蓝色虚线画的是 $\beta=1$ 的情形，截距正是最优目标值 $\beta\log Z=0.768$。空心圆是一个把概率集中在中等回答上的策略：它“花掉”的 KL 和 $\beta\approx0.7$ 的最优策略差不多，期望奖励却低 0.32。DPO 论文图 2 用同样的坐标比较 DPO 与 PPO [@rafailov2023dpo]；这里是玩具例子，由脚本计算。
:::

::: warn 这个解为什么不能直接用
(3.10) 里的 $Z(q)$ 要对**所有**可能的回答求和，数量是 $\abs{\mathcal V}^{\abs{o}}$ 级的，算不出来；黑板上只有三个回答，所以我们能算。而且神经网络策略未必能精确表示 $\pi^*$（推导要求策略类是“任意分布”，DPO 论文称之为非参数的策略类 [@rafailov2023dpo]）。所以 RLHF 不直接写出 $\pi^*$，而是用强化学习**从采样中逼近它**：这就是 PPO 的工作。§7 会看到，DPO 找到了一种让 $Z(q)$ 自己消掉的办法。
:::

还有一个小性质，下一页和 §7 都会用到：如果给同一个提示下所有回答的奖励都加上同一个常数 $c(q)$，(3.10) 的分子分母同乘 $e^{c(q)/\beta}$，$\pi^*$ 不变。这和上一页“BT 奖励只确定到每个提示的平移”严丝合缝：奖励模型学不出来的那部分，本来也不影响最优策略。

## 过度优化：KL 在防什么

KL 惩罚防的主要是奖励模型的**失效**。Stiennon 等人系统地测过：用越来越强的优化去追奖励模型的分数，人的真实偏好先升后降，最终奖励模型与人的偏好**负相关** [@stiennon2020]。

::: fig figures/l03-overopt.svg | 图 3.6 奖励过度优化（示意）
**看两条曲线分开的地方：在竖虚线（真实偏好的最高点）右边，奖励模型的分数（绿线）还在上升，人的真实偏好（虚线曲线）却已经开始下降。** 横轴是优化强度，可以用策略到参考模型的 KL 来量。KL 惩罚的作用就是让优化停在左边。这是示意图：形状取自 Stiennon 等人论文图 5 的定性结论，曲线不是论文数据 [@stiennon2020]。
:::

用作文类比：学生发现模拟评委对某些套话、对篇幅特别宽容，于是作文越写越长、套话越来越多；评委的分数越来越高，真正的读者越来越不耐烦。KL 惩罚相当于规定“你的文风不许离原来的自己太远”，套话和注水都要付代价。**但是这个比方有个地方不对**：真实的学生是有意钻空子，策略没有“意图”，它只是沿着奖励模型的梯度走，哪里分数高就往哪里去。

## β 该取多大

$\beta$ 是在“多拿奖励”和“少走远”之间的汇率：每多走 1 nat 的 KL，要多拿 $\beta$ 分奖励才划算。黑板上的扣价 1 分/单位就是汇率 1。真实系统的取值差别很大：

| 系统 | KL 系数 | 奖励的尺度 | 来源 |
|---|---|---|---|
| Ziegler 等（2019） | 固定或自适应（控制器增益 $K_\beta=0.1$） | 归一化到均值 0、方差 1 | [@ziegler2019] |
| Stiennon 等（2020） | $\beta=0.05$ | 参考摘要的平均分为 0 | [@stiennon2020] |
| InstructGPT（2022） | $\beta=0.02$；扫描显示最优约 0.01 到 0.02 | 示范回答的平均分为 0 | [@ouyang2022] |
| HH-RLHF（2022） | $\lambda_{KL}=0.001$，作者认为“可能完全不需要” | 偏好模型分数 | [@bai2022hh] |
| DPO（2023） | $\beta=0.1$；TL;DR 摘要任务 $0.5$ | 无显式奖励（§7） | [@rafailov2023dpo] |

差一个数量级以上并不奇怪：$\beta$ 的单位是“奖励分 / nat”，奖励的尺度一变，$\beta$ 就得跟着变。所以不存在一个“标准的 $\beta$”；DPO 的 $\beta$ 在 (3.7) 里扮演同样的角色，但训练方式不同，数值不能和 PPO 的直接比较。

Ziegler 等人还给了一种**自适应**的做法：设一个目标 KL，实际 KL 高了就加大 $\beta$，低了就减小 [@ziegler2019]：

::: eq Ziegler 的自适应 KL 控制器 | (3.12)
$$e_t=\clip\!\Big(\frac{\mathrm{KL}_t-\mathrm{KL}_{target}}{\mathrm{KL}_{target}},\,-0.2,\,0.2\Big),\qquad\beta_{t+1}=\beta_t\,(1+K_\beta\,e_t),\quad K_\beta=0.1$$
$\clip(x,a,b)$ 把 $x$ 截到区间 $[a,b]$ 里。每一步 $\beta$ 最多变化 $\pm2\%$。
:::

::: ex 控制器走一步
目标 KL 为 6。某一步实测 KL 为 12：相对误差 $(12-6)/6=1.0$，截到 0.2，$\beta$ 乘以 $1+0.1\times0.2=1.02$。下一步实测 5.4：相对误差 $-0.1$，不用截，$\beta$ 乘以 $0.99$。控制器每步只做很小的修正，靠累积把 KL 稳在目标附近。
:::

## 对齐税与 PPO-ptx

§1 那个错误框里留了一笔账：对齐税。KL 惩罚能不能顺便把它补上？

::: err 很多人以为：KL 惩罚把模型拴在参考模型上，预训练学到的能力也就保住了
很多人以为：既然策略离参考模型不远，参考模型会的东西，策略自然也都还会。

其实：InstructGPT 在 1.3B 模型上把 KL 系数一路加到 2.0，是默认值 0.02 的 100 倍，公开 NLP 基准上的退步**仍然修不好** [@ouyang2022]。KL 项约束的是“在 RL 提示上的回答分布”，管不到“在别的任务上的能力”。
:::

InstructGPT 的办法是在目标里直接混入预训练数据的似然：

::: eq PPO-ptx：混入预训练梯度 | (3.13)
$$\mathcal J_{ptx}(\theta)=\E_{q\sim\mathcal D,\;o\sim\pi_\theta}\Big[r_\phi(q,o)-\beta\log\frac{\pi_\theta(o\mid q)}{\pi_{ref}(o\mid q)}\Big]+\gamma_{ptx}\,\E_{x\sim\mathcal D_{pretrain}}\big[\log\pi_\theta(x)\big]$$
据 InstructGPT 式 (2)（arXiv 版；NeurIPS 正式版删去了这个式子，只用文字描述）[@ouyang2022]。$\gamma_{ptx}=27.8$；每个 RL 回合配 8 个预训练样本。$\gamma_{ptx}=0$ 的版本论文称为“PPO”，文中所说的 InstructGPT 指的是 PPO-ptx。
:::

**读法。** 第二项就是第 2 课的预训练损失（取负号前的对数似然），乘上一个很大的系数混进 RL 的梯度里。论文附录说 $\gamma_{ptx}\ge20$ 就足以在 1.3B 模型上恢复退步，27.8 在各个尺寸上都好用 [@ouyang2022]。KL 项管不到的能力，混入预训练数据就直接在那些能力上加一道锚。

::: warn “参考模型就是 SFT 模型”这句话要打折扣
InstructGPT 正文和式 (2) 把参考模型写成 $\pi^{SFT}$，但附录说明：RL 的初始化模型是在预训练 GPT-3 上用示范数据训 2 个 epoch、并混入 10% 预训练数据得到的，“这些模型也用来计算 KL 奖励”，而不是正文那个训了 16 个 epoch 的 SFT 基线；上面那组“加大 KL 系数能否修好对齐税”的扫描实验（附录 E.6）里，KL 的参考又换成了预训练 GPT-3 [@ouyang2022]。说“参考模型通常是 SFT 模型”没错，但具体是哪一个，各实现并不相同。
:::

:::: quiz 小练习：β 与倾斜
仍用黑板上的 $\pi_{ref}=[0.6,0.3,0.1]$、$r=[0,1,2]$。（1）$\beta=0.5$ 时，回答 3 和回答 1 在最优策略下的概率之比是多少？在参考分布下呢？（2）把所有奖励都加 10，最优策略变不变？
::: answer 看答案
（1）由 (3.10)，$\frac{\pi^*(3)}{\pi^*(1)}=\frac{\pi_{ref}(3)}{\pi_{ref}(1)}\,e^{(r_3-r_1)/\beta}=\frac{0.1}{0.6}\,e^{2/0.5}=\frac{54.60}{6}=9.10$。参考分布下是 $0.1/0.6=0.167$。对照图 3.4 的 $\beta=0.5$ 行（图里是三位小数 0.072 与 0.660，四位小数是 0.0725 与 0.6597，见练习 7）：$0.6597/0.0725=9.10$。$Z$ 在比值里消掉了。

（2）不变。每个权重都乘上 $e^{10/0.5}$，$Z$ 也乘上同一个数，归一化后抵消。
:::
::::

::: key 这一页讲了三件事
- **第一，目标是“得分减扣价”。** RLHF 的目标 (3.7) = 奖励模型的分数 − $\beta\times$ 到参考模型的 KL；黑板上一加扣价，“全押最高分”就从 2 分跌到 $-0.3026$。KL 可以摊成逐 token 的惩罚 (3.8)，不打折扣时两者完全等价；它又等于熵奖励加参考似然奖励 (3.9)，防止押宝一种回答，也防止跑到奖励模型没见过的地方去讨好它。
- **第二，最优解是“乘一乘，再归一化”。** 若策略可以任意，$\pi^*\propto\pi_{ref}e^{r/\beta}$ (3.10)，最优值 $\beta\log Z$ (3.11)；黑板上 $\beta=1$ 时是 $[0.2785,0.3785,0.3430]$ 与 0.7675。$Z$ 在真实模型上算不出来，所以要用 RL 从采样中逼近；DPO 则设法让它消掉。
- **第三，KL 管不住所有事。** $\beta$ 的数值依赖奖励尺度（0.001 到 0.5 都有人用）；KL 保不住预训练能力，InstructGPT 靠混入预训练梯度（PPO-ptx，$\gamma_{ptx}=27.8$）。
:::

# PPO：一次只走一小步 | 策略梯度、重要性比与裁剪目标 | 40

学过游泳或者学过开车的朋友都有体会：好教练纠正动作，从来不是让你一下子全改，而是“手再抬高一点……好，就这样，别再抬了”。一次改太多，动作就变形了；已经改到位的地方，他也不会让你继续往那个方向加码。

上一页给了目标 (3.7)，也说明了它的最优解在真实模型上写不出来。剩下的问题是：**怎样用梯度上升一步步去逼近它，而且每一步都不迈得太大？** 这里有两个麻烦。

- **第一，要改的东西就是出题的人。** (3.7) 的期望是对 $o\sim\pi_\theta$ 取的，而 $\pi_\theta$ 正是我们要改的东西：参数一动，样本的分布也跟着动，没法像监督学习那样“固定数据、对损失求导”。
- **第二，样本很贵。** 每个样本都要让策略自回归地生成一整段回答（第 4 课会讲这为什么慢），我们希望一批样本能用好几次。

PPO（proximal policy optimization，近端策略优化）[@schulman2017ppo] 对这两个麻烦各给了一个答案：策略梯度，和“裁剪过的”重要性比。第二个答案，就是那位教练的“好，别再抬了”。

## 策略梯度：让好的 token 更可能

**含义。** 策略梯度（policy gradient）是“期望奖励对策略参数的梯度”的一个可以用样本估计的表达式。

::: pre 对数导数技巧 | 见过 $\nabla\pi=\pi\nabla\log\pi$ 的可以跳过
对任意依赖 $\theta$ 的正函数 $p_\theta$，$\nabla_\theta\log p_\theta=\frac{\nabla_\theta p_\theta}{p_\theta}$（链式法则），所以 $\nabla_\theta p_\theta=p_\theta\,\nabla_\theta\log p_\theta$。它的用处是把“对概率求导”变回“按概率求期望”，于是又能用采样来估计。完整的策略梯度定理在 [M09 §2](../math/m09-rl-math.html#p2)，“减去基线不改变期望”的证明在 [M09 §3](../math/m09-rl-math.html#p3)。
:::

::: deriv 策略梯度（赌博机形式）
$\nabla_\theta\,\E_{o\sim\pi_\theta}[R(o)]=\nabla_\theta\sum_o\pi_\theta(o)\,R(o)=\sum_oR(o)\,\nabla_\theta\pi_\theta(o)$ || 期望写成求和；$R$ 是这段回答的回报，不依赖 $\theta$
$=\sum_o\pi_\theta(o)\,R(o)\,\nabla_\theta\log\pi_\theta(o)$ || 对数导数技巧
$=\E_{o\sim\pi_\theta}\big[R(o)\,\nabla_\theta\log\pi_\theta(o)\big]$ || 又变回了期望，可以用策略自己的样本估计
$=\E_{o\sim\pi_\theta}\Big[R(o)\sum_t\nabla_\theta\log\pi_\theta(o_t\mid q,o_{<t})\Big]$ || 自回归分解：序列的对数概率是逐 token 之和
:::

**理解。** 最后一行的意思很朴素：采一段回答，如果它的回报高，就把它每个 token 的对数概率都往上推；回报低就往下压。实际中不直接用回报 $R$，而是用**优势**（advantage）$\hat A_t$：“第 $t$ 个 token 让结果比预期好了多少”。好于预期为正、差于预期为负。用**真实**的优势（或者“回报减去一个只依赖状态的基线”）代替回报，不改变梯度的期望，却大大减小方差（§5 会先在黑板上算一个两选一的例子，再证明“减基线不改变期望”；方差的分析见 [M09 §3](../math/m09-rl-math.html#p3)）。实际用的是估计值 $\hat A_t$：它要靠一个学出来的价值网络，价值网络不准时 $\hat A_t$ 会带来偏差（§5）。怎样算 $\hat A_t$ 是下一页的内容。于是 PPO 论文的式 (1) [@schulman2017ppo]，写成本课的记号：

::: eq 策略梯度估计 | (3.14)
$$\hat g=\hat\E_t\Big[\hat A_t\,\nabla_\theta\log\pi_\theta(o_t\mid q,o_{<t})\Big]$$
$\hat\E_t$ 表示在一批采样得到的 token 上取平均（PPO 论文的记号）。每个 token 的梯度方向是“让它更可能”，权重是它的优势。
:::

## 一批样本用几次：重要性比

(3.14) 要求样本来自**当前**的 $\pi_\theta$。可我们想让一批样本做好几步更新：做完第一步，参数已经变了，这批样本就成了“旧策略” $\pi_{\theta_{old}}$ 的样本。旧样本还能不能用来估计新策略下的平均？我们在黑板上试一试。

::: ex 黑板上 · 用旧样本算新期望
某个状态下只有三个 token 可选。采样那一刻（旧策略）的概率是 $\pi_{old}=[0.5,\ 0.3,\ 0.2]$；更新了几步之后（新策略）变成 $\pi_{new}=[0.4,\ 0.3,\ 0.3]$。每个 token 带着一个数 $f=[1,\ 0,\ 2]$（比如它的优势）。我们想要的是**新策略下** $f$ 的平均。

- 直接按新策略算：$0.4\times1+0.3\times0+0.3\times2=1.0$。
- 可手里的样本是旧策略采的。直接拿来平均：$0.5\times1+0.3\times0+0.2\times2=0.9$。差了 0.1，不对。
- 给每个样本“改票数”，乘上“新概率 ÷ 旧概率”：$\rho=[0.4/0.5,\ 0.3/0.3,\ 0.3/0.2]=[0.8,\ 1.0,\ 1.5]$。再平均：$0.5\times0.8\times1+0.3\times1.0\times0+0.2\times1.5\times2$，也就是 $0.4+0+0.6=1.0$。对上了。

token 3 在新策略下比样本里出现得更频繁（0.2 变 0.3），所以它的样本按 1.5 倍计入；token 1 变少了（0.5 变 0.4），按 0.8 倍计入。
:::

这个办法叫**重要性采样**（importance sampling）：从一个分布采样，去估计另一个分布下的期望，只要给每个样本乘上两个分布的概率之比。

::: eq 重要性采样恒等式 | (3.15)
$$\E_{a\sim\pi_\theta}[f(a)]=\sum_a\pi_{\theta_{old}}(a)\,\frac{\pi_\theta(a)}{\pi_{\theta_{old}}(a)}\,f(a)=\E_{a\sim\pi_{\theta_{old}}}\Big[\frac{\pi_\theta(a)}{\pi_{\theta_{old}}(a)}\,f(a)\Big]$$
第一个等号只是乘了再除以同一个数（要求 $\pi_{\theta_{old}}(a)>0$）。详见 [M04 §7](../math/m04-probability.html#p7)（方差与有效样本数）和 [M09 §5](../math/m09-rl-math.html#p5)。
:::

代回黑板：左边是新策略下的平均 1.0，右边是旧样本改票数后的平均 1.0。

**理解。** 比值是在给旧样本“改票数”。旧策略以 0.2 的概率采到某个 token，新策略给它 0.3：在新策略下它会比样本里出现得更频繁，所以这个样本按 $0.3/0.2=1.5$ 倍计入；新策略只给它 0.1 的话，就按 0.5 倍计入。只要每个样本都这样加权，旧样本的平均就还是新策略下的期望。

把它用到每个 token 上，就得到 PPO 论文里的“保守策略迭代”替代目标（下标 CPI 是 conservative policy iteration 的缩写）[@schulman2017ppo]：

::: eq 概率比与替代目标 | (3.16)
$$\rho_t(\theta)=\frac{\pi_\theta(o_t\mid q,o_{<t})}{\pi_{\theta_{old}}(o_t\mid q,o_{<t})},\qquad\mathcal J^{CPI}(\theta)=\hat\E_t\big[\rho_t(\theta)\,\hat A_t\big]$$
$\rho_t$ 是一个正数：新策略给这个已采样 token 的概率，是采样时那一刻的几倍。$\theta=\theta_{old}$ 时 $\rho_t=1$。
:::

为什么对它求梯度是对的？在 $\theta=\theta_{old}$ 这一点上：

::: deriv 替代目标在起点处给出策略梯度
$\nabla_\theta\rho_t=\dfrac{\nabla_\theta\pi_\theta(o_t\mid\cdot)}{\pi_{\theta_{old}}(o_t\mid\cdot)}=\rho_t\,\nabla_\theta\log\pi_\theta(o_t\mid\cdot)$ || 分母是采样时记下的数，不依赖 $\theta$；再用对数导数技巧
$\nabla_\theta\mathcal J^{CPI}\big|_{\theta=\theta_{old}}=\hat\E_t\big[\hat A_t\cdot1\cdot\nabla_\theta\log\pi_\theta(o_t\mid\cdot)\big]$ || 在起点 $\rho_t=1$
$=\hat g$ || 正是 (3.14)
:::

::: warn 为什么是逐 token 的比值，而不是整段回答的比值
(3.15) 是对**一个动作**写的。整段回答的概率是逐 token 概率之积，所以整段回答的重要性权重是逐 token 比值之积：

$$\frac{\pi_\theta(o\mid q)}{\pi_{\theta_{old}}(o\mid q)}=\prod_{t=1}^{\abs{o}}\rho_t(\theta)$$

乘积对很小的偏差也极其敏感。一段 200 个 token 的回答，即使每个 token 的比值都只有 1.01，乘起来也是 $1.01^{200}=7.32$；每个都是 0.99，就是 $0.99^{200}=0.134$。用这样的权重，少数几个样本就会主导整批梯度，方差大到没法用。(3.16) 只给第 $t$ 项乘上它自己的 $\rho_t$，不去乘前面各 token 的比值，等于假设“前文 $o_{<t}$ 出现的频率”在新旧策略之间没怎么变。这个近似只在 $\theta$ 离 $\theta_{old}$ 很近时才可靠，所以必须管住每一步走多远：这正是下面 TRPO 的约束和 PPO 的裁剪要做的事。PPO 论文直接从逐时间步的替代目标出发 [@schulman2017ppo]；这个近似从哪里来、乘积的方差怎样随长度指数增长，见 [M09 §5](../math/m09-rl-math.html#p5)。
:::

可是离开起点越远，$\mathcal J^{CPI}$ 就越不可信：它只在 $\theta_{old}$ 附近是真实目标的好近似。如果放开手去最大化它，某个优势为正的 token 的 $\rho_t$ 可以被推到 10、100，目标值线性增长，参数被带到一个面目全非的地方。PPO 论文明说：没有约束时，最大化 $L^{CPI}$（即本课的 $\mathcal J^{CPI}$）会导致过大的策略更新；它对朴素的策略梯度损失也有同样的判断：在同一批样本上做多步优化缺乏依据，经验上常导致破坏性的大幅更新 [@schulman2017ppo]。

TRPO（trust region policy optimization，信赖域策略优化）的名字说出了它的想法：替代目标只在旧参数附近一个小范围里可信，这个范围叫**信赖域**（trust region），每一步只在信赖域里面找最好的点。它用一个硬约束来划定这个范围：在 $\hat\E_t[\KL(\pi_{\theta_{old}}(\cdot\mid s_t)\,\|\,\pi_\theta(\cdot\mid s_t))]\le\delta$ 的条件下最大化 $\mathcal J^{CPI}$（这里的 $\delta$ 是一个小的正数，表示每一步允许的平均 KL，和下一页的 TD 残差 $\delta_t$ 无关）。PPO 论文解释了 TRPO 为什么用约束而不是在目标里减去一个 KL 惩罚：很难选一个在不同问题、甚至同一问题的不同阶段都合适的惩罚系数 [@schulman2017ppo]。但带约束的问题不能直接用梯度上升解：TRPO 要把目标线性化、把 KL 约束做二次近似，再用共轭梯度法近似求解 [@schulman2017ppo]，实现复杂。PPO 想要一个只用一阶优化（普通梯度上升）、又能管住步子的目标。

## 裁剪的替代目标

PPO 的办法很像开头那位教练：动作改到位了，就不再为“改得更多”叫好。我们先在黑板上把四种情形各算一遍。

::: ex 黑板上 · 两个比值、两种优势、四种情形
取 $\varepsilon=0.2$，允许的区间是 $[0.8,\ 1.2]$。两个比值：$\rho=1.5$（新策略给这个 token 的概率比采样时涨了 50%）和 $\rho=0.7$（跌了 30%）；优势 $\hat A=+1$ 表示好 token，$-1$ 表示坏 token。每一项的算法是：算两个数，不裁剪的 $\rho\hat A$，和先把 $\rho$ 截进 $[0.8,1.2]$ 再乘的 $\clip(\rho)\hat A$，取**较小**的那个。

| $\rho$ | $\hat A$ | $\rho\hat A$ | $\clip(\rho)\hat A$ | 取较小者 | 对 $\rho$ 的梯度 | 发生了什么 |
|---|---|---|---|---|---|---|
| 1.5 | +1 | 1.5 | 1.2 | 1.2 | 0 | 好 token 已涨够，不再奖励继续涨 |
| 0.7 | +1 | 0.7 | 0.8 | 0.7 | +1 | 好 token 反而跌了，照常拉回 |
| 1.5 | −1 | −1.5 | −1.2 | −1.5 | −1 | 坏 token 反而涨了，照常压回 |
| 0.7 | −1 | −0.7 | −0.8 | −0.8 | 0 | 坏 token 已压够，不再奖励继续压 |

四种情形里，梯度变成 0 的只有两种：往“好的方向”已经走过头的那两种。往坏的方向越界，不但不裁剪，还照常惩罚。
:::

好，把黑板上的做法写成公式。PPO 把概率比**裁剪**到 $[1-\varepsilon,1+\varepsilon]$ 里，再和未裁剪的版本取较小者：

::: eq PPO 的裁剪目标 | (3.17)
$$\mathcal J^{CLIP}(\theta)=\hat\E_t\Big[\min\Big(\rho_t(\theta)\,\hat A_t,\ \clip\big(\rho_t(\theta),\,1-\varepsilon,\,1+\varepsilon\big)\,\hat A_t\Big)\Big]$$
PPO 论文式 (7)，$\varepsilon$ 是超参数，论文举例取 0.2 [@schulman2017ppo]；InstructGPT 也用 0.2 [@ouyang2022]。
:::

**理解。** 取较小者的效果是：只在“再往这个方向走会让目标**变好**”的那一侧截断，让这一项不再提供继续前进的动力；在让目标**变坏**的那一侧不截断，照常惩罚。论文把它说成未裁剪目标的一个悲观的下界 [@schulman2017ppo]。下面把单项拆成分段函数，看清楚黑板上那张表为什么是那样。

::: deriv 单项的分段形式
$A>0:\ \min\big(\rho A,\ \clip(\rho)A\big)=A\cdot\min\big(\rho,\ \clip(\rho)\big)$ || 乘一个正数不改变大小顺序，可以提出来
$\min\big(\rho,\ \clip(\rho)\big)=\min(\rho,\ 1+\varepsilon)$ || 分三段核对：$\rho<1-\varepsilon$ 时裁剪值 $1-\varepsilon$ 更大，取 $\rho$；区间内两者相等；$\rho>1+\varepsilon$ 时取 $1+\varepsilon$
$A<0:\ \min\big(\rho A,\ \clip(\rho)A\big)=A\cdot\max\big(\rho,\ \clip(\rho)\big)$ || 乘一个负数会颠倒大小顺序，min 变成 max
$\max\big(\rho,\ \clip(\rho)\big)=\max(\rho,\ 1-\varepsilon)$ || 同样分三段核对：$\rho<1-\varepsilon$ 时取 $1-\varepsilon$；区间内相等；$\rho>1+\varepsilon$ 时取 $\rho$
:::

::: eq 裁剪目标的单项 | (3.18)
$$\ell(\rho,A)=\begin{cases}A\cdot\min(\rho,\,1+\varepsilon), & A>0\\[2pt] A\cdot\max(\rho,\,1-\varepsilon), & A<0\end{cases}\qquad\frac{\partial\ell}{\partial\rho}=\begin{cases}0, & A>0\text{ 且 }\rho>1+\varepsilon\\ 0, & A<0\text{ 且 }\rho<1-\varepsilon\\ A, & \text{其他}\end{cases}$$
在 $\theta_{old}$ 附近（$\rho\approx1$）裁剪不起作用，$\mathcal J^{CLIP}$ 与 $\mathcal J^{CPI}$ 在一阶上相同 [@schulman2017ppo]。
:::

代回黑板：$A=+1$、$\rho=1.5$ 走第一行，$\min(1.5,\ 1.2)=1.2$，属于“$A>0$ 且 $\rho>1+\varepsilon$”，导数 0；$A=-1$、$\rho=0.7$ 走第二行，$-1\times\max(0.7,\ 0.8)=-0.8$，属于“$A<0$ 且 $\rho<1-\varepsilon$”，导数 0；另外两种都落在“其他”，导数就是 $A$，也就是 $+1$ 和 $-1$。和黑板上的表一格不差。

::: fig figures/l03-ppo-clip.svg | 图 3.7 PPO 裁剪目标的单项随概率比 ρ 的变化（ε = 0.2）
**看灰色区域：只有在那里梯度为 0。** 左图 $A>0$：好动作的概率涨过 $1+\varepsilon$ 以后，目标变平，不再奖励继续上涨；但如果它的概率反而降了（$\rho<1-\varepsilon$），目标照常沿斜线把它拉回来。右图 $A<0$ 正好镜像：坏动作的概率降过 $1-\varepsilon$ 以后不再奖励继续压低；它的概率反而涨了（$\rho>1+\varepsilon$）则照常惩罚。红点是每轮更新的起点 $\rho=1$。据 PPO 论文图 1 重绘 [@schulman2017ppo]，曲线由脚本计算。
:::

大家可以在图 3.7 上把黑板的四种情形找出来：图上标出的四个黑点正是它们。左图在 $\rho=1.5$ 处落进灰色区域，在 $\rho=0.7$ 处还在斜线上；右图正好反过来。一般地，四种越界情形列成一张表（中间一列是区间 $[1-\varepsilon,1+\varepsilon]$ 以内）：

| | $\rho<1-\varepsilon$ | $1-\varepsilon\le\rho\le1+\varepsilon$ | $\rho>1+\varepsilon$ |
|---|---|---|---|
| $A>0$（好动作） | 概率反而降了：**不裁剪**，照常拉回 | 正常更新 | 已涨够：**梯度为 0** |
| $A<0$（坏动作） | 已压够：**梯度为 0** | 正常更新 | 概率反而涨了：**不裁剪**，照常压回 |

::: ex 再来四个 token：从对数概率算起
真实的实现里，手上是对数概率，不是现成的 $\rho$。一个 minibatch 里有四个 token（数字为笔者自拟），$\varepsilon=0.2$。$\log\pi_{\theta_{old}}$ 是采样时记下的对数概率，$\log\pi_\theta$ 是几步更新之后的。$\rho=e^{\log\pi_\theta-\log\pi_{\theta_{old}}}$。最后一列是这一项对 $\log\pi_\theta(o_t)$ 的梯度：未被截断时它等于 $\hat A\rho$（因为 $\partial\rho/\partial\log\pi_\theta=\rho$），被截断时为 0。

| token | $\log\pi_{\theta_{old}}$ | $\log\pi_\theta$ | $\rho$ | $\hat A$ | $\rho\hat A$ | $\clip(\rho)\hat A$ | 取较小者 | 对 $\log\pi_\theta$ 的梯度 |
|---|---|---|---|---|---|---|---|---|
| a | −1.20 | −1.00 | 1.2214 | +0.8 | 0.9771 | 0.9600 | 0.9600 | 0（已涨够） |
| b | −0.50 | −0.60 | 0.9048 | +0.5 | 0.4524 | 0.4524 | 0.4524 | +0.4524 |
| c | −2.00 | −1.70 | 1.3499 | −0.6 | −0.8099 | −0.7200 | −0.8099 | −0.8099（反而涨了） |
| d | −0.90 | −1.20 | 0.7408 | −0.4 | −0.2963 | −0.3200 | −0.3200 | 0（已压够） |

平均目标值 $(0.9600+0.4524-0.8099-0.3200)/4=0.0706$。逐个读：a 是好 token，概率已经涨了 22%，超过 20% 的上限，梯度停了。b 是好 token，概率却降了约 10%，在区间内，正常往上推。c 是坏 token，概率不降反升 35%，属于“往坏的方向越界”，不裁剪，而且梯度按 $\rho=1.35$ 放大了。d 是坏 token，已经压低了 26%，梯度停了。

换成对数概率看，裁剪边界是 $\ln1.2=0.1823$ 和 $\ln0.8=-0.2231$：上下不对称，往下可以多走一点。
:::

::: err 很多人以为：裁剪保证新旧策略之比留在 [1−ε, 1+ε] 内
很多人以为：PPO 把比值“夹”在了区间里，所以一轮更新之后，每个 token 的 $\rho$ 都在 0.8 到 1.2 之间。

其实：裁剪只是让**越界那一项**的梯度变成 0，不是给参数加约束。同一个 minibatch 里其他 token 的梯度、下一个 minibatch 的更新，都可能继续把某个 token 的 $\rho$ 推出区间；而且在“往坏方向越界”的一侧根本不裁剪（黑板上 $\rho=1.5$、$\hat A=-1$ 那一行，上例的 token c）。所以 PPO 只是**近似**的信赖域。实践中常监控新旧策略之间的 KL，发现走远了就提前停止这一轮更新（这是常见做法，不是 PPO 论文的要求）。
:::

::: ana 类比续：每次改稿只许改一小步
学生拿到一批评分后开始改稿。好的段落，可以往“更像它”的方向改，但改过 20% 就不再因此加分；差的段落要删改，删过 20% 也不再因此加分。可如果某处改着改着反而更像差段落了，那是要照常扣分的。**但是这个比方有个地方不对**：真实的改稿限制是“最多改多少”，PPO 的裁剪只是“改多了不再给奖励”，并不禁止改多；而且它是逐个 token 判断的，不看整段。
:::

## 完整的 PPO 损失与一轮迭代

PPO 论文把策略目标、价值函数的损失和熵奖励合在一个式子里，用于策略和价值共享参数的情形 [@schulman2017ppo]：

::: eq PPO 的合并目标 | (3.19)
$$\mathcal J^{CLIP+VF+S}(\theta)=\hat\E_t\Big[\mathcal J^{CLIP}_t(\theta)-c_1\big(V_\theta(s_t)-V_t^{targ}\big)^2+c_2\,S[\pi_\theta](s_t)\Big]$$
$c_1,c_2$ 是系数，$S$ 是熵奖励，$V_t^{targ}$ 是价值网络的回归目标（下一页）。RLHF 里策略和价值网络通常是两个独立的网络（例如 Stiennon 等人的做法 [@stiennon2020]），这时第二项单独作为价值网络的损失；熵奖励往往不用（例如 HH-RLHF 明确写了不加熵奖励 [@bai2022hh]），笔者的理解是 KL 项里已经含有熵奖励 (3.9)。
:::

一轮 PPO 迭代（PPO 论文的算法 1 [@schulman2017ppo]，放到 RLHF 里）是这样的：

1. **采样（rollout）**：用当前策略对一批提示生成回答，同时记下每个 token 的 $\log\pi_{\theta_{old}}(o_t)$。
2. **打分**：奖励模型给每段回答打分；参考模型算出每个 token 的 $\log\pi_{ref}(o_t)$，按 (3.8) 合成逐 token 奖励；价值网络给出每个 token 的 $V$；用 GAE（下一页）算出优势 $\hat A_t$。这时 (3.8) 里的 $\pi_\theta$ 就是采样那一刻的 $\pi_{\theta_{old}}$，合成的 $r_t$ 在这一轮里当作常数，不对它求导。这样做在这一轮的起点不丢梯度：在 $\theta=\theta_{old}$ 处（两种写法里的对数比相同），直接对 (3.7) 求导，比“把 KL 修正后的奖励当常数、用策略梯度”只多出一项 $-\beta\,\E_{o\sim\pi_\theta}[\nabla_\theta\log\pi_\theta(o\mid q)]$；把整段回答看成一个动作、取 $b=1$，由 §5 的 (3.21) 它等于 0。
3. **更新**：把这批数据切成若干 minibatch，按 (3.17) 更新策略、按价值损失更新价值网络，重复 $n_{ep}$ 个 epoch。
4. 令 $\theta_{old}\leftarrow\theta$，回到第 1 步。

InstructGPT 每轮 512 段回答，minibatch 64，只做 1 个 epoch，共 256k 个回合 [@ouyang2022]。大家可能会问：只做 1 个 epoch，还需要裁剪吗？需要。512 被切成 8 个 minibatch 依次更新，从第 2 个 minibatch 开始，参数已经被前面的 minibatch 改过，$\rho_t$ 就不再等于 1（这是笔者的推论）。Stiennon 等人每批做 4 个 epoch [@stiennon2020]。

那么裁剪到底有多重要？PPO 论文做过一个消融。

::: fig figures/l03-ppo-ablation.svg | 图 3.8 PPO 论文的消融：不同替代目标的平均归一化得分
**看最上面那根红色的负数条：不裁剪、不加惩罚，直接在同一批样本上多步优化 $\mathcal J^{CPI}$，平均得分比随机策略还差。** 论文说明，这个负分主要来自一个环境（HalfCheetah）上极差的得分 [@schulman2017ppo]。裁剪 $\varepsilon=0.2$ 最好（0.82）；把裁剪换成对旧策略的自适应或固定 KL 惩罚，最好也只有 0.74。数据是 PPO 论文表 1：7 个 MuJoCo 机器人控制环境、每个 3 个随机种子，得分归一化到“随机策略 = 0、最好 = 1” [@schulman2017ppo]。这是连续控制上的结果，不是语言模型上的。
:::

## 三种“KL”，别混为一谈

读 RLHF 的论文和代码时，“KL”至少指三样不同的东西：

| | 锚点 | 作用 | 谁在用 |
|---|---|---|---|
| RLHF 奖励里的 $\beta\,\KL(\pi_\theta\|\pi_{ref})$ | 冻结的参考模型，整个训练不变 | 防过度优化、留在语言里（§3） | Ziegler、Stiennon、InstructGPT，DPO 的目标 (3.7) |
| PPO 的自适应 KL 惩罚 $\beta_{old}\,\KL(\pi_{\theta_{old}},\pi_\theta)$ | 上一轮的策略快照，每轮更新 | 限制单轮步长；PPO 论文里是裁剪的**备选**，实验中更差 | PPO 论文 §4 的变体 |
| PPO 裁剪 | 上一轮的策略快照 | 逐样本截断激励，**不是 KL** | PPO、InstructGPT |

InstructGPT 用的是第一行加第三行 [@ouyang2022]。PPO 论文的自适应规则是：测得的 KL $d<d_{targ}/1.5$ 就把 $\beta_{old}$ 减半，$d>1.5\,d_{targ}$ 就加倍，1.5 和 2 是启发式选的 [@schulman2017ppo]。这里的 $\beta_{old}$ 和 RLHF 的 $\beta$ 不是一个东西（本课特意换了记号）。

::: key 这一页讲了三件事
- **第一，策略梯度按优势推拉。** (3.14)：推高好 token、压低坏 token 的对数概率，权重是优势 $\hat A_t$。
- **第二，旧样本要“改票数”。** 想复用一批样本，就要乘重要性比 $\rho_t=\pi_\theta/\pi_{\theta_{old}}$ (3.15)–(3.16)；黑板上改票数之后，旧样本的平均从 0.9 回到正确的 1.0。它在起点处给出正确的梯度，离起点越远越不可信。
- **第三，裁剪只管“往好的方向走过头”。** (3.17)–(3.18)：黑板上四种情形里只有两种梯度为 0，往坏方向越界照常惩罚。它是近似的信赖域，不保证 $\rho$ 留在区间里。RLHF 里的一轮：采样 → 奖励模型与参考模型打分 → GAE 算优势 → 裁剪目标更新，InstructGPT 取 $\varepsilon=0.2$、每轮 512 段、1 个 epoch。
:::

# 价值网络与 GAE：功劳怎么分 | 给每个 token 记功：优势、TD 残差与 λ | 35

大家做过小组作业吧？最后交上去，得了 90 分。这 90 分里谁的功劳大？是最后熬夜排版的那位，还是一开始把题目想清楚的那位？只看最后一个分数，是分不出来的。可要是老师中途看过几版草稿，每次都说一句“这一版大概能拿 70”“改了这一处，现在能拿 80 了”，那这一处的功劳就清楚了：10 分。

上一页的每个公式里都有一个 $\hat A_t$，这一页讲它从哪里来。问题是**记功**（credit assignment）：一段 200 个 token 的回答，奖励模型在最后给了 0.8 分，每个 token 该分到多少功劳？最省事的做法是每个 token 都拿整段的回报。这样做没有偏差，却非常嘈杂：同一个提示下，一段回答碰巧得了高分，里面那句写得很差的话也跟着被奖励；要靠大量样本才能把这种噪声平均掉。

更好的做法，就是那位看草稿的老师：每一步都问，“写到这里，本来预计能得几分？写完这个 token 之后，预计变成了几分？”两者之差才是这个 token 的功劳。回答第一个问题的，就是**价值网络**（critic），也就是作文类比里那位“预测分数的老师”。这一页给出直觉和关键公式；完整的推导（基线的方差分析、GAE 的偏差分析）在 [M09 §3–§4](../math/m09-rl-math.html#p3)。

## 黑板上：减去一个“预期分”

先看“减去预期”到底有什么用。我们把问题缩到最小。

::: ex 黑板上 · 两个回答，减不减基线
一个提示，只有两个回答。策略写回答 1 的概率是 $\sigma(\theta)=0.7$，写回答 2 的概率是 0.3，参数只有一个 $\theta$。评委给回答 1 打 1.0 分，给回答 2 打 0.8 分：两个都是正分，但回答 1 更好。

先求两个“往哪边推”的方向。由 §2 前置框第 3 条，$\frac{d}{d\theta}\log\sigma(\theta)=1-\sigma(\theta)=0.3$；回答 2 的概率是 $1-\sigma(\theta)=\sigma(-\theta)$，同理 $\frac{d}{d\theta}\log\sigma(-\theta)=-\sigma(\theta)=-0.7$。所以采到回答 1，方向是 $+0.3$（$\theta$ 变大，回答 1 更可能）；采到回答 2，方向是 $-0.7$（$\theta$ 变小，回答 2 更可能）。

**不减基线**，一个样本的梯度是“分数 × 方向”：

- 采到回答 1（概率 0.7）：$1.0\times0.3=0.3$；
- 采到回答 2（概率 0.3）：$0.8\times(-0.7)=-0.56$。

平均是 $0.7\times0.3+0.3\times(-0.56)$，也就是 $0.21-0.168=0.042$。方向是对的（$\theta$ 变大，回答 1 更可能），可两个样本一正一负。采到回答 2 时，它明明比回答 1 差，却因为拿了正分而被往上推。

**减去基线** $b=0.94$，也就是期望分数 $0.7\times1.0+0.3\times0.8$：

- 采到回答 1：$(1.0-0.94)\times0.3=0.018$；
- 采到回答 2：$(0.8-0.94)\times(-0.7)=0.098$。

平均是 $0.7\times0.018+0.3\times0.098$，也就是 $0.0126+0.0294=0.042$。和不减基线时一模一样。可这回两个样本都是正数：回答 2 比预期差，所以它被往下压，也就是把 $\theta$ 往上推。

最后算一下噪声。不减基线时，单个样本梯度的方差是 $0.7\times0.3^2+0.3\times0.56^2-0.042^2$，等于 0.155316；减去基线后是 $0.7\times0.018^2+0.3\times0.098^2-0.042^2$，等于 0.001344。方差小了约 116 倍（$0.155316/0.001344=115.56$），标准差小了 10.75 倍。
:::

::: fig figures/l03b-baseline-board.svg | 图 3.9 黑板上的两个回答：减去基线，平均不变，样本却不再东倒西歪
**比较上下两条数轴上两个圆点的位置：上面不减基线，两个样本一个在 +0.3、一个在 −0.56；下面减去基线 0.94，两个样本挤在 +0.018 与 +0.098，而三角形标出的平均值都是 0.042。** 圆点的面积正比于采到它的概率（0.7 与 0.3）。右侧是两种做法的样本方差。数字由脚本逐项计算，与正文例题相同。
:::

平均不变、噪声大减，这就是减去“预期分”的好处。下面把“预期分”和“比预期好多少”说准确。

## 价值函数与优势

**含义。** 状态 $s_t$ 的**价值** $V(s_t)$ 是：从这个状态出发、按当前策略继续写下去，将来能拿到的奖励总和的期望。**优势** $A(s_t,a_t)$ 是：在 $s_t$ 选了动作 $a_t$ 之后，期望的总奖励比“平均水平” $V(s_t)$ 高多少。

**理解。** 对语言模型，$s_t$ 是“提示 + 已写出的半截回答”。价值就是老师看着这半截作文估计的最终得分；优势就是“写了这个词之后，预估分涨了多少”。一个 token 的优势为正，说明它让局面变好了。黑板上的 0.94 就是价值，$1.0-0.94=0.06$ 与 $0.8-0.94=-0.14$ 就是两个回答的优势。

**数学。** 记折扣因子为 $\gamma\in(0,1]$（每往后一步，奖励打 $\gamma$ 折）：

::: eq 价值、动作价值与优势 | (3.20)
$$\begin{aligned}V^\pi(s_t)&=\E_\pi\Big[\sum_{l\ge0}\gamma^l\,r_{t+l}\ \Big|\ s_t\Big]\\ Q^\pi(s_t,a_t)&=\E\big[r_t+\gamma\,V^\pi(s_{t+1})\ \big|\ s_t,a_t\big]\\ A^\pi(s_t,a_t)&=Q^\pi(s_t,a_t)-V^\pi(s_t)\end{aligned}$$
$Q$ 是“先做 $a_t$、之后按策略走”的期望回报。语言模型里，给定 $s_t$ 和 $a_t$，下一状态（把 token 接上去）和这一步的奖励 $r_t$（按 (3.8)，奖励模型也是确定的函数）都是确定的，所以 $Q^\pi(s_t,a_t)=r_t+\gamma V^\pi(s_{t+1})$，剩下的随机性全在 $V^\pi$ 里对之后各 token 的采样。
:::

为什么减去 $V(s_t)$ 不会把梯度弄偏？黑板上已经看到了：平均都是 0.042。原因是它只依赖状态，不依赖这一步选了哪个动作；对动作求期望时，它乘上的“方向”平均为零。下面固定状态 $s$，把 $\pi_\theta(a\mid s)$ 简写成 $\pi_\theta(a)$，$b$ 是任意一个只依赖 $s$ 的数：

::: deriv 基线不改变策略梯度的期望
$\E_{a\sim\pi_\theta}\big[b\,\nabla_\theta\log\pi_\theta(a)\big]=b\sum_a\pi_\theta(a)\,\nabla_\theta\log\pi_\theta(a)$ || 期望写成求和；$b$ 不依赖 $a$，提到外面
$=b\sum_a\nabla_\theta\pi_\theta(a)=b\,\nabla_\theta\sum_a\pi_\theta(a)$ || 对数导数技巧反过来用；有限求和与求导可交换
$=b\,\nabla_\theta1=0$ || 概率之和恒为 1
:::

::: eq 基线的期望为零 | (3.21)
$$\E_{a\sim\pi_\theta}\big[b(s)\,\nabla_\theta\log\pi_\theta(a\mid s)\big]=0$$
:::

代回黑板：$b\times\big(0.7\times0.3+0.3\times(-0.7)\big)$，也就是 $b\times(0.21-0.21)=0$，不管 $b$ 取多少。所以在 (3.14) 里把回报换成“回报减去任意只依赖状态的基线”，期望梯度不变；选 $V(s_t)$ 作基线，能让方差小很多（方差的分析见 [M09 §3](../math/m09-rl-math.html#p3)）。

::: err 很多人以为：拿了正分的回答，就该被推高
很多人以为：奖励是正的，就说明这个回答“好”，训练就该让它更可能。

其实：要看的是它比**预期**好还是差。黑板上的回答 2 拿了 0.8 分，是正分，可预期是 0.94，它的优势是 $-0.14$，训练应该让它**更不可能**。不减基线时，它照样被往上推，只是推得比回答 1 少一些，方向要靠很多样本相互抵消才对，这就是噪声的来源。
:::

## TD 残差：老师改口的幅度

真实的 $V^\pi$ 不知道，我们训练一个网络 $V_\psi$ 去近似它。有了 $V_\psi$，怎样给每个 token 记功？回到开头那位看草稿的老师，我们在黑板上看一段四个 token 的回答。

::: ex 黑板上 · 老师每写一个 token 改一次口
沿用 §3 那段四个 token 的回答：逐 token 奖励 $r=[-0.005,\ 0.0025,\ -0.010,\ 1.0]$（前三个是很小的 KL 奖励，最后一个带着奖励模型的 1.0 分）。价值网络在写每个 token 之前的预估是 $V=[0.50,\ 0.60,\ 0.70,\ 0.90]$，回答结束后 $V=0$。

每写一个 token，老师的“改口幅度”是：这一步实际拿到的奖励，加上新的预估，减去原来的预估（不打折扣）。

- 第 1 个：$-0.005+0.60-0.50=0.095$；
- 第 2 个：$0.0025+0.70-0.60=0.1025$；
- 第 3 个：$-0.010+0.90-0.70=0.190$；
- 第 4 个：$1.0+0-0.90=0.100$。

写完第 3 个 token，老师的预估从 0.70 跳到 0.90，改口 0.19，是整段里最大的一次：这个 token 让局面明显变好了。第 4 个 token 的 0.1 说明，奖励模型最后给的 1.0 分比老师预期的 0.9 高了 0.1。
:::

这个“改口幅度”叫 **TD 残差**（temporal-difference residual）：

::: eq TD 残差 | (3.22)
$$\delta_t=r_t+\gamma\,V_\psi(s_{t+1})-V_\psi(s_t)$$
写完第 $t$ 个 token 后：“这一步实际拿到的奖励 + 新的预估”减去“原来的预估”。回答结束后 $V_\psi=0$。
:::

代回黑板：$\gamma=1$，$\delta_1=r_1+V_2-V_1=-0.005+0.60-0.50=0.095$，就是老师的第一次改口。

GAE 论文证明：如果 $V_\psi$ 恰好是真实的 $V^{\pi}$，那么 $\delta_t$ 的期望就是优势 $A^\pi(s_t,a_t)$；否则 $\delta_t$ 是有偏的 [@schulman2016gae]。（语言模型里状态转移和 $r_t$ 都是确定的，这时 $\delta_t$ 就等于 $r_t+\gamma V^\pi(s_{t+1})-V^\pi(s_t)=A^\pi(s_t,a_t)$ 本身，连期望都不用取。）直观地说，$\delta_t$ 只看一步，剩下的全交给老师的预估，老师估得不准，它就跟着不准；但它只含一步的随机性，所以方差小。

## 从一步到多步：GAE

另一个极端是完全不信老师，直接用实际拿到的奖励：$\sum_l\gamma^lr_{t+l}-V_\psi(s_t)$。它只在最后减去一个基线，所以没有偏差，但包含了之后每一步采样的随机性，方差大。中间还有一整族“看 $k$ 步真实奖励，剩下的交给老师”的估计：

::: eq k 步优势估计 | (3.23)
$$\hat A_t^{(k)}=\sum_{l=0}^{k-1}\gamma^l\,\delta_{t+l}=-V_\psi(s_t)+r_t+\gamma r_{t+1}+\cdots+\gamma^{k-1}r_{t+k-1}+\gamma^kV_\psi(s_{t+k})$$
第二个等号是**裂项相消**：中间的 $V_\psi$ 一加一减全部抵消。
:::

::: deriv 裂项相消（以 k = 2 为例）
$\delta_t+\gamma\,\delta_{t+1}=\big(r_t+\gamma V_{t+1}-V_t\big)+\gamma\big(r_{t+1}+\gamma V_{t+2}-V_{t+1}\big)$ || 代入 (3.22)，$V_t$ 是 $V_\psi(s_t)$ 的简写
$=-V_t+r_t+\gamma r_{t+1}+\gamma^2V_{t+2}+\big(\gamma V_{t+1}-\gamma V_{t+1}\big)$ || 把同类项放在一起
$=-V_t+r_t+\gamma r_{t+1}+\gamma^2V_{t+2}$ || 中间的 $V_{t+1}$ 抵消；一般的 $k$ 同理
:::

代回黑板，看第 1 个 token 的两步估计：左边 $\delta_1+\delta_2=0.095+0.1025=0.1975$；右边 $-V_1+r_1+r_2+V_3$，即 $-0.50-0.005+0.0025+0.70=0.1975$。两边相等，中间那个 $V_2=0.60$ 真的一加一减消掉了。

**广义优势估计**（generalized advantage estimation，GAE）不选某一个 $k$，而是把所有 $k$ 按 $(1-\lambda)\lambda^{k-1}$ 加权平均，$\lambda\in[0,1]$ [@schulman2016gae]：

::: deriv GAE 化简成 TD 残差的指数加权和
$\hat A_t^{GAE}=(1-\lambda)\big(\hat A_t^{(1)}+\lambda\hat A_t^{(2)}+\lambda^2\hat A_t^{(3)}+\cdots\big)$ || 定义：权重 $(1-\lambda)\lambda^{k-1}$ 之和为 1
$c_l:=(1-\lambda)\sum_{k\ge l+1}\lambda^{k-1}$ || 看某一项 $\gamma^l\delta_{t+l}$：由 (3.23)，$\hat A^{(k)}_t$ 含 $\delta_t,\dots,\delta_{t+k-1}$，所以它出现在所有 $k\ge l+1$ 的估计里；$c_l$ 是它的总权重
$=(1-\lambda)\big(\lambda^{l}+\lambda^{l+1}+\cdots\big)=(1-\lambda)\dfrac{\lambda^l}{1-\lambda}=\lambda^l$ || 等比级数求和（$\lambda<1$）
$\hat A_t^{GAE}=\sum_{l\ge0}c_l\,\gamma^l\delta_{t+l}=\sum_{l\ge0}(\gamma\lambda)^l\,\delta_{t+l}$ || 把每一项的总权重合起来
:::

::: eq GAE 与它的递推形式 | (3.24)
$$\hat A_t^{GAE(\gamma,\lambda)}=\sum_{l\ge0}(\gamma\lambda)^l\,\delta_{t+l},\qquad\hat A_{\abs{o}}=\delta_{\abs{o}},\quad\hat A_t=\delta_t+\gamma\lambda\,\hat A_{t+1}$$
$\lambda=0$ 时 $\hat A_t=\delta_t$（只看一步）；$\lambda=1$ 时 $\hat A_t=\sum_l\gamma^lr_{t+l}-V_\psi(s_t)$（实际回报减基线：把 $\sum_l\gamma^l\delta_{t+l}$ 裂项相消，回答结束后 $V_\psi=0$）。严格说，$\lambda=1$ 时上面加权平均的权重 $(1-\lambda)\lambda^{k-1}$ 全是 0，推导不适用；这时直接用 (3.24) 左边的和作定义，它也是 $\lambda\to1$ 的极限。回答结束之后的 $\delta$ 都记为 0，所以 $\sum_{l\ge0}$ 实际只加到最后一个 token。递推形式从最后一个 token 往前算，一遍就得到所有 token 的优势。
:::

$\lambda$ 是偏差和方差之间的旋钮。GAE 论文的结论是：$\lambda<1$ 只有在价值函数不准时才引入偏差；最好的 $\lambda$ 通常比最好的 $\gamma$ 小得多；在他们的实验里 $\lambda$ 取 0.9 到 0.99 之间通常最好 [@schulman2016gae]。

::: fig figures/l03-gae-weights.svg | 图 3.10 GAE 给往后第 l 个 TD 残差的权重：γλ 的 l 次方
**看两条竖虚线：权重在往后约 17 到 20 个 token 的地方降到 0.36 左右，更远的 token 贡献越来越小。** 蓝线是 PPO 论文在 MuJoCo 上的设置（$\gamma=0.99$、$\lambda=0.95$），紫线是 Stiennon 等人在摘要任务上的设置（$\gamma=1$、$\lambda=0.95$）[@schulman2017ppo; @stiennon2020]。最上面的水平虚线 $\gamma\lambda=1$ 是“所有未来一视同仁”（实际回报减基线），红色竖条 $\lambda=0$ 是“只看这一步”。曲线由脚本计算。
:::

在 RLHF 里，折扣 $\gamma$ 取 1：InstructGPT 明说估计优势时“不打折扣” [@ouyang2022]，Stiennon 等人取 $\gamma=1$、$\lambda=0.95$ [@stiennon2020]。原因在 §3 讲过：只有不打折扣，逐 token 奖励之和才等于序列级目标。InstructGPT 没有报告它用的 $\lambda$。

好，回到黑板，把四次改口按 $\lambda=0.95$ 累加起来。

::: ex 黑板上 · 从后往前递推优势（γ = 1，λ = 0.95）
改口幅度已经算好：$\delta=[0.095,\ 0.1025,\ 0.190,\ 0.100]$。按 (3.24) 从最后一个 token 往前，每往前一格，把后一格的优势乘 0.95 再加上这一格的 $\delta$：

- $\hat A_4=\delta_4=0.100$，$\hat A_3=0.190+0.95\times0.100=0.2850$；
- $\hat A_2=0.1025+0.95\times0.2850=0.37325$，$\hat A_1=0.095+0.95\times0.37325=0.44959$（图 3.11 和下文取四位小数：0.3733 与 0.4496）。

**对照两个极端。** $\lambda=0$：$\hat A=\delta=[0.095,\,0.1025,\,0.19,\,0.1]$，每个 token 只拿自己那一步的“意外”。$\lambda=1$：先算从第 $t$ 个 token 起的实际回报 $R_t=\sum_{l\ge0}r_{t+l}=[0.9875,\,0.9925,\,0.99,\,1.0]$（这里不写 $G_t$，因为 $G$ 在本课程里留给 GRPO 的组大小），再减 $V$：$[0.4875,\,0.3925,\,0.29,\,0.1]$。$\lambda=0.95$ 落在两者之间，更靠近 $\lambda=1$。

**读数。** 第 1 个 token 自己的即时奖励是负的（$-0.005$），却拿到了 0.4496 的优势：后面几次“局面变好”的功劳，按 $0.95$ 的折扣往前传到了它身上。这就是开头说的，老师中途的评价让功劳在最后评分出来之前就记上了。
:::

::: fig figures/l03-gae-tokens.svg | 图 3.11 一段 4 个 token 的回答：从奖励到优势
**看蓝色那一行：优势从右往左递推，每往前一格乘 0.95 再加上这一格的 δ。** 奖励模型的 1.0 分只在最后一个 token 上；前三个 token 只有很小的 KL 奖励（红字）。价值网络的预估让功劳能“往前传”：第 1 个 token 拿到 0.45 的优势，尽管它自己的即时奖励是负的。下面两行灰字是 $\lambda=0$ 与 $\lambda=1$ 的对照，最后一行是价值网络的回归目标。数据与 §3 的例题相同（笔者自拟），由脚本计算。
:::

## 价值网络怎么训练

老师也要学。价值网络用回归来训练：让 $V_\psi(s_t)$ 逼近一个目标值。常见的做法是把目标取成“优势 + 旧的预估”，也就是 $\lambda$-回报（GAE 论文讨论了 TD($\lambda$) 形式的目标；“目标 = 优势 + $V$”这种写法是常见实现，本课未能在原文逐字核对）：

::: eq 价值网络的损失 | (3.25)
$$\mathcal L_V(\psi)=\hat\E_t\Big[\big(V_\psi(s_t)-V_t^{targ}\big)^2\Big],\qquad V_t^{targ}=\hat A_t+V_{\psi_{old}}(s_t)$$
就是 (3.19) 的第二项。上例中 $\lambda=0.95$ 的目标是 $[0.9496,\,0.9733,\,0.9850,\,1.0]$：每个位置都在往“这段回答最终大约 0.99 分”靠。
:::

价值网络是和策略差不多大的一个 Transformer，在每个 token 位置输出一个数。InstructGPT 的价值网络是 6B，**用奖励模型初始化**，学习率 $9\times10^{-6}$（1.3B、6B 策略）或 $5\times10^{-6}$（175B 策略）[@ouyang2022]；Stiennon 等人的价值网络与策略**参数完全独立**、同样用奖励模型初始化，而且奖励模型、策略、价值网络三者一样大 [@stiennon2020]。用奖励模型初始化是自然的选择（笔者的理解）：奖励模型已经会读“提示 + 回答”并估计整段的好坏，价值网络要做的是在半截回答上估计同一件事。

::: warn 为什么语言模型的价值网络难训
DeepSeekMath 论文指出了两个问题 [@shao2024deepseekmath]：第一，价值函数通常是**与策略同等规模**的另一个模型，带来可观的显存与计算负担（下一页会算这笔账）；第二，在语言模型里通常只有**最后一个 token** 拿到奖励模型的分数，要训练一个在每个 token 上都准确的价值函数很难。价值网络不准，(3.22) 的 $\delta_t$ 就有偏，GAE 的优势也跟着有偏。
:::

::: ana 类比续：预测分数的老师，以及不请老师的办法
**映射。** 价值网络 = 老师看着半截作文估分；TD 残差 = 老师在学生多写了一句之后改口的幅度；GAE = 把后面若干次改口按 $\gamma\lambda$ 打折累加，算作这一句的功劳。

**收益。** 它说明了为什么优势能“往前传”：一句好的开头让老师的预估提前上涨，功劳在最后评分出来之前就记上了。

**但是这个比方有个地方不对。** 老师自己也是学出来的，而且只有作文写完才知道真实得分；如果老师看半截作文的眼光很差，他的改口就是噪声。第 8 课的 GRPO 干脆不请这位老师：同一道题让学生写 $G$ 份，每份按“比这组平均分高几个标准差”记功（课程的第 5 个类比）。代价是：一组全对或全错时，优势全是 0，这道题不提供学习信号；而且同一份答卷里的每个 token 拿到同样的优势。
:::

:::: quiz 小练习：改一个价值，看优势怎么变
在上面的例子里，把老师对第 3 个状态的预估从 $V_3=0.70$ 改成 $0.80$，其余不变（$\lambda=0.95$）。哪些 $\delta$ 变了？$\hat A_1$ 变成多少？
::: answer 看答案
$V_3$ 出现在 $\delta_2=r_2+V_3-V_2$（多了 0.1）和 $\delta_3=r_3+V_4-V_3$（少了 0.1）里。新的 $\delta_2=0.2025$，$\delta_3=0.090$，$\delta_1,\delta_4$ 不变。递推：$\hat A_4=0.1$，$\hat A_3=0.090+0.095=0.185$，$\hat A_2=0.2025+0.95\times0.185=0.37825$，$\hat A_1=0.095+0.95\times0.37825=0.45434$。

$\hat A_1$ 只从 0.4496 变到 0.4543：中间状态的价值一加一减，大部分被裂项抵消了，只剩 $(1-\lambda)$ 量级的影响。$\lambda$ 越接近 1，优势对中间价值的误差越不敏感（但方差越大）。
:::
::::

::: key 这一页讲了三件事
- **第一，减去“预期分”，平均不变、噪声大减。** 优势 = 这一步之后的期望回报 − 这一步之前的期望回报 (3.20)；减去只依赖状态的基线不改变梯度的期望 (3.21)。黑板上平均都是 0.042，方差却从 0.155 降到 0.0013，约 116 倍。
- **第二，TD 残差是老师的一次改口。** $\delta_t$ (3.22) 是一步的“意外”；$k$ 步估计 (3.23) 靠裂项相消把真实奖励和价值预估接起来；GAE (3.24) 是 $\delta$ 的 $(\gamma\lambda)^l$ 加权和，从最后一个 token 往前一遍递推算完。RLHF 取 $\gamma=1$，Stiennon 等人取 $\lambda=0.95$；黑板上第 1 个 token 的优势是 0.4496。
- **第三，老师又大又难请。** 价值网络按 (3.25) 回归训练，通常与策略同样大、用奖励模型初始化；它又大又难训，这正是第 8 课 GRPO 要去掉它的原因。
:::

# 四个模型的账单 | PPO-RLHF 在显存里放了什么，为什么第 8 课要去掉价值网络 | 20

大家买过打印机吗？打印机本身不贵，真正花钱的是后面一盒接一盒的墨盒。只看标价，这笔账是算不清的。

PPO 版的 RLHF 也有它的“墨盒”。把前三页拼起来，它在训练时同时用到**四个**网络：策略、参考模型、奖励模型、价值网络。DPO 论文开篇就把 RLHF 的代价概括为：要训练多个语言模型，还要在训练循环里从策略采样 [@rafailov2023dpo]。这一页把这句话变成具体的数字：每个网络做什么、要占多少显存、每个 token 要花多少计算。

::: fig figures/l03-four-models.svg | 图 3.12 PPO-RLHF 的四个网络与一轮迭代的数据流
**看实线粗框与虚线框的区别：只有策略和价值网络要反向传播、要存优化器状态；参考模型和奖励模型只做前向。** 一轮迭代：① 策略生成回答并记下每个 token 的 $\log\pi_{\theta_{old}}$（图中简写为 $\pi_{old}$）；② 三个网络各读一遍（提示，回答）；③ 合成逐 token 奖励 (3.8)；④ 用价值网络的预估算 GAE 优势 (3.24)；⑤ 按裁剪目标更新策略、按回归损失更新价值网络。灰字是 InstructGPT 的配置 [@ouyang2022]。
:::

| 网络 | 训练/冻结 | 算什么 | 什么时候用 | InstructGPT 的尺寸 |
|---|---|---|---|---|
| 策略 $\pi_\theta$ | 训练 | 生成回答；更新时重算 $\log\pi_\theta(o_t)$ | 采样与更新 | 1.3B / 6B / 175B |
| 参考模型 $\pi_{ref}$ | 冻结 | 每个 token 的 $\log\pi_{ref}(o_t)$ | 采样之后 | 与策略同尺寸（RL 初始化模型） |
| 奖励模型 $r_\phi$ | 冻结 | 每段回答一个分数 | 采样之后 | 6B，所有策略共用 |
| 价值网络 $V_\psi$ | 训练 | 每个 token 的 $V_\psi(s_t)$ | 采样之后与更新 | 6B，由奖励模型初始化 |

两点补充。第一，旧策略 $\pi_{\theta_{old}}$ **不是**第五个网络：(3.16) 只在已经采样的 token 上用到它的对数概率，采样时顺手记下即可（笔者依据公式的推论）。第二，InstructGPT 的 RL 训练还对权重做了指数滑动平均（EMA，衰减率 0.992）[@ouyang2022]，这是权重的又一份拷贝；论文没有说它是只对策略做、还是也对价值网络做，也没有说用什么精度存。

## 显存账：每个参数几个字节

好，现在请大家猜一猜。一个 7B 的模型，16 位权重是 $7\times10^9\times2=14$ GB。拿它做 PPO，四个网络都是 7B，光是模型状态（还没算激活值）要多少显存？30 GB？50 GB？

先别急着猜大数，我们从一个参数算起。

::: ex 黑板上 · 一个参数要占几个字节
用 Adam 做混合精度训练时，一个**要训练**的参数在显存里有五样东西 [@rajbhandari2019zero]：

- 16 位的参数本身：2 字节；
- 16 位的梯度：2 字节；
- 32 位的主权重：4 字节；
- Adam 的动量：4 字节；
- Adam 的方差：4 字节。

合计 $2+2+4+4+4=16$ 字节。一个**冻结**的参数不需要梯度，也不需要优化器状态，只存 16 位权重：2 字节。

现在造一个玩具：每个网络都只有 1B（$10^9$）个参数，GB 取 $10^9$ 字节。

- SFT：只训练策略，$16$ GB；
- DPO：训练策略，冻结参考模型，$16+2=18$ GB；
- GRPO 式：训练策略，冻结参考模型和奖励模型，$16+2+2=20$ GB；
- PPO：训练策略和价值网络，冻结参考模型和奖励模型，$16+16+2+2=36$ GB。

PPO 一行里最大的一块不是策略自己，而是和它一样按 16 字节计的价值网络。
:::

::: fig figures/l03b-bytes-board.svg | 图 3.13 黑板上的显存账：先数一个参数的字节，再数四种做法各放了几个网络
**上面看一个参数的格子：训练的参数占 8 格（每格 2 字节，共 16 字节），冻结的只占 1 格；下面看每一行有几个 16、几个 2。** 下半部分是每个网络 1B 参数时四种后训练方法的模型状态；把 1B 换成 7B，每个数乘 7，就是正文的 112、126、140、252 GB。按 (3.26) 由脚本计算。
:::

::: note 这笔账的出处与口径
这是 ZeRO 论文的记法，$\Psi$ 是参数个数：16 位的参数 $2\Psi$ 字节，16 位的梯度 $2\Psi$ 字节，再加上优化器状态 $12\Psi$ 字节，即 32 位的主权重、动量、方差各 4 字节（ZeRO 论文把这个 12 记作 $K$，和本课排序时的回答数 $K$ 无关），合计 $16\Psi$ 字节 [@rajbhandari2019zero]。冻结的网络只存 16 位权重，$2\Psi$ 字节。InstructGPT 附录写明它用 16 位权重与激活、外加 32 位主权重 [@ouyang2022]，与这个假设相符。ZeRO 这类分片技术只改变每张卡分到多少，不改变总量（怎样分片见 [M10 §5](../math/m10-compute-arithmetic.html#p5)）。
:::

把黑板上的规则写成一个式子：

::: eq 模型状态的显存（记账估算） | (3.26)
$$\mathrm{Mem}_{states}\approx16\,N_{train}+2\,N_{frozen}\quad\text{（字节；}N\text{ 为参数个数）}$$
$N_{train}$、$N_{frozen}$ 分别是所有要训练的网络、所有冻结的网络的参数个数之和。只算模型状态：**不含**激活值、采样时的 KV cache（第 4 课）和各种临时缓冲。这是按规则记账，不是任何论文报告的实测显存。
:::

代回黑板：PPO 的 $N_{train}=2\times10^9$、$N_{frozen}=2\times10^9$，$16\times2+2\times2=36$ GB。对，36。

::: ex 7B 的四种后训练，各要多少
设每个网络都是 7B（$7\times10^9$ 个参数），GB 取 $10^9$ 字节。黑板上的每个数乘 7：

- **SFT**：只训练策略。$16\times7=112$ GB。
- **DPO**（§7）：训练策略，冻结参考模型。$112+2\times7=126$ GB，是 SFT 的 1.125 倍。
- **GRPO 式**（第 8 课）：训练策略，冻结参考模型和奖励模型，没有价值网络。$112+14+14=140$ GB，1.25 倍。
- **PPO**：训练策略和价值网络，冻结参考模型和奖励模型。$16\times(7+7)+2\times(7+7)=224+28=252$ GB，2.25 倍。

揭晓答案：252 GB，是这个 7B 模型 16 位权重（14 GB）的 **18 倍**。PPO 比 GRPO 式多出的 112 GB 全部来自价值网络：它要训练，所以和策略一样按 16 字节/参数计。Stiennon 等人的配置（四个网络都是 6.7B）按同样规则是 $16\times13.4+2\times13.4=241.2$ GB。
:::

::: fig figures/l03-memory.svg | 图 3.14 模型状态的显存：四种后训练方法（7B）与 InstructGPT 的 175B 配置
**看左图 PPO 那根柱子里紫色的一段：价值网络一个就和策略一样大，把显存推到 SFT 的 2.25 倍。** 右图是 InstructGPT 的实际搭配：175B 的策略配 6B 的奖励模型和 6B 的价值网络，总共约 3,258 GB，其中价值网络只占 2.9%。所以“价值网络很贵”取决于它有多大；当它和策略一样大时（Stiennon 等人的做法，也是 DeepSeekMath 所说的常见情形），它才成为主要负担之一。按 (3.26) 由脚本计算。
:::

::: err 很多人以为：PPO 的四个模型一定一样大
很多人以为：PPO 里的奖励模型、价值网络天然和策略一样大，所以显存永远是 SFT 的两倍多。

其实：“四个模型一样大”不是定律，而是一种常见的实现选择。InstructGPT 让 175B 的策略配 6B 的奖励模型与价值网络，175/6 约为 29 倍（6B 大概对应 GPT-3 家族里 6.7B 那一档 [@brown2020gpt3]，但 InstructGPT 原文没有写“6.7B”，这是推论）。按 (3.26)，这时价值网络只占总账的 2.9%。代价是一个小价值网络要去估计一个大策略的回答能得几分，估得准不准，论文没有单独报告。
:::

## 计算账：每个 token 多少次运算

显存之外还有计算。用第 2 课的经验规则（推导见 [M10 §1](../math/m10-compute-arithmetic.html#p1)）：一个 $N$ 参数的网络，每个 token 前向约 $2N$ 次浮点运算，前向加反向约 $6N$ 次。设四个网络一样大，PPO 每处理一个回答 token：

::: eq PPO 每个 token 的运算量（笔者估算） | (3.27)
$$\underbrace{2N}_{\text{策略生成}}+\underbrace{2N+2N+2N}_{\text{参考、奖励、价值前向}}+\underbrace{6N+6N}_{\text{策略、价值训练}}=20N\quad\text{vs.}\quad\text{SFT 的 }6N$$
忽略注意力的 $T^2$ 项；InstructGPT 那样只做 1 个 epoch 时成立；做 $n_{ep}$ 个 epoch 时，训练的两项 $6N+6N$ 要乘以 $n_{ep}$。
:::

约是 SFT 的 3.3 倍。而且这还低估了墙钟时间：策略生成是一个 token 接一个 token 的自回归解码，GPU 的算力大部分闲着、在等显存搬数据（这是[第 4 课](lesson-04-inference-kv-cache.html)的主题），所以同样的 $2N$ 次运算，生成要比训练时的前向慢得多。DPO 就没有这一步：它在固定的偏好数据上训练，每个 token 大约是策略的 $6N$ 加上参考模型前向的 $2N$，而参考模型的对数概率还可以在训练前一次性算好（笔者依据 DPO 损失的形式推论）。

## 伏笔：DeepSeek 为什么去掉价值网络

2024 年的 DeepSeekMath 论文在提出 GRPO 时，把 PPO 的问题说得很直接：PPO 里的价值函数通常是**与策略同等规模**的另一个模型，带来可观的显存与计算负担；而且语言模型里通常只有最后一个 token 拿到奖励分数，训练一个在每个 token 上都准确的价值函数很难 [@shao2024deepseekmath]。这两句话分别对应本页的显存账和上一页末尾的“价值网络难训”。

GRPO 的回答是不要价值网络：对同一道题采样一组 $G$ 个回答，用组内的平均奖励作基线，每个回答的优势是“比这组平均分高出几个标准差”（课程的第 5 个类比：同题多答、组内排名）。大家回想一下 §5 黑板上的 0.94：那是“预期分”，由老师（价值网络）来估；GRPO 换了个办法，让同一道题的一组答卷自己给出“预期分”。按 (3.26)，这把 7B 的模型状态从 252 GB 降到 140 GB（第 8 课按 DeepSeekMath 7B 配置算出的 6.91B 参数记账，得 248.8 GB 与 138.2 GB，比例相同）；奖励模型和参考模型、KL 惩罚、裁剪目标都保留了下来。[第 8 课](lesson-08-deepseekmath-grpo.html)会逐项推导 GRPO 的目标，以及它换用的 KL 估计器。第 13 课的 R1 又用规则判分代替了一部分奖励模型。

::: key 这一页讲了三件事
- **第一，四个网络，两个要训练。** PPO-RLHF 同时用策略（训练）、参考模型（冻结）、奖励模型（冻结）、价值网络（训练）。旧策略只需要记下的对数概率，不是第五个网络。
- **第二，显存按“训练 16、冻结 2”记账 (3.26)。** 黑板上 1B 时是 16、18、20、36 GB；7B 时 SFT 112 GB、DPO 126 GB、GRPO 式 140 GB、PPO 252 GB，是 16 位权重的 18 倍。计算上 PPO 每个 token 约 $20N$，是 SFT 的 3.3 倍，而且其中的自回归生成特别慢。
- **第三，最贵的墨盒是价值网络。** 它和策略一样大时是最大的额外负担，又难训；DeepSeek 的 GRPO 去掉的正是它。但它不一定和策略一样大：InstructGPT 的 175B 配置里它只占 2.9%。
:::

# DPO：奖励模型就藏在策略里 | 从闭式最优解逐行推出 DPO 的损失、梯度与隐式奖励 | 40

想知道一位朋友的口味，其实不用问他。翻翻他的外卖记录，拿来和一般人的点单习惯比一比：他比一般人点得多的那几样，就是他爱吃的；比一般人点得少的，就是他不爱吃的。偏好就藏在选择里。

上一页的账单很长：四个网络、训练中在线采样、PPO 的一堆超参数。2023 年的 DPO（direct preference optimization，直接偏好优化）论文问了一个问题：我们在 §3 已经知道，**对任意奖励**，KL 约束目标的最优策略长什么样 (3.10)。既然奖励和最优策略一一对应，能不能把 (3.10) 倒过来读，从策略里把奖励读出来？如果能，就可以跳过“先学奖励、再用强化学习逼近最优策略”这两步，**直接用偏好数据去拟合策略**。答案是能，而且推导只有四步 [@rafailov2023dpo]。我们先在黑板上倒着读一次。

## 黑板上：把 §3 的最优策略倒过来读

::: ex 黑板上 · 从最优策略读回奖励
§3 的黑板：$\pi_{ref}=[0.6,\ 0.3,\ 0.1]$，$r=[0,\ 1,\ 2]$，$\beta=1$，最优策略 $\pi^*=[0.2785,\ 0.3785,\ 0.3430]$。现在假装我们忘了 $r$，只知道 $\pi_{ref}$（“一般人的点单习惯”）和 $\pi^*$（“这位朋友的点单”）。能不能把奖励读回来？

- 每个回答被放大了几倍：$\pi^*/\pi_{ref}=0.2785/0.6=0.4642$，$0.3785/0.3=1.2617$，$0.3430/0.1=3.430$（精确值 3.4298）。
- 取对数，再乘 $\beta=1$：$-0.7675$，$0.2325$，$1.2325$（用四位小数的 $\pi^*$ 去算，末位会差 1，来自舍入）。

读回来的不是 $[0,1,2]$，而是 $[0,1,2]$ 整体减去了 0.7675，正是 §3 算过的 $\ln Z=\ln2.1544$。

可是看两两之差：$0.2325-(-0.7675)=1$，$1.2325-(-0.7675)=2$，$1.2325-0.2325=1$，和真正的奖励差一模一样。所以用 Bradley–Terry 算“回答 2 胜过回答 1”的概率，读回来的奖励给出 $\sigma(1)=0.7311$，真正的奖励也给出 $\sigma(1)=0.7311$。多出来的那个 $\ln Z$，在比较里消掉了。
:::

::: fig figures/l03b-dpo-roundtrip.svg | 图 3.15 黑板上倒着读：从最优策略读回的奖励只差一个常数，而这个常数在比较里消掉
**看右边两排点：上排是真正的奖励 0、1、2，下排是从 $\pi^*$ 读回的 $\beta\log(\pi^*/\pi_{ref})$，整排往下平移了 $\ln Z=0.7675$，而点与点之间的间隔（1 和 1）完全相同。** 左边是参考分布与最优策略（§3 的例子，$\beta=1$）以及每个回答被放大的倍数。数字由脚本计算。
:::

黑板上发生的两件事，就是 DPO 的前两步：第一，从最优策略读回奖励，只差一个常数；第二，Bradley–Terry 只看差值，这个常数消掉。下面逐行写出来。

## 第一步：把奖励写成策略的函数

从 §3 的闭式解出发。它说：给定奖励 $r$，最优策略是 $\pi^*=\pi_{ref}e^{r/\beta}/Z$。把这个关系反过来读，就是：给定最优策略，奖励是什么。

::: deriv 从最优策略反解奖励
$\pi^*(o\mid q)=\dfrac{1}{Z(q)}\,\pi_{ref}(o\mid q)\exp\!\Big(\dfrac{r(q,o)}{\beta}\Big)$ || (3.10)，对任意奖励函数 $r$ 成立（前提：策略可以是任意分布）
$\log\pi^*(o\mid q)=\log\pi_{ref}(o\mid q)+\dfrac{r(q,o)}{\beta}-\log Z(q)$ || 两边取对数；乘积变和，除法变差
$r(q,o)=\beta\log\dfrac{\pi^*(o\mid q)}{\pi_{ref}(o\mid q)}+\beta\log Z(q)$ || 把 $r/\beta$ 留在一边，其余移到另一边，再乘 $\beta$
:::

::: eq 奖励的重参数化 | (3.28)
$$r(q,o)=\beta\log\frac{\pi^*(o\mid q)}{\pi_{ref}(o\mid q)}+\beta\log Z(q)$$
DPO 论文式 (5) [@rafailov2023dpo]。读法：一个回答的奖励 = $\beta\times$“最优策略相对参考模型把它的概率放大了多少倍”的对数，再加一个**只依赖提示**的常数。
:::

代回黑板：回答 3 读回 $1.2325$，加上 $\beta\log Z=0.7675$，正好是 2。对，就是它原来的奖励。

这一步本身还没有用：在真实模型上 $Z(q)$ 仍然算不出来。关键在下一步。

## 第二步：代入 Bradley–Terry，配分函数消掉

人的偏好按 BT 模型 (3.2) 只依赖两个回答的**奖励差**。把 (3.28) 代进去，两个回答来自同一个提示，共享同一个 $Z(q)$。为了写得紧凑，记 $z^*(o)=\log\frac{\pi^*(o\mid q)}{\pi_{ref}(o\mid q)}$，于是 (3.28) 就是 $r(q,o)=\beta\,z^*(o)+\beta\log Z(q)$：

::: deriv 配分函数在奖励差里抵消
$P(o_w\succ o_l\mid q)=\sigma\big(r(q,o_w)-r(q,o_l)\big)$ || BT 模型 (3.2)
$=\sigma\big(\beta z^*(o_w)+\beta\log Z(q)-\beta z^*(o_l)-\beta\log Z(q)\big)$ || 对两个回答分别代入 (3.28)
$=\sigma\big(\beta z^*(o_w)-\beta z^*(o_l)\big)$ || 同一个提示，$\beta\log Z(q)$ 一加一减，抵消
:::

::: eq 用最优策略表示的偏好概率 | (3.29)
$$P(o_w\succ o_l\mid q)=\sigma\Big(\beta\log\frac{\pi^*(o_w\mid q)}{\pi_{ref}(o_w\mid q)}-\beta\log\frac{\pi^*(o_l\mid q)}{\pi_{ref}(o_l\mid q)}\Big)$$
DPO 论文式 (6)（原文写成 $1/(1+\exp(\cdot))$ 的形式，附录 A.2 化成 sigmoid）[@rafailov2023dpo]。式中只剩下策略，没有奖励，也没有 $Z$。
:::

代回黑板：回答 2 对回答 1，$\sigma(0.2325-(-0.7675))=\sigma(1)=0.7311$，一个 $Z$ 都不用算。

为什么恰好能消掉？回到 §2 的那条性质：BT 模型下，奖励只确定到每个提示的一个平移，**看不见**只依赖提示的常数；而 $\beta\log Z(q)$ 正是这样一个常数。§3 末尾也说过，给奖励加一个只依赖提示的常数不改变最优策略。两件事合起来：偏好数据测不出来的那部分，恰好也是最优策略不关心、又算不出来的那部分。如果偏好模型依赖奖励的绝对值（练习 12），这一步就不成立。

## 第三步：用最大似然拟合策略

(3.29) 用的是未知的最优策略 $\pi^*$。DPO 的做法是：把它换成要训练的策略 $\pi_\theta$，然后像训练奖励模型 (3.3) 那样，最大化偏好数据的似然。我们先在黑板上算一对。

::: ex 黑板上 · 一对回答的 DPO 损失
一对偏好数据，四个整段对数概率（笔者自拟）：$\log\pi_\theta(o_w)=-12.0$，$\log\pi_{ref}(o_w)=-13.0$，$\log\pi_\theta(o_l)=-15.5$，$\log\pi_{ref}(o_l)=-15.0$。取 $\beta=0.1$（DPO 论文的默认值）。

- 偏好回答被放大了多少：$\log\pi_\theta(o_w)-\log\pi_{ref}(o_w)=-12.0+13.0=1.0$，也就是放大了 $e^{1}$ 倍；乘 $\beta$，得 $0.1$。
- 不偏好回答：$-15.5+15.0=-0.5$，缩小到 $e^{-0.5}$；乘 $\beta$，得 $-0.05$。
- 两者之差（间隔）：$0.1-(-0.05)=0.15$。
- 当作 BT 的分数差：$\sigma(0.15)=0.5374$，损失 $-\ln0.5374=0.6210$。

训练开始时 $\pi_\theta=\pi_{ref}$，间隔是 0，损失是 $\ln2=0.6931$。现在策略相对参考模型把 $o_w$ 抬高、把 $o_l$ 压低，损失就降到了 0.6210。
:::

好，把一对换成整个偏好数据集：

::: eq DPO 损失 | (3.30)
$$\mathcal L_{DPO}(\theta)=-\E_{(q,o_w,o_l)\sim\mathcal D_{pref}}\Big[\log\sigma\Big(\beta\log\frac{\pi_\theta(o_w\mid q)}{\pi_{ref}(o_w\mid q)}-\beta\log\frac{\pi_\theta(o_l\mid q)}{\pi_{ref}(o_l\mid q)}\Big)\Big]$$
DPO 论文式 (7) [@rafailov2023dpo]。它是一个普通的二分类交叉熵，数据是固定的偏好对，不需要采样，不需要奖励模型，也不需要价值网络。
:::

把括号里的两项分别看成一个“奖励”，就得到论文标题里那句话的含义：

::: eq 隐式奖励 | (3.31)
$$\hat r_\theta(q,o)=\beta\log\frac{\pi_\theta(o\mid q)}{\pi_{ref}(o\mid q)},\qquad\mathcal L_{DPO}(\theta)=-\E\Big[\log\sigma\big(\hat r_\theta(q,o_w)-\hat r_\theta(q,o_l)\big)\Big]$$
和奖励模型损失 (3.3) 一字不差，只是把 $r_\phi$ 换成了 $\hat r_\theta$。论文标题就是这个意思：你的语言模型悄悄地就是一个奖励模型 [@rafailov2023dpo]。
:::

代回黑板：$\hat r_w=0.1$，$\hat r_l=-0.05$，$-\log\sigma(0.1-(-0.05))=0.6210$。黑板上那两个“乘了 $\beta$ 的放大量”，就是两个隐式奖励。

**逻辑链。** 训练 DPO 等于同时做了两件事：用 BT 最大似然拟合一个奖励 $\hat r_\theta$；而 $\pi_\theta$ 恰好就是这个奖励在 KL 约束目标下的最优策略：把 $\hat r_\theta$ 代入 (3.10)，$\pi_{ref}\,e^{\hat r_\theta/\beta}=\pi_{ref}\cdot\pi_\theta/\pi_{ref}=\pi_\theta$，配分函数 $Z(q)=\sum_o\pi_\theta(o\mid q)=1$，最优策略就是 $\pi_\theta$ 自己。DPO 论文还证明了反方向：在温和的假设下（论文附录给出的是：对所有提示和回答 $\pi_{ref}>0$，且 $\beta>0$），任何与 BT 模型相容的奖励类，都能写成某个策略的 $\beta\log(\pi/\pi_{ref})$ 形式，所以用这种形式表示奖励不损失一般性（论文定理 1）[@rafailov2023dpo]。这里的“奖励类”指彼此只差一个只依赖提示的函数的一族奖励（BT 分不出它们）：由 (3.28)，族里的任一成员 $r$ 减去 $\beta\log Z(q)$，就是它的最优策略 $\pi^*$ 给出的 $\beta\log(\pi^*/\pi_{ref})$。黑板上的 $[0,1,2]$ 与读回来的 $[-0.7675,0.2325,1.2325]$，就是同一族里的两个成员。

实现时只要几行。下面是笔者按式 (3.30) 写的 PyTorch 风格示意（DPO 论文附录 B 给了一段等价的参考代码）：

```python
# logp_* : 整段回答的对数概率 = 回答各 token 的 log 概率之和，形状 [batch]
pi_logratio  = logp_policy_w - logp_policy_l      # 当前策略：偏好 − 不偏好
ref_logratio = logp_ref_w    - logp_ref_l         # 参考模型：冻结，可在训练前一次算好
loss = -F.logsigmoid(beta * (pi_logratio - ref_logratio)).mean()
```

$\beta\big[(\log\pi_\theta(o_w)-\log\pi_\theta(o_l))-(\log\pi_{ref}(o_w)-\log\pi_{ref}(o_l))\big]$ 重新分组就是 $\beta(\log\pi_\theta(o_w)-\log\pi_{ref}(o_w))-\beta(\log\pi_\theta(o_l)-\log\pi_{ref}(o_l))=\hat r_w-\hat r_l$，和 (3.30) 是同一个量。代回黑板：`pi_logratio` $=-12.0+15.5=3.5$，`ref_logratio` $=-13.0+15.0=2.0$，差 1.5，乘 $\beta=0.1$ 是 0.15，就是黑板上的间隔。

::: fig figures/l03-dpo-vs-rlhf.svg | 图 3.16 RLHF 与 DPO 的流程对比
**看右边少了什么：没有奖励模型，没有“采样—打分”的循环。** 左边的 RLHF 先用最大似然训练奖励模型，再在强化学习循环里让策略采样、奖励模型打分、PPO 更新，还要参考模型提供 KL 惩罚。右边的 DPO 只有一步最大似然，参考模型只提供每个偏好回答的 $\log\pi_{ref}$。据 DPO 论文图 1 重绘 [@rafailov2023dpo]。
:::

## 第四步：梯度在做什么

记 $\hat r_w=\hat r_\theta(q,o_w)$，$\hat r_l=\hat r_\theta(q,o_l)$，令 $u=\hat r_l-\hat r_w$（“排错的程度”：$u>0$ 表示隐式奖励把这一对排反了），单个样本的损失就是 $-\log\sigma(-u)$。下面把 $\pi_\theta(o\mid q)$ 简写成 $\pi_\theta(o)$。

::: deriv DPO 的梯度
$\dfrac{d}{du}\big[-\log\sigma(-u)\big]=\dfrac{\sigma'(-u)}{\sigma(-u)}$ || 链式法则：内层 $-u$ 的导数是 $-1$，与外层的负号相消
$=1-\sigma(-u)=\sigma(u)$ || §2 前置框的第 2 条、第 1 条性质
$\nabla_\theta\big[-\log\sigma(-u)\big]=\sigma(u)\,\nabla_\theta u$ || 链式法则
$\nabla_\theta u=\beta\big(\nabla_\theta\log\pi_\theta(o_l)-\nabla_\theta\log\pi_\theta(o_w)\big)$ || 由 (3.31)，$\pi_{ref}$ 冻结
$\nabla_\theta\mathcal L_{DPO}=-\beta\,\E\big[\sigma(\hat r_l-\hat r_w)\,(\nabla_\theta\log\pi_\theta(o_w)-\nabla_\theta\log\pi_\theta(o_l))\big]$ || 代回 $u$，把负号提到最前面，再对数据取期望
:::

::: eq DPO 梯度 | (3.32)
$$\nabla_\theta\mathcal L_{DPO}=-\beta\,\E\Big[\underbrace{\sigma(\hat r_l-\hat r_w)}_{\text{隐式奖励排错的概率}}\big(\underbrace{\nabla_\theta\log\pi_\theta(o_w)}_{\text{推高 }o_w}-\underbrace{\nabla_\theta\log\pi_\theta(o_l)}_{\text{压低 }o_l}\big)\Big]$$
与 DPO 论文 §4 的梯度式一致 [@rafailov2023dpo]。和奖励模型的梯度 (3.4) 结构相同，只是 $\nabla r_\phi$ 换成了 $\beta\nabla\log\pi_\theta$。
:::

**读法。** 每对样本把偏好回答的对数概率往上推、把不偏好回答的往下压；推压的力度是“隐式奖励把这一对排反了的概率”。已经排对、间隔很大的对，几乎不再贡献梯度；排反的对贡献最大。DPO 论文报告，去掉这个权重、对每一对一视同仁地推压，语言模型会退化 [@rafailov2023dpo]。权重让 DPO 在一个样本已经学会之后停下来，这和 §3 里 KL 惩罚的作用相通：它们都让模型不要在一个方向上走得太远。

::: warn 论文附录里的梯度有两处笔误
DPO 论文附录 A.4 的推导里，式 (21) 中 sigmoid 的自变量写成了 $\hat r_l-\hat r_w$（与式 (7) 相反），末式的权重写成了 $\sigma(\hat r_w-\hat r_l)$（与 §4 正文相反）；arXiv 的 v1 和 v3 都是这样。正文 §4 的形式，也就是 (3.32)，是对的。本课的研究笔记用有限差分核对过：一个三选项的 softmax 玩具策略（$\beta=0.1$，$o_w$、$o_l$ 是第 1、3 个选项）上，对三个 logits 的数值梯度是 $[-0.050645,\,0,\,0.050645]$，(3.32) 给出同样的数（权重 0.50645），附录末式给出 $[-0.049355,\,0,\,0.049355]$（权重 0.49355），不一致。读原文时以正文为准。
:::

## 代回黑板：两个 β

::: ex 隐式奖励、损失与梯度权重
还是黑板上那一对（$\log\pi_\theta(o_w)=-12.0$，$\log\pi_{ref}(o_w)=-13.0$，$\log\pi_\theta(o_l)=-15.5$，$\log\pi_{ref}(o_l)=-15.0$），这次把两个 $\beta$ 并排算。表中间隔 $m=\hat r_w-\hat r_l$，损失是 $-\log\sigma(m)$，梯度权重是 $\sigma(-m)$，最后一列 $\sigma(m)$ 是隐式奖励给出的 $P(o_w\succ o_l)$。$\beta=0.1$ 是 DPO 论文的默认值，0.5 是它在 TL;DR 摘要实验里用的值。

| $\beta$ | $\hat r_w$ | $\hat r_l$ | 间隔 $m$ | 损失 | 梯度权重 | $\sigma(m)$ |
|---|---|---|---|---|---|---|
| 0.1 | 0.100 | −0.050 | 0.150 | 0.6210 | 0.4626 | 0.5374 |
| 0.5 | 0.500 | −0.250 | 0.750 | 0.3869 | 0.3208 | 0.6792 |

训练开始时 $\pi_\theta=\pi_{ref}$，所有间隔都是 0，损失都是 $\ln2=0.6931$，权重都是 0.5。

同样的对数概率变化，$\beta$ 越大，隐式奖励的间隔越大，损失越小，梯度权重 $\sigma(-m)$ 也越小：$\beta$ 大意味着“离参考模型走一点就算很多奖励”，损失在离参考模型更近的地方就饱和了，所以不需要走远。这正是 $\beta$ 在 (3.7) 里的角色：它越大，最优策略离参考模型越近。注意这说的是“饱和得早”，不是“当前这一步的梯度小”：(3.32) 前面还乘着 $\beta$，对 $\log\pi_\theta(o_w)$ 的梯度大小是 $\beta\sigma(-m)$，上表两行分别是 $0.1\times0.4626=0.0463$ 和 $0.5\times0.3208=0.1604$，$\beta=0.5$ 的反而更大。
:::

::: fig figures/l03-dpo-plane.svg | 图 3.17 DPO 损失奖励什么：梯度权重（左）与对数比平面（右）
**看右图的斜虚线：损失只取决于点在主对角线的哪一侧、离它多远（也就是 $\Delta_w-\Delta_l$），与点沿对角线方向的位置无关。** 右图横轴是偏好回答的对数比 $\Delta_w=\log\pi_\theta(o_w)-\log\pi_{ref}(o_w)$，纵轴是不偏好回答的 $\Delta_l$，$\beta=0.1$。损失只依赖 $\Delta_w-\Delta_l$，所以等损失线都平行于对角线，往右下方损失下降。点 A 是上面的例题；点 B 是两个回答的概率都下降了，但 $o_l$ 降得更多，损失 0.598 反而比 A 更低。左图是 (3.32) 的梯度权重随间隔的变化，曲线上的圆点从左到右依次是 $m=-1,\,0,\,0.15,\,0.75,\,1$（0.15 与 0.75 是上面表中 $\beta=0.1$ 与 $\beta=0.5$ 两行）。由脚本计算。
:::

::: err 很多人以为：DPO 损失下降，偏好回答就更可能了
很多人以为：损失降了，说明模型更愿意写偏好回答了。

其实：DPO 只约束两个回答**之间**的相对间隔。上图的点 B：$\log\pi_\theta(o_w)$ 从 −13.0 降到 −14.0，$\log\pi_\theta(o_l)$ 从 −15.0 降到 −18.0，$\beta=0.1$ 时间隔 $m=-0.1-(-0.3)=0.2$，损失从 0.6931 降到 0.5981，而偏好回答的概率比训练前还低了 $1-e^{-1}\approx63\%$。损失函数本身不禁止这种走法。这是笔者从损失形式推出的可能失败模式，DPO 论文没有讨论它；实践中是否发生、多严重，取决于数据和训练设置。
:::

::: err 很多人以为：DPO 不需要参考模型、没有奖励模型、去掉了 KL 约束
很多人以为：DPO 把 RLHF 里的东西都扔掉了。

其实：三句都不对。参考模型显式出现在 (3.30) 里（只是它的对数概率可以离线算好）；奖励模型是隐式的 $\hat r_\theta$ (3.31)；DPO 优化的正是 §3 的 KL 约束目标 (3.7)，$\beta$ 的角色和 RLHF 里一样。DPO 去掉的是**单独训练的奖励模型**和**强化学习的采样循环**。
:::

## DPO 与 PPO 真的等价吗

推导里的等价性有三个前提：策略可以是任意分布（DPO 论文附录 A.1 称为非参数的策略类）；人的偏好确实服从 BT 模型；数据无限多 [@rafailov2023dpo]。现实中这三条都不完全成立，于是两者在实践中并不等价。

最大的区别是**在线与离线**：PPO 在训练中不断从当前策略采样，由奖励模型给**新写出**的回答打分，还能用没有标签的提示；DPO 只在固定的偏好对上训练，策略写出的新回答永远得不到反馈。DPO 论文自己也指出，在摘要实验里它没有用 PPO 所用的那些无标签提示 [@rafailov2023dpo]。参考模型的选择也因此变得重要：有 SFT 模型就用它；没有的话，论文建议先在偏好回答 $o_w$ 上做一次最大似然微调，得到的模型作参考，以减小偏好数据与参考模型之间的分布差异 [@rafailov2023dpo]。

DPO 论文的实验结果（以下均为论文实测）：在情感控制任务上，DPO 的奖励–KL 前沿严格优于 PPO；在 TL;DR 摘要上，以 GPT-4 为评判、采样温度 0 时，DPO 的胜率约 61%，高于 PPO 的 57%；人工评测中 DPO 对 PPO 胜出 58%；实验中最大的模型是 6B [@rafailov2023dpo]。评判者是 GPT-4，论文另做了人与 GPT-4 一致率的校验。这些结论的方向可信，具体幅度依赖任务与设置。

超参数方面，DPO 论文默认 $\beta=0.1$（TL;DR 用 0.5），batch 64，RMSprop 优化器，学习率 $10^{-6}$，150 步线性 warmup；arXiv 第一版写的优化器是 Adam，后来的版本改成了 RMSprop [@rafailov2023dpo]。DeepSeek 的第一代对话模型 DeepSeek LLM 就在 SFT 之后用 DPO 训了 1 个 epoch，学习率 $5\times10^{-6}$，batch 512；论文没有报告 $\beta$ [@deepseek2024llm]。第 6 课会讲它的偏好数据怎么构造。

::: ana 类比续：不请评委，直接拿判决书改自己
**映射。** DPO 里没有模拟评委。学生直接拿着一沓判决书（“这两篇里 A 更好”），把自己写 A 的倾向**相对于原来的自己**调高、写 B 的倾向调低；已经明显偏向 A 的判决书，就少看几眼（梯度权重）。“相对于原来的自己”就是 $\pi_{ref}$：隐式奖励是 $\beta\log(\pi_\theta/\pi_{ref})$，不是 $\log\pi_\theta$ 本身。这也是开头外卖记录的道理：口味要和“一般人”比，才读得出来。

**收益。** 它说明了 DPO 为什么简单：不用训练评委，也不用写新作文给评委看。

**但是这个比方有两个地方不对。** 学生从不写新作文接受评判（离线），所以在判决书没覆盖到的题目上怎么变，没有任何约束；而且“A 比 B 更像我会写的”既可以靠多写 A 做到，也可以靠 A、B 都少写、B 少写得更多做到（上面的点 B）。
:::

::: key 这一页讲了三件事
- **第一，奖励能从最优策略里读回来，只差一个常数。** 从 §3 的闭式解反解奖励 (3.28)；黑板上从 $\pi^*$ 读回 $[-0.7675,0.2325,1.2325]$，比真奖励整体少 $\ln Z$。代入只看差值的 BT 模型，配分函数 $Z(q)$ 抵消 (3.29)。
- **第二，DPO 就是把奖励模型损失里的 $r_\phi$ 换成隐式奖励。** $\hat r_\theta=\beta\log(\pi_\theta/\pi_{ref})$ (3.31)，损失 (3.30)（黑板上一对的损失 0.6210）；梯度 (3.32) 按“隐式奖励排错的概率”加权，推高 $o_w$、压低 $o_l$。论文附录 A.4 的梯度式有笔误，以正文为准。
- **第三，省下的是奖励模型和采样循环，代价是离线。** 7B 时 126 GB 对 PPO 的 252 GB；它只学相对间隔，偏好回答的绝对概率可能下降，新写出的回答得不到反馈。
:::

## 贯穿这一课的三件事

**第一，同一个 KL 锚。** 从 Ziegler 到 InstructGPT，从 DPO 到 GRPO，目标里都有同一项 $\beta\,\KL(\pi_\theta\|\pi_{ref})$。它的最优解 $\pi^*\propto\pi_{ref}e^{r/\beta}$ (3.10) 说明：后训练主要是在参考模型已经会写的回答之间重新分配概率，参考模型几乎不写的回答，要很大的奖励才能被放大。第 13 课讲 R1-Zero 直接在基座模型上做强化学习时，还会回到“基座模型会写什么”这个问题。

**第二，只看差值。** Bradley–Terry 只依赖奖励之差 (3.2)，于是奖励只确定到每个提示的平移；这个看不见的平移恰好就是 $\beta\log Z(q)$，DPO 靠它消掉了配分函数 (3.29)。黑板上从头到尾都是这件事：两篇作文都加 5 分，胜率不变；从 $\pi^*$ 读回的奖励整体少了 0.7675，差值一分不差。

**第三，价值网络的账单。** 当价值网络和策略一样大时，要训练的模型状态翻倍（7B 时从 112 GB 到 224 GB，总账从 GRPO 式的 140 GB 涨到 252 GB，(3.26)），每个 token 的计算从约 $12N$ 涨到约 $20N$ (3.27)；而且只有最后一个 token 有奖励，它很难训准。DeepSeekMath 的 GRPO 正是从这里下刀 [@shao2024deepseekmath]。

::: key 全课要点
- InstructGPT 三步：SFT → Bradley–Terry 奖励模型 → 带 KL 惩罚的 PPO；12,725 / 33,207 / 31,144 个提示；1.3B 的结果被偏好于 175B GPT-3，但公开基准上有对齐税。
- 奖励模型损失 $-\log\sigma(r_w-r_l)$；KL 约束目标的最优解 $\pi_{ref}e^{r/\beta}/Z$；PPO 的 $\min(\rho\hat A,\clip(\rho)\hat A)$；GAE 的 $\sum(\gamma\lambda)^l\delta_{t+l}$；DPO 的 $-\log\sigma(\hat r_w-\hat r_l)$，$\hat r=\beta\log(\pi_\theta/\pi_{ref})$。
- 7B 模型状态：SFT 112、DPO 126、GRPO 式 140、PPO 252 GB。第 8 课从“去掉价值网络”讲起。
:::

## 最后给大家留个问题

回头看 (3.27)：PPO 每处理一个回答 token 约 $20N$ 次运算，其中策略生成只占 $2N$，是最便宜的一项。InstructGPT 每一轮都要让策略自己写 512 段回答；只看运算量，这一步看上去不该是瓶颈。

可 §6 说过，同样的 $2N$ 次运算，生成要比训练时的前向慢得多。大家用聊天机器人的时候，其实天天都在看这个现象：你贴进去一大段话，它一眨眼就“读”完了；它的回答，却是一个字一个字往外蹦的。同一个模型，读得飞快，写得慢吞吞。

大家先想一想：运算量一样，为什么“写”比“读”慢那么多？慢在哪里？是算力不够，还是别的什么东西卡住了？这就是[第 4 课](lesson-04-inference-kv-cache.html)要揭晓的问题：答案藏在 KV cache 和显存带宽里。

还有一个问题，留得更远一点。§5 黑板上那个“预期分” 0.94，是价值网络这位老师估出来的；而第 8 课的 GRPO 把老师辞退了。没有老师，每个回答比“预期”好多少，又该拿什么来量？[第 8 课](lesson-08-deepseekmath-grpo.html)会给出 DeepSeek 的答案：同一道题多写几份，让它们互相比。

::: key 这一页讲了三件事
- **第一，四种办法各有各的账。** 7B 时模型状态 SFT 112、DPO 126、GRPO 式 140、PPO 252 GB；每个 token 约 $6N$、$8N$、$12N$、$20N$。没有哪一种在每一栏都赢：PPO 贵在价值网络和在线采样，买到的是给新回答打分；DPO 便宜，代价是离线。
- **第二，三条线贯穿全课。** 同一个 KL 锚 $\pi^*\propto\pi_{ref}e^{r/\beta}$；只看差值，所以 $Z(q)$ 能在 DPO 里消掉；价值网络的账单，是 GRPO 下刀的地方。
- **第三，留下两个问题。** 运算量不大的“生成”为什么反而慢（第 4 课：KV cache 与带宽墙）；去掉价值网络后，“预期分”从哪里来（第 8 课：GRPO）。
:::

## 概念题

:::: quiz 练习 1 · 三种 KL，别混了
（a）PPO 论文的自适应 KL 变体取 $d_{targ}=0.01$。某一轮更新后测得旧策略与新策略之间的 KL 为 $d=0.004$，下一轮测得 $d=0.02$。两次之后 $\beta_{old}$ 各怎样变？（b）这个 $\beta_{old}$ 与 (3.7) 里的 $\beta$ 是同一个东西吗？（c）InstructGPT 用了哪几种“KL”？
::: answer 看答案
（a）规则是 $d<d_{targ}/1.5=0.00667$ 时减半，$d>1.5\,d_{targ}=0.015$ 时加倍 [@schulman2017ppo]。$0.004<0.00667$，$\beta_{old}$ 减半；$0.02>0.015$，$\beta_{old}$ 加倍。

（b）不是。$\beta_{old}$ 惩罚的是到**上一轮快照** $\pi_{\theta_{old}}$ 的 KL，锚点每轮都换，作用是限制单轮步长；$\beta$ 惩罚的是到**冻结参考模型** $\pi_{ref}$ 的 KL，锚点整个训练不变，作用是防过度优化、留在语言里。

（c）RLHF 奖励里的 $\beta\,\KL(\pi_\theta\|\pi_{ref})$（$\beta=0.02$），加上 PPO 的裁剪（裁剪不是 KL）。它没有用 PPO 论文的自适应 KL 惩罚。
:::
::::

:::: quiz 练习 2 · β 的两个极端
用闭式解 (3.10) 回答：（a）$\beta\to0$ 时最优策略是什么？对应 §3 开头说的哪一种坏情况？（b）$\beta\to\infty$ 呢？（c）某个回答参考模型给的概率恰好是 0，但奖励模型给它很高的分，最优策略给它多少概率？这说明了参考模型的什么作用？
::: answer 看答案
（a）$e^{r/\beta}$ 被最大的奖励压倒，$\pi^*$ 把全部概率放在参考模型给了正概率的回答里奖励最高的那一个（若并列则在它们之间按 $\pi_{ref}$ 分配）。这就是“只剩一种回答”，也就是 §3 黑板上的“全押”，而且完全听凭奖励模型，最容易被过度优化。

（b）$e^{r/\beta}\to1$，$\pi^*\to\pi_{ref}$：完全不学，也就是黑板上的“不动”。

（c）0。$\pi^*(o)\propto\pi_{ref}(o)e^{r(o)/\beta}$，$\pi_{ref}(o)=0$ 时无论奖励多高都是 0。参考模型划定了“可以写什么”的范围，后训练只在这个范围里重新分配概率。
:::
::::

:::: quiz 练习 3 · “1.3B 胜过 175B”到底说了什么
InstructGPT 说 1.3B 模型的回答比 175B GPT-3 的更受偏好。（a）这个结论是在什么数据上、由谁判断的？（b）它是否意味着 1.3B InstructGPT 在各种能力上都强于 175B GPT-3？给出论文里的反例。（c）论文说模型被“对齐”到了谁的偏好？
::: answer 看答案
（a）在留出的 API 用户提示分布上，由标注员做两两偏好判断 [@ouyang2022]。

（b）不意味着。在 SQuAD、DROP、HellaSwag、WMT15 法译英等公开数据集上，RLHF 后的模型反而退步（对齐税），需要 PPO-ptx 混入预训练梯度来弥补；而且把 KL 系数加到 100 倍也修不好这些退步 [@ouyang2022]。

## 计算题

:::: quiz 练习 4 · Bradley–Terry 与排序拆对
（a）奖励模型给偏好回答 2.1 分、另一个回答 0.6 分。求 BT 下标注员偏好前者的概率和这一对的损失。两者都加 5 分呢？（b）某提示下标注员给 $K=7$ 个回答排序，产生多少对比较？每个回答参与几对？一个 batch 64 个提示、都是 $K=7$ 时共多少对？（c）要让 BT 概率达到 99%，奖励差至少是多少？
::: answer 看答案
（a）$\Delta=1.5$，$\sigma(1.5)=0.8176$，损失 $-\ln0.8176=0.2014$。都加 5 分，$\Delta$ 不变，概率和损失都不变：奖励只确定到平移，所以 InstructGPT 要另加偏置把示范回答的平均分调成 0。

（b）$\binom72=21$ 对；每个回答参与 $K-1=6$ 对；$64\times21=1{,}344$ 对（上限是 $K=9$ 时的 2,304 对）。

（c）$\sigma(\Delta)=0.99\Rightarrow e^{-\Delta}=1/99\Rightarrow\Delta=\ln99=4.595$。换成几率的说法：胜率 99% 就是几率 99，对数几率 $\ln99$。

:::: quiz 练习 5 · 从对数概率到裁剪
$\varepsilon=0.2$。某 token 采样时 $\log\pi_{\theta_{old}}=-2.30$。（a）几步更新后 $\log\pi_\theta=-2.00$。求 $\rho$；分别对 $\hat A=+0.5$ 和 $\hat A=-0.5$ 求这一项的目标值，并判断梯度是否为 0。（b）若更新后 $\log\pi_\theta=-2.40$ 呢？
::: answer 看答案
（a）$\rho=e^{-2.00+2.30}=e^{0.3}=1.3499>1.2$。$\hat A=+0.5$：$\min(0.675,\ 1.2\times0.5)=0.6$，取的是裁剪项，梯度为 0（好 token 已涨够）。$\hat A=-0.5$：$\min(-0.675,\ -0.6)=-0.675$，取的是未裁剪项，梯度照常，会把这个 token 的概率往下压（坏 token 反而涨了）。这和 §4 黑板上 $\rho=1.5$ 那两行是同一种情形：比值都越过了 1.2。

（b）$\rho=e^{-0.1}=0.9048$，在 $[0.8,1.2]$ 内，两种情形都不裁剪：$\hat A=+0.5$ 时目标 0.4524，$\hat A=-0.5$ 时 $-0.4524$，梯度都照常。

:::: quiz 练习 6 · 一段三个 token 的 GAE

:::: quiz 练习 9 · DPO 的隐式奖励
$\beta=0.2$。$\log\pi_\theta(o_w)=-20.0$，$\log\pi_{ref}(o_w)=-20.5$；$\log\pi_\theta(o_l)=-18.0$，$\log\pi_{ref}(o_l)=-17.0$。（a）求 $\hat r_w$、$\hat r_l$、间隔、损失和梯度权重。（b）注意 $o_l$ 的对数概率（−18.0）比 $o_w$ 的（−20.0）还高，为什么 DPO 仍然认为这一对“排对了”？

:::: quiz 练习 11 · 用拉格朗日乘子再推一次闭式解
对固定的提示，把策略写成有限个回答上的概率 $\pi(o)$，并设每个回答都有 $\pi_{ref}(o)>0$。在约束 $\sum_o\pi(o)=1$ 下最大化 $F(\pi)=\sum_o\pi(o)r(o)-\beta\sum_o\pi(o)\log\frac{\pi(o)}{\pi_{ref}(o)}$。用拉格朗日乘子法推出 (3.10)，并说明驻点是最大值。
::: answer 看答案
拉格朗日函数 $\mathcal F=F(\pi)+\mu\big(\sum_o\pi(o)-1\big)$。对每个 $\pi(o)$ 求偏导并令其为 0：

$$r(o)-\beta\Big(\log\frac{\pi(o)}{\pi_{ref}(o)}+1\Big)+\mu=0\ \Rightarrow\ \pi(o)=\pi_{ref}(o)\,e^{r(o)/\beta}\,e^{(\mu-\beta)/\beta}.$$

（$\pi\log\pi$ 对 $\pi$ 的导数是 $\log\pi+1$。）$e^{(\mu-\beta)/\beta}$ 对所有 $o$ 相同，由 $\sum_o\pi(o)=1$ 定出它等于 $1/Z$，得到 (3.10)。二阶导数 $\partial^2F/\partial\pi(o)^2=-\beta/\pi(o)<0$，交叉项为 0，所以 $F$ 在 $\pi(o)>0$ 的区域上严格凹；约束 $\sum_o\pi(o)=1$ 是线性的，凹函数在线性约束下满足一阶条件的点就是全局最大值，严格凹又保证它唯一。解的每个分量都是正数，自动满足 $\pi(o)\ge0$，所以不需要另加非负约束。这和正文用 Gibbs 不等式的推导殊途同归；§3 黑板上“乘一乘，再归一化”的规则，这里又推出了一遍。
:::

:::: quiz 练习 12 · 配分函数为什么能消掉
（a）从 (3.28) 出发，写出 $P(o_w\succ o_l\mid q)$ 并说明 $Z(q)$ 为何消失。（b）假设换一个偏好模型：“标注员认可回答 $o$ 的概率是 $\sigma(r(q,o))$”，只依赖单个回答的绝对奖励。代入 (3.28) 后 $Z(q)$ 还能消掉吗？这对 DPO 意味着什么？
::: answer 看答案
（a）见 §7 第二步：两个回答来自同一个提示，(3.28) 里的 $\beta\log Z(q)$ 在 $r(q,o_w)-r(q,o_l)$ 中一加一减；BT 只依赖这个差，所以 $Z(q)$ 消失，得到 (3.29)。黑板上就是：读回的奖励整体少了 0.7675，差值一分不差。

（b）不能。$\sigma\big(\beta\log\frac{\pi^*(o)}{\pi_{ref}(o)}+\beta\log Z(q)\big)$ 里 $\beta\log Z(q)$ 没有另一项来抵消，而它需要对所有回答求和才能算出。DPO 的重参数化依赖偏好模型“只看同一提示下奖励之差”这一性质；BT 和 Plackett–Luce 满足它，所以 DPO 论文对这两种模型都给出了损失 [@rafailov2023dpo]。
:::
