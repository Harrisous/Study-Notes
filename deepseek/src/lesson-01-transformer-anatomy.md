## 这一课回答什么问题

GPT 的全部工作可以用一句话说完：读进前 $t$ 个 token，给出第 $t+1$ 个 token 在整个词表上的概率分布。难的是中间那一步。读完这一课，下面这些问题你都能自己回答，而且能把答案写成公式、算出数字：

- 文字是怎么变成一列列数的？为什么说“查表”和“独热向量乘矩阵”是同一件事？
- 注意力到底在算什么？公式为什么是 $\softmax(QK^\top/\sqrt{d_k})V$，偏偏要除以 $\sqrt{d_k}$？
- 训练时模型一次读进 1024 个 token、同时给出 1024 个预测，它怎么保证每个预测都没有偷看答案？
- “多头”注意力的头是什么？拼接之后那个 $W^O$ 在做什么？
- 前馈网络（FFN）占了每层三分之二的参数，它在做什么？
- 残差连接和 LayerNorm 为什么能让几十层的网络训练得动？GPT-2 为什么把 LayerNorm 挪了位置？
- GPT-2 small 为什么有 124,439,808 个参数，而它的论文却印着 117M？每生成一个 token 要做多少次运算？

## 问题：从一段前缀到下一个词的分布

**含义。** 语言模型（language model）是一个函数：输入一段 token 序列的前 $t$ 个，$x_1,\dots,x_t$，输出一个长度为 $V$ 的概率向量，第 $v$ 个分量是“下一个 token 恰好是 $v$”的概率。写成

$$p_\theta(x_{t+1}=v\mid x_1,\dots,x_t),\qquad v=0,1,\dots,V-1,$$

其中 $\theta$ 代表模型的全部参数。GPT-2 small 的 $V=50{,}257$，所以每一步的输出是 50,257 个非负数，加起来等于 1。

**理解。** 想象你在读一本书，每读完一个词就猜下一个词，并且不只猜一个，而是给每个候选词都报一个把握。“The cat sat on the” 之后，“mat”“floor”“sofa”都该有不小的把握，“quantum”则几乎为零。GPT 做的就是这件事，只是它要为 50,257 个候选词同时报数。

这个函数要满足四个要求，每一个都会在后面逼出一个具体的设计：

1. **任意长度。** 前缀可以是 1 个 token，也可以是 1024 个。同一组参数必须能处理任何长度。
2. **按内容取用前文。** 预测“The cat that the dog chased **sat**”里的 sat 时，要用到隔了四个词的 cat。该回头看哪个词，取决于词的**内容**，不取决于固定的距离。
3. **不许偷看未来。** 预测 $x_{t+1}$ 时只能用 $x_1,\dots,x_t$。
4. **训练能并行。** 一段 1024 个 token 的训练文本，最好一次前向传播就同时给出全部 1024 个位置的预测，而不是一个一个算。

循环神经网络（RNN）满足前三条，但第 4 条不行：它必须读完第 $t$ 个 token 才能处理第 $t+1$ 个。《Attention Is All You Need》的表 1 把这个差别量化了：一层自注意力需要的“顺序步骤数”是 $O(1)$，一层循环层是 $O(n)$（$n$ 是序列长度）；代价是自注意力每层的计算量是 $O(n^2\cdot d)$，而循环层是 $O(n\cdot d^2)$ [@vaswani2017]。GPT 选择了前者。这笔 $n^2$ 的账，会在第 4 课和第 14 课回来找我们。

## 一句话答案

GPT 的回答可以压缩成一句话：**先查表把每个 token 变成一个向量，然后让这些向量流过 $L$ 个结构相同的块，每块里先让 token 之间交换信息（注意力，只许看过去），再让每个 token 自己加工（前馈网络），每次都把结果“加回”一条贯穿全程的向量流（残差流）；最后把每个位置的向量变回词表上的概率。**

后面的每一页都是这句话里的一个短语：查表与位置在 [§2](#p2)，注意力在 [§3](#p3)、[§4](#p4)，前馈网络在 [§5](#p5)，残差流与 LayerNorm 在 [§6](#p6)，变回概率在 [§7](#p7)，最后在 [§8](#p8) 把参数和运算次数一笔一笔算清。

图 1.1 值得停下来看一分钟。它有三个一眼能看出的事实，后面几页会一个个解释：

- **宽度处处是 768。** 除了 FFN 中间那一段（3072）和最后的 logits（50,257），所有写回残差流的向量都是 $[T,768]$。这不是巧合：残差连接要求“加回去”的东西和流本身同形。
- **只有一个地方跨位置。** 整张图里，只有注意力放大框中的 $QK^\top$ 和 $AV$ 两步出现了 $[T,T]$ 这种“位置对位置”的形状。其他所有运算，包括 LayerNorm、FFN、所有投影，都是对 $T$ 个位置各自独立地做同一件事。
- **12 个块长得一样。** 它们结构相同、参数各自独立，所以写一遍方程，加一个上标 $(l)$ 就够了。

## 从 Transformer 到 GPT

2017 年的 Transformer 是为机器翻译设计的**编码器–解码器**（encoder–decoder）结构：编码器读源语言句子，解码器一边读已经译出的目标语言前缀，一边通过**交叉注意力**（cross-attention）查看编码器的输出，逐词生成译文 [@vaswani2017]。解码器的自注意力带着因果掩码，本身就是一个“只看过去、预测下一个”的语言模型。

GPT-1（2018）做了减法：删掉编码器，也就删掉了交叉注意力，只留下带掩码自注意力的解码器，堆 12 层，报告的原话是“12-layer decoder-only transformer with masked self-attention heads” [@radford2018]。它同时把正弦位置编码换成了可学习的位置表、把 ReLU 换成了 GELU；输出层则沿用原 Transformer 的权重共享，直接乘以输入嵌入矩阵的转置 [@radford2018; @vaswani2017]。GPT-2（2019）在此基础上把 LayerNorm 移到每个子层的**输入**处，并在最后一块之后再加一个 LayerNorm [@radford2019; @gpt2code]。图 1.2 把这三步画在一起。

::: fig figures/l01-lineage.svg | 图 1.2 从 Transformer 的编码器–解码器到仅解码器的 GPT-1 与 GPT-2 | scroll

## GPT 前向传播方程组

下面把图 1.1 翻译成方程。这是本课的“参考卡”：每个方程后面几页都会单独展开，这里先把它们放在一起，方便以后查。所有方程都对一个位置 $t$ 写出（$t=1,\dots,T$），$T$ 个位置用的是**同一组**参数。

::: def GPT 前向传播方程组（GPT-2 式，Pre-LN）
输入：token 编号 $x_1,\dots,x_T\in\{0,\dots,V-1\}$。输出：每个位置的下一词分布。

$$
\begin{aligned}
&\text{(1.1)}&\mathbf h^{(0)}_t&=E^\top\mathbf e_{x_t}+P^\top\mathbf e_{t}\\[4pt]
&&&\text{对每一块 } l=1,\dots,L\text{（每块一套独立参数）：}\\[4pt]
&\text{(1.2)}&\bar{\mathbf h}_t&=\LayerNorm_1^{(l)}\big(\mathbf h^{(l-1)}_t\big)\\
&\text{(1.3)}&\mathbf q_{t,i}&=W^Q_i\bar{\mathbf h}_t+\mathbf b^Q_i\quad(\mathbf k_{t,i},\ \mathbf v_{t,i}\text{ 同理，换成 }K,V)\\
&\text{(1.4)}&\alpha_{t,j,i}&=\frac{\exp\!\big(\mathbf q_{t,i}^\top\mathbf k_{j,i}/\sqrt{d_h}\big)}{\sum_{s=1}^{t}\exp\!\big(\mathbf q_{t,i}^\top\mathbf k_{s,i}/\sqrt{d_h}\big)}\ \ (j\le t),\qquad\alpha_{t,j,i}=0\ \ (j>t)\\
&\text{(1.5)}&\mathbf o_{t,i}&=\sum_{j=1}^{t}\alpha_{t,j,i}\,\mathbf v_{j,i}\\
&\text{(1.6)}&\mathbf u_t&=W^O\big[\mathbf o_{t,1};\mathbf o_{t,2};\dots;\mathbf o_{t,n_h}\big]+\mathbf b^O\\
&\text{(1.7)}&\mathbf h'_t&=\mathbf h^{(l-1)}_t+\mathbf u_t\\
&\text{(1.8)}&\mathbf m_t&=W_2\,\mathrm{GELU}\big(W_1\LayerNorm_2^{(l)}(\mathbf h'_t)+\mathbf b_1\big)+\mathbf b_2\\
&\text{(1.9)}&\mathbf h^{(l)}_t&=\mathbf h'_t+\mathbf m_t\\[4pt]
&&&\text{最后：}\\[4pt]
&\text{(1.10)}&\mathbf z_t&=E\,\LayerNorm_f\big(\mathbf h^{(L)}_t\big)\\
&\text{(1.11)}&p_\theta(x_{t+1}=v\mid x_{\le t})&=\softmax(\mathbf z_t)_v=\frac{e^{z_{t,v}}}{\sum_{w=0}^{V-1}e^{z_{t,w}}}
\end{aligned}
$$

其中用到的两个逐位置函数（对一个 $d$ 维向量或逐个元素作用）：

$$
\begin{aligned}
&\text{(1.12)}&\LayerNorm(\mathbf x)&=\boldsymbol\gamma\odot\frac{\mathbf x-\mu\mathbf 1}{\sqrt{\sigma^2+\epsilon}}+\boldsymbol\beta,\qquad \epsilon=10^{-5},\\
&&\mu&=\frac1d\sum_{k=1}^{d}x_k,\qquad \sigma^2=\frac1d\sum_{k=1}^{d}(x_k-\mu)^2\\[4pt]
&\text{(1.13)}&\mathrm{GELU}(x)&=x\,\Phi(x)=\frac x2\Big[1+\mathrm{erf}\big(x/\sqrt2\big)\Big]\\
&&&\approx\frac x2\Big[1+\tanh\Big(\sqrt{2/\pi}\,\big(x+0.044715\,x^3\big)\Big)\Big]
\end{aligned}
$$
:::

方程组里每个符号的形状、类型和含义如下。第一次读可以只扫一眼，读到后面某一页时再回来对照。

| 符号 | 形状 / 类型 | 含义 | GPT-2 small |
|---|---|---|---|
| $x_t$ | 整数 | 第 $t$ 个 token 的编号 | 如 464 = `The` |
| $\mathbf e_{x_t}$；$\mathbf e_t$ | $\R^{V}$；$\R^{T_{max}}$，独热 | 第 $x_t$（或第 $t$）个分量为 1、其余为 0 的列向量 | — |

| $\mathbf h^{(l)}_t$ | $\R^{d}$ | 第 $l$ 块输出后，位置 $t$ 在残差流上的状态；$l=0$ 是嵌入 | 768 |
| $\bar{\mathbf h}_t$ | $\R^{d}$ | LayerNorm 之后的副本，只供子层读取，不改残差流 | 768 |
| $W^Q_i,W^K_i,W^V_i$ | $\R^{d_h\times d}$ | 第 $i$ 个头的查询、键、值投影；12 个头按行拼起来是 $W^Q\in\R^{n_hd_h\times d}$ | $64\times768$ |

| $\alpha_{t,j,i}$ | 实数，$[0,1]$ | 头 $i$ 中位置 $t$ 分给位置 $j$ 的注意力权重；对 $j$ 求和为 1 | — |
| $\mathbf o_{t,i}$ | $\R^{d_h}$ | 头 $i$ 在位置 $t$ 的输出 | 64 |
| $W^O,\ \mathbf b^O$ | $\R^{d\times n_hd_h}$，$\R^{d}$ | 输出投影与偏置 | $768\times768$ |
| $\mathbf u_t$ | $\R^{d}$ | 注意力子层写回残差流的增量 | 768 |
| $\mathbf h'_t$ | $\R^{d}$ | 块内两个子层之间的残差流状态 | 768 |
| $W_1,\ \mathbf b_1$ | $\R^{d_{ff}\times d}$，$\R^{d_{ff}}$ | FFN 第一层（升维） | $3072\times768$ |
| $W_2,\ \mathbf b_2$ | $\R^{d\times d_{ff}}$，$\R^{d}$ | FFN 第二层（降维） | $768\times3072$ |
| $\mathbf m_t$ | $\R^{d}$ | FFN 子层写回残差流的增量 | 768 |

::: warn 代码里的两处约定
**位置从 0 数。** 本课让 $t$ 从 1 数到 $T$；GPT-2 的代码从 0 数，第 $t$ 个 token 用的是 `wpe` 的第 $t-1$ 行。**权重是转置存放的。** 代码一次处理整段序列，把 $T$ 个 token 按行堆成矩阵 $H\in\R^{T\times d}$，于是 (1.3) 在代码里是 $Q=\bar HW_{\text{代码}}+\mathbf 1\mathbf b^\top$，其中 $W_{\text{代码}}=(W^Q)^\top$；Hugging Face 的 GPT-2 用 `Conv1D` 层，权重形状是（输入维, 输出维），而 PyTorch 的 `nn.Linear` 是（输出维, 输入维），从一个搬到另一个时要转置 [@hfgpt2; @nanogpt]。列写法和行写法的来回翻译见 [M01 §3](../math/m01-vectors-matrices.html#p3)。
:::

::: ex 第一遍形状检查：“The unbelievable tokenization”
GPT-2 的分词器把这句话切成 4 个 token：`The`、`Ġunbelievable`、`Ġtoken`、`ization`，编号 464、24479、11241、1634（`Ġ` 代表前面的空格，[§2](#p2) 会解释）[@gpt2code; @hfgpt2]。于是 $T=4$。沿方程组走一遍形状：

- (1.1)：4 个编号 → 查两张表 → $H^{(0)}\in\R^{4\times768}$，共 3,072 个数。
- (1.3)：每个头的 $Q,K,V$ 都是 $[4,64]$；12 个头合起来是 $[12,4,64]$。
- (1.4)：每个头一张 $4\times4$ 的打分表，因果掩码只留下下三角 $1+2+3+4=10$ 格，其余 6 格权重为 0。
- (1.5)–(1.9)：回到 $[4,768]$；12 块之后仍是 $[4,768]$。
- (1.10)–(1.11)：$Z\in\R^{4\times50257}$，共 201,028 个 logits。第 4 行是“ization 之后下一个 token”的分布；第 1 行是“只读了 The 之后”的分布。

一次前向传播给出了 4 个预测，而不只是最后一个。这件事在 [§4](#p4) 讲因果掩码时会变得非常重要。
:::

## 三类运算

把方程组按“谁和谁发生关系”分一下类，本课后面的几乎所有结论都从这个分类里来：

1. **查表**：(1.1)。不做乘加，只按编号取行。
2. **逐位置运算**：(1.2)(1.3)(1.6)(1.7)(1.8)(1.9)(1.10)(1.11)。对 $T$ 个位置各做一遍**同样**的计算，位置之间互不相干。这类运算的参数占了模型的绝大部分，运算量与 $T$ 成正比。
3. **跨位置运算**：只有 (1.4) 和 (1.5)。位置 $t$ 在这里读取位置 $j\le t$ 的键和值。它没有任何参数，运算量却与 $T^2$ 成正比。

这个分类马上给出三个推论。第一，因为跨位置的只有注意力，“不偷看未来”只需要在 (1.4) 一处设防（[§4](#p4)）。第二，因为逐位置运算对每个 token 都一样，参数量与 $T$ 无关，而每个 token 的运算量约等于“每个参数做一次乘加”，这就是 $2N$（[§8](#p8)）。第三，生成新 token 时，旧 token 的逐位置结果不会变，只有注意力需要回头读旧 token 的键和值，这就是第 4 课 KV cache 的出发点。

::: key 本页要点
- GPT 是一个函数 $x_{\le t}\mapsto p_\theta(x_{t+1}\mid x_{\le t})$；一次前向传播对序列里每个位置同时给出这样一个分布。
- 结构：嵌入 → $L$ 个相同的块（注意力 + FFN，各自读一份残差流、再把结果加回去）→ 最终 LayerNorm → 乘 $E^\top$ → softmax。GPT-2 small：$L=12$、$d=768$、$n_h=12$、$d_{ff}=3072$、$V=50{,}257$。
- 方程组 (1.1)–(1.13) 是全课的参考卡。只有 (1.4)(1.5) 跨位置，其余都是逐位置运算或查表。
:::

# 从文字到向量：分词、嵌入与位置 | BPE、查表、位置编码 | 30

网络只会对数做乘法和加法，而输入是文字。这一页走完方程 (1.1) 之前和之中的三步：把文字切成 token 并编号（分词），把编号变成向量（词嵌入），再告诉模型每个 token 排在第几（位置）。三步里只有后两步属于网络本身；分词在网络之外完成，训练时也不会改变。

## 分词：BPE 把文字切成常见的片段

**问题。** 词表该用什么单位？用单个字符，词表很小，但一句话会变成很长的序列，而 [§1](#p1) 说过注意力的代价随长度的平方增长；用整词，序列短了，可词表会大到装不下，而且训练时没见过的词（比如一个新造的专有名词）根本无法表示。需要一个中间方案：常见的词整个保留，罕见的词拆成常见的片段。

**含义。** **字节对编码**（byte pair encoding，BPE）是一种自动找出这些“常见片段”的算法：从单个字符出发，反复把语料里**出现次数最多的相邻一对**粘成一个新符号，粘多少次由人事先定好 [@sennrich2016]。

**理解。** 它很像一个人在记笔记时逐渐发明缩写：先注意到“e”后面最常跟“s”，于是把“es”当成一个符号；接着发现“es”后面常跟“t”，于是有了“est”……常见的词最后会被粘成一个整体，罕见的词则停留在几个片段的组合上。

**数学。** Sennrich 等人把它写成一个很短的算法：符号表初始化为全部字符，每个词末尾加一个词尾符号 `</w>`；每一轮统计所有相邻符号对 $(A,B)$ 的出现次数（每个词里出现的次数乘以这个词的频数，再对所有词求和），把次数最多的那一对在所有词里替换成新符号 $AB$。最终的符号表大小 = 初始字符数 + 合并次数，合并次数是这个算法唯一的超参数 [@sennrich2016]。

::: ex 手算前三次合并
Sennrich 论文算法 1 的玩具语料是四个词及其频数：low 出现 5 次、lower 2 次、newest 6 次、widest 3 次 [@sennrich2016]。先把它们拆成字符：`l o w </w>`、`l o w e r </w>`、`n e w e s t </w>`、`w i d e s t </w>`。

第 1 轮，数几对候选：$(e,s)$ 出现在 newest 和 widest 里，$6+3=9$ 次；$(s,t)$、$(t,\texttt{</w>})$ 同样是 9 次；$(w,e)$ 出现在 lower 和 newest 里，$2+6=8$ 次；$(l,o)$ 是 $5+2=7$ 次。最多的是 9 次，有三对打平，算法取最先遇到的 $(e,s)$，于是 newest 变成 `n e w es t </w>`。

第 2 轮：$(es,t)$ 9 次，合并成 `est`。第 3 轮：$(est,\texttt{</w>})$ 9 次，合并成 `est</w>`。三次之后，newest 已经是 `n e w est</w>`，widest 是 `w i d est</w>`：两个词共享了一个表示“最高级词尾”的片段。继续做下去，第 4、5 轮会合出 `lo`、`low`，一直到第 10 轮的全部轨迹画在图 1.3 (a)。
:::

::: fig figures/l01-bpe.svg | 图 1.3 BPE 的合并轨迹 | scroll
**看每一行里加深的方块：它是这一轮新粘出来的符号。** (a) 把 Sennrich 等人论文算法 1 的代码原样运行在它自己的玩具语料上，前 10 次合并及其出现次数 [@sennrich2016]；注意论文图 1 用的是另一组词（low、lowest、newer、wider），很多教程把两者混在一起，手算时请用这一组。(b) GPT-2 的分词器处理“ unbelievable”（前面带一个空格）时的 12 次合并，右侧的 rank 是这一对在 GPT-2 合并表里的名次，名次越小越先合并；12 次之后整个词成为编号 24479 的一个 token [@hfgpt2]。两组数据都由生成脚本逐步复现。
:::

GPT-2 用的是 BPE 的**字节级**（byte-level）变体：初始符号不是字符，而是 256 个可能的字节值，所以任何文字（任何语言、表情符号、乱码）都能表示成字节序列，永远不会遇到“词表外”的输入 [@radford2019]。它的词表有 50,257 项，来历是

$$50{,}257=\underbrace{256}_{\text{单字节}}+\underbrace{50{,}000}_{\text{合并次数}}+\underbrace{1}_{\texttt{<|endoftext|>}},$$

最后那一个是标记文档结尾的特殊 token，编号 50256 [@hfgpt2]。为了让字节能打印出来，GPT-2 把每个字节映射成一个可见字符，空格字节 0x20 被映射成 `Ġ`，所以词表里的 `Ġworld` 表示“空格 + world” [@gpt2code]。下表是几个真实的切分结果（用官方分词代码与 Hugging Face 上的词表文件复现）：

| 文本 | GPT-2 切出的 token | 编号 |
|---|---|---|
| `Hello world` | `Hello`、`Ġworld` | 15496、995 |
| `The unbelievable tokenization` | `The`、`Ġunbelievable`、`Ġtoken`、`ization` | 464、24479、11241、1634 |
| ` lower newest widest` | `Ġlower`、`Ġnewest`、`Ġwidest` | 2793、15530、46232 |
| `DeepSeek` | `Deep`、`Se`、`ek` | 29744、4653、988 |

“tokenization”被切成两段，是因为合并表里没有 $(\texttt{Ġtoken},\texttt{ization})$ 这一对；“DeepSeek”在 GPT-2 的词表里没有整词，只能由三段拼成。

::: warn 分词器不是网络的一部分
分词规则在训练前就定死了，梯度下降不会改变它。网络只看到一串整数，它对 24479 的全部“理解”都存在嵌入表的第 24479 行里；切分方式的缺陷（词被切碎、数字被切成奇怪的片段）只能靠后面的层去弥补。
:::

## 嵌入：一次查表

**问题。** 编号 24479 只是一个标签。它不比 11241 “大”，也不和 24478 “相近”。如果把编号本身当成一个数喂给网络，网络会被迫学习一个毫无意义的大小关系。我们需要的是：每个 token 对应一个**向量**，意思相近的 token，向量也可以相近。

**含义。** **词嵌入**（token embedding）就是一张表 $E\in\R^{V\times d}$：每个 token 占一行，每行 $d$ 个可学习的数。用的时候按编号取出那一行。

**理解。** 可以把它想成一本有 50,257 页的档案册，每页记着一个 token 的 768 项“特征”。这些特征没有人为指定的名字，它们是训练出来的：训练结束时，经常出现在相似上下文里的 token，它们的档案往往也相似。

**数学。** 为了把“查表”写进方程，引入**独热向量**（one-hot vector）$\mathbf e_v\in\R^{V}$：第 $v$ 个分量是 1，其余都是 0。于是

::: deriv 独热向量乘矩阵 = 取出一行
$(E^\top\mathbf e_v)_k=\sum_{w=0}^{V-1}(E^\top)_{kw}\,(\mathbf e_v)_w$ || 矩阵乘向量的定义（[M01 §2](../math/m01-vectors-matrices.html#p2)）
$=\sum_{w=0}^{V-1}E_{wk}\,(\mathbf e_v)_w$ || 转置：$(E^\top)_{kw}=E_{wk}$
$=E_{vk}$ || $\mathbf e_v$ 只有第 $v$ 个分量是 1，求和里只剩 $w=v$ 这一项
:::

::: eq 嵌入 = 独热向量乘嵌入表 | (1.14)
$$E^\top\mathbf e_v=\big(E_{v1},E_{v2},\dots,E_{vd}\big)^\top=E\text{ 的第 }v\text{ 行（竖起来）}$$
数学上它是一个没有偏置的线性层，输入恰好是独热向量；实现上它是按下标取行，不做任何乘法。
:::

::: fig figures/l01-embedding.svg | 图 1.4 同一个矩阵 E 用两次：输入时取一行，输出时与每一行做点积 | scroll
**看两个面板里 $E$ 被高亮的那一行：上面是“按编号取出一行”，下面是“拿最终向量去和每一行打分”。** 这是一个 5 个词、$d=3$ 的玩具例子，所有数字由生成脚本算出。(a) 独热向量乘 $E$ 的结果就是 cat 那一行；(b) 输出层把最终的隐藏向量 $\tilde{\mathbf h}$ 与 $E$ 的每一行做点积得到 logits，sat 的点积最大，softmax 之后概率 0.557。(b) 的讲解在 [§7](#p7)。
:::

::: ex 查表省下了多少运算
如果老老实实做独热向量乘矩阵，$[1,V]\times[V,d]$ 要 $2Vd$ 次运算（[M01 §5](../math/m01-vectors-matrices.html#p5) 的 $2mnk$ 规则）。GPT-2 small：$2\times50{,}257\times768=77{,}194{,}752$，每个 token 约 $7.7\times10^7$ 次，其中 $50{,}256$ 行乘的都是 0。查表把这些全部省掉，只剩一次内存读取：768 个数。

这一数字并没有消失：[§7](#p7) 的输出层要把最终向量与**所有** 50,257 行做点积，那里的 $2Vd$ 次运算一次也省不了。
:::

**嵌入表的梯度是稀疏的。** 由 (1.14)，$\mathbf h=E^\top\mathbf e_v$ 的第 $k$ 个分量就是 $E_{vk}$，所以经输入端流到 $E$ 的梯度只落在第 $v$ 行：从输入这一侧看，一次训练只更新本批数据里出现过的那些行，极少出现的 token 几乎得不到训练（训练过程是第 2 课的内容）。GPT-2 的输出层还会再用一次同一个 $E$，那一侧的梯度是稠密的，[§7](#p7) 会回到这一点。

GPT-2 的代码把 `wte` 初始化为标准差 0.02 的正态分布、`wpe` 为 0.01，并直接把两者相加 [@gpt2code]。《Attention Is All You Need》在嵌入之后还要乘一个 $\sqrt{d_{model}}$ [@vaswani2017]，GPT-2 没有这一步。

::: def 组件卡 · 词嵌入
**含义**：给词表里每个 token 一行可学习的向量，按编号取出。

**数学意义**：一个输入为独热向量的线性映射 $\mathbf e_v\mapsto E^\top\mathbf e_v$，即 $E$ 的第 $v$ 行；实现为查表。

**逻辑意义**：把没有大小关系的离散编号，变成可以做点积、做加法、可以被梯度塑造几何关系的 $d$ 维向量；后面所有层都只处理这种向量。没有它，网络只能处理编号本身，而编号之间的大小与远近毫无意义。
:::

## 位置：没有它，注意力分不清先后

**问题。** 先看注意力的输出 (1.5)：$\mathbf o_t=\sum_{j\le t}\alpha_{t,j}\mathbf v_j$。这是一个**求和**，求和不管各项的次序。假如只有词嵌入、没有位置信息，把前缀里 $x_1,\dots,x_{t-1}$ 的顺序任意打乱，第一层里位置 $t$ 看到的是同一组键和值，只是编号换了，于是权重 $\alpha_{t,j}$ 跟着各自的键一起换位，加权和一分不差。

::: ex “Alice thanked Bob .”与“Bob thanked Alice .”
两句话的最后一个 token 都是句号，前面三个 token 是同一组词、顺序不同。没有位置信息时，第一层注意力里句号的查询 $\mathbf q_4$ 相同，面对的键值对集合 $\{(\mathbf k_j,\mathbf v_j)\}_{j=1}^{4}$ 也相同，所以 $\mathbf o_4$ 完全相同。可这两句话谁感谢谁正好相反。模型必须知道 Alice 在 thanked 的前面还是后面。
:::

严格地说，多层的因果模型能从掩码本身间接推出一点位置信息（位置 1 只看得见自己，第二层以后各位置不再对称）。这是笔者从方程组推出的，不是所引论文的结论；这种信息很间接，GPT 系列都显式地加入了位置。第一层对前缀排列不敏感这件事，[§9](#p9) 的练习 12 会逐步证明一遍。

**含义。** **位置编码**（positional encoding）是给每个位置 $t$ 一个 $d$ 维向量，把它加到该位置的词嵌入上，于是同一个词出现在不同位置时，进入网络的向量不同。

**做法一：可学习的位置表**（GPT-1、GPT-2）。再建一张表 $P\in\R^{T_{max}\times d}$，第 $t$ 行给第 $t$ 个位置，和词嵌入一样靠训练学出来 [@radford2018; @gpt2code]。这就是方程 (1.1) 的第二项 $P^\top\mathbf e_t$。它简单，代价是一个硬上限：GPT-2 small 的表只有 1024 行，第 1025 个位置没有向量可查。

**做法二：正弦位置编码**（Transformer 原论文）。不学，而是用固定公式给出 [@vaswani2017]：

::: eq 正弦位置编码 | (1.15)
$$PE_{(t,2m)}=\sin(\omega_m t),\qquad PE_{(t,2m+1)}=\cos(\omega_m t),\qquad \omega_m=10000^{-2m/d}$$
$m=0,1,\dots,\tfrac d2-1$。维度两两成对，第 $m$ 对是一个以角速度 $\omega_m$ 转动的“时钟”，波长 $2\pi/\omega_m$ 从 $2\pi$ 按等比数列增长到接近 $10000\cdot2\pi$。
:::

**理解。** 把一个位置写成一组时钟的读数：秒针转得最快（$m=0$，每 6.28 个位置转一圈），分针慢一些，时针更慢……只看秒针分不清第 3 个和第 9 个位置（差不多转了一圈），但加上慢针就分得清了。$d=512$ 时一共有 256 根指针，最慢的一根要约 60,611 个位置才转一圈（图 1.5）。类比的边界：真时钟的读数单独显示在表盘上，而这里的读数是**加**进词向量的，和词的特征挤在同一组坐标里（下文“为什么是相加而不是拼接”）；模型也不会像人一样“读表”，只能通过后面的矩阵乘法和点积间接用上这些数。

::: fig figures/l01-position.svg | 图 1.5 正弦位置编码：一组转速不同的时钟（d = 512） | scroll
**看左图四条曲线的疏密：同一段位置区间里，$m=0$ 的维度已经振荡了约 20 次，$m=128$ 的维度还没走完四分之一个周期。** 右图是波长 $2\pi\cdot10000^{2m/d}$ 随维度对编号 $m$ 的变化，纵轴是对数刻度，所以指数增长画成了直线；标出的数值由生成脚本计算，与原论文 §3.5 所说“从 $2\pi$ 到 $10000\cdot2\pi$ 的等比数列”一致 [@vaswani2017]。
:::

::: ex 位置 1 的前四维
$d=512$，$t=1$。第 0 对：$\omega_0=1$，$(\sin1,\cos1)=(0.8415,\ 0.5403)$。第 1 对：$\omega_1=10000^{-2/512}=e^{-(2/512)\ln10000}\approx0.9647$，$(\sin0.9647,\cos0.9647)=(0.8219,\ 0.5697)$。两对的读数很接近，因为相邻两根快针的转速只差约 3.5%；要到 $m$ 大很多的维度，读数才明显不同。
:::

**为什么偏偏用正弦和余弦？** 原论文给出的理由是一个假设：对任意固定的位移 $k$，位置 $t+k$ 的编码是位置 $t$ 编码的一个**线性函数**，这可能让模型容易学会按相对位置取用信息 [@vaswani2017]。这个线性关系可以直接推出来：

::: deriv 位移 k 等于把每一对维度旋转一个固定角度
$\sin(\omega(t+k))=\sin(\omega t)\cos(\omega k)+\cos(\omega t)\sin(\omega k)$ || 正弦的和角公式
$\cos(\omega(t+k))=\cos(\omega t)\cos(\omega k)-\sin(\omega t)\sin(\omega k)$ || 余弦的和角公式
$\begin{pmatrix}\sin\omega(t+k)\\\cos\omega(t+k)\end{pmatrix}=\begin{pmatrix}\cos\omega k&\sin\omega k\\-\sin\omega k&\cos\omega k\end{pmatrix}\begin{pmatrix}\sin\omega t\\\cos\omega t\end{pmatrix}$ || 把两行写成矩阵乘向量；矩阵只依赖 $k$，不依赖 $t$
:::

中间那个矩阵是一个二维旋转。也就是说，“往后挪 $k$ 个位置”等于把每一对维度各自旋转角度 $\omega_mk$。这个观察是第 5 课 RoPE（旋转位置编码）的种子：RoPE 不再把位置**加**到嵌入上，而是直接把查询和键按位置**旋转**，让点积只依赖相对位移。

原论文也试过可学习的位置表，结果“几乎相同”：表 3 的 (E) 行，可学习版本困惑度 4.92、BLEU 25.7，正弦版本 4.92、25.8 [@vaswani2017]。选正弦的理由是它“或许”能外推到比训练时更长的序列，论文没有用实验验证这一点。GPT 选择了可学习的表 [@radford2018]。

**为什么是相加而不是拼接？** 这是一个选择。拼接 $[\mathbf a;\mathbf b]$ 再乘 $W=[W_a\ W_b]$ 等于 $W_a\mathbf a+W_b\mathbf b$（分块乘法，[M01 §4](../math/m01-vectors-matrices.html#p4)），相加再乘 $W$ 等于 $W\mathbf a+W\mathbf b$：相加是拼接在 $W_a=W_b$ 时的特例。好处是维度不变、后面各层不必变宽；代价是词和位置共用同一组坐标，要由模型自己在 768 维里分配方向。本课引用的论文没有单独检验这个代价。

::: def 组件卡 · 位置编码
**含义**：给每个位置一个向量，加到该位置的词向量上。

**数学意义**：可学习版是第二张查找表 $P^\top\mathbf e_t$；正弦版是固定函数 (1.15)，位移 $k$ 在每一对维度上是一个旋转。

**逻辑意义**：注意力的加权求和对前缀的排列不敏感，没有位置信息就分不清“谁在谁前面”。可学习表的代价是长度上限 $T_{max}$；正弦编码没有上限，但能否外推只是一个假设。
:::

::: key 本页要点
- 分词在网络之外：GPT-2 用字节级 BPE，$50{,}257=256+50{,}000+1$；BPE 反复合并出现最多的相邻一对。
- 词嵌入 $E^\top\mathbf e_v$ 就是取 $E$ 的第 $v$ 行：数学上是线性层，实现上是查表，经输入端的梯度只落在出现过的行上。
- 注意力的求和不管次序，所以要加位置向量：GPT 用可学习的表（上限 1024），原 Transformer 用正弦时钟；正弦编码的位移是逐对旋转，这是 RoPE 的起点。
- 方程 (1.1)：$\mathbf h^{(0)}_t=E^\top\mathbf e_{x_t}+P^\top\mathbf e_t$，形状 $[T,768]$。
:::

# 注意力（一）：内容寻址的加权平均 | 从“按内容取信息”推出 softmax(QKᵀ/√d)V，并手算一遍 | 35

这一页回答全课最核心的问题：位置 $t$ 怎样从它前面的位置取信息。答案是方程 (1.3)–(1.5)，也就是缩放点积注意力。为了先看清它的骨架，这一页只讲**一个头**，并暂时把 $\sqrt{d_k}$ 当成一个给定的常数；为什么除以它、为什么要掩码、为什么要多个头，是下一页的事。

## 问题：固定权重的平均为什么不够

回到 [§1](#p1) 的第 2 个要求：预测“The cat that the dog chased **sat**”中 sat 之后的词时，模型需要知道“坐下的是 cat”。位置 $t$（sat）必须从前面的某个位置（cat）把信息拿过来。

最省事的办法是把前面所有位置的向量平均一下：$\mathbf o_t=\frac1t\sum_{j\le t}\mathbf v_j$。它的毛病是一视同仁：sat 是第 $t=7$ 个 token，cat 只占 $1/7$ 的权重，其余 $6/7$ 是 The、that、the、dog、chased 和 sat 自己的混合。再进一步，给每个**相对距离**配一个固定权重（比如“总是多看前一个词”，卷积网络就是这样做的），也不行：cat 与 sat 之间隔了几个词，取决于具体句子，“隔 4 个位置”这条规则换一句话就错了。

所以权重不能是常数，也不能只依赖距离，而要**依赖内容**：位置 $t$ 需要什么，位置 $j$ 有什么，两者对得上，权重就大。我们要的是一个函数 $\alpha_{t,j}=f(\text{位置 }t\text{ 的内容},\ \text{位置 }j\text{ 的内容})$，而且它要便宜、可导、能对所有 $(t,j)$ 一次算完。

## 图景：图书馆检索

::: ana 类比：注意力 = 图书馆检索
**映射。** 位置 $t$ 带着一个检索问题走进图书馆，这个问题就是**查询**（query）$\mathbf q_t$；书架上每本书（每个位置 $j$）的书脊上贴着一张标签，这是**键**（key）$\mathbf k_j$；书的内容是**值**（value）$\mathbf v_j$。问题与标签的匹配度是点积 $\mathbf q_t^\top\mathbf k_j$；softmax 按匹配度分配阅读时间；输出 $\mathbf o_t$ 是按阅读时间加权的读书笔记。

**收益。** 它解释了为什么要把“标签”和“内容”分开：决定读不读一本书的依据（键），和从书里读到的东西（值），可以是两回事。它也解释了“按内容寻址”：你按主题找书，不是按书架编号找书。

**失效的地方。** 真实的检索是挑出一本书来读；注意力却把**所有**书按权重混在一起读，权重永远不会恰好是 0 或 1。标签和内容都是学出来的，而且同一本书在不同的头里可以贴完全不同的标签（每个头有自己的 $W^K$）。还有一点真实图书馆里没有：检索者自己也是书架上的一本书，位置 $t$ 的查询也会和它自己的键做匹配。
:::

## 形式化：查询、键、值

三个新术语，按“含义 → 理解 → 数学”各走一遍。它们都由同一个输入 $\bar{\mathbf h}_j$（LayerNorm 之后的隐藏状态，[§6](#p6) 讲）经过三个不同的矩阵得到：

| 术语 | 含义 | 理解（图书馆里） | 数学（一个头，GPT-2 small） |
|---|---|---|---|
| 查询 query | 位置 $t$ 想找什么 | 检索问题 | $\mathbf q_t=W^Q\bar{\mathbf h}_t+\mathbf b^Q\in\R^{64}$ |
| 键 key | 位置 $j$ 能被什么找到 | 书脊标签 | $\mathbf k_j=W^K\bar{\mathbf h}_j+\mathbf b^K\in\R^{64}$ |
| 值 value | 位置 $j$ 被找到后交出什么 | 书的内容 | $\mathbf v_j=W^V\bar{\mathbf h}_j+\mathbf b^V\in\R^{64}$ |

其中 $W^Q,W^K,W^V\in\R^{d_k\times d}$，这里 $d_k=d_h=64$，$d=768$。注意三个矩阵作用在**同一个** $\bar{\mathbf h}_j$ 上：每个位置同时扮演三个角色，作为提问者（$\mathbf q$）、作为被检索的标签（$\mathbf k$）、作为被取走的内容（$\mathbf v$）。这就是“**自**注意力”（self-attention）的“自”：查询和键值来自同一个序列。

有了这三样东西，注意力分三步：

::: eq 第一步：打分 | (1.16)
$$s_{t,j}=\frac{\mathbf q_t^\top\mathbf k_j}{\sqrt{d_k}},\qquad j=1,\dots,t$$
$s_{t,j}$ 是一个实数，表示“位置 $t$ 的问题”与“位置 $j$ 的标签”有多对得上。除以 $\sqrt{d_k}$ 的理由在 [§4](#p4)。
:::

::: pre softmax 与它的三条性质 | 熟悉 softmax 的可以跳过
**softmax** 把任意一组实数 $z_1,\dots,z_n$ 变成一组概率：$\softmax(\mathbf z)_i=e^{z_i}/\sum_{k=1}^{n}e^{z_k}$。本课反复用到它的三条性质：

1. **输出非负、和为 1**：$e^{z_i}>0$，分子加起来正好等于分母。
2. **单调**：$z_i$ 越大，$\softmax(\mathbf z)_i$ 越大，排名不变。
3. **平移不变**：所有 $z_i$ 同时加上同一个常数 $c$，结果不变，因为 $e^{z_i+c}/\sum_ke^{z_k+c}=e^ce^{z_i}/(e^c\sum_ke^{z_k})$，$e^c$ 上下约掉。实现里常先减去最大值再取指数，防止 $e^{z}$ 溢出，靠的就是这一条。

还有一个会在 [§4](#p4) 用到的量：**温度**（temperature）。把 $\mathbf z$ 先除以 $\tau>0$ 再做 softmax，$\tau$ 越小分布越尖，$\tau\to0$ 时趋向只在最大值处为 1 的“独热”分布（前提是最大值只有一个；若有 $r$ 个并列最大，极限是在这 $r$ 处各为 $1/r$）；$\tau$ 越大分布越平，$\tau\to\infty$ 时趋向均匀分布。softmax 与温度在 [M04 §4](../math/m04-probability.html#p4) 有专门一节。
:::

::: eq 第二步：softmax 得到权重 | (1.17)
$$\alpha_{t,j}=\softmax_j(s_{t,1},\dots,s_{t,t})=\frac{e^{s_{t,j}}}{\sum_{k=1}^{t}e^{s_{t,k}}},\qquad \alpha_{t,j}\ge0,\quad\sum_{j=1}^{t}\alpha_{t,j}=1$$
只对 $j\le t$ 求和：位置 $t$ 只能看自己和前面的位置。这件事在矩阵形式里由“因果掩码”实现（[§4](#p4)）。
:::

::: eq 第三步：加权平均 | (1.18)
$$\mathbf o_t=\sum_{j=1}^{t}\alpha_{t,j}\,\mathbf v_j\in\R^{d_k}$$
输出是值向量的加权平均，权重由查询与键的匹配度决定。
:::

(1.16)–(1.18) 连起来就是方程组里的 (1.4)(1.5)。

## 数学意义：内容寻址的加权平均

(1.17) 说权重非负、和为 1，所以 (1.18) 的 $\mathbf o_t$ 是 $\mathbf v_1,\dots,\mathbf v_t$ 的一个**凸组合**（convex combination）：几何上，它一定落在这 $t$ 个点围成的凸多边形（凸包）里面。这句话有两个极端值得记住：

- 若某个 $\alpha_{t,j}\approx1$，其余 $\approx0$：$\mathbf o_t\approx\mathbf v_j$，注意力退化成“查表取一个”。
- 若所有 $\alpha_{t,j}=1/t$：$\mathbf o_t$ 是简单平均，退化成本页开头那个一视同仁的方案。

真实的注意力介于两者之间，而且**在哪里取值由内容决定**。“内容寻址”（content-based addressing）是相对于计算机内存的“按地址寻址”说的：内存按编号取数据，而注意力按“键与查询像不像”取数据，并且是软性的、按相似度混合的。

**为什么用点积打分？** 点积 $\mathbf q^\top\mathbf k=\norm{\mathbf q}\norm{\mathbf k}\cos\varphi$（$\varphi$ 是两个向量的夹角）同时量了方向是否一致和向量有多长（[M01 §1](../math/m01-vectors-matrices.html#p1)），它只含乘法和加法，处处可导，而所有 $(t,j)$ 的点积恰好是一次矩阵乘法 $QK^\top$。原论文比较过另一种打分方式“加性注意力”（用一个带隐藏层的小网络打分）：两者理论复杂度相近，但点积注意力可以用高度优化的矩阵乘法代码实现，实践中快得多、也更省内存 [@vaswani2017]。

**为什么要三个不同的矩阵？** 把 (1.16) 展开（忽略偏置）：$\mathbf q_t^\top\mathbf k_j=\bar{\mathbf h}_t^\top(W^Q)^\top W^K\bar{\mathbf h}_j$。中间的 $(W^Q)^\top W^K$ 是一个学出来的 $d\times d$ 矩阵，所以“相关”的标准不是固定的几何相似，而是模型自己学的一种双线性打分。它一般不对称：$t$ 找 $j$ 的分数不等于 $j$ 找 $t$ 的分数（“我需要你”不等于“你需要我”）。而值用第三个矩阵 $W^V$，让“被找到的理由”和“交出去的内容”可以不同。

## 矩阵形式：一次算完整段

代码不会一个位置一个位置地算。把 $T$ 个位置的查询**按行**堆成 $Q\in\R^{T\times d_k}$（第 $t$ 行是 $\mathbf q_t^\top$），$K$、$V$ 同理，三步就变成三次矩阵运算：

::: eq 缩放点积注意力（矩阵形式） | (1.19)
$$\Attn(Q,K,V)=\softmax\!\Big(\frac{QK^\top}{\sqrt{d_k}}+M\Big)V,\qquad M_{tj}=\begin{cases}0,&j\le t\\-\infty,&j>t\end{cases}$$
形状：$[T,d_k]\times[d_k,T]\to[T,T]$；softmax 逐行；$[T,T]\times[T,d_k]\to[T,d_k]$。这是《Attention Is All You Need》的式 (1) 加上解码器的掩码 $M$ [@vaswani2017]。本课的 $M$ 只表示这个 $T\times T$ 的掩码矩阵；第 6 课沿用 DeepSeek LLM 的记号，那里的 $M$ 是每个 token 的非嵌入运算量，两者无关。
:::

$QK^\top$ 的第 $(t,j)$ 格正是 $\mathbf q_t^\top\mathbf k_j$（矩阵乘法的“批量点积”读法，[M01 §2](../math/m01-vectors-matrices.html#p2)）；加上 $M$ 之后，上三角变成 $-\infty$，$e^{-\infty}=0$，所以逐行 softmax 恰好只在 $j\le t$ 上归一化，与 (1.17) 一致；最后 $A V$ 的第 $t$ 行是 $\sum_j\alpha_{t,j}\mathbf v_j^\top$，正是 (1.18)。

::: fig figures/l01-attention-graph.svg | 图 1.6 缩放点积注意力（单头）：计算图与每一步的形状 | scroll
**看左边五个方框右侧的形状：前四步的输出都是 $[T,T]$ 的“位置对位置”表，最后一步乘 $V$ 才回到 $[T,64]$；这张表就是注意力“跨位置”的部分。** 左图据《Attention Is All You Need》图 2（左）重绘 [@vaswani2017]，原图自下而上，这里自上而下，并按 GPT-2 small 标出 $d_k=64$。右边三个 $8\times8$ 小表用随机数据示意 $S$、$S+M$ 与 $A$：红色格子是被掩掉的“未来”，蓝色深浅是权重。第一行只剩一个格子，所以第一个 token 的注意力权重必然全部落在它自己身上。
:::

## 手算一个例子

下面用 3 个 token、$d_k=2$ 的小例子把 (1.16)–(1.19) 完整走一遍。查询、键、值直接给出（真实模型里它们由 (1.3) 从隐藏状态算出，这里跳过那一步）。句子是 “The cat sat”。

| 位置 $t$ | token | 查询 $\mathbf q_t$ | 键 $\mathbf k_t$ | 值 $\mathbf v_t$ |
|---|---|---|---|---|
| 1 | The | $(1,\ 1)$ | $(0,\ 1)$ | $(1,\ 0)$ |
| 2 | cat | $(0,\ 2)$ | $(2,\ 0)$ | $(0,\ 1)$ |
| 3 | sat | $(2,\ 1)$ | $(1,\ 1)$ | $(1,\ 1)$ |

::: ex 五步手算：打分、缩放、掩码、softmax、加权和
**第 1 步：原始点积 $QK^\top$。** 第 $t$ 行第 $j$ 列是 $\mathbf q_t\cdot\mathbf k_j$。例如 $\mathbf q_3\cdot\mathbf k_2=2\times2+1\times0=4$。

$$QK^\top=\begin{pmatrix}1&2&2\\2&0&2\\1&4&3\end{pmatrix}$$

**第 2 步：除以 $\sqrt{d_k}=\sqrt2\approx1.4142$。**

$$S=\frac{QK^\top}{\sqrt2}=\begin{pmatrix}0.7071&1.4142&1.4142\\1.4142&0&1.4142\\0.7071&2.8284&2.1213\end{pmatrix}$$

**第 3 步：加掩码。** 上三角（$j>t$）换成 $-\infty$：第 1 行只留第 1 格，第 2 行留前 2 格，第 3 行全留。

$$S+M=\begin{pmatrix}0.7071&-\infty&-\infty\\1.4142&0&-\infty\\0.7071&2.8284&2.1213\end{pmatrix}$$

**第 4 步：逐行 softmax。** 先取指数（$e^{-\infty}=0$），再除以行和：

| 行 | $e^{s_{t,1}}$ | $e^{s_{t,2}}$ | $e^{s_{t,3}}$ | 行和 | 权重 $\alpha_{t,\cdot}$ |
|---|---|---|---|---|---|
| 1（The） | 2.0281 | 0 | 0 | 2.0281 | $(1,\ 0,\ 0)$ |
| 2（cat） | 4.1133 | 1.0000 | 0 | 5.1133 | $(0.8044,\ 0.1956,\ 0)$ |
| 3（sat） | 2.0281 | 16.9188 | 8.3421 | 27.2891 | $(0.0743,\ 0.6200,\ 0.3057)$ |

**第 5 步：加权平均 $\mathbf o_t=\sum_j\alpha_{t,j}\mathbf v_j$。**

- $\mathbf o_1=1\cdot(1,0)=(1,\ 0)$，原样取回自己的值。
- $\mathbf o_2=0.8044\,(1,0)+0.1956\,(0,1)=(0.8044,\ 0.1956)$。
- $\mathbf o_3=0.0743\,(1,0)+0.6200\,(0,1)+0.3057\,(1,1)=(0.3800,\ 0.9257)$。

**读结果。** sat 的查询与 cat 的键点积最大（4），于是 sat 把 62% 的注意力给了 cat，它的输出 $\mathbf o_3$ 主要由 $\mathbf v_2$ 构成。每一行的权重都加起来等于 1（例如 $0.0743+0.6200+0.3057=1$），可以用计算器核对。
:::

::: fig figures/l01-attention-example.svg | 图 1.7 手算例子的几何：打分是点积，输出是值向量的加权平均 | scroll
**看右图三个蓝圈：每个输出都落在它“看得见”的那些值向量围成的区域里。** 左图：$\mathbf k_3$ 的方向比 $\mathbf k_2$ 更接近 $\mathbf q_3$（夹角的余弦 0.949 对 0.894），但 $\mathbf k_2$ 更长，所以点积仍是它最大，这正是点积与余弦相似度的差别。右图：$\mathbf o_1$ 只能等于 $\mathbf v_1$；$\mathbf o_2$ 只看得见 $\mathbf v_1,\mathbf v_2$，只能落在两者的连线上；$\mathbf o_3$ 落在整个三角形内、靠近 $\mathbf v_2$ 一侧。所有坐标由生成脚本按上面的五步算出。
:::

两处对照可以帮你看清后面两节要讲的东西。其一，如果**不除以** $\sqrt2$，第 3 行的权重会是 $(0.0351,\ 0.7054,\ 0.2595)$，比 $(0.0743,\ 0.6200,\ 0.3057)$ 更尖：缩放在控制 softmax 的“温度”。其二，如果**不加掩码**，第 1 行的权重会是 $(0.1978,\ 0.4011,\ 0.4011)$：The 会从后面两个 token 那里拿走约 80% 的信息，而其中的 cat 正是它要预测的下一个词。下一页专门处理这两件事。

::: def 组件卡 · 缩放点积注意力（单头）
**含义**：每个位置用一个查询去和前面所有位置的键比对，按匹配度把它们的值加权平均，作为自己从上下文里取到的信息。

**数学意义**：$\mathbf o_t=\sum_{j\le t}\softmax_j(\mathbf q_t^\top\mathbf k_j/\sqrt{d_k})\,\mathbf v_j$，是值向量的凸组合，权重由一个学出来的双线性打分 $\bar{\mathbf h}_t^\top(W^Q)^\top W^K\bar{\mathbf h}_j$ 决定；矩阵形式 (1.19) 是三次矩阵运算。

**逻辑意义**：它是整个网络里唯一让不同位置交换信息的地方。没有它，每个 token 只能看见自己，模型退化成“只凭当前这一个词猜下一个词”；有了它，取哪些信息由内容决定，而不是由固定距离决定。
:::

::: warn 失败模式：平方的账单与“软”的检索
**账单随 $T^2$ 增长。** 每个头每层都要算一张 $T\times T$ 的表。GPT-2 small 在 $T=1024$ 时，一张表 $1{,}048{,}576$ 格，12 个头 × 12 层就是 $150{,}994{,}944$ 个分数，其中每张表严格上三角的 $1024\times1023/2=523{,}776$ 格（49.95%）会被掩码丢掉。上下文每长一倍，这个数乘 4。第 4 课、第 14 课都在和这笔账打交道。

**检索是“软”的。** softmax 的输出永远严格大于 0，注意力永远做不到“只取一个”；要近似做到，分数之间必须拉开很大的差距。反过来，当前缀很长、很多位置的分数差不多时，有用的信息会被大量无关位置稀释。这一点在 [§4](#p4) 讲缩放时还会出现。
:::

::: key 本页要点
- 注意力 = 内容寻址的加权平均：打分 $s_{t,j}=\mathbf q_t^\top\mathbf k_j/\sqrt{d_k}$，权重 $\alpha_{t,j}=\softmax_j(s_{t,j})$，输出 $\mathbf o_t=\sum_{j\le t}\alpha_{t,j}\mathbf v_j$。
- 查询、键、值由三个矩阵从同一个隐藏状态算出；打分是学出来的双线性形式，一般不对称。
- 输出是值向量的凸组合，介于“取一个”与“取平均”之间。矩阵形式 $\softmax(QK^\top/\sqrt{d_k}+M)V$，唯一的 $[T,T]$ 部分就是它的 $T^2$ 账单。
- 手算例子：sat 把 62% 的权重给了 cat，$\mathbf o_3=(0.3800,0.9257)$。
:::

# 注意力（二）：缩放、因果掩码与多头 | 为什么除以根号 d、掩码怎样让训练诚实、输出投影做什么 | 35

上一页的注意力还有三个没回答的“为什么”：为什么分数要除以 $\sqrt{d_k}$；为什么要把上三角换成 $-\infty$；为什么 GPT-2 用 12 个 64 维的头，而不是一个 768 维的头。三个问题的答案分别是：控制 softmax 的温度，让并行训练不作弊，让一个位置能同时按几种标准取信息。

## 为什么除以 $\sqrt{d_k}$

**问题。** 点积 $\mathbf q^\top\mathbf k=\sum_{i=1}^{d_k}q_ik_i$ 是 $d_k$ 项之和。项数越多，和的波动越大。GPT-2 small 每个头 $d_k=64$；如果分数的典型大小随 $d_k$ 增长，softmax 就会越来越尖，最后几乎把全部权重压在一个位置上。我们希望打分的尺度**不依赖**于头的维度这种架构上的任意选择。

先量一量点积会有多大。这需要两条关于方差的事实。

::: pre 独立随机变量的方差 | 熟悉“独立变量之和的方差等于方差之和”的可以跳过
**期望**（mean）$\E[X]$ 是随机变量 $X$ 的平均值；**方差**（variance）$\Var(X)=\E[X^2]-(\E[X])^2$ 量的是它偏离平均值的程度，标准差是方差的平方根。本节只用两条事实：

1. 若 $X,Y$ 独立，则 $\E[XY]=\E[X]\E[Y]$。
2. 若 $X_1,\dots,X_n$ 相互独立，则 $\Var(X_1+\cdots+X_n)=\Var(X_1)+\cdots+\Var(X_n)$：独立的波动不会互相抵消，也不会互相放大，只是方差相加。

所以 $n$ 个独立、方差为 1 的数相加，和的标准差是 $\sqrt n$，不是 $n$。推导与更多例子见 [M04 §3](../math/m04-probability.html#p3)（期望与方差的定义在 [M04 §2](../math/m04-probability.html#p2)）。
:::

**推导。** 《Attention Is All You Need》的脚注给出了下面这个估算，前提是一个明确的假设：$\mathbf q$ 与 $\mathbf k$ 的各分量是相互独立、均值为 0、方差为 1 的随机变量 [@vaswani2017]。

::: deriv 点积的均值与方差
$\E[\mathbf q^\top\mathbf k]=\sum_{i=1}^{d_k}\E[q_ik_i]=\sum_{i=1}^{d_k}\E[q_i]\,\E[k_i]=0$ || 期望的线性；$q_i$ 与 $k_i$ 独立；均值都是 0
$\Var(\mathbf q^\top\mathbf k)=\sum_{i=1}^{d_k}\Var(q_ik_i)$ || 全部 $2d_k$ 个分量相互独立，所以 $d_k$ 个乘积 $q_ik_i$ 也相互独立（各用一组互不重叠的分量），方差相加
$\Var(q_ik_i)=\E[q_i^2k_i^2]-\big(\E[q_ik_i]\big)^2=\E[q_i^2]\,\E[k_i^2]-0=1\cdot1$ || 方差的定义；$q_i^2,k_i^2$ 独立；$\E[q_i^2]=\Var(q_i)=1$
$\Var(\mathbf q^\top\mathbf k)=d_k$ || 把第 3 行代回第 2 行，$d_k$ 个 1 相加
$\Var\!\big(\mathbf q^\top\mathbf k/\sqrt{d_k}\big)=\frac{1}{d_k}\Var(\mathbf q^\top\mathbf k)=1$ || 常数 $c$ 乘随机变量，方差乘 $c^2$
:::

::: eq 缩放之后，分数的方差回到 1 | (1.20)
$$\Var\big(\mathbf q^\top\mathbf k\big)=d_k,\qquad\Var\Big(\frac{\mathbf q^\top\mathbf k}{\sqrt{d_k}}\Big)=1$$
前提：$\mathbf q,\mathbf k$ 的分量相互独立、均值 0、方差 1。$d_k=64$ 时，不缩放的分数标准差是 8；$d_k=128$ 时是 $\sqrt{128}\approx11.31$。
:::

::: ex 用随机数验证
在 Python 里生成 200,000 对 64 维向量，每个分量独立地取自标准正态分布，算出它们的点积：样本方差是 63.77（理论 64），标准差 7.985（理论 8）；除以 8 之后方差是 0.996。图 1.8 (a) 画的就是这两组数的分布。
:::

**这为什么要紧：softmax 的温度。** 把分数除以 $\sqrt{d_k}$，等于把 softmax 的温度固定在“分数标准差约为 1”的地方。反过来，不缩放就等于用温度 $\tau=1/\sqrt{d_k}$ 做 softmax，头越宽，分布越尖。下表用一组固定的分数 $\mathbf z=(2,\ 1,\ 0.1)$ 看温度的效果，最后一行相当于 $d_k=64$ 不缩放时把分数放大 8 倍：

| 温度 $\tau$ | $\softmax(\mathbf z/\tau)$ |
|---|---|
| 2 | $(0.5017,\ 0.3043,\ 0.1940)$ |
| 1 | $(0.6590,\ 0.2424,\ 0.0986)$ |
| 0.5 | $(0.8638,\ 0.1169,\ 0.0193)$ |
| 0.25 | $(0.9815,\ 0.0180,\ 0.0005)$ |
| 1/8（放大 8 倍） | $(0.9997,\ 0.0003,\ 0.0000)$ |

::: fig figures/l01-scaling.svg | 图 1.8 为什么除以 $\sqrt{d_k}$：点积的尺度随维度增长，softmax 随之饱和 | scroll
**看右图曲线从左下到右上的爬升：分数的标准差从 1 变成 8，512 个位置里最大的那个权重平均从 0.027 涨到约 0.73。** (a) 在原论文脚注的假设下（分量独立、均值 0、方差 1），$d_k=64$ 的点积标准差约为 8，除以 $\sqrt{64}=8$ 后回到 1；直方图由 200,000 对随机向量算出。(b) 把 512 个独立的 $\mathcal N(0,s^2)$ 分数送进 softmax，取最大权重、对 2,000 次抽样求平均；$s=8$ 正是 $d_k=64$ 而不缩放的情形。两组数据都由生成脚本计算。
:::

::: pre 导数、雅可比矩阵与链式法则 | 熟悉多元微积分的可以跳过
**导数**量的是“输入动一点，输出跟着动多少”：$f'(x)\approx\big(f(x+h)-f(x)\big)/h$，$h$ 很小。输入和输出都是向量时，要回答的是“第 $j$ 个输入动一点，第 $i$ 个输出动多少”，这些数排成一个矩阵，叫**雅可比矩阵**（Jacobian）：若 $\mathbf y=f(\mathbf x)$，$\mathbf x\in\R^{n}$，$\mathbf y\in\R^{m}$，则 $J\in\R^{m\times n}$，$J_{ij}=\partial y_i/\partial x_j$。两个马上要用的例子：线性映射 $\mathbf y=W\mathbf x$ 的雅可比就是 $W$ 本身；逐元素函数 $y_i=g(x_i)$ 的雅可比是对角矩阵 $\diag\big(g'(x_1),\dots,g'(x_n)\big)$。

**链式法则**：几步串起来的函数 $\mathbf z=g(f(\mathbf x))$，它的雅可比是各步雅可比的乘积 $J_{g\circ f}=J_g\,J_f$（后一步写在左边）。反向传播就是从损失出发，把这些矩阵从后往前一路乘回来：只要途中有一个因子是零矩阵，梯度就传不到更前面的参数。详见 [M06 §3](../math/m06-calculus-backprop.html#p3)；softmax 的雅可比在 [M06 §5](../math/m06-calculus-backprop.html#p5) 有更完整的推导。
:::

**饱和为什么伤害训练。** softmax 对输入的导数（雅可比矩阵）是

::: deriv softmax 的导数
$\dfrac{\partial p_i}{\partial z_j}=\dfrac{\partial}{\partial z_j}\dfrac{e^{z_i}}{\sum_ke^{z_k}}=\dfrac{\delta_{ij}e^{z_i}\sum_ke^{z_k}-e^{z_i}e^{z_j}}{\big(\sum_ke^{z_k}\big)^2}$ || 商的求导法则；$\delta_{ij}$ 在 $i=j$ 时为 1、否则为 0
$=p_i\,\delta_{ij}-p_ip_j=p_i(\delta_{ij}-p_j)$ || 用 $p_i=e^{z_i}/\sum_ke^{z_k}$ 化简
$p=(1,0,\dots,0)\ \Rightarrow\ \dfrac{\partial p_i}{\partial z_j}=0\ \text{对所有 }i,j$ || $i=1$ 时 $\delta_{1j}-p_j=0$；$i\ne1$ 时 $p_i=0$。有限的 $\mathbf z$ 给出的 $p_i$ 都严格大于 0，所以这是 $z_1-\max_{j\ne1}z_j\to\infty$ 时的极限
:::

也就是说，当 softmax 的输出变成独热分布时，它对**所有**分数的导数都是 0，梯度传不回 $\mathbf q$ 和 $\mathbf k$，这个头的打分方式就学不动了。原论文 v2 的正文说，点积变大会把 softmax 推进“梯度极小”的区域，并用上面那个方差估算作为脚注解释 [@vaswani2017]。

::: warn 三处需要诚实的地方
**这是一个估算，不是证明缩放最优。** 脚注只算了一个方差，而且依赖“分量独立、单位方差”的假设；训练开始之后，$\mathbf q,\mathbf k$ 的分量既不独立、方差也不是 1。论文自己用的词是“我们猜测”（We suspect）。它解释了“为什么点积会大”，没有证明“除以 $\sqrt{d_k}$ 是最好的做法”。

**方差论证是后来加的。** 2017 年 6 月 12 日的 v1 只有一句“点积可能过大、梯度变得无用”的猜测；方差估算是一周后的 v2 才加入的脚注，在 PDF 里编号为 4（arXiv 网页版显示为 1）[@vaswani2017]。

**“梯度变小”要分清说的是什么。** 严格为 0 只发生在完全独热的极限。沿用图 1.8 (b) 的设定（512 个独立的 $\mathcal N(0,s^2)$ 分数，$s$ 是分数的标准差），在 $s=8$ 的中等饱和情形下，雅可比矩阵的整体大小（Frobenius 范数，即全部元素的平方和再开方）反而比 $s=1$ 时大（笔者用 20,000 组随机分数估计：平均约 0.24 对 0.071）；接近 0 的是流向**非最大**位置的梯度。更准确的说法是：不缩放时，softmax 的温度被头的维度这个无关的选择绑架，维度越大越容易饱和。
:::

**实验上的动机。** 原论文还提到，另有研究发现 $d_k$ 较小时点积注意力与加性注意力表现相近，$d_k$ 较大时加性注意力胜过**不缩放**的点积注意力，这是他们引入缩放的实验依据 [@vaswani2017]。

**这是一个选择，还有别的选法。** 除以 $\sqrt{d_k}$ 与把 $W^Q$（连同偏置 $\mathbf b^Q$）的初始值缩小 $\sqrt{d_k}$ 倍在初始化时的前向计算上是等价的（$\mathbf q/\sqrt{d_k}=(W^Q/\sqrt{d_k})\bar{\mathbf h}+\mathbf b^Q/\sqrt{d_k}$）。区别在训练中：固定的 $1/\sqrt{d_k}$ 一直都在，缩小的初始值却会被梯度更新改掉；而且固定因子也把流到 $W^Q$ 的梯度缩小了 $\sqrt{d_k}$ 倍（对一个位置，$\partial\mathcal L/\partial W^Q=\mathbf g\,\bar{\mathbf h}^\top/\sqrt{d_k}$，其中 $\mathbf g\in\R^{d_k}$ 是损失对缩放后查询 $\mathbf q/\sqrt{d_k}$ 的梯度，形状 $[d_k,1]\times[1,d]=[d_k,d]$，与 $W^Q$ 同形），所以同样的学习率下，两种写法每一步对分数的改动并不一样。GPT-2 的代码采用固定的缩放：`w = w * tf.rsqrt(v.shape[-1])`，也就是乘以 $1/\sqrt{64}=1/8$ [@gpt2code]。

## 因果掩码：让并行训练诚实

**问题。** [§1](#p1) 的例子说，一次前向传播对 4 个 token 给出了 4 个预测。训练时，我们正是要让每个位置的预测去对准下一个真实的 token：位置 1 的预测对准 `Ġunbelievable`，位置 2 对准 `Ġtoken`，依此类推（第 2 课会把这写成交叉熵损失）。可是，这 4 个 token 是**同时**喂进去的。如果位置 1 的注意力能看到位置 2，它只要把位置 2 的输入“抄”过来，就能完美地“预测”位置 2：损失降得飞快，模型却什么都没学会。到了真正生成的时候，位置 2 还不存在，这种“能力”一点用也没有。

**含义。** **因果掩码**（causal mask）是一个加在打分表上的 $T\times T$ 矩阵：允许看的格子（$j\le t$）加 0，不允许看的格子（$j>t$）加 $-\infty$。原论文的说法是在 softmax 的输入里把“非法连接”置为 $-\infty$ [@vaswani2017]。

**数学。** 就是 (1.19) 里的 $M$。它起作用的关键在于：$-\infty$ 是加在 softmax **之前**的。

::: deriv 掩码之后的 softmax 恰好只在前缀上归一化
$\softmax(S_{t,:}+M_{t,:})_j=\dfrac{e^{S_{tj}+M_{tj}}}{\sum_{k=1}^{T}e^{S_{tk}+M_{tk}}}$ || softmax 的定义；$S=QK^\top/\sqrt{d_k}$，$S_{t,:}$、$M_{t,:}$ 是 $S$、$M$ 的第 $t$ 行
$e^{S_{tk}+M_{tk}}=e^{S_{tk}}\ (k\le t),\qquad e^{S_{tk}+M_{tk}}=e^{-\infty}=0\ (k>t)$ || $M_{tk}=0$ 或 $-\infty$
$\softmax(S_{t,:}+M_{t,:})_j=\dfrac{e^{S_{tj}}}{\sum_{k=1}^{t}e^{S_{tk}}}\ (j\le t),\qquad =0\ (j>t)$ || 分子、分母里 $k>t$ 的项都消失；$S_{tj}=s_{t,j}$，正是 (1.17)
:::

如果反过来先做 softmax、再把上三角的权重清零，每行的权重就加不到 1 了，还得再归一化一次。先加 $-\infty$ 一步到位。GPT-2 的代码没有用真正的 $-\infty$，而是减去 $10^{10}$：`w = w*b - 1e10*(1-b)` [@gpt2code]；$e^{-10^{10}}$ 在浮点数里就是 0，效果相同。

::: fig figures/l01-mask.svg | 图 1.9 因果掩码：一次前向传播给出 T 个只看过去的预测 | scroll
**看右表每一行的最右一列：第 $t$ 行要预测的正是第 $t+1$ 个输入。** 左表是一组示意分数（为讲解而设，不是真实模型的输出），加掩码后逐行 softmax 得到右表，每行权重和为 1。底部红字：如果不加掩码，第 1 行会把约 78% 的权重分给“未来”的三个位置，其中 0.132 来自它要预测的答案本身。行标签是“The unbelievable tokenization”的 GPT-2 分词结果。
:::

**因果掩码保证了什么？** 下面证明一个比“注意力不看未来”更强的结论：**整个网络**在位置 $t$ 的每一个中间结果，都只依赖 $x_1,\dots,x_t$。记号 $f(x_1,\dots,x_t)$ 表示“某个只以 $x_1,\dots,x_t$ 为自变量的函数”，不同的行里 $f$ 可以不同。

::: deriv 位置 $t$ 的状态只依赖前缀 $x_1,\dots,x_t$（对层数归纳）
$\mathbf h^{(0)}_t=E^\top\mathbf e_{x_t}+P^\top\mathbf e_t=f(x_t)$ || 起点：(1.1) 逐位置查表
$\mathbf h^{(l-1)}_j=f(x_1,\dots,x_j)\quad\text{对所有 }j$ || 归纳假设
$\bar{\mathbf h}_j,\ \mathbf q_{j,i},\ \mathbf k_{j,i},\ \mathbf v_{j,i}=f(x_1,\dots,x_j)$ || (1.2)(1.3) 逐位置
$\mathbf o_{t,i}=\sum_{j\le t}\alpha_{t,j,i}\,\mathbf v_{j,i}=f(x_1,\dots,x_t)$ || 掩码：只剩 $j\le t$
$\mathbf h^{(l)}_t=\mathbf h^{(l-1)}_t+\mathbf u_t+\mathbf m_t=f(x_1,\dots,x_t)$ || (1.6)–(1.9) 逐位置
$p_\theta(x_{t+1}\mid x_{\le t})=\softmax\big(E\,\LayerNorm_f(\mathbf h^{(L)}_t)\big)=f(x_1,\dots,x_t)$ || 归纳到 $l=L$
:::

整个链条里只有第 4 行用到了别的位置，而掩码恰好在这里把 $j>t$ 的权重变成 0；剩下的 $j\le t$ 满足 $x_{\le j}\subseteq x_{\le t}$，所以不会引入 $x_{t+1}$ 及以后的任何信息。其余各行都是逐位置运算，本来就不会把别的位置混进来。


这个结论有两个后果，分别属于第 2 课和第 4 课。

1. **训练是诚实的，而且是并行的。** 一次前向传播给出 $T$ 个预测，第 $t$ 个预测在数学上**就是**只读了前 $t$ 个 token 时模型会给出的预测。于是一段 1024 个 token 的训练文本一次提供 1024 个合法的训练信号，不必像循环网络那样一步一步地展开。这就是 [§1](#p1) 第 4 个要求的答案。
2. **旧位置的结果永远不变。** 在序列末尾追加新 token，不会改变任何旧位置的 $\mathbf k_{j,i}$、$\mathbf v_{j,i}$。所以生成时可以把它们存起来反复使用，这就是第 4 课的 **KV cache**，而且它是**精确的**优化，不是近似。GPT-2 的官方代码里已经有这个缓存，形状为 `[batch, n_layer, 2, n_head, sequence, n_embd // n_head]` [@gpt2code]。

::: def 组件卡 · 因果掩码
**含义**：打分表上三角加 $-\infty$，让每个位置只能看见自己和前面的位置。

**数学意义**：$\softmax(S+M)$ 的第 $t$ 行恰好是只在 $j\le t$ 上归一化的 softmax；配合逐位置运算，整张网络在位置 $t$ 的输出只依赖 $x_1,\dots,x_t$（归纳证明）。

**逻辑意义**：它让“一次前向算出 $T$ 个预测”的并行训练不作弊，也让生成时缓存旧位置的键和值成为精确的做法。没有它，训练损失会被“抄答案”压低，而模型在真正生成时一无所能。
:::

## 多头注意力：同时按几种标准取信息

**问题。** 一个头只有一套 softmax 权重，也就是说，位置 $t$ 在一个头里只能按**一种**标准给前文分配注意力。可一个词往往同时需要几种信息：预测 sat 之后的词，既要知道主语是谁（cat），也要知道紧挨着的前一个词、时态、句子结构……一套权重只能在这些需求之间妥协，结果是把几种信息平均成一团。原论文的说法是：只用一个头时，“平均”会妨碍模型同时关注不同表示子空间里、不同位置上的信息 [@vaswani2017]。

**含义。** **多头注意力**（multi-head attention）把一个宽的注意力拆成 $n_h$ 个窄的头，每个头有自己的 $W^Q_i,W^K_i,W^V_i$，各自独立地打分、softmax、加权平均，最后把 $n_h$ 个结果拼起来，再乘一个输出矩阵 $W^O$。

**数学。** 这就是方程组的 (1.3)–(1.6)。GPT-2 small 取 $n_h=12$、$d_h=d/n_h=64$：

::: eq 多头注意力 | (1.21)
$$\mathbf o_{t,i}=\sum_{j\le t}\softmax_j\!\Big(\frac{\mathbf q_{t,i}^\top\mathbf k_{j,i}}{\sqrt{d_h}}\Big)\mathbf v_{j,i},\qquad \mathbf u_t=W^O\begin{pmatrix}\mathbf o_{t,1}\\\vdots\\\mathbf o_{t,n_h}\end{pmatrix}+\mathbf b^O$$
$\mathbf q_{t,i},\mathbf k_{t,i},\mathbf v_{t,i},\mathbf o_{t,i}\in\R^{d_h}$；$W^O\in\R^{d\times n_hd_h}$；$i=1,\dots,n_h$ 是头的编号。
:::

**拆头不花任何计算。** 把 12 个头的 $W^Q_i$ 按行叠起来，就是一个 $768\times768$ 的大矩阵 $W^Q$；大矩阵乘 $\bar{\mathbf h}_t$ 得到的 768 维向量，按顺序每 64 个数切一段，第 $i$ 段就是 $\mathbf q_{t,i}$（分块乘法，[M01 §4](../math/m01-vectors-matrices.html#p4)）。所以代码先用一次大乘法算出全部查询，再 reshape 成 $[12,T,64]$。GPT-2 更进一步，把 $W^Q,W^K,W^V$ 拼成一个 `c_attn`，一次乘完再切成三份 [@gpt2code]；按本课的列写法它是 $2304\times768$，代码按行写法转置存放，形状是 $[768,2304]$（[§1](#p1) 的“代码里的两处约定”）。

**合头：$W^O$ 在做什么。** 把 $W^O$ 按列切成 12 块 $W^O_i\in\R^{d\times d_h}$，分块乘法给出：

::: deriv 拼接再乘 $W^O$ = 每个头各写一份、再相加
$W^O\big[\mathbf o_{t,1};\dots;\mathbf o_{t,n_h}\big]=\big[W^O_1\ \cdots\ W^O_{n_h}\big]\begin{pmatrix}\mathbf o_{t,1}\\\vdots\\\mathbf o_{t,n_h}\end{pmatrix}$ || 把 $W^O$ 按列分成 $n_h$ 块，每块 $d_h$ 列
$=\sum_{i=1}^{n_h}W^O_i\,\mathbf o_{t,i}$ || 分块乘法：内侧维度被切开时，结果是各块乘积之和
:::

::: eq $W^O$ 的另一种读法 | (1.22)
$$\mathbf u_t=\sum_{i=1}^{n_h}W^O_i\,\mathbf o_{t,i}+\mathbf b^O,\qquad W^O_i\in\R^{d\times d_h}$$
每个头用自己的“写入矩阵” $W^O_i$ 把 64 维的结果映射回 768 维，12 份相加。Elhage 等人指出，“拼接再乘”与“各头独立相加”在数学上等价 [@elhage2021]。
:::

(1.22) 回答了“$W^O$ 做什么”。第一，它把每个头的 64 维结果**放回** 768 维的残差流：没有它，12 个头的输出只能拼成 768 维，第 $i$ 个头永远只能写第 $64(i-1)+1$ 到 $64i$ 这 64 个坐标，而下一层想从哪些方向读取信息，是由下一层自己的 $W^Q,W^K,W^V$ 决定的，不一定是这 64 个坐标。第二，它让头与头的结果**混合**：残差流上的同一个方向可以同时接收好几个头的贡献。

**“多个子空间”是什么意思。** 第 $i$ 个头的打分（忽略偏置）是 $\bar{\mathbf h}_t^\top(W^Q_i)^\top W^K_i\bar{\mathbf h}_j$，中间的 $768\times768$ 矩阵是一个 $[768,64]$ 与一个 $[64,768]$ 相乘，秩至多是 64。几何上，这个头只通过一个 64 维的“窗口”比较两个 768 维的状态，窗口之外的方向它看不见（[M01 §6](../math/m01-vectors-matrices.html#p6)）。12 个头有 12 个不同的窗口，所以位置 $t$ 能同时按 12 种标准挑选前文。

::: ex 两个头的手算：同一个位置，两套权重
回到 [§3](#p3) 的 “The cat sat”（$d=2$）。把它拆成 $n_h=2$ 个头、每头 $d_h=1$：头 1 只用查询、键、值的第 1 个坐标，头 2 只用第 2 个坐标。这相当于取 $W^Q_1=W^K_1=W^V_1=(1\ \ 0)$、$W^Q_2=W^K_2=W^V_2=(0\ \ 1)$，都是 $1\times2$ 的矩阵，正是“按行切块”。只看第 3 行（sat），缩放因子 $\sqrt{d_h}=1$。

- **头 1**：查询 $2$，三个键 $(0,\ 2,\ 1)$，分数 $(0,\ 4,\ 2)$；指数 $(1,\ 54.598,\ 7.389)$，和 62.987；权重 $(0.0159,\ 0.8668,\ 0.1173)$。三个值 $(1,\ 0,\ 1)$，输出 $o_{3,1}=0.0159+0.1173=0.1332$。
- **头 2**：查询 $1$，三个键 $(1,\ 0,\ 1)$，分数 $(1,\ 0,\ 1)$；指数 $(2.7183,\ 1,\ 2.7183)$，和 6.4366；权重 $(0.4223,\ 0.1554,\ 0.4223)$。三个值 $(0,\ 1,\ 1)$，输出 $o_{3,2}=0.1554+0.4223=0.5777$。

同一个位置，头 1 把 87% 的权重给了 cat，头 2 只给 cat 16%，把其余权重平分给 The 和 sat 自己。单头时（[§3](#p3)）只有一套折中的权重 $(0.0743,\ 0.6200,\ 0.3057)$。

**合头。** 拼接得 $(0.1332,\ 0.5777)$。取 $W^O=\begin{pmatrix}1&0.5\\-1&1\end{pmatrix}$，按 (1.22) 读：头 1 经第 1 列 $W^O_1=(1,-1)^\top$ 写入 $0.1332\,(1,-1)$，头 2 经第 2 列 $W^O_2=(0.5,\ 1)^\top$ 写入 $0.5777\,(0.5,\ 1)$，相加得 $\mathbf u_3=(0.4220,\ 0.4445)$（忽略偏置），和直接计算 $W^O(0.1332,\ 0.5777)^\top$ 的结果一样。如果 $W^O=I$，头 1 只能写第 1 个坐标、头 2 只能写第 2 个；换成一般的 $W^O$，两个头都能写到两个坐标上，这就是上面说的“放回”与“混合”。
:::

::: fig figures/l01-multihead.svg | 图 1.10 多头注意力：拆头、各自 softmax、经 $W^O$ 合头 | scroll
**看 (b) 的四组柱子：同一个位置 $t=8$，不同的头把权重分给了完全不同的位置。** (a) 768 维的查询按顺序切成 12 段，不做任何运算。(b) 四个头的权重分布是示意（由脚本从固定的分数算出），用来说明“12 套独立的 softmax”；真实模型中各个头学到什么，要看具体模型。(c) 拼接 12 个头的输出再乘 $W^O$，等于每个头经自己那一个列块 $W^O_i$（绿色）写回 768 维后相加 [@elhage2021]。
:::

**多个小头不比一个大头贵。** 一个 768 维的大头，打分要 $2T^2d$ 次运算；12 个 64 维的小头各 $2T^2d_h$，合计 $12\times2T^2\times64=2T^2\times768$，一样多（[M01 §4](../math/m01-vectors-matrices.html#p4)）。原论文也说，由于每个头的维度变小了，多头的总计算量与全维度的单头相近 [@vaswani2017]。多出来的只是 $n_h$ 次 softmax，而 softmax 相对于矩阵乘法可以忽略。

::: ex 头数的实测效果与 GPT-2 的参数账
**原论文的消融实验**（机器翻译，表 3 的 (A) 行，保持总计算量不变）[@vaswani2017]：基线是 8 个头、每头 64 维，BLEU 25.8、困惑度 4.92。改成 1 个 512 维的头，BLEU 降到 24.9（低 0.9），困惑度升到 5.29；16 个头与 8 个头持平；32 个头、每头只有 16 维时，BLEU 又降到 25.4。头太少，一个位置只能按一种标准取信息；头太多，每个头的窗口太窄。

**GPT-2 small 一层注意力的参数。** 融合的 `c_attn`：$768\times2304+2304=1{,}771{,}776$；输出投影 $W^O$ 加偏置：$768\times768+768=590{,}592$；合计 $2{,}362{,}368$，其中偏置只占 3,072 个。忽略偏置就是 $4d^2=4\times768^2=2{,}359{,}296$，[§8](#p8) 会用到这个 $4d^2$。
:::

::: def 组件卡 · 多头与 $W^O$
**含义**：把注意力拆成 12 个 64 维的头，各自独立地选择看哪里，再由 $W^O$ 把 12 份结果合起来写回残差流。

**数学意义**：拆头是对 $W^Q,W^K,W^V$ 按行分块（不花运算）；每个头的打分是一个秩至多为 $d_h$ 的双线性形式；合头 $W^O[\mathbf o_{t,1};\dots;\mathbf o_{t,n_h}]=\sum_iW^O_i\mathbf o_{t,i}$。

**逻辑意义**：一个 softmax 只能给出一种权重分配，多头让一个位置同时按多种标准取信息，而总运算量不变。$W^O$ 让每个头的结果能写到残差流的任意方向上，并与其他头的结果叠加。
:::

::: key 本页要点
- 在“分量独立、均值 0、方差 1”的假设下 $\Var(\mathbf q^\top\mathbf k)=d_k$，除以 $\sqrt{d_k}$ 让分数方差回到 1，等于把 softmax 的温度固定下来；这是一个估算和一个选择，不是最优性证明。
- 因果掩码在 softmax 之前加 $-\infty$；配合逐位置运算，位置 $t$ 的一切结果只依赖 $x_1,\dots,x_t$。于是并行训练诚实，旧位置的 K、V 可以精确缓存（第 4 课）。
- 多头 = 12 套独立的 softmax，总运算量与单头相同；$\mathbf u_t=\sum_iW^O_i\mathbf o_{t,i}$，每个头经自己的 $W^O_i$ 写回残差流。GPT-2 small 一层注意力 2,362,368 个参数 $\approx4d^2$。
:::

# 前馈网络：每个位置自己的键值记忆 | 4 倍宽的两层网络、GELU 与“键值记忆”的读法 | 25

注意力负责在位置之间搬运信息。这一页讲块里的另一个子层：**前馈网络**（feed-forward network，FFN），方程 (1.8)。它不跨位置，却占了每个块三分之二的参数。

## 问题：注意力只会“搬运”，不会“加工”

先看注意力在做什么样的运算。把权重 $\alpha_{t,j}$ 看作已经算好，输出 $\mathbf o_t=\sum_j\alpha_{t,j}\mathbf v_j=\sum_j\alpha_{t,j}(W^V\bar{\mathbf h}_j+\mathbf b^V)$ 对各位置的隐藏状态是**线性**的，再乘 $W^O$ 也还是线性的。注意力唯一的非线性藏在权重的 softmax 里，它决定“从哪里搬”，而搬过来的内容只经过了线性变换。

线性变换再怎么叠也还是线性变换：两个矩阵相乘仍是一个矩阵（[M01 §2](../math/m01-vectors-matrices.html#p2)）。如果网络里只有注意力，每个位置能表达的“加工”方式非常有限。我们需要在每个位置上再放一个有足够容量的**非线性**函数，把搬来的信息和自己原有的信息组合、变换成新的特征。

## 形式化：两层、4 倍宽、逐位置

**含义。** FFN 是一个两层的全连接网络：先把 768 维升到 3072 维，过一个非线性函数，再降回 768 维。

**理解。** 它对每个位置单独、用同一套参数计算，位置之间互不相干，所以叫“逐位置”（position-wise）的前馈网络 [@vaswani2017]。可以把它想成传送带旁的一个加工工位：每个 token 路过时被同一台机器加工一次。

**数学。**

::: eq 前馈网络 | (1.23)
$$\FFN(\mathbf x)=W_2\,\mathrm{GELU}(W_1\mathbf x+\mathbf b_1)+\mathbf b_2,\qquad W_1\in\R^{d_{ff}\times d},\ \ W_2\in\R^{d\times d_{ff}},\ \ d_{ff}=4d$$
GPT-2 small：$768\to3072\to768$。原 Transformer 用 ReLU $\max(0,x)$，GPT 系列换成 GELU [@vaswani2017; @radford2018]。
:::

参数量：$W_1$ 与 $\mathbf b_1$ 共 $768\times3072+3072=2{,}362{,}368$，$W_2$ 与 $\mathbf b_2$ 共 $3072\times768+768=2{,}360{,}064$，合计 $4{,}722{,}432=8d^2+5d$。注意力一层是 $4d^2+4d$（[§4](#p4)），所以 FFN 占了两个子层权重的 $8/12=2/3$。Geva 等人的论文开篇第一句说的就是这件事：前馈层占了 Transformer 参数的三分之二 [@geva2021]。

**为什么偏偏是 4 倍？** 这是惯例，不是推论。原论文只给了数值 $d_{ff}=2048=4\times512$，没有解释 [@vaswani2017]；它的表 3 (C) 行改过这个数：$d_{ff}=1024$ 时困惑度 5.12、BLEU 25.4，$4096$ 时 4.75、26.2（基线 2048 是 4.92、25.8），越宽越好，但参数也越多。GPT-3 的论文说它“总是”让前馈层是瓶颈层的四倍宽 [@brown2020]。第 5 课会看到，换成 SwiGLU 之后常用的 $\tfrac83d$ 也是在“保持参数量不变”这个约束下从 4 倍推出来的。

## 键值记忆：换一种读法

把 (1.23) 的两个矩阵按行、按列拆开，FFN 就能读成一张“键–值”表，和上一页的注意力摆在一起比较。记 $W_1$ 的第 $m$ 行为 $\mathbf k_m^\top$（$\mathbf k_m\in\R^{d}$），$W_2$ 的第 $m$ 列为 $\mathbf v_m\in\R^{d}$，$m=1,\dots,d_{ff}$：

::: deriv 把 FFN 写成 3072 条“键–值”的加权和
$W_1\mathbf x+\mathbf b_1=\big(\mathbf k_1^\top\mathbf x+b_{1,1},\ \dots,\ \mathbf k_{d_{ff}}^\top\mathbf x+b_{1,d_{ff}}\big)^\top$ || 矩阵乘向量的“批量点积”读法：每一行与 $\mathbf x$ 做点积
$c_m:=\mathrm{GELU}\big(\mathbf k_m^\top\mathbf x+b_{1,m}\big),\qquad m=1,\dots,d_{ff}$ || GELU 逐元素作用，得到 $d_{ff}$ 个系数
$W_2\,\mathbf c=\sum_{m=1}^{d_{ff}}c_m\,\mathbf v_m$ || 矩阵乘向量的“列的加权和”读法（[M01 §2](../math/m01-vectors-matrices.html#p2)）
$\FFN(\mathbf x)=\sum_{m=1}^{d_{ff}}\mathrm{GELU}\big(\mathbf k_m^\top\mathbf x+b_{1,m}\big)\,\mathbf v_m+\mathbf b_2$ || 合起来
:::

::: eq FFN 的键值记忆读法 | (1.24)
$$\FFN(\mathbf x)=\sum_{m=1}^{d_{ff}}\underbrace{\mathrm{GELU}\big(\mathbf k_m^\top\mathbf x+b_{1,m}\big)}_{\text{第 }m\text{ 条记忆被“唤起”的程度}}\ \mathbf v_m+\mathbf b_2$$
Geva 等人的式 (1) 写作 $\mathrm{FF}(\mathbf x)=f(\mathbf x\cdot K^\top)\cdot V$（行向量写法，忽略偏置），并把它与记忆网络 $\mathrm{softmax}(\mathbf x\cdot K^\top)\cdot V$ 对照：两者只差非线性是否归一化 [@geva2021]。
:::

读成文字就是：FFN 里存着 $d_{ff}=3072$ 条“记忆”，每条由一个键 $\mathbf k_m$ 和一个值 $\mathbf v_m$ 组成；输入 $\mathbf x$ 与每个键比一比（点积），GELU 把比对结果变成“这条记忆被唤起多少”，最后把被唤起的值按程度加起来。这和注意力是同一个骨架（比对键 → 算权重 → 加权求和值），区别只在键值从哪里来、权重怎么算：

| | 注意力 | FFN |
|---|---|---|
| 键、值从哪来 | 由上下文里的其他 token 现算：$\mathbf k_j=W^K\bar{\mathbf h}_j$ | 训练好的参数本身：$W_1$ 的行、$W_2$ 的列 |
| 有多少条 | $t$ 条（随上下文变长） | 固定 3072 条 |
| 权重 | softmax：非负、和为 1、彼此竞争 | GELU：各自独立，可正可略负，不必和为 1 |
| 在做什么 | 从**这段话**里按内容取信息 | 从**训练数据沉淀下来的知识**里按内容取信息 |

::: ex 一个 3 条记忆的 FFN
取 $d=2$、$d_{ff}=3$，偏置都为 0。三个键 $\mathbf k_1=(1,0)$、$\mathbf k_2=(0,1)$、$\mathbf k_3=(-1,-1)$；三个值 $\mathbf v_1=(1,1)$、$\mathbf v_2=(-1,2)$、$\mathbf v_3=(3,0)$。输入 $\mathbf x=(1.5,\ 0.5)$。

- 比对：$\mathbf k_1^\top\mathbf x=1.5$，$\mathbf k_2^\top\mathbf x=0.5$，$\mathbf k_3^\top\mathbf x=-2$。
- 唤起程度：$\mathrm{GELU}(1.5)=1.5\,\Phi(1.5)=1.5\times0.93319=1.39979$；$\mathrm{GELU}(0.5)=0.5\times0.69146=0.34573$；$\mathrm{GELU}(-2)=-2\times0.02275=-0.04550$。
- 输出：$1.39979\,(1,1)+0.34573\,(-1,2)-0.04550\,(3,0)=(0.91756,\ 2.09125)$。

第 1 条记忆被强烈唤起，第 2 条中等，第 3 条的键与输入方向相反，几乎没被唤起（只“漏”出一点负值）。换成 ReLU，第 3 条的系数会恰好是 0。
:::

**这个读法有实证支持，但它是一种解释框架。** Geva 等人在一个 16 层、$d=1024$、$d_{ff}=4096$ 的语言模型（共 65,536 个键）上做了分析：许多键与训练文本中可以辨认的模式相关，值则在输出词表上诱导出一个分布；低层（第 1–9 层）的键更多对应浅层的模式（如重复出现的 n-gram、以同一个词结尾的前缀），高层（第 10–16 层）的键更多对应语义层面的模式（如同一个话题）[@geva2021]。这些是**实测**结论，针对的是他们分析的那个模型；它说明 (1.24) 这个读法有用，并不意味着每个神经元都有一个人类能读懂的含义。第 17 课的 Engram 会把“用查表存知识”这个想法推得更远。

## GELU：按大小加权，而不是按正负一刀切

**含义。** **GELU**（Gaussian error linear unit，高斯误差线性单元）定义为 $\mathrm{GELU}(x)=x\,\Phi(x)$，其中 $\Phi$ 是标准正态分布的累积分布函数（$\Phi(x)$ = 一个标准正态随机变量小于 $x$ 的概率）[@hendrycks2016]。

**理解。** ReLU 按**符号**决定去留：$x>0$ 就原样通过，否则变成 0，像一扇只有开和关的门。GELU 按**大小**给权重：把 $x$ 乘上一个介于 0 和 1 之间的“通过概率” $\Phi(x)$。$x$ 很大时 $\Phi(x)\approx1$，几乎原样通过；$x$ 很负时 $\Phi(x)\approx0$，几乎被关掉；在 0 附近则是平滑过渡。原论文的说法是：它按输入的值加权，而不是按输入的符号门控 [@hendrycks2016]。

**数学。** 见方程组 (1.13)。几个可以用计算器核对的值：$\mathrm{GELU}(1)=0.84134$，$\mathrm{GELU}(-1)=-0.15866$，$\mathrm{GELU}(2)=1.95450$，$\mathrm{GELU}(-3)=-0.00405$；最小值约为 $-0.170$，出现在 $x\approx-0.752$ 处。它处处光滑，而且在负半轴有一个小小的“下凹”：与 ReLU 不同，它不是单调的。

$\Phi$ 本身要用误差函数 $\mathrm{erf}$ 计算，原论文给了两个近似：tanh 形式（方程组 (1.13) 第二行）和 $x\,\sigma(1.702x)$，作者说他们的所有实验都用前者 [@hendrycks2016]。GPT-2 的官方代码用的正是 tanh 近似：`0.5*x*(1+tanh(sqrt(2/pi)*(x+0.044715*x^3)))` [@gpt2code]；Hugging Face 把它叫作 `gelu_new` [@hfgpt2]。在 $[-6,6]$ 上，tanh 近似与精确值的最大误差是 $4.73\times10^{-4}$（在 $x\approx-2.70$ 处），sigmoid 近似是 $2.03\times10^{-2}$（在 $x\approx2.27$ 处）；$\abs{x}$ 更大时两种误差都趋于 0，所以这也是整条实轴上的最大误差。

::: fig figures/l01-ffn.svg | 图 1.11 前馈网络：3072 条键值记忆，与 GELU 非线性 | scroll
**看 (a) 中间那一列系数：只有少数几条记忆被明显唤起（绿色），输出主要由它们的值向量组成。** (a) 把 $W_1$ 的行读作键、$W_2$ 的列读作值，按 (1.24) 画出 GPT-2 small 一个位置上的 FFN；系数的深浅是示意 [@geva2021]。(b) 精确 GELU（黑）、GPT-2 代码里的 tanh 近似（橙点线，两者在图中几乎重合）与 ReLU（灰虚线）；最小值点与 $(1,0.841)$ 由生成脚本计算，近似误差在 $[-6,6]$ 上取最大值。
:::

**GPT 为什么用 GELU 而不是 ReLU？** GPT-1 的报告只写了“用了 GELU”，没有给理由 [@radford2018]，本课也没有找到说明动机的一手资料。GELU 处处可导、在 0 附近平滑，这是它与 ReLU 的数学区别；在 GPT 的规模上这带来多大好处，所引论文里没有对照实验。第 5 课会讲后来普遍换成的 SwiGLU。

::: def 组件卡 · 前馈网络（FFN）
**含义**：每个位置独立地过一个 $768\to3072\to768$ 的两层网络，把注意力搬来的信息与自身信息加工成新特征。

**数学意义**：$\FFN(\mathbf x)=W_2\,\mathrm{GELU}(W_1\mathbf x+\mathbf b_1)+\mathbf b_2$；等价地，$\sum_m\mathrm{GELU}(\mathbf k_m^\top\mathbf x+b_{1,m})\,\mathbf v_m+\mathbf b_2$，是 3072 条“键–值记忆”的加权和（再加一个固定偏置），权重互相独立、不归一化。

**逻辑意义**：注意力对值是线性的，只负责搬运；FFN 提供每个位置上的非线性与大容量（每层 $8d^2$ 个参数，占权重的 2/3），模型的大部分“知识”被认为存储在这里。去掉它，网络在每个位置上几乎只剩线性变换。
:::

::: key 本页要点
- FFN 逐位置作用：$768\to3072\to768$，GELU 夹在中间；每层 $8d^2+5d=4{,}722{,}432$ 个参数，是注意力的两倍。
- 4 倍宽是惯例，没有理论推导；原论文的消融显示更宽更好，但更贵。
- 键值记忆读法：$\FFN(\mathbf x)=\sum_m\mathrm{GELU}(\mathbf k_m^\top\mathbf x+b_{1,m})\mathbf v_m+\mathbf b_2$。与注意力相比，键值是固定参数，权重不归一化。
- $\mathrm{GELU}(x)=x\Phi(x)$：按大小加权的软门控；GPT-2 用 tanh 近似，与精确值的最大误差约 $4.73\times10^{-4}$。
:::

# 残差流与 LayerNorm | 加法更新、梯度高速公路、尺度控制与 Pre-LN | 35

前面几页的每个子层都有一个共同的动作：从残差流上“读一份”，算完之后“加回去”。这一页讲这两个动作本身：**加回去**是残差连接，它让深层网络训练得动；**读一份之前先归一化**是 LayerNorm，它控制每个子层看到的数值尺度。最后讲 GPT-2 把 LayerNorm 挪了位置这件事，以及它背后的一个定理。

## 残差连接：每层只学“改多少”

**问题。** 把几十个非线性层直接串起来，会出两类麻烦。第一，如果某一层最好“什么都不做”，它得费力学出一个恒等映射，而一个随机初始化的非线性层离恒等映射很远。第二，反向传播时梯度要依次乘上每一层的导数（雅可比矩阵）；如果每层都让梯度缩小一点，比如乘 0.9，那么 24 层之后只剩 $0.9^{24}\approx0.080$，最底下的层几乎学不到东西，这就是**梯度消失**（vanishing gradient）。

**含义。** **残差连接**（residual connection）让一层的输出等于“输入 + 这一层算出的修正量”，而不是完全由这一层重新算出。He 等人的原始写法是：想让一组层拟合映射 $\mathcal H(\mathbf x)$，不如让它们拟合残差 $\mathcal F(\mathbf x)=\mathcal H(\mathbf x)-\mathbf x$，输出写成 [@he2016]

::: eq 残差连接 | (1.25)
$$\mathbf y=\mathcal F(\mathbf x,\{W_i\})+\mathbf x$$
恒等捷径不增加任何参数，也几乎不增加计算 [@he2016]。GPT 的 (1.7) $\mathbf h'_t=\mathbf h^{(l-1)}_t+\mathbf u_t$ 与 (1.9) $\mathbf h^{(l)}_t=\mathbf h'_t+\mathbf m_t$ 都是这个形式。
:::

**理解。** “什么都不做”现在变得很容易：让 $\mathcal F$ 输出 0 就行，而一个权重很小的层输出本来就接近 0。每一层只需要学“在现有基础上改多少”。

## 残差流：所有子层共用的一条总线

把 (1.7)(1.9) 从第 1 块一直展开到第 $L$ 块，整条残差流就写成了一个求和：

::: deriv 把 L 个块的残差连接一路展开
$\mathbf h^{(l)}_t=\mathbf h^{(l-1)}_t+\mathbf u^{(l)}_t+\mathbf m^{(l)}_t$ || 把 (1.7) 代入 (1.9)；上标 $(l)$ 标出这是第 $l$ 块的增量
$\mathbf h^{(L)}_t=\mathbf h^{(L-1)}_t+\mathbf u^{(L)}_t+\mathbf m^{(L)}_t=\mathbf h^{(L-2)}_t+\sum_{l=L-1}^{L}\big(\mathbf u^{(l)}_t+\mathbf m^{(l)}_t\big)$ || 对 $\mathbf h^{(L-1)}_t$ 再用一次同一个式子
$\mathbf h^{(L)}_t=\mathbf h^{(0)}_t+\sum_{l=1}^{L}\big(\mathbf u^{(l)}_t+\mathbf m^{(l)}_t\big)$ || 一直展开到第 0 层（望远镜求和）
:::

::: eq 残差流 = 嵌入 + 所有子层增量之和 | (1.26)
$$\mathbf h^{(L)}_t=\underbrace{E^\top\mathbf e_{x_t}+P^\top\mathbf e_t}_{\text{嵌入}}+\sum_{l=1}^{L}\big(\underbrace{\mathbf u^{(l)}_t}_{\text{注意力写入}}+\underbrace{\mathbf m^{(l)}_t}_{\text{FFN 写入}}\big)$$
GPT-2 small：1 份嵌入 + 24 份增量，每一份都是 768 维向量。
:::

这就是**残差流**（residual stream）的观点：Elhage 等人把残差流描述为此前所有层的输出与原始嵌入之和，它本身不做任何处理，所有层都通过它来通信 [@elhage2021]。每个子层先从流上读一份（经过 LayerNorm），算出一个增量，再把增量写回流上。因为一切都是加法，流上的 768 个坐标没有哪一个是“特殊的”，Elhage 等人称之为残差流没有“特权基”（privileged basis）：信息可以存在任何方向上，一个子层写下的方向要靠后面的子层用自己的矩阵去读 [@elhage2021]。

::: ana 类比：残差流 = 传送带
**映射。** 残差流是一条传送带，每个位置的 768 维向量是带上的一件货；24 个子层是带子旁边的 24 个工位。每个工位先看一眼（LayerNorm 之后读一份），加工出一个增量，再把增量放回带上（⊕）。没人动的货原样往下走，这就是恒等映射。

**收益。** 它让 (1.26) 一眼可见：终点的货 = 起点的货 + 每个工位放上去的东西；放回的增量必须与货同形，所以宽度处处是 768。它也预告了第 16 课：Hyper-Connections 把一条带子扩成几条，mHC 要求带子之间的调度“守恒”。

**失效的地方。** 真实的“件”是连续向量空间里的一个点，“放回”是向量加法：两个工位放上去的增量可以互相抵消，也可以叠加成一个新方向，这是实物传送带没有的。工位也不是只拿走一件货来加工：注意力工位会同时看带上**其他位置**的货。
:::

::: fig figures/l01-residual.svg | 图 1.12 残差流是一条传送带：24 个工位各自读一份、加回一个增量 | scroll
**看带子上的 ⊕：每个子层对残差流做的唯一一件事，就是往上加一个向量。** 蓝色是注意力工位，灰色是 FFN 工位；它们读之前都要先过自己的 LayerNorm（“LN”），写回时不过。底部两行是前向的展开式 (1.26) 与反向的“梯度高速公路” (1.27)。这是示意图，工位数与宽度取自 GPT-2 small 的配置；画法沿用本课程的“传送带”类比，概念出自 [@elhage2021]。
:::

## 梯度高速公路

残差连接让梯度也有一条直达的路。记第 $l$ 块两个分支合起来的雅可比矩阵为 $J_l=\partial(\mathbf u^{(l)}_t+\mathbf m^{(l)}_t)/\partial\mathbf h^{(l-1)}_t$（$J_l$ 是只让同一位置的 $\mathbf h^{(l-1)}_t$ 变动、其他位置固定时的雅可比矩阵。注意力让 $\mathbf h^{(l)}_t$ 还依赖 $j<t$ 的旧状态，但下面的乘积对 $\partial\mathbf h^{(L)}_t/\partial\mathbf h^{(l)}_t$ 仍然是精确的：由 [§4](#p4) 的因果性，$\mathbf h^{(l)}_t$ 的变动只会传到位置 $\ge t$，而位置 $t$ 在每一层只读位置 $\le t$，所以从 $\mathbf h^{(l)}_t$ 到 $\mathbf h^{(L)}_t$ 的每一条路都始终走在位置 $t$ 上。损失对 $\mathbf h^{(l)}_t$ 的梯度还要加上经过后面位置 $s>t$ 的那些项；把 $T$ 个位置的状态拼成一个 $Td$ 维向量、$J_l$ 取整段序列的雅可比矩阵，下面每一行也原样成立，只是 $I$ 变成 $Td\times Td$ 的单位矩阵。雅可比矩阵与链式法则见 [§4](#p4) 的前置框，[M06 §7](../math/m06-calculus-backprop.html#p7) 从 $\mathbf x+f(\mathbf x)$ 的导数讲起，专讲这条路）：

::: deriv 反向传播穿过 L−l 个残差块
$\dfrac{\partial\mathbf h^{(l)}_t}{\partial\mathbf h^{(l-1)}_t}=I+J_l$ || 对 $\mathbf h^{(l)}_t=\mathbf h^{(l-1)}_t+(\mathbf u^{(l)}_t+\mathbf m^{(l)}_t)$ 求导，恒等项求导得单位矩阵
$\dfrac{\partial\mathbf h^{(L)}_t}{\partial\mathbf h^{(l)}_t}=(I+J_L)(I+J_{L-1})\cdots(I+J_{l+1})$ || 链式法则：逐层相乘
$=I+\sum_{k=l+1}^{L}J_k+\sum_{k>k'}J_kJ_{k'}+\cdots$ || 把乘积展开：第一项永远是 $I$
:::

::: eq 梯度高速公路 | (1.27)
$$\frac{\partial\mathbf h^{(L)}_t}{\partial\mathbf h^{(l)}_t}=I+\sum_{k=l+1}^{L}J_k+(\text{两个及以上 }J\text{ 的乘积})$$
无论中间的层把梯度缩小多少，恒等项 $I$ 这一条路径都把顶层的梯度原样送到第 $l$ 层。没有残差连接时，这里只有 $J_LJ_{L-1}\cdots J_{l+1}$ 这一项。总梯度是所有项之和，其余项可以加强它，也可以部分抵消它；恒等项保证的是“有一条不经过任何 $J$ 的路”，不是总和的大小。
:::

对照开头的例子：若每个子层让梯度乘 0.9，没有残差时 24 层之后剩 $0.9^{24}\approx0.080$；有残差时，至少还有一条“乘 1”的直达路径。这是残差结构给出的结构性保证，不依赖训练得好不好。

**初始化要跟着层数缩小。** (1.26) 说残差流是 $2L$ 份增量之和。GPT-2 的报告说，它在初始化时把残差层的权重乘以 $1/\sqrt N$，$N$ 是残差层的数目 [@radford2019]。Hugging Face 和 nanoGPT 把 $N$ 解读为 $2L$（每块两个残差分支），对每个输出投影（$W^O$ 与 $W_2$）用标准差 $0.02/\sqrt{2L}$ 初始化；GPT-2 small 是 $0.02/\sqrt{24}\approx0.00408$ [@hfgpt2; @nanogpt]。值得注意的是，OpenAI 公开的 GPT-2 代码是推理代码，里面每个线性层的权重都按标准差 0.02 初始化（只有位置表 `wpe` 是 0.01），并没有这一步 [@gpt2code]。这个缩放的用意可以这样理解（笔者的推导）：若 $2L$ 份增量在初始化时近似独立、各自方差为 $\sigma^2$，它们之和的方差是 $2L\sigma^2$；把每份的标准差乘以 $1/\sqrt{2L}$，总和的方差就回到 $\sigma^2$，与层数无关。这和 [§4](#p4) 里除以 $\sqrt{d_k}$ 是同一个“独立变量之和”的道理。

::: def 组件卡 · 残差连接与残差流
**含义**：每个子层的输出不替换输入，而是加到输入上；整条残差流是嵌入与所有子层增量之和。

**数学意义**：$\mathbf h^{(l)}=\mathbf h^{(l-1)}+\mathbf u^{(l)}+\mathbf m^{(l)}$，展开为 (1.26)；反向时 $\partial\mathbf h^{(L)}/\partial\mathbf h^{(l)}$ 总含单位矩阵 $I$ (1.27)。

**逻辑意义**：让每层只学“改多少”，“什么都不做”变得容易；给梯度一条不衰减的直达路径，使几十层的网络可训练；并给所有子层一条共享的、线性可加的通信总线。代价是：流上的东西只加不删，尺度会随深度累积，这正是下面 LayerNorm 要处理的问题。
:::

## LayerNorm：控制每个子层看到的尺度

**问题。** 残差流是几十份增量之和，它的大小会随深度变化；到了某一层，流上向量的长度可能是嵌入层的好几倍。而子层对输入的尺度很敏感：[§4](#p4) 说过，查询和键的长度直接决定 softmax 的温度；GELU 在输入的不同尺度上表现也完全不同（接近线性，或接近 ReLU）。我们希望每个子层读到的输入都有一个稳定的尺度，不管它处在第几层。

**含义。** **层归一化**（layer normalization，LayerNorm）把**每个 token 自己的** $d$ 个分量减去它们的均值、除以它们的标准差，再乘一个可学习的缩放 $\boldsymbol\gamma$、加一个可学习的平移 $\boldsymbol\beta$。

**理解。** 就像把每份答卷先换算成“标准分”，再按需要统一调整：不管原始分数整体偏高还是偏低、分散还是集中，换算后都在同一个尺度上。关键是统计量只在**同一个 token 的 768 个分量**上计算，不跨 token、不跨样本，所以训练和推理时的计算完全一样（这是它与 batch normalization 的区别）[@ba2016]。类比的边界也在这里：学校的标准分是拿一个人的分数和**全体考生**比，LayerNorm 却是拿一个分量和**同一个 token 的其他分量**比，更像把一份答卷里 768 道小题的得分互相比较；换算之后还要乘 $\boldsymbol\gamma$、加 $\boldsymbol\beta$，模型可以学着把某些分量重新放大。

**数学。** 见方程组 (1.12)。Ba 等人的原式没有 $\epsilon$ [@ba2016]；实现里在方差上加一个很小的 $\epsilon=10^{-5}$ 防止除以 0 [@gpt2code; @hfgpt2]。

::: ex 手算一次 LayerNorm
取 $d=4$，$\mathbf x=(2,4,6,8)$，$\boldsymbol\gamma=\mathbf 1$，$\boldsymbol\beta=\mathbf 0$。

均值 $\mu=(2+4+6+8)/4=5$；方差 $\sigma^2=\big((-3)^2+(-1)^2+1^2+3^2\big)/4=20/4=5$；标准差 $\sqrt5\approx2.2361$。于是

$$
\begin{aligned}
\LayerNorm(\mathbf x)&=\Big(\frac{-3}{2.2361},\ \frac{-1}{2.2361},\ \frac{1}{2.2361},\ \frac{3}{2.2361}\Big)\\
&=(-1.3416,\ -0.4472,\ 0.4472,\ 1.3416).
\end{aligned}
$$

加上 $\epsilon=10^{-5}$ 之后，前四位小数不变。两个性质可以直接验证：把 $\mathbf x$ 换成 $10\mathbf x=(20,40,60,80)$ 或 $\mathbf x+100\cdot\mathbf 1=(102,104,106,108)$，结果完全一样（忽略 $\epsilon$）：LayerNorm 对整体放大和整体平移都不敏感。输出的长度 $\sqrt{1.3416^2\times2+0.4472^2\times2}=2=\sqrt d$。
:::

**几何意义。** 上例最后那个 $\sqrt d$ 不是巧合。减去均值，等于把 $\mathbf x$ 投影到与全 1 向量 $\mathbf 1$ 垂直的超平面上（[M01 §6](../math/m01-vectors-matrices.html#p6) 的投影）；再除以标准差，由 $\sum_k(x_k-\mu)^2=d\,\sigma^2$ 得 $\norm{\mathbf x-\mu\mathbf 1}/\sigma=\sqrt d$。所以在乘 $\boldsymbol\gamma$、加 $\boldsymbol\beta$ 之前，LayerNorm 的输出总是落在一个半径为 $\sqrt d$ 的球面上（$d=768$ 时半径约 27.7）。这里有两个前提：忽略 $\epsilon$（带上它，半径是 $\sqrt d\,\sigma/\sqrt{\sigma^2+\epsilon}$，略小于 $\sqrt d$）；$\mathbf x$ 的分量不全相等（否则 $\sigma=0$，输出是零向量）。它丢掉了“长度”这一个自由度和“均值”这一个自由度，只保留方向。这就是“尺度控制”的准确含义。

**参数账。** 每个 LayerNorm 有 $\boldsymbol\gamma,\boldsymbol\beta$ 两个 $d$ 维向量，共 $2d=1536$ 个参数。GPT-2 small 每块 2 个、最后 1 个，共 25 个，合计 $25\times1536=38{,}400$ 个参数，只占总数的 0.031%。它们便宜，但位置很重要。

## Post-LN 与 Pre-LN：GPT-2 挪了什么

LayerNorm 放在哪里，有两种做法。原 Transformer 把它放在每个子层**之后、残差相加之后**：$\mathbf x_{l+1}=\LayerNorm(\mathbf x_l+\mathrm{Sublayer}(\mathbf x_l))$ [@vaswani2017]，后来称为 **Post-LN**。GPT-2 把它挪到每个子层的**输入**处，并在整个堆栈之后加一个最终 LayerNorm [@radford2019; @gpt2code]，即方程组里的 (1.2)(1.8)(1.10)，称为 **Pre-LN**：

::: eq 两种放法（每个子层） | (1.28)
$$
\begin{aligned}
\text{Post-LN：}&\quad \mathbf x_{l+1}=\LayerNorm\big(\mathbf x_l+\mathrm{Sublayer}(\mathbf x_l)\big)\\
\text{Pre-LN：}&\quad \mathbf x_{l+1}=\mathbf x_l+\mathrm{Sublayer}\big(\LayerNorm(\mathbf x_l)\big)
\end{aligned}
$$
$\mathbf x_l\in\R^{d}$ 是第 $l$ 个子层之前残差流上的向量，$\mathrm{Sublayer}$ 是注意力或 FFN。Post-LN 的主干上每一步都要经过 LayerNorm；Pre-LN 的主干上只有加法，LayerNorm 只在分支里。
:::

::: fig figures/l01-layernorm.svg | 图 1.13 Post-LN 与 Pre-LN | scroll
**看 (a)(b) 两列的主干：Post-LN 的主干要穿过 LayerNorm，Pre-LN 的主干是一条只有加法的直路。** (a)(b) 据 Xiong 等（2020）图 1 重绘 [@xiong2020]。(c) 该文引理 2 在简化假设下给出的初始化时隐藏状态范数平方的期望（除以 $d$）：Post-LN 每层送进第二个 LayerNorm 之前的那个和（原文记作 $x^{post,5}$）都是 1.5，经过 LayerNorm 之后恒为 1，不随层数变化；Pre-LN 的残差流则在 $1+l/2$ 与 $1+3l/2$ 之间随层号线性增长；由生成脚本按公式画出。
:::

**Xiong 等人的定理。** 为什么这个挪动重要？Xiong 等人在一个简化的设定下分析了初始化时的梯度 [@xiong2020]。他们的假设必须一起说清：单头注意力；$W^Q,W^K$ 初始化为 0（注意力退化为均匀平均）；所有权重都是 $d\times d$；输入向量也从同一个高斯分布采样；FFN 用 ReLU；并对若干向量的范数做了“以高概率有界”的假设。在这个设定下，他们的定理 1 说：

::: thm 初始化时最后一层 FFN 权重的梯度（Xiong 等 2020，定理 1）
以至少 $0.99-\delta-\frac{\epsilon}{0.9+\epsilon}$ 的概率，

$$\text{Post-LN：}\ \Big\|\frac{\partial\tilde{\mathcal L}}{\partial W^{2,L}}\Big\|_F\le\mathcal O\big(d\sqrt{\ln d}\big),\qquad \text{Pre-LN：}\ \Big\|\frac{\partial\tilde{\mathcal L}}{\partial W^{2,L}}\Big\|_F\le\mathcal O\Big(d\sqrt{\tfrac{\ln d}{L}}\Big)$$

$\tilde{\mathcal L}$ 是该定理所分析的训练损失（一个标量，记号沿用原文），$W^{2,L}\in\R^{d\times d}$ 是第 $L$ 层（最后一层）FFN 的第二个权重矩阵，$\norm{\cdot}_F$ 是 Frobenius 范数（所有元素平方和再开方），$\epsilon,\delta$ 来自上述有界性假设（这里的 $\epsilon$ 沿用原文记号，与 LayerNorm 里的 $\epsilon=10^{-5}$ 无关）。Post-LN 的上界与层数 $L$ 无关，Pre-LN 的上界随 $L$ 增大而按 $1/\sqrt L$ 变小。
:::

直观的来源是他们的两个引理。引理 2 就是图 1.13 (c)：Pre-LN 的残差流范数平方随层数线性增长。引理 3 说 LayerNorm 的雅可比矩阵的范数与输入的范数成反比，约为 $\sqrt d/\norm{\mathbf x}$。两者合起来：Pre-LN 最后那个 LayerNorm 的输入越深越大，于是把传回来的梯度按 $1/\sqrt L$ 缩小了；Post-LN 没有这个效果，顶层的梯度在训练一开始就很大。

**实测后果：warm-up。** 顶层梯度一开始就很大，意味着一开始就用较大的学习率会把训练搞坏。所以 Post-LN 必须先用很小的学习率“热身”（warm-up），再逐渐增大；Pre-LN 可以去掉这一步 [@xiong2020]。他们在 IWSLT14 德英翻译上的实验：Post-LN 不用 warm-up、直接用 Adam，BLEU 只有 8.45；用了 warm-up，约 34 [@xiong2020]。学习率调度本身是第 2 课的内容。

::: err 三个常见的说法，以及更准确的版本
**“Pre-LN 是 GPT-2 发明的。”** 不是。GPT-2 的报告自己说这一改动类似于“pre-activation”的残差网络 [@radford2019]；Xiong 等人说 Pre-LN 此前已经在若干系统里实现过 [@xiong2020]。本课没有确定最早的出处。

**“Transformer 原论文用的是 Pre-LN。”** 论文的 §3.1 写的是 Post-LN [@vaswani2017]；但 Google 的官方代码库 tensor2tensor 后来把默认配置改成了 Pre-LN：2017 年 6 月的早期版本与论文一致，是 Post-LN；2017 年 10 月的 v1.2.5 加入 `transformer_base_v2`（Pre-LN），并让默认的 `transformer_base` 改用它，`transformer_base_v1` 则保留论文的 Post-LN [@t2t]。论文与代码不一致，说哪个版本要讲清楚。

**“GPT-2 的最终 LayerNorm 在最后一个自注意力之后。”** 报告的字面说法如此，但代码里的 `ln_f` 位于全部 12 个块（包括最后一个 FFN）之后、输出层之前 [@radford2019; @gpt2code]。本课以代码为准。
:::

**Pre-LN 也有代价（笔者推论）。** 由引理 2，Pre-LN 的残差流越来越长，而每个子层的输入先经过 LayerNorm、增量的尺度大致固定，所以越往深处，单个子层的增量占整条流的比例越小。这是笔者的直观推论，不是所引论文的结论。Post-LN 与 Pre-LN 各有代价，这个两难是第 16 课 mHC 的出发点之一；第 5 课则把 LayerNorm 换成更便宜的 RMSNorm。

::: def 组件卡 · LayerNorm
**含义**：把每个 token 的 768 个分量减均值、除标准差，再做一次可学习的逐分量缩放和平移。

**数学意义**：$\boldsymbol\gamma\odot(\mathbf x-\mu\mathbf 1)/\sqrt{\sigma^2+\epsilon}+\boldsymbol\beta$；在 $\boldsymbol\gamma,\boldsymbol\beta$ 之前，输出是投影到 $\mathbf 1^\perp$ 超平面、再缩放到半径 $\sqrt d$ 球面上的向量，对输入的整体放大与平移不变。

**逻辑意义**：让每个子层读到尺度稳定的输入，不受残差流随深度累积的影响。放在分支里（Pre-LN）时，主干保持一条只有加法的直路，训练更稳，可以去掉 warm-up；放在主干上（Post-LN）时，顶层梯度在初始化时偏大。
:::

::: key 本页要点
- 残差连接 $\mathbf y=\mathbf x+\mathcal F(\mathbf x)$：每层只学增量。残差流 $\mathbf h^{(L)}=\mathbf h^{(0)}+\sum_l(\mathbf u^{(l)}+\mathbf m^{(l)})$ 是所有子层共享的线性总线，没有特权基。
- 反向时 $\partial\mathbf h^{(L)}/\partial\mathbf h^{(l)}=I+\cdots$：恒等项是梯度高速公路。残差分支的初始化按 $1/\sqrt{2L}$ 缩小（Hugging Face / nanoGPT 的解读）。
- LayerNorm 在每个 token 的 $d$ 个分量上归一化：去均值、缩放到半径 $\sqrt d$ 的球面，再乘 $\boldsymbol\gamma$ 加 $\boldsymbol\beta$；GPT-2 small 全部 LN 只有 38,400 个参数。
- Post-LN 的主干穿过 LN，Pre-LN 的主干只有加法。Xiong 等人的定理：初始化时 Post-LN 顶层梯度 $\mathcal O(d\sqrt{\ln d})$，Pre-LN 为 $\mathcal O(d\sqrt{\ln d/L})$；所以 Post-LN 需要 warm-up。
:::

# 输出：从向量回到词表 | 最终 LayerNorm、反嵌入、权重共享、logits 与 softmax，以及全程形状追踪 | 25

12 个块之后，每个位置 $t$ 手里是一条 768 维的向量 $\mathbf h^{(12)}_t$。最后要把它变成 50,257 个候选 token 上的概率，也就是方程组的 (1.10)(1.11)。这一页讲这最后三步，然后把整次前向传播的形状从头到尾追一遍。

## 最终 LayerNorm

Pre-LN 的残差流越往深处越长（[§6](#p6) 图 1.13），如果直接拿 $\mathbf h^{(12)}_t$ 去算 logits，logits 的整体大小、也就是 softmax 的“温度”，会随层数漂移。所以 GPT-2 在所有块之后、输出层之前加了一个 LayerNorm（代码名 `ln_f`），记它的输出为 $\tilde{\mathbf h}_t=\LayerNorm_f(\mathbf h^{(12)}_t)$ [@radford2019; @gpt2code]。它只有 1,536 个参数。

## 反嵌入：与每个 token 做一次点积

**含义。** **反嵌入**（unembedding）是嵌入的反方向：嵌入把 token 编号变成 $d$ 维向量，反嵌入把 $d$ 维向量变回“每个 token 一个分数”。这些分数叫 **logits**。

**理解。** 可以把 $\tilde{\mathbf h}_t$ 看成一个查询，拿它去和词表里 50,257 个 token 的“标签”逐一比对；比对的分数越高，这个 token 越可能是下一个。这和注意力的打分是同一种运算，只是“键”换成了固定的 token 向量，而且不做加权平均，只要分数。

**数学。** 用输入嵌入表 $E\in\R^{V\times d}$ 本身来打分（为什么可以这样，见下一节）：

::: eq 反嵌入与 logits | (1.29)
$$\mathbf z_t=E\,\tilde{\mathbf h}_t\in\R^{V},\qquad z_{t,v}=E_{v,:}\cdot\tilde{\mathbf h}_t=\sum_{k=1}^{d}E_{vk}\,\tilde h_{t,k}$$
第 $v$ 个 logit 是最终向量与第 $v$ 个 token 的嵌入向量的点积。形状 $[V,d]\times[d]\to[V]$；整段序列是 $\tilde H E^\top$，$[T,768]\times[768,50257]\to[T,50257]$。
:::

**logits 这个词。** **含义**：未经归一化的分数，可正可负。**理解**：它们本身不是概率，只有相对大小有意义，所有 logits 同时加一个常数，概率不变（softmax 的平移不变性，[§3](#p3)）。**数学**：取对数之后，概率与 logits 只差一个与 $v$ 无关的常数：

::: deriv 对数概率 = logit − log-sum-exp
$p_\theta(x_{t+1}=v\mid x_{\le t})=\dfrac{e^{z_{t,v}}}{\sum_{w}e^{z_{t,w}}}$ || (1.11)
$\log p_\theta(x_{t+1}=v\mid x_{\le t})=z_{t,v}-\log\sum_{w}e^{z_{t,w}}$ || 两边取自然对数；分母对所有 $v$ 相同
:::

所以 logits 就是“差一个公共常数的对数概率”。第 2 课会看到，训练的损失正是 $-\log p_\theta(\text{真实的下一个 token})$，也就是 $-z_{t,v^\star}+\log\sum_we^{z_{t,w}}$。

::: ex 一个 5 个词的输出层
用图 1.4 (b) 的玩具例子：词表 {the, cat, sat, on, mat}，$d=3$，最终向量 $\tilde{\mathbf h}=(-0.4,\ 2.0,\ 0.6)$。

- logits：$\mathbf z=E\tilde{\mathbf h}=(-0.04,\ 0.12,\ 1.78,\ 0.32,\ 0.22)$。例如 $z_{\text{sat}}=(-0.3)(-0.4)+0.8\times2.0+0.1\times0.6=0.12+1.60+0.06=1.78$。
- $\log\sum_we^{z_w}=\log(0.9608+1.1275+5.9299+1.3771+1.2461)=\log10.6414=2.3647$。
- $\log p(\text{sat})=1.78-2.3647=-0.5847$，$p(\text{sat})=e^{-0.5847}=0.557$。五个概率是 $(0.090,\ 0.106,\ 0.557,\ 0.129,\ 0.117)$，精确值加起来等于 1（这五个三位小数是四舍五入后的值，相加得 0.999）。

把 $\tilde{\mathbf h}$ 放大一倍，logits 也放大一倍，$p(\text{sat})$ 变成 0.862：最终向量的长度起着温度的作用，这正是为什么需要 `ln_f` 来稳住它。
:::

**这一步很贵。** 每个位置要做 50,257 个 768 维的点积，约 $2dV=77{,}194{,}752$ 次运算（[§8](#p8) 会看到它占了 GPT-2 small 前向运算的约 29%）。训练时 $T=1024$ 个位置一起算，logits 张量是 $1024\times50257=51{,}463{,}168$ 个数，按 32 位浮点约 205.9 MB，比一整层的参数还大得多。

## 权重共享：同一个 E 用两次

**含义。** **权重共享**（weight tying）是让输出层的打分矩阵就是输入嵌入矩阵 $E$，而不是另学一个 $V\times d$ 的矩阵。

**理解。** 输入端，$E$ 的第 $v$ 行回答“token $v$ 该用哪个向量表示”；输出端，$E$ 的第 $v$ 行回答“最终向量指向哪个方向时，下一个词该是 $v$”。两者都是“token 与 $d$ 维方向之间的一本对照词典”，共用一本，既省参数，也让两端的几何一致。

**数学。** GPT-1 报告的输出公式直接写成 $P(u)=\mathrm{softmax}(h_nW_e^\top)$（行写法：$h_n$ 每行一个位置），$W_e$ 就是输入的词嵌入矩阵 [@radford2018]；GPT-2 的代码是 `logits = tf.matmul(h_flat, wte, transpose_b=True)` [@gpt2code]；《Attention Is All You Need》也让两个嵌入层与 softmax 前的线性层共享同一个矩阵 [@vaswani2017]。原论文为这个做法引用的是 Press 与 Wolf：他们发现把输入嵌入与输出嵌入绑成同一个矩阵，能降低多种语言模型的困惑度，在神经机器翻译里还能把模型缩小到原来的一半以下而不损失性能 [@press2017]。按他们自己的说明，这个做法并非首创：更早的 log-bilinear 模型（Mnih 与 Hinton，2009）已经这样用过，只是没有解释、也没有检验效果；Inan 等人同期独立地给出了另一种解释 [@press2017]。

::: ex 共享省了多少
GPT-2 small 的 $E$ 有 $50{,}257\times768=38{,}597{,}376$ 个参数。不共享的话，输出层要再多这么多，总参数从 124,439,808 变成 163,037,184，多出 31%。对 GPT-2 xl（$d=1600$），这一项是 80,411,200，只占其总数 1,557,611,200 的约 5%：共享对小模型省得最多。
:::

共享还改变了 $E$ 的学习方式。[§2](#p2) 说过，输入端只有出现过的 token 那几行会拿到梯度；输出端却不同：softmax 对**所有** 50,257 个 logits 都有梯度（第 2 课会推出它等于“预测概率减去独热目标”），所以每一步训练，$E$ 的每一行都会从输出端得到更新。

::: warn 类比的边界：两种角色并不完全相同
输入端要的是“这个 token 本身是什么”，输出端要的是“什么样的上下文之后该出现它”。两者相关但不相同，共享是一个选择，不是推论；所引文献报告的是困惑度的改善和参数的节省 [@press2017]。
:::

::: def 组件卡 · 反嵌入、权重共享与 softmax
**含义**：用最终向量与每个 token 的嵌入向量做点积得到 logits，再用 softmax 变成下一词的概率；打分矩阵与输入嵌入共用。

**数学意义**：$\mathbf z_t=E\,\LayerNorm_f(\mathbf h^{(L)}_t)$，$\log p(v)=z_{t,v}-\log\sum_we^{z_{t,w}}$；每个 logit 是一个点积，概率对 logits 的整体平移不变。

**逻辑意义**：把 $d$ 维的内部表示翻译回离散的词表，产生可以计算损失、可以采样的分布。共享 $E$ 让输入与输出的“词典”一致，GPT-2 small 省下 3,860 万个参数（占 31%）；代价是一个矩阵要同时服务两种角色。
:::

## 生成：把这一切放进一个循环（预告第 4 课）

训练时，一次前向传播给出 $T$ 个位置的分布。生成时，我们只关心**最后一个**位置的分布：从中选出一个 token（怎么选、温度和 top-p 采样，是第 4 课的内容），把它接到序列末尾，再做一次前向传播，如此循环。

[§4](#p4) 的归纳证明说，追加新 token 不会改变任何旧位置的结果，所以每一步真正需要新算的，只有新 token 自己那一列，外加它的查询要和所有旧位置的键、值做注意力。于是可以把旧位置的 $\mathbf k,\mathbf v$ 存起来，这就是 **KV cache**。GPT-2 small 每个 token 要存 12 层 × 2（K 和 V）× 768 个数，按 16 位浮点是 $2\times12\times768\times2=36{,}864$ 字节 = 36 KiB，1024 个 token 就是 36 MiB；同样算法下 GPT-3 175B（96 层、$d=12288$）每个 token 要 4.5 MiB。这笔“字节账”是第 4 课、第 9 课的主角。

::: key 本页要点
- 最终 LayerNorm `ln_f` 稳住 logits 的尺度；反嵌入 $\mathbf z_t=E\tilde{\mathbf h}_t$：每个 logit 是最终向量与一个 token 嵌入的点积。
- $\log p(v)=z_v-\log\sum_we^{z_w}$：logits 是差一个公共常数的对数概率，第 2 课的损失由此而来。
- 权重共享：输出层复用 $E$，GPT-2 small 省下 38,597,376 个参数（总数的 31%）；输出端让 $E$ 的每一行每步都得到梯度。
- 全程形状：$[T]\to[T,768]\to\cdots\to[T,50257]$；只有注意力内部出现 $[T,T]$；参数逐步相加恰为 124,439,808。生成时旧位置的 K、V 可以缓存：GPT-2 small 每 token 36 KiB（fp16）。
:::

## 参数量：逐项数出来

每个块里的参数，按图 1.1 的方框逐项数（带偏置，GPT-2 的写法）：

::: deriv 一个块的参数
$\underbrace{d\cdot3d+3d}_{W_{qkv}}+\underbrace{d\cdot d+d}_{W^O}=4d^2+4d$ || 注意力：融合的 $Q,K,V$ 投影 $[d,3d]$ 加偏置，输出投影 $[d,d]$ 加偏置
$\underbrace{d\cdot4d+4d}_{W_1}+\underbrace{4d\cdot d+d}_{W_2}=8d^2+5d$ || FFN：升维 $[d,4d]$ 与降维 $[4d,d]$，各带偏置
$2\times2d=4d$ || 两个 LayerNorm，各有 $\boldsymbol\gamma,\boldsymbol\beta$
$(4d^2+4d)+(8d^2+5d)+4d=12d^2+13d$ || 相加
:::

再加上块外的部分：词嵌入 $Vd$、位置嵌入 $T_{max}d$、最终 LayerNorm $2d$、输出层 0（共享）：

::: eq GPT-2 式模型的精确参数量 | (1.30)
$$N_{total}=(V+T_{max})\,d+L\,(12d^2+13d)+2d$$
推导见上；前提是带偏置、Pre-LN、输出层与词嵌入共享、FFN 为 $4d$ 宽 [@radford2019; @gpt2code]。
:::

::: ex GPT-2 small：一个不差地数到 124,439,808
$L=12$，$d=768$，$V=50{,}257$，$T_{max}=1024$。

- 嵌入：$(50{,}257+1024)\times768=51{,}281\times768=39{,}383{,}808$。
- 每块：$12\times768^2+13\times768=7{,}077{,}888+9{,}984=7{,}087{,}872$；12 块共 $85{,}054{,}464$。
- 最终 LayerNorm：$2\times768=1{,}536$。
- 合计：$39{,}383{,}808+85{,}054{,}464+1{,}536=124{,}439{,}808$。

这正是 OpenAI 仓库现在给 GPT-2 small 起的名字 “124M” 的来历。报告表 2 印的是 117M；官方仓库后来说明，最初的参数计数有误 [@radford2019; @gpt2code]。
:::

**$12Ld^2$ 从哪里来。** 当 $d$ 很大时，每块的 $13d$ 远小于 $12d^2$（在 GPT-2 small 里，$13d/12d^2$ 只有 0.14%），略去它，再略去块外的嵌入和 LayerNorm，就得到 Kaplan 等人的近似 [@kaplan2020]：

::: eq 非嵌入参数的近似 | (1.31)
$$N\approx2\,d\,L\,(2d_{attn}+d_{ff})=12\,L\,d^2\qquad(d_{attn}=d,\ d_{ff}=4d)$$
12 = 注意力的 4（$Q,K,V,O$ 四个 $d\times d$ 矩阵）+ FFN 的 8（两个 $d\times4d$ 矩阵）。Kaplan 等人把 $N$ 定义为**不含嵌入**的参数量，式 (2.1) [@kaplan2020]。
:::

## 运算量：每个 token 约 2N

**推导。** [M01 §5](../math/m01-vectors-matrices.html#p5) 数过：一个 token 经过一个 $m\times k$ 的权重矩阵，要做 $mk$ 次乘法和 $mk$ 次加法，共 $2mk$ 次运算，而 $mk$ 正是这个矩阵的参数个数。所以**每个权重、每个 token，两次运算**。把一个块里所有的矩阵乘加起来：

::: deriv 每个 token 的前向运算量
$2\times(3d^2+d^2+4d^2+4d^2)=24d^2$ || 每块的四组权重矩阵：$W_{qkv}$、$W^O$、$W_1$、$W_2$，每个参数 2 次运算
$L\times24d^2=2\times12Ld^2\approx2N$ || $L$ 个块；偏置、LayerNorm、GELU、softmax 的运算相对很少，略去
$+\ 4\,t\,d\ \text{（每层，位置 }t\text{）}$ || 注意力的打分 $QK^\top$ 与加权求和 $AV$：位置 $t$ 与 $t$ 个位置各做一次 $d$ 维点积，两步各 $2td$
$+\ 2dV$ || 反嵌入：与 $V$ 个 token 各做一次 $d$ 维点积；共享的 $E$ 不计入 $N$，但运算照做
:::

注意力那一项不含参数，却随上下文长度增长，而且不同文献的算法差一倍。Kaplan 等人的表 1 把它记为每 token $2\,n_{layer}\,n_{ctx}\,d_{attn}$ [@kaplan2020]；PaLM 的附录和 Chinchilla 论文的附录按整张 $T\times T$ 表计算，相当于每 token $4LTd$ [@palm2022; @hoffmann2022]。一个自洽的解释是（笔者推导，Kaplan 的论文没有这样说明）：因果模型里位置 $t$ 只和 $t$ 个位置做注意力，每层 $4td$，对 $t=1,\dots,T$ 取平均约为 $2Td$；而稠密实现往往先算满整张表再掩码，就是 $4Td$。

::: eq 每个 token 的前向运算量 | (1.32)
$$C_{fwd}\approx\underbrace{2N}_{\text{权重矩阵乘}}+\underbrace{2LTd}_{\text{注意力（Kaplan 口径）}}\quad\Big[+\underbrace{2dV}_{\text{反嵌入}}\Big],\qquad N\approx12Ld^2$$
Kaplan 等人的式 (2.2) 只有前两项，而且 $N$ 不含嵌入 [@kaplan2020]；按 PaLM 口径，注意力项是 $4LTd$ [@palm2022]。
:::

::: ex GPT-2 small，T = 1024
- 权重矩阵乘：$2\times12\times12\times768^2=169{,}869{,}312$。
- 注意力（Kaplan 口径）：$2\times12\times1024\times768=18{,}874{,}368$，是前一项的 11%；按 PaLM 口径翻倍为 $37{,}748{,}736$。
- 反嵌入：$2\times768\times50{,}257=77{,}194{,}752$。
- 合计（Kaplan 口径，含反嵌入）：$265{,}938{,}432$，约 $2.66\times10^8$ 次运算。反嵌入占其中 29%。

一个有用的巧合：共享嵌入的小模型里，“$2\times$（总参数 − 位置表）”$=2\times123{,}653{,}376=247{,}306{,}752$，与真实的矩阵乘运算量 $169{,}869{,}312+77{,}194{,}752=247{,}064{,}064$ 只差 0.1%。因为共享的 $E$ 在输出端被用了一次“乘法”，它的每个参数也贡献了 2 次运算。
:::

**注意力项什么时候追上权重项？** 令 $2LTd=2\cdot12Ld^2$，得 $T=12d$；按 PaLM 口径是 $T=6d$。GPT-2 small：$12d=9{,}216$、$6d=4{,}608$，都远大于它的上下文 1024，所以在 GPT-2 上注意力只占小头（Kaplan 口径 10.0%）。GPT-3 175B 的 $12d=147{,}456$，在 2048 的上下文下注意力项只有 $4.83\times10^9$，占“权重 + 注意力”的 $2048/(147{,}456+2048)=1.37\%$（若权重项改用表 D.1 的 $2N=349.2\times10^9$，是 1.36%，见练习 6）。这就是 Kaplan 等人说“当 $d_{model}>n_{ctx}/12$ 时，与上下文有关的计算只占小部分”的来历 [@kaplan2020]。可是当上下文长到十几万、上百万 token（第 14、18、19 课）时，比例就反过来了。

::: fig figures/l01-flops.svg | 图 1.15 GPT-2 small 每个 token 的前向运算量 | scroll
**看 (b) 两条曲线越过 50% 的位置：上下文超过 $6d$ 到 $12d$ 之后，注意力就成了运算的大头。** (a) $T=1024$ 时每个 token 的三项运算，虚线框是按 PaLM 口径多出来的一倍注意力。(b) 注意力项在“权重矩阵乘 + 注意力”中的占比随上下文长度的变化，实线 $T/(12d+T)$ 按 Kaplan 口径，虚线 $T/(6d+T)$ 按 PaLM 口径 [@kaplan2020; @palm2022]；GPT-2 的上下文 1024 处只占 10%。全部由生成脚本按 (1.32) 计算。
:::

## 两个预告：训练的 6N，解码的带宽

**训练约 $6N$。** 反向传播要为每个权重矩阵算两次矩阵乘（对输入的梯度、对权重的梯度），运算量约为前向的两倍，所以训练一个 token 约 $2N+4N=6N$ 次运算；训练 $D$ 个 token 就是 $6ND$。第 2 课会推导它，并用它来谈 scaling law。

**解码受带宽限制。** 生成一个新 token 时，运算量仍是约 $2N$，可是这 $2N$ 次运算要把 $N$ 个权重（外加整份 KV cache）从显存里读一遍，每读一个数只做两次运算。第 4 课会说明，这使得解码的速度由显存带宽而不是算力决定，这也是 DeepSeek 一再想办法少存、少读 KV cache 的根本原因：第 9、18、19 课压缩缓存本身，第 14 课的稀疏注意力则不减少缓存、只让每一步少读一些。

## 推导题

:::: quiz 练习 9 · 方差估算的推广
设 $\mathbf q,\mathbf k\in\R^{d_k}$ 的分量相互独立、均值为 0，$\Var(q_i)=\sigma_q^2$，$\Var(k_i)=\sigma_k^2$。（a）求 $\Var(\mathbf q^\top\mathbf k)$。（b）要让分数方差为 1，应除以多少？（c）若只知道 $d_k=128$ 且 $\sigma_q=\sigma_k=1$，不缩放时分数的标准差是多少？
::: answer 看答案
（a）沿用 [§4](#p4) 的推导：$\Var(q_ik_i)=\E[q_i^2]\E[k_i^2]-(\E[q_i]\E[k_i])^2=\sigma_q^2\sigma_k^2$；$d_k$ 项独立，方差相加：$\Var(\mathbf q^\top\mathbf k)=d_k\sigma_q^2\sigma_k^2$。

（b）除以 $\sigma_q\sigma_k\sqrt{d_k}$。标准做法只除以 $\sqrt{d_k}$，隐含了 $\sigma_q=\sigma_k=1$ 的假设；实际的 $\sigma_q,\sigma_k$ 由 LayerNorm 与投影矩阵的尺度决定，训练中会变。

（c）$\sqrt{128}\approx11.31$。
:::

:::: quiz 练习 10 · LayerNorm 的两条性质
忽略 $\epsilon$，取 $\boldsymbol\gamma=\mathbf 1$、$\boldsymbol\beta=\mathbf 0$，并设 $\mathbf x$ 的分量不全相等（$\sigma>0$），记 $\mathbf y=\LayerNorm(\mathbf x)$。证明：（a）$\mathbf y$ 的分量均值为 0，且 $\norm{\mathbf y}=\sqrt d$；（b）对任意 $a>0$ 与实数 $b$，$\LayerNorm(a\mathbf x+b\mathbf 1)=\LayerNorm(\mathbf x)$。用 $\mathbf x=(1,2,3,4)$ 核对。
::: answer 看答案
（a）$y_k=(x_k-\mu)/\sigma$。$\sum_ky_k=(\sum_kx_k-d\mu)/\sigma=0$。$\norm{\mathbf y}^2=\sum_k(x_k-\mu)^2/\sigma^2=d\sigma^2/\sigma^2=d$，因为 $\sigma^2$ 的定义就是 $\frac1d\sum_k(x_k-\mu)^2$。

（b）$\mathbf x'=a\mathbf x+b\mathbf 1$ 的均值 $\mu'=a\mu+b$，方差 $\sigma'^2=a^2\sigma^2$，$\sigma'=a\sigma$（$a>0$）。于是 $y'_k=(ax_k+b-a\mu-b)/(a\sigma)=(x_k-\mu)/\sigma=y_k$。

核对：$\mathbf x=(1,2,3,4)$，$\mu=2.5$，$\sigma^2=(2.25+0.25+0.25+2.25)/4=1.25$，$\mathbf y=(-1.3416,\ -0.4472,\ 0.4472,\ 1.3416)$，与 [§6](#p6) 里 $(2,4,6,8)$ 的结果完全相同，因为 $(2,4,6,8)=2\cdot(1,2,3,4)$。长度 $\sqrt{2\times1.8+2\times0.2}=\sqrt4=2=\sqrt d$。
:::

:::: quiz 练习 11 · 用参数量抓笔误

:::: quiz 练习 12 · 没有位置编码，注意力分不清先后
设第一层没有位置编码：$\mathbf h^{(0)}_j=E^\top\mathbf e_{x_j}$。看单头注意力在位置 $t$ 的输出 $\mathbf o_t=\sum_{j\le t}\alpha_{t,j}\mathbf v_j$。（a）设 $\pi$ 是 $\{1,\dots,t-1\}$ 的任意一个排列，把前缀换成 $x'_j=x_{\pi(j)}$（$j<t$），保留 $x'_t=x_t$。证明第一层的新输出 $\mathbf o'_t=\mathbf o_t$。（b）加上可学习的位置表 $P$ 之后，证明在哪一步失效？（c）用 [§2](#p2) 的 “Alice thanked Bob .” 说明这个结论的含义，并说明为什么它只对第一层成立。
::: answer 看答案
（a）第一层的查询、键、值都是逐位置算出来的（方程 (1.2)(1.3)），只取决于该位置的 token。所以对 $j<t$，$\mathbf k'_j=\mathbf k_{\pi(j)}$、$\mathbf v'_j=\mathbf v_{\pi(j)}$；而 $x'_t=x_t$ 给出 $\mathbf q'_t=\mathbf q_t$、$\mathbf k'_t=\mathbf k_t$、$\mathbf v'_t=\mathbf v_t$。记 $c=\sqrt{d_k}$，逐项比较：

- 分母：$Z'=\exp(\mathbf q_t^\top\mathbf k_t/c)+\sum_{s<t}\exp(\mathbf q_t^\top\mathbf k_{\pi(s)}/c)$。$\pi$ 只是把 $1,\dots,t-1$ 换了个次序，求和里还是原来那 $t-1$ 项，所以 $Z'=Z$。
- 权重：$\alpha'_{t,j}=\exp(\mathbf q_t^\top\mathbf k_{\pi(j)}/c)/Z=\alpha_{t,\pi(j)}$（$j<t$），$\alpha'_{t,t}=\alpha_{t,t}$。
- 输出：$\mathbf o'_t=\alpha_{t,t}\mathbf v_t+\sum_{j<t}\alpha_{t,\pi(j)}\mathbf v_{\pi(j)}=\alpha_{t,t}\mathbf v_t+\sum_{i<t}\alpha_{t,i}\mathbf v_i=\mathbf o_t$。中间一步令 $i=\pi(j)$：$j$ 走遍 $1,\dots,t-1$ 时，$i$ 也恰好把它们各走一遍。

（b）有了位置表，$\mathbf h^{(0)}_j=E^\top\mathbf e_{x_j}+P^\top\mathbf e_j$ 由 token 和位置号 $j$ 共同决定。排列之后，位置 $j$ 上的 token 换成了 $x_{\pi(j)}$，位置号却还是 $j$，所以 $\mathbf k'_j$ 一般不等于任何一个原来的 $\mathbf k_i$。第一步“$\mathbf k'_j=\mathbf k_{\pi(j)}$”不再成立，后面的换元也就无从谈起。

（c）两句话的最后一个 token 都是句号，前三个 token 互为排列（$\pi$ 对调位置 1 和 3）。由（a），没有位置编码时，句号在第一层的输出一模一样，模型分不出谁感谢谁。这个结论只对第一层成立：到了第二层，句号读取的是其他位置的第一层输出，而位置 2（thanked）在第一层看到的前缀从 “Alice thanked” 变成了 “Bob thanked”，它的输出变了，新的键值集合就不再是原来的一个排列。这正是 [§2](#p2) 所说“因果掩码能间接带来一点位置信息”的来源，只是这种信息很间接。
:::
