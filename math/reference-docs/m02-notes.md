# M02 补充核实（秩、低秩分解与 SVD）

M02 作者在写课时逐条核实过以下事实（2026-09-24）。它们不在共享的 `math-refs-doc.md` 里，或者是对它的复算与更正，

## 1. 新增来源：Axler《Linear Algebra Done Right》第 4 版

- 读取方式：作者网站 `https://linear.axler.net/LADR4e.pdf`（CC BY-NC 4.0 开放获取；PDF 首页印 “© 2024 Sheldon Axler”，
  页首日期 “16 August 2026”，印刷版由 Springer 出版）。用 pypdf 抽取全文后按结果编号逐条核对。
- 本课引用的结果编号与书中标题（页码为书页）：
  - 2.22 “length of linearly independent list ≤ length of spanning list”（p. 35）
  - 2.30 every spanning list contains a basis；2.32 every linearly independent list extends to a basis；
    2.34 basis length does not depend on basis；2.37 dimension of a subspace（dim U ≤ dim V）
  - 3.21 “fundamental theorem of linear maps”：dim V = dim null T + dim range T（p. 62）
  - 3.51 matrix multiplication as linear combinations of columns or rows
  - 3.52 定义 column rank / row rank；3.56 “column–row factorization”；3.57 “column rank equals row rank”；
    3.58 定义 rank = column rank（pp. 77–79）
  - 7.29 “real spectral theorem”（p. 245）
  - 7.64 properties of T*T（(d) dim range T = dim range T*T）；7.65 奇异值定义为 T*T 特征值的非负平方根
  - 7.70 “singular value decomposition”（p. 273），证明即“对 T*T 用谱定理、令 f_k = T e_k / s_k 并验证正交”；
    7.80 matrix version of SVD：A = B D C*（p. 277）
  - 7.82–7.86：‖Tv‖ ≤ s₁‖v‖，最大值取到，于是定义的范数等于最大奇异值（pp. 280–281）
  - 7.92 “best approximation by linear map whose range has dimension ≤ k”：min ‖T − S‖ = s_{k+1}，
    证明用“S e₁,…,S e_{k+1} 线性相关”（p. 284）。本课 §5 谱范数版本的逐行推导按此写成。
- 书中还有 3.133（列秩 = 行秩的另一证明）与 Frobenius 范数（p. 331 的习题），本课未引用。

## 2. NumPy `matrix_rank` 的默认阈值

本机 NumPy 1.26.4 的 docstring：秩 = 大于 `tol` 的奇异值个数；`tol` 缺省为 `S.max() * max(M, N) * eps`。
本课 §1 的数值：精确构造的 M = [[1,0,1],[0,1,2],[1,1,3]] 第三个奇异值算出来为 6.87e-17，阈值 2.74e-15，报告秩 2；
加 1e-6 量级噪声（`default_rng(0)`）后报告 3。
