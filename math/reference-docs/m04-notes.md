## 1. 交叉引用的论文事实（本课正文用到的）

- **Vaswani et al. 2017（arXiv:1706.03762）**【交叉引用 lesson-01-doc C2、E1、E2】：方差论证是 v2 起加入的 §3.2.1 脚注 4（PDF 编号；
  arXiv HTML 显示为脚注 1），假设 q、k 的分量是 “independent random variables with mean 0 and variance 1”，结论 “mean 0 and variance $d_k$”；
  v1 只有 “growing too large in magnitude” 的猜测。脚注只估计尺度，不证明缩放最优。→ 正文 §3 (M4.15) 与“这个推导说明了什么”框。
- **DeepSeek-V2（arXiv:2405.04434 v5）式 (18)**【交叉引用 lesson-09-doc §2.4】：注意力缩放为 $1/\sqrt{d_h+d_h^R}$，$d_h=128$、$d_h^R=64$，即 $1/\sqrt{192}\approx0.07217$。→ §3 例题、练习 5。
- **Leviathan et al. 2023（arXiv:2211.17192 v2）**【交叉引用 lesson-04-doc C59、C61、C63、C64、§2.8】：各种采样都可写成“调整后的分布”（§2.2）；
  接受规则 $\min(1,p/q)$、残差 $\mathrm{norm}(\max(0,p-q))$（§2.3）；式 (1) $\frac{1-\alpha^{\gamma+1}}{1-\alpha}$（截断几何变量，i.i.d. 接受率假设）；
  $\beta=\sum_x\min(p,q)$（Thm 3.5）；附录 A.1 的两行正确性证明。→ §2 尾和公式例题、§5 投机采样、练习 7。
- **DeepSeek-V3（arXiv:2412.19437 v2）§5.4.3**【交叉引用 lesson-04-doc C71】：MTP 预测第二个后续 token 的接受率 “between 85% and 90%”，解码 1.8 倍 TPS。→ §2 例题。
- **Holtzman et al. 2020（arXiv:1904.09751 v2）**【交叉引用 lesson-04-doc C53、C55–C58、§2.7】：温度式 (4)（原文 $t$，分母 $u_l'$ 为排版错误）；
  top-$p$ 最小集合式 (2)(3)；固定 $k$ 在平坦/尖锐分布上都不合适（§3.2）；$p$ 通常取 $[0.9,1)$（§5）；GPT-2 Large 上贪心解码重复率 73.66%（Table 1）。→ §4、§5、练习 2。
- **Fan et al. 2018（arXiv:1805.04833 v1）§5.4**【交叉引用 lesson-04-doc C54、E22】：“We randomly sample from the k=10 most likely candidates”。
  归属写法按 E22：它是常被引用的早期出处，不是标题级贡献。→ §5。
- **DeepSeekMath（arXiv:2402.03300 v3）**【交叉引用 lesson-08-doc C16–C20、C26、§2.2】：GRPO 目标式 (3) 含逐 token 比值 $\pi_\theta/\pi_{\theta_{old}}$ 与裁剪；
  结果监督优势 = 减组均值、除以组标准差；每个问题采 64 个输出；“The policy model only has a single update following each exploration stage.”（§4.2）；
  论文未说明 std 除以 $G$ 还是 $G-1$。→ §2 组内标准化例题、§6、§7、练习 3、练习 9。
  练习 3 的“只更新一次”读法沿用 lesson-08-doc 核查补记的限定（对整批样本只做一步优化器更新）。
- **TRL GRPOTrainer（commit c8ef2433）**【交叉引用 lesson-08-doc §2.3、卡片 trl-grpo】：`nanstd` 用贝塞尔修正（`count/(count-1)`），
  `advantages / (std_rewards + 1e-4)`；两种约定相差 $\sqrt{(G-1)/G}$（$G=4$：0.866，$G=64$：0.992）。→ §6 warn 框、练习 9。
- **PPO（arXiv:1707.06347 v2）**【交叉引用 lesson-03-doc C41】：概率比与裁剪，“say, ϵ = 0.2”。→ §7。
- **Schulman KL 博客（2020-03-07）**【交叉引用 math-refs-doc C21】：k3 $=(r-1)-\log r$ 无偏且非负。无偏依赖 $\E_q[r]=1$，本课把它与 (M4.28) 的 $\E_q[w]=1$ 对应起来（笔者的讲法，推导见 lesson-08-doc §2.4 (e)）。
- **DeepSeek-V3.2（arXiv:2512.02556 v1）**【交叉引用 lesson-08-doc 卡片 deepseekai2025v32、§2.4 (g)】：规模化 GRPO 时用 $\rho=\pi_\theta/\pi_{old}$ 修正 k3，并去掉优势的 std 归一化。→ §7。

## 2. 本课自己核实的事实

- **FP32 / FP64 的最小次正规数**：numpy 1.26.4 本机 `np.finfo(np.float32).smallest_subnormal` = 1e-45（即 $2^{-149}\approx1.40\times10^{-45}$），
  `np.finfo(np.float64).smallest_subnormal` = 5e-324（$2^{-1074}$）；与 math-refs-doc §3.1 表一致。逐次乘 0.5：FP32 在第 150 次变 0（$2^{-150}$ 恰为
  最小次正规数的一半，就近取偶舍入为 0），FP64 在第 1075 次变 0。→ §1 warn 框。
- **exp 上溢阈值**：`math.log(np.finfo(np.float64).max)` = 709.7827，FP32 = 88.7228。→ §4 warn 框。
- **正态分布的 68–95 规则**：`erf(1/√2)` = 0.6827，`1 − erf(2/√2)` = 0.0455（教科书结论，本机复算）。→ §3 前置框。

## 4. 笔者推导或示意（正文已标注）

- §7 “整段权重的对数是逐 token 对数比值之和，标准差按 √T 增长”的数值示意（每 token 0.05、T = 1000）假设各 token 独立，是笔者的示意计算，不是任何论文的测量。
